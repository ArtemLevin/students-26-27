# Навигатор преподавателя

Страница: `teacher/index.html`.

Это статический плиточный каталог персональных кабинетов учеников. Для просмотра на локальном компьютере откройте файл в браузере или запустите локальный статический сервер из корня репозитория.

Функции: поиск по имени/фамилии/предмету, фильтр по направлению и предмету, локальное избранное, светлая/тёмная тема, адаптивная сетка. Избранное и тема хранятся только в браузере.

## Добавление ученика

Когда появляется новый `students/<slug>/site/index.html`, добавьте одну плитку с относительной ссылкой `../students/<slug>/site/index.html` и уникальным атрибутом `data-slug`. Укажите направление, предмет и строку поиска. Для дополнительных предметов разместите вторую ссылку внутри той же плитки.

Проверка ссылок из корня репозитория:

```bash
node --test teacher/navigation.test.mjs
node --check teacher/app.js
```

Тест намеренно сигнализирует о новых страницах, не включённых в каталог.

## Важное ограничение публикации

Этот каталог **не разворачивается** существующим `deploy/student-static/build.mjs`. Производственный VPS использует случайные секретные URL учеников и возвращает 404 в корне сайта. Общий каталог со ссылками на эти URL раскрыл бы их всем, кто получит его адрес.

Для полноценного размещения каталога преподавателя на VPS потребуется отдельный аутентифицированный доступ (например, защищённый маршрут с авторизацией) и формирование ссылок из `STUDENT_URL_MAP` исключительно на сервере во время развёртывания. **Никогда не копируйте секретные URL или `STUDENT_URL_MAP` в Git.**

Локальные относительные ссылки настоящей версии работают при доступе к полной структуре репозитория или при отдельной публикации этой структуры в подходящем окружении.
