14. Структура учебного материала

Перед задачами разместить подробную теорию.

Теоретическая часть должна включать:

определения;

свойства;

правила;

смысл обозначений;

область применимости;

графическую или геометрическую интерпретацию;

короткие примеры из пособия;

связь с задачами;

важные ограничения;

критерии выбора метода.

Каждая задача оформляется по следующей структуре:

Что дано.

Что требуется найти или доказать.

Смысл условий.

Геометрическая, графическая или алгебраическая интерпретация.

Идея решения из 2–5 кратких пунктов.

Пошаговое решение.

Проверка по исходному условию.

Обоснование полноты решения.

Вывод.

Ответ.

Для каждого существенного действия пояснять:

что выполняется;

зачем выполняется;

почему действие допустимо;

какое правило используется;

что означает полученный результат;

как результат связан с условием;

как результат связан с визуальной моделью.

15. Пошаговый режим

Пошаговое решение должно поддерживать:

открытие этапов по одному;

сохранение уже открытых этапов;

выделение текущего шага;

кнопку «Предыдущий шаг»;

кнопку «Следующий шаг»;

кнопку «Показать всё решение»;

кнопку «Скрыть решение»;

кнопку «Вернуться к началу»;

автоматическую синхронизацию с визуализацией;

прокрутку к текущему шагу при необходимости.

При переключении шага визуализация должна:

подсвечивать связанные объекты;

обновлять подписи;

показывать используемые элементы;

скрывать преждевременные элементы;

обновлять краткое пояснение.

Состояние пошагового решения можно сохранять в localStorage.
