01 · Парабола

y = ax² + bx + c

Коэффициенты можно читать прямо с рисунка

Для квадратичной функции a ≠ 0. Направление ветвей сразу даёт знак a, пересечение с осью Oy — знак c, а положение вершины помогает определить знак b.

xв=−b2a ⇒ b=−2axв
Знак a
a > 0 — ветви вверх; a < 0 — ветви вниз.
Коэффициент c
c = f(0). Точка пересечения с Oy имеет координаты (0; c).
Знак b
Определите знак a и знак xв, затем используйте b = −2axв.
Частая ошибка: потерять внешний минус в формуле b = −2axв.

Пример чтения

a > 0, c < 0, xв < 0, значит b > 0.

Проверка знаков b

При a > 0: вершина справа от Oy даёт b < 0, вершина слева — b > 0. При xв = 0 получаем b = 0.

02 · Гипербола

y = k / x

Сначала ограничение, затем знак k

Для гиперболы ключевые признаки считываются быстро: ноль нельзя подставлять вместо x, знак k определяет четверти, а величина |k| меняет положение ветвей относительно осей.

y=kx , x≠0
k > 0
Ветви расположены в I и III четвертях.
k < 0
Ветви расположены во II и IV четвертях.
Асимптоты
x = 0 и y = 0. График к ним приближается, но не пересекает.
Величина |k|
При одном и том же ненулевом x: чем больше |k|, тем больше |y|.
Приведение к стандартному виду: 1/(2x) = 0,5/x, поэтому здесь k = 0,5.

Четверти

Построение

Берите значения x, симметричные относительно нуля: −4, −2, −1, 1, 2, 4. Для y = 2/x получаются значения −1/2, −1, −2, 2, 1, 1/2.

Сравнить k = 1, 2, 0,5 и −1 →

Частые ошибки: подставлять x = 0, соединять ветви через Oy, путать четверти и принимать коэффициент в 1/(2x) за k = 2.
03 · Модуль

y = |f(x)|

Всё, что было ниже Ox, отражается вверх

Правило относится к случаю, когда модуль наложен на всю правую часть. Верхняя часть исходного графика остаётся на месте, нижняя отражается симметрично относительно оси Ox.

f(x), если f(x)≥0 −f(x), если f(x)<0
Шаг 1
Постройте исходный график y = f(x).
Шаг 2
Найдите точки, где f(x) = 0.
Шаг 3
Участки ниже Ox отразите вверх; участки с y ≥ 0 оставьте без изменений.

Линейный пример

Для y = |2x − 1| излом находится там, где 2x − 1 = 0, то есть при x = 1/2.

То же правило для других графиков

|x² − x − 6|: корни исходной параболы −2 и 3; участок между ними отражается вверх.

|1/x|: сохраняется x ≠ 0; ветвь из III четверти отражается во II.

05 · Путь А

5 заданий

Тренировочный блок

Парабола y = ax² + bx + c имеет ветви вверх, пересекает Oy ниже Ox, а её вершина лежит слева от Oy. Определите знаки a, b, c.
Проверить ответ

a > 0, b > 0, c < 0.

Соотнесите y = 3/x, y = −2/x, y = 1/(4x) с описаниями: II и IV четверти; I и III четверти при |x| = 1 с |y| > 1; I и III четверти при |x| = 1 с |y| < 1.
Проверить ответ

3/x → второе описание; −2/x → первое; 1/(4x) → третье.

Для y = 2/x составьте таблицу при x ∈ {−4, −2, −1, 1, 2, 4}, постройте график и укажите асимптоты.
Проверить ответ

y: −1/2, −1, −2, 2, 1, 1/2. Асимптоты: x = 0 и y = 0.

Постройте y = |x − 2|. Укажите точку излома и часть прямой y = x − 2, которая отражается относительно Ox.
Проверить ответ

Точка излома (2; 0). Отражается участок, соответствующий x < 2.

Для y = |x² − 4x + 3| найдите корни подмодульного выражения, x вершины, промежуток отрицательности исходной параболы и участок отражения.
Проверить ответ

Корни 1 и 3; xв = 2; исходная парабола ниже Ox на (1; 3); этот участок отражается вверх.
