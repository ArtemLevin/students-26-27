01 · Группировка

Первый тип задач

Четыре слагаемых: два вынесения

Четыре слагаемых иногда удаётся сгруппировать попарно. В каждой паре выносим свой общий множитель; если возникла одинаковая скобка, выносим её ещё раз.

Исходное уравнение

x³ = x² − 7x + 7

Сначала приведите уравнение к нулю.

Перенос

x³ − x² + 7x − 7 = 0

При переносе каждое слагаемое меняет знак.

Группировка

(x³ − x²) + (7x − 7) = 0

Выбраны пары с общими множителями.

Первое вынесение

x²(x − 1) + 7(x − 1) = 0

Теперь в обеих частях суммы совпадает скобка (x − 1).

Второе вынесение

(x − 1)(x² + 7) = 0

Вынесите совпадающий множитель; примените правило нулевого произведения.

Ответ

x = 1

Ветка x² + 7 = 0 не даёт действительных корней, поскольку x² + 7 > 0.

Шаг 1 из 6
Разбор со знаком минус
x³ − 3x² − 8x + 24 = x²(x − 3) − 8(x − 3) = (x − 3)(x² − 8).

Второй множитель равен −8. Из уравнения x² = 8 получаем два корня ±2√2; третий корень x = 3.

Правило: количество слагаемых подсказывает приём группировки, но само по себе его успешность не гарантирует. Следите за знаком вынесенного множителя.
02 · Общий множитель

Слагаемое или целая скобка

Выносите всё, что действительно общее

Вынести x
x³ = 4x² + 5x → x(x² − 4x − 5) = x(x − 5)(x + 1) = 0.

Ответ: −1; 0; 5. Деление на x потеряло бы корень 0.

Вынести две скобки
(x − 4)(x − 5)(x − 3) = (x − 4)(x − 5)(x − 2).
После переноса: (x − 4)(x − 5)[(x − 3) − (x − 2)] = 0.

Последняя скобка равна −1. Ответ: 4; 5.

Квадрат трёхчлена
x(x² + 2x + 1) = 2(x + 1).
x(x + 1)² − 2(x + 1) = (x + 1)[x(x + 1) − 2] = 0.

Ответ: −2; −1; 1.

Единица остаётся: AB − B = B(A − 1). В частности, x(x − 2)² − (x − 2) = (x − 2)[x(x − 2) − 1].
03 · Формулы сокращённого умножения

Вместо раскрытия больших степеней

Разность квадратов позволяет сократить путь

a2−b2=(a−b)(a+b)

Для уравнения (2x − 3)² = (1 − 2x)² разность квадратов даёт (4x − 4)(−2) = 0, откуда x = 1.

a⁴ − b⁴=(a² − b²)(a² + b²)=(a − b)(a + b)(a² + b²)

Для действительных a и b равенство a⁴ = b⁴ выполняется ровно в двух случаях: a = b или a = −b (оба могут совпасть).

Пример
(2x − 1)⁴ = (3 − 2x)⁴. Первый случай: 2x − 1 = 3 − 2x, значит x = 1. Второй приводит к −1 = −3 и невозможен.
В задачах со степенью 4 применяйте структуру квадратов: раскрытие четвёртых степеней обычно создаёт лишние вычисления.
04 · Критические ошибки

Проверка равносильности

Четыре места, где легко потерять корень

01 · Минус перед скобкой.

−(x − 2) = −x + 2.

Знак каждого члена после раскрытия меняется.

02 · Исчезающая единица.

AB − B = B(A − 1).

После вынесения B второе слагаемое оставляет −1.

03 · Два квадратных корня.

x² = 9 → x = ±3.

При x² = −9 действительных корней нет.

04 · Деление на x.

x(x − 5)(x + 1) = 0.

Нельзя делить на x, не рассмотрев случай x = 0.

От группировки к четвёртой степени

Решайте над множеством действительных чисел. Для проверки раскройте строку с ответом после самостоятельной попытки.

01. x³ − x² + 9x − 9 = 0
Проверить ответ и ключевое преобразование

(x − 1)(x² + 9) = 0

Ответ: 1

02. x³ − 4x² − 9x + 36 = 0
Проверить ответ и ключевое преобразование

(x − 4)(x − 3)(x + 3) = 0

Ответ: −3; 3; 4

03. x³ = 3x² + 4x
Проверить ответ и ключевое преобразование

x(x − 4)(x + 1) = 0

Ответ: −1; 0; 4

04. (x − 2)(x − 5)(x + 1) = (x − 2)(x − 5)(x − 4)
Проверить ответ и ключевое преобразование

5(x − 2)(x − 5) = 0

Ответ: 2; 5

05. x(x² − 6x + 9) = 2(x − 3)
Проверить ответ и ключевое преобразование

(x − 3)(x² − 3x − 2) = 0

Ответ: 3; (3 − √17)/2; (3 + √17)/2

06. x(x² + 4x + 4) = 3(x + 2)
Проверить ответ и ключевое преобразование

(x + 2)(x + 3)(x − 1) = 0

Ответ: −3; −2; 1

07. (2x − 5)² = (3 − 2x)²
Проверить ответ и ключевое преобразование

(4x − 8)(−2) = 0

Ответ: 2

08. (3x + 1)² = (5 − 3x)²
Проверить ответ и ключевое преобразование

(6x − 4)·6 = 0

Ответ: 2/3

09. (2x − 3)⁴ = (x + 4)⁴
Проверить ответ и ключевое преобразование

2x − 3 = ±(x + 4)

Ответ: −1/3; 7

10. (3x + 2)⁴ = (5 − 3x)⁴
Проверить ответ и ключевое преобразование

3x + 2 = 5 − 3x; другая ветвь невозможна

Ответ: 1/2
