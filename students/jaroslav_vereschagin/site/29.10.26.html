01 / нормализация

Подготовьте неравенство к методу интервалов

Перенесите все слагаемые в левую часть, справа оставьте нуль. При переносе меняется знак слагаемого, знак самого неравенства сохраняется.

(x − 3)(2x + 3) < −7(x − 3)(2x + 3) + 7 < 02x² + 3x − 6x − 9 + 7 < 02x² − 3x − 2 < 0

Решаем соответствующее уравнение: 2x² − 3x − 2 = 0. Дискриминант равен 25, корни: −½ и 2. Парабола направлена вверх, выражение отрицательно между корнями.

Ответ: (−½; 2).

Не записывайте знак равенства между строками преобразования неравенства. Равенство используйте отдельно при нахождении корней.

02 / общий множитель

Повторяющуюся скобку вынесите целиком

В выражениях с одинаковым множителем сохраните структуру скобок: это позволяет увидеть два простых корня без лишнего раскрытия квадратов.

(x − 7)² < √11 · (x − 7)(x − 7)² − √11 · (x − 7) < 0(x − 7) · ((x − 7) − √11) < 0

Нули множителей: x = 7 и x = 7 + √11. Произведение отрицательно между ними.

Ответ: (7; 7 + √11).

03 / область допустимых значений

Знаменатель диктует исключения

При любом знаке неравенства дробь не существует там, где знаменатель равен нулю. Нули знаменателя всегда выколоты.

−10(x − 3)² − 5 ≥ 0(x − 3)² − 5 = 0 ⇒ x = 3 − √5 или x = 3 + √5

Числитель отрицателен, значит дробь будет положительной при отрицательном знаменателе. Обе границы исключаются, несмотря на нестрогий знак.

Ответ: (3 − √5; 3 + √5).

Порядок корней: 3 − √5 < 3 + √5. При выборе пробной точки учитывайте её положение относительно критических значений.

04 / общий знаменатель

Из двух дробей получите одну

Сначала запишите ограничения, затем приведите дроби к общему знаменателю. В числителе внимательно раскройте скобки.

1x − 1x − 4 > 0,   x ≠ 0, x ≠ 4(x − 4) − xx(x − 4) > 0−4x(x − 4) > 0

Числитель отрицателен, поэтому знаменатель должен быть отрицательным. Это происходит при 0 < x < 4.

Ответ: (0; 4).

Правило ВУПС

Вычитаемое, умножаемое, подставляемое заключайте в скобки, если внутри есть сумма или разность.

x − 1x − x − 3x − 2 = (x − 1)(x − 2) − x(x − 3)x(x − 2)−x(x − 3) = −x² + 3x

Минус перед вычитаемым действует на каждый член скобки. Потеря этого знака изменит числитель и итоговое множество решений.

05 / исследование знака

Пройдите по числовой оси

Размещайте критические точки по возрастанию, выбирайте пробное число внутри каждого промежутка и определяйте знак. Через корень нечётной кратности знак меняется, чётной — сохраняется.

  1. Нормализация

    Справа нуль, слева одно выражение.

  2. Критические точки

    Корни числителя и запрещённые значения знаменателя.

  3. Знаки

    Пробная точка и учёт кратностей.

  4. Ответ

    Нужные промежутки и верные скобки.

06 / замена переменной

Похожим знаменателям дайте одно имя

Если знаменатели отличаются лишь постоянным слагаемым, сделайте замену целого повторяющегося выражения: это позволит не раскрывать произведение квадратных многочленов.

1x² + 4x + 3 − 1x² + 4x + 4 > 12 t = x² + 4x + 3 = (x + 2)² − 1,   t ≥ −1 x² + 4x + 4 = t + 11t − 1t + 1 > 12,   t ≠ 0, t ≠ −1

Приводим к общему знаменателю, сохраняя скобки:

2(t + 1) − 2t − t(t + 1)2t(t + 1) > 0(1 − t)(t + 2)2t(t + 1) > 0

С учётом t ≥ −1 и ОДЗ получаем 0 < t < 1. Вернёмся к исходной переменной:

0 < (x + 2)² − 1 < 11 < (x + 2)² < 2−√2 < x + 2 < −1,   или   1 < x + 2 < √2

Ответ: (−2 − √2; −3) ∪ (−1; −2 + √2).

В задачах с заменой обязательны два действия: определить допустимые значения новой переменной и вернуться к исходной переменной в ответе.
