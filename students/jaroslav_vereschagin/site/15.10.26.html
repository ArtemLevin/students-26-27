01 / Системы уравнений

Найдите все подходящие пары

Пара (x; y) считается решением, когда оба исходных уравнения выполняются одновременно.

Одна система — два метода

Выбирайте способ, который быстрее приводит к уравнению с одной неизвестной. После решения обязательно вернитесь ко второй переменной.

01

Метод подстановки

Из первого уравнения удобно выразить y = 5 − x². Во втором уравнении ставим скобки: знак перед y меняет знаки обоих слагаемых.

{ x² + y = 5; 6x² − y = 2 }6x² − (5 − x²) = 2 → 7x² = 7x = −1 или 1; y = 4

Ответ: (−1; 4), (1; 4). Исследовать знаки квадратного выражения ↗

Ошибка: −(5 − x²) = −5 + x². При подстановке сохраняйте внешние скобки.

02

Метод сложения и вычитания

У исходной системы коэффициенты при y противоположны. Складываем левые и правые части соответственно.

(x² + y) + (6x² − y) = 5 + 27x² = 7 → x = ±1 → y = 4

Если коэффициенты различаются, домножьте уравнения на подходящие ненулевые числа, чтобы неизвестная исчезла.

{ x² + 2y = 5; 6x² − 3y = 2 }3 · (первое) + 2 · (второе)15x² = 19; x = ±√(19/15); y = 28/15

Иногда исчезают обе квадратные части: из системы 2x² + 3y² = 11 и 4x² + 6y² = 11x получаем x = 2, затем y = ±1.

02 / Выбор метода

Как решать быстрее

Подстановка

Удобно выразить одну переменную

  1. Выразите x или y.
  2. Подставьте целиком в другое уравнение.
  3. Решите уравнение с одной неизвестной.
  4. Досчитайте другую неизвестную для каждого корня.
Сложение / вычитание

Коэффициенты можно сократить

  1. Сравните коэффициенты.
  2. Если требуется, домножьте уравнения.
  3. Сложите или вычтите обе части.
  4. Найдите обе переменные и проверьте пары.

Если x² = a и a > 0, учитывайте оба значения: x = ±√a. Аналогично при y² = a.

03 / Метод интервалов

Корни → ось → знаки → ответ

Перед поиском корней перенесите всё влево. Справа должен остаться ноль: f(x) > 0, f(x) < 0, f(x) ≥ 0 или f(x) ≤ 0.

  1. ККорни

    Решите f(x) = 0.

  2. ООсь

    Отметьте корни по порядку.

  3. ЗЗнаки

    Проверьте знак на промежутке.

  4. АОтвет

    Выберите нужные интервалы.

04

Следите за граничными точками

Для x² − x − 2 ≤ 0 находим корни −1 и 2. Пробное значение x = 0 даёт −2, значит берём середину вместе с корнями.

x ∈ [−1; 2]

При > и < корни выколотые; при ≥ и ≤ нули многочлена включаются в решение. Бесконечность всегда записывают с круглой скобкой.

05

Четыре линейных множителя

(x − 1)(x + 1)(x − 2)(x + 5) ≥ 0Корни: −5, −1, 1, 2. При x = 0 произведение равно 10 > 0.

Все корни простые, поэтому знаки чередуются. Ответ: x ∈ (−∞; −5] ∪ [−1; 1] ∪ [2; +∞).

Чередование происходит при переходе через корень нечётной кратности; через корень чётной кратности знак не меняется.

  3. 03{ x² + 2y = 8; 2x² − 3y = 2 }

  4. 04{ 3x² + 2y² = 14; 6x² + 4y² = 14x }

    x ∈ [−3; 2].

  7. 07x² − 5x + 6 < 0
