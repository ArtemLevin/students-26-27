Парабола и рациональные функции

01 · Парабола

y = ax² + bx + c, a ≠ 0

Сначала найдите опорные точки

До построения определите направление ветвей, вершину, ось симметрии и пересечения с осями. Если точек мало, используйте симметрию относительно прямой x = xв.

xв = −b/(2a)
затем yв = f(xв)
Ветви
a > 0 — вверх; a < 0 — вниз.
Ось симметрии
x = xв.
Ox
Положите y = 0 и решите квадратное уравнение.
Oy
Положите x = 0: точка имеет координаты (0; c).
Опорный пример: для y = x² − x − 6 получаем V(1/2; −25/4), нули x = −2 и x = 3, точку (0; −6); ветви направлены вверх.
Контроль: пересечений с Ox может быть два, одно или ни одного. Корни нельзя «дорисовывать» по форме графика.
02 · Рациональная функция

Сначала ограничение

ОДЗ записывается до сокращения

Если функция содержит дробь, значения, обнуляющие исходный знаменатель, остаются запрещёнными и после сокращения одинаковых множителей.

y = ((x + 4)(x² + 3x + 2))/(x + 1)
ОДЗ
x ≠ −1.
Разложение
x² + 3x + 2 = (x + 1)(x + 2).
Сокращение
y = (x + 4)(x + 2) = x² + 6x + 8, при этом x ≠ −1.
Парабола
V(−3; −1), нули −4 и −2, пересечение с Oy: (0; 8).
Главный принцип: сокращение упрощает формулу, но исходное ОДЗ сохраняется.
03 · Выколотая точка

x = −1 запрещён

Координату «дырки» даёт упрощённая формула

Подставьте запрещённое значение x = −1 в параболу y = x² + 6x + 8. Получается y = 3, поэтому на графике выколота точка (−1; 3).

Упрощённая формула

y = x² + 6x + 8

Она описывает форму параболы.

Исходная функция

x ≠ −1

Точка (−1; 3) исключена, поэтому отмечается пустым кружком.

Типичная ошибка: после сокращения забыть исходный нуль знаменателя и поставить в запрещённой точке обычную сплошную точку.
04 · Алгоритм

Пять действий

От дроби к корректному графику

1 · ОДЗ
Выпишите ограничения исходного знаменателя.
2 · Множители
Разложите выражения на множители.
3 · Сокращение
Сократите общий множитель, сохранив исходное ОДЗ.
4 · График
Если получилась парабола, найдите вершину, ось симметрии и пересечения с осями.
5 · Дырка
Подставьте запрещённый x в упрощённую формулу и отметьте выколотую точку.
Разложение трёхчлена: если известны корни x₁ и x₂, то ax² + bx + c = a(x − x₁)(x − x₂). Для приведённого трёхчлена удобно искать два числа, произведение которых равно c, а сумма — b.
Знаки и квадрат: (−3)² = 9, −3² = −9, −(−3)² = −9. Скобки определяют, что именно возводится в квадрат.
05 · Внимательность

Перед записью ответа

Две короткие проверки

Произведение равно нулю

(5x + 2)(−x − 4) = 0 даёт x = −0,4 и x = −4. Если требуется больший корень, ответ −0,4.

Путь, скорость, время

t = S/v. Если ответ нужен в минутах, часы переводятся по формуле tмин = 60tч.

Финальная проверка: что именно спрашивают, в каких единицах и требуется ли выбрать один из нескольких корней.

07 · Путь А

10 заданий

Тренировочный блок

Для y = x² − 6x + 5 определите направление ветвей, вершину и ось симметрии.
Проверить ответ

Ветви вверх; V(3; −4); x = 3.

Для y = −2x² + 8x − 3 определите направление ветвей, вершину и точку пересечения с Oy.
Проверить ответ

Ветви вниз; V(2; 5); (0; −3).

Для y = x² + x − 6 найдите все точки пересечения с осями координат.
Проверить ответ

(−3; 0), (2; 0), (0; −6).

Постройте y = x² − 4x + 3 по ключевым точкам.
Проверить ответ

V(2; −1); ось x = 2; нули 1 и 3; (0; 3); ветви вверх.

Вычислите A = (−3)², B = −3², C = −(−3)² и объясните различие записи.
Проверить ответ

A = 9, B = −9, C = −9.

Упростите y = ((x − 1)(x² + x − 6))/(x + 3), выпишите ОДЗ и найдите выколотую точку.
Проверить ответ

x ≠ −3; y = (x − 1)(x − 2); выколотая точка (−3; 20).

Постройте y = ((x + 4)(x² + 3x + 2))/(x + 1). Укажите ОДЗ, вершину, пересечения с осями и выколотую точку.
Проверить ответ

x ≠ −1; y = x² + 6x + 8; V(−3; −1); (−4; 0), (−2; 0), (0; 8); дырка (−1; 3).

Постройте y = ((x − 5)(x² − 4))/(x − 2). Укажите ОДЗ, вершину, пересечения с осями и выколотую точку.
Проверить ответ

x ≠ 2; y = x² − 3x − 10; V(3/2; −49/4); (−2; 0), (5; 0), (0; −10); дырка (2; −12).

Постройте y = ((x + 3)(x² + 5x + 4))/(x + 3) и объясните, почему после сокращения остаётся выколотая точка.
Проверить ответ

x ≠ −3; y = x² + 5x + 4; V(−5/2; −9/4); дырка (−3; −2). Запрет относится к исходной дроби.

Постройте y = ((x + 1)(x² − 1))/(x − 1) и определите число общих точек с прямой y = 4.
Проверить ответ

x ≠ 1; y = (x + 1)²; дырка (1; 4). С прямой y = 4 остаётся одна общая точка: (−3; 4).
