01 / Метод

Повторяющаяся часть — ключ к решению

Когда одно выражение входит в уравнение несколько раз, замените его коротким обозначением t.

Перед заменой проверьте, можно ли просто сократить одинаковые слагаемые. При сокращении ОДЗ исходного уравнения сохраняется.
u(x) → t → x

Назовите повторяющуюся конструкцию t = u(x). Запишите её ограничения. Решите уравнение для t, отберите допустимые значения, решите u(x) = t, проверьте каждый найденный x.

t = (x + 2)² ≥ 0

Значение t отрицательным быть не может; невозможный корень нужно исключить.

t = 1/(x − 2) ≠ 0

Дробь может быть отрицательной. Исключаются x = 2 и t = 0.

02 / Примеры

Семь структур — семь способов увидеть главное

Материал исходного чек-листа с важнейшими переходами и проверкой допустимости.

При сумме неотрицательных выражений ноль получается только в том случае, когда все слагаемые одновременно равны нулю.
01

Замена квадрата

(x + 2)⁴ − 4(x + 2)² − 5 = 0
Замена / ограничение
t = (x + 2)² ≥ 0
После преобразования
t² − 4t − 5 = 0
Отбор
t = 5; t = −1 исключается

Ответ −2 − √5; −2 + √5

02

Замена дроби целиком

1/(x − 2)² − 1/(x − 2) − 6 = 0
Замена / ограничение
t = 1/(x − 2); x ≠ 2, t ≠ 0
После преобразования
t² − t − 6 = 0
Отбор
t = 3 или t = −2

Ответ 7/3; 3/2

03

Сокращение радикалов

x² − 2x + √(3 − x) = 8 + √(3 − x)
Замена / ограничение
x ≤ 3, радикал определён
После преобразования
x² − 2x − 8 = 0
Отбор
x = 4 нарушает ОДЗ

Ответ −2

04

Сумма квадратов

(x² − 25)² + (x² + 3x − 10)² = 0
Замена / ограничение
Оба квадрата ≥ 0
После преобразования
x² − 25 = 0 И x² + 3x − 10 = 0
Отбор
Нужен общий корень

Ответ −5

05

Разность квадратов

x⁴ = (4x − 5)²
Замена / ограничение
A = x²; B = 4x − 5
После преобразования
(x² − 4x + 5)(x² + 4x − 5) = 0
Отбор
Первая скобка действительных корней не даёт

Ответ −5; 1

06

Подготовка скрытой замены

(x² − 5x + 7)² − (x − 2)(x − 3) = 3
Замена / ограничение
t = x² − 5x + 7 ≥ 3/4
После преобразования
t² − (t − 1) = 3
Отбор
t = 2; t = −1 исключается

Ответ (5 − √5)/2; (5 + √5)/2

07

Связанные знаменатели

1/[x(x + 3)] − 1/(x² + 3x + 2) = 1/60
Замена / ограничение
t = x² + 3x ≥ −9/4; t ≠ 0, −2
После преобразования
1/t − 1/(t + 2) = 1/60
Отбор
t = 10; t = −12 невозможно

Ответ −5; 2
