Исследовать переход к модулю

Свойства степеней

Произведение
am·an=am+n
Частное
aman=am−n
при a ≠ 0
Степень степени
(am)n=amn
Степень произведения
(ab)n=anbn
Дополнительно: a⁰ = 1 и a⁻ⁿ = 1/aⁿ при a ≠ 0.

Пример: дробь под корнем

Что дано: √(36a²¹/a¹⁵), a = 2.

Смысл условия: сначала можно сократить степени с основанием a, затем извлечь корень.

Идея решения: ОДЗ → вычесть показатели → выделить квадрат → подставить 2.
Шаг 1. ОДЗ: a ≠ 0.
Шаг 2. 36a²¹/a¹⁵ = 36a⁶.
Шаг 3. √(36a⁶) = 6|a³|.
Шаг 4. При a = 2: 6 · 8 = 48.
Проверка: a = 2 удовлетворяет ОДЗ; итог положителен, что согласуется с квадратным корнем.

Отрицательные показатели

a⁻¹²/a⁻¹⁷ = a⁻¹²⁻⁽⁻¹⁷⁾ = a⁵

При a = 2 получаем 32. Здесь особенно важно не потерять второй минус.

Корень: условия и главный модуль

U2=|U|

Например, √(x⁶) = |x³|. Запись без модуля допустима только при дополнительном знании о знаке выражения.

Произведение

√(uv) = √u · √v при u ≥ 0 и v ≥ 0.

Частное

√(u/v) = √u / √v при u ≥ 0 и v > 0.

Ловушка: √(x + y) ≠ √x + √y в общем случае.

Пример: объединить корни, чтобы сократить степени

Что дано: (√(25a⁹)·√(16b⁸))/√(a⁵b⁸).

Смысл условий: a > 0 и b ≠ 0. После сокращения b исчезнет из формулы, но ограничение b ≠ 0 останется.

Шаг 1. Объединяем допустимые радикалы в один корень.
Шаг 2. Получаем √(400a⁴).
Шаг 3. Это 20a², поскольку a² ≥ 0.
Шаг 4. При a = 4: 20 · 16 = 320.
Проверка полноты: сокращение не отменяет исходные ограничения a > 0 и b ≠ 0.

Формулы работают в обе стороны

Квадрат разности
(a − b)² = a² − 2ab + b²
Квадрат суммы
(a + b)² = a² + 2ab + b²

При сворачивании сначала проверьте крайние квадраты, затем средний член ±2ab.

x² − 4x + 4→(x − 2)²
9x² − 6x + 1→(3x − 1)²
16k² − 8k + 1→(4k − 1)²

Связка: полный квадрат → корень → модуль

√(x² − 4x + 4)→√((x − 2)²)→|x − 2|

Распознанный полный квадрат позволяет убрать радикал корректно, сохранив модуль.

Проверить равенство на модели

Модуль определяется знаком выражения

Модуль x — расстояние от x до нуля, поэтому |x| ≥ 0.

|U| = U при U ≥ 0; |U| = −U при U < 0.

Пример: раскрыть |5 − 2x| Главный вопрос: какой знак имеет 5 − 2x? Граница получается из равенства 5 − 2x = 0.

Что дано: |5 − 2x|. Требуется раскрыть модуль по определению.

Шаг 1. Если 5 − 2x ≥ 0, модуль раскрывается как 5 − 2x.
Шаг 2. Из 5 − 2x ≥ 0 следует x ≤ 5/2.
Шаг 3. Если 5 − 2x < 0, появляется внешний минус: −(5 − 2x) = 2x − 5.
Шаг 4. Второй случай соответствует x > 5/2.
|5 − 2x| = 5 − 2x при x ≤ 5/2; 2x − 5 при x > 5/2.
Исследовать знак 5 − 2x

Комплексный пример

√(a² + 8ab + 16b²)→√((a + 4b)²)→|a + 4b|

При a = 3,3 и b = 1,7: |3,3 + 4 · 1,7| = |10,1| = 10,1.

Типичные ошибки

Потеря модуля

√(x²) записывают как x. Самопроверка: результат квадратного корня не может быть отрицательным.

Ошибка в показателях

При a⁻¹²/a⁻¹⁷ забывают скобки: показатель равен −12 − (−17).

Корень распределяют по сумме

Свойство произведения ошибочно переносят на √(x + y).

Теряют ОДЗ

Переменная исчезла после сокращения, а исходное ограничение на неё продолжает действовать.
