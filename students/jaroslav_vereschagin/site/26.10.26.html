01 / Конструкция

Знаки определяются по промежуткам

Для дроби F(x) = P(x) / Q(x) сначала найдите нули числителя и знаменателя. Они делят числовую ось на области, внутри которых знак не меняется.

P(x)Q(x)   ⋚ 0,   Q(x) ≠ 0

    Слева выражение, справа нуль.

  2. 02 / КорниНайдите границы

    Решите P(x)=0 и Q(x)=0.

  3. 03 / ЗнакиПроверьте промежутки

    Подставьте пробное число и учтите кратность.

  4. 04 / ОтветЗапишите интервалы

    Выберите знак и проверьте скобки.

Важно: уравнение для нахождения граничных точек записывается со знаком равенства. Для пробной подстановки выбирайте точку внутри проверяемого интервала.

03 / Переход через точку

Двойной корень сохраняет знак

У простого корня знак меняется, у корня чётной кратности — сохраняется. При этом точка всё равно может быть нулём выражения либо запрещённым значением.

(x − 1)² = (x − 1)(x − 1)

Корень 1 повторяется дважды. Для x² − 9 корни −3 и 3 различны, каждый простой.

Постоянный множитель −9 может перевернуть все знаки, однако точку −9 на ось добавлять нельзя.

04 / Разбор

Два примера, которые стоит запомнить

Кратный корень при строгом знаке

(x − 1)²(x + 2)x − 3   < 0

Критические точки: −2, 1, 3. У корня 1 кратность 2 — знак на соседних промежутках одинаков. Точка 3 запрещена знаменателем, а −2 и 1 исключены из-за строгого неравенства.

Ответ: (−2; 1) ∪ (1; 3)

Проверить знаки на оси →

Сокращение не возвращает запрещённую точку

(x − 1)²(x + 2)(x − 1)(x − 4)   ≥ 0

Сначала фиксируем ОДЗ: x ≠ 1 и x ≠ 4. После сокращения остаётся дробь (x − 1)(x + 2) / (x − 4), но единица всё ещё запрещена.

Ответ: [−2; 1) ∪ (4; +∞)

05 / Выбор оси

При замене t = x² учитываем t ≥ 0

Квадрат действительного числа всегда неотрицателен. Когда выполняется замена t = x², исследуем знаки по оси t и возвращаемся к x только после нахождения допустимых промежутков.

(x² + 2)(x² − 4)x² + 1   > 0
  1. Обозначьте t = x², t ≥ 0.
  2. Получите (t + 2)(t − 4) / (t + 1) > 0.
  3. При t ≥ 0 множители t + 2 и t + 1 положительны; значит, t > 4.
  4. Вернитесь к x: x² > 4, поэтому x < −2 или x > 2.

Ответ: (−∞; −2) ∪ (2; +∞)

06 / Самопроверка

Пять вещей перед ответом

  • Отмечены только действительные нули числителя и знаменателя.
  • У корней чётной кратности знак не изменён.
  • Все нули знаменателя исключены, даже после сокращения.
  • Квадрат скобки раскрыт верно: (x − 1)² = x² − 2x + 1.
  • Для замены t = x² учтено t ≥ 0; в ответе снова используется x.
