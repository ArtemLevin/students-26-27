01 · Общая основа

Сначала степень

Составные числа, дроби и корни приводим к удобным степеням. Это помогает увидеть одинаковые основания.

01Составное число
8 = 23  ·  16 = 24  ·  125 = 53
02Дробь
1/2 = 2−1
03Корень
⁵√16 = 24/5
04Правила
au · av = au+v;   au/av = au−v
05Степень степени
(au)v = auv;   a−u = 1/au

Формулы записаны для a > 0; для остальных оснований учитывайте область определения.

02 · Неизвестное в показателе

Одинаковое основание

Для a > 0 и a ≠ 1 справедливо: если af(x) = ag(x), то f(x) = g(x).

2x = 1/⁵√8  →  2x = 2−3/5  →  x = −3/5
  1. Определите, где находится неизвестное.
  2. Приведите обе части к одному основанию.
  3. Объедините степени с одинаковым основанием.
  4. Приравняйте показатели и проверьте ответ.

Опорный разбор: лишний множитель перед степенью

8 · 2x = 1/⁵√16

  1. 23 · 2x = 2−4/5

  2. 2x+3 = 2−4/5

  3. x + 3 = −4/5;   x = −19/5.

03 · Неизвестное в основании

Как получить x1

Когда допустимо, возведите обе части в степень, обратную исходному показателю. Проверяйте знаки и область определения.

Нечётная степень корня

x3/5 = 125  →  x = 1255/3 = 3125

Отрицательный показатель

x−3/5 = 8  →  x = 8−5/3 = 1/32
Проверяйте оба корня. При отрицательном x преобразование (x4/3)3/4 даёт |x|, поэтому непосредственная замена на x теряет решение.

  1. x4/3 = 16  ↔  (∛x)4 = 16.

  2. ∛x = ±2.

  3. x = −8 или x = 8. Оба значения дают 16.

Чётный знаменатель показателя

Для несократимого m/n требуется x ≥ 0; при отрицательной степени дополнительно x ≠ 0.

Нечётный знаменатель

Отрицательные x допустимы. При чётном числителе могут существовать два противоположных корня.

Ещё один пример с двумя корнями

x−2 = 4  ↔  x2 = 1/4  →  x = ±1/2

04 · Задача прикладного характера

От условия к длине

Формула задаёт зависимость силы натяжения от длины. Условие «не более» сохраняем как неравенство.

T = ρgL3 − mg

T — сила натяжения (Н), ρ — плотность (кг/м³), g — ускорение (м/с²), m — масса (кг), L — длина (м), L ≥ 0.

  1. Подставляем T = 1000, ρ = 1000, g = 10, m = 25.

  2. 1000 = 10000L3 − 250.

  3. L3 = 1250/10000 = 1/8.

  4. L = 0,5 м.

Когда сказано «не больше». Если T ≤ 1000, то 10000L3 − 250 ≤ 1000, откуда 0 ≤ L ≤ 0,5. Наибольшая длина равна 0,5 м. Предельное значение достигается при равенстве.
