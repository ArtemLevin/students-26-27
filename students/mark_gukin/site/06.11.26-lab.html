Исследуйте два коэффициента

Меняйте коэффициенты a и b, наблюдайте, как перестраивается график и как изменяются две опорные точки. Убедитесь, что они позволяют восстановить оба параметра.

02

Параметры модели

Изменение a растягивает или отражает кривую; b перемещает её вверх или вниз. Для тангенса учитываются разрывы у асимптот.

Текущий графикОпорные точкиИсходное состояние (при сравнении)
Формулаy = 2 cos x + 1
Первая точка A(0; 3)
Вторая точка B(π; −1)

Что показывают точки?

При x = 0 значение косинуса равно 1, а при x = π оно равно −1. Получаются уравнения a + b = y(A) и −a + b = y(B).

a + b = 3; −a + b = −1 ⇒ a = 2, b = 1.

Как использовать на занятии

Выберите функцию, измените сначала a, затем b. Следите за ординатами A и B и проверяйте, что система уравнений возвращает выбранные коэффициенты. Для синуса точки 0 и π дали бы одно и то же уравнение, поэтому используется π/2; для тангенса используются 0 и π/4.
