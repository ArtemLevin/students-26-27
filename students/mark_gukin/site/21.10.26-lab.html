Что следует из двух точек?

Система из двух уравнений определяет два неизвестных параметра. Для каждого примера восстановленная формула уже известна из пособия.

Вертикальный сдвиг

По A(1;−3) находим b = −3; по B(4;−1) получаем a² = 4 и a = 2.

Проверочная точка: f(32) = 2.

Сдвиг внутри аргумента

По A(−4;0) находим b = 5; по B(−1;2) получаем a² = 4 и a = 2.

Проверочная точка: f(11) = 4.
