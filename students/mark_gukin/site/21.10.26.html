01 / Определение

«Метод циклопа»

Мнемонический приём из занятия: аргумент логарифма приравниваем основанию, возведённому в степень, указанную справа.

Главный переходlogab=c⟺b=ac\\log_a b=c\\iff b=a^c
Три ограничения. Основание a > 0, a ≠ 1, аргумент b > 0.
Пример

log2(80/(t − 20)) = 3 → 80/(t − 20) = 8 → t = 30.
ОДЗ: t > 20; найденное значение допустимо.

02 / Вычисления

Подготовка чисел

Степенная запись десятичных дробей сокращает вычисления с произведениями.

Записи из занятия0,7 = 7 · 10−1  ·  0,4 = 4 · 10−1  ·  4200 = 42 · 102

Искомое значение t в прикладной формуле определим после сокращения коэффициента.

Исходное уравнение84 = 0,7 · 4200 · 0,442 · log2100 − 20t − 20

03 / Инструменты

Небольшой набор свойств

Эти равенства используются в вычислениях, при восстановлении функций и решении уравнений.

01Специальные значения
loga 1 = 0;
loga a = 1
02Степень аргумента
loga(un) = n · loga u
03Степень основания
logap u = (1/p) · loga u, p ≠ 0
04Сумма
loga u + loga v = loga(uv)

Аргументы u, v в формулах положительны, основания допустимы. Например, log√5 25 = 4 и log1/√3 27 = −6.

04 / Функции

Две точки определяют параметры

Удобнее выбирать точки с небольшими целыми координатами; x = 1 или y = 0 часто упрощают систему.

Сдвиг по вертикали

f(x)=b+logaxf(x)=b+\\log_a x

Точки A(1;−3), B(4;−1).

  1. −3 = b + loga 1, поэтому b = −3.
  2. −1 = −3 + loga 4, поэтому a² = 4.
  3. a = 2 (основание положительно).
f(x) = −3 + log2 x; f(32) = 2. ОДЗ: x > 0.

Сдвиг внутри аргумента

f(x)=loga(x+b)f(x)=\\log_a(x+b)

Точки A(−4;0), B(−1;2).

  1. 0 = loga(b − 4), поэтому b − 4 = 1.
  2. b = 5; из 2 = loga 4 следует a² = 4.
  3. a = 2 (основание положительно).
f(x) = log2(x + 5); f(11) = 4. ОДЗ: x > −5.

05 / Решение

Логарифмическое уравнение

Сначала проверяем допустимость каждого аргумента, затем выполняем равносильные преобразования.

logaU(x)=c⟺U(x)=ac\\log_a U(x)=c\\iff U(x)=a^c
Дробное основание
log1/7(7 − x) = −2

7 − x = (7−1)−2 = 49 → x = −42.

Проверка: 7 − (−42) = 49 > 0.

Число рядом с логарифмом
log5(7 − x) = log5(3 − x) + 1

ОДЗ: x < 3. Представим 1 = log5 5 и свернём сумму:

log5(7 − x) = log5(5(3 − x))

7 − x = 5(3 − x) → 4x = 8 → x = 2.

Проверка обоих аргументов: 7 − 2 = 5 > 0; 3 − 2 = 1 > 0.

06 / Алгоритм

ОДЗ → преобразование → отбор

Последовательность соответствует блок-схеме на отдельной странице PDF.

  1. Для каждого логарифма запишите условия a > 0, a ≠ 1 и положительности аргумента.
  2. При необходимости представьте число как логарифм того же основания: 1 = log5 5.
  3. Сверните суммы логарифмов; при одинаковых основаниях приравняйте аргументы либо перейдите от loga U = c к U = ac.
  4. Решите полученное алгебраическое уравнение.
  5. Проверьте каждого кандидата по исходному ОДЗ и равенству; отбросьте недопустимые значения.
Типичная ошибка: полученный алгебраический кандидат считают корнем без проверки аргументов логарифмов.
