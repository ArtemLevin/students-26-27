01 / Определение

«Метод циклопа»

Мнемонический приём из занятия: аргумент логарифма приравниваем основанию, возведённому в степень, указанную справа.

Главный переходlogab=c⟺b=ac\log_a b=c\iff b=a^c
Три ограничения. Основание a>0,a≠1a > 0, a \ne 1, аргумент b>0b > 0.
Пример

log2(80/(t−20))=3→80/(t−20)=8→t=30.\log _{2}(80/(t − 20)) = 3 \to 80/(t − 20) = 8 \to t = 30.ОДЗ: t&gtt &gt 20; найденное значение допустимо.

03 / Инструменты

Небольшой набор свойств

Эти равенства используются в вычислениях, при восстановлении функций и решении уравнений.

01Специальные значения
loga1=0;logaa=1\log _{a} 1 = 0;;\quad \log _{a} a = 1
02Степень аргумента
loga(un)=n·logau\log _{a}(u^{n}) = n \cdot \log _{a} u
03Степень основания
logapu=(1/p)·logau,p≠0\log _{a^{p}} u = (1/p) \cdot \log _{a} u, p \ne 0
04Сумма
logau+logav=loga(uv)\log _{a} u + \log _{a} v = \log _{a}(uv)

Аргументы u,vu, v в формулах положительны, основания допустимы. Например, log525=4\log _{\sqrt{5}} 25 = 4 и log1/327=−6\log _{1/\sqrt{3}} 27 = −6.

05 / Решение

Логарифмическое уравнение

Сначала проверяем допустимость каждого аргумента, затем выполняем равносильные преобразования.

logaU(x)=c⟺U(x)=ac\log_a U(x)=c\iff U(x)=a^c
Дробное основание
log17(7−x)=−2\log _{1/7}(7 − x) = −2

7−x=(7−1)−2=49→x=−42.7 − x = (7^{−1})^{−2} = 49 \to x = −42.

Проверка: 7−(−42)=49>07 − (−42) = 49 > 0.

Число рядом с логарифмом
log5(7−x)=log5(3−x)+1\log _{5}(7 − x) = \log _{5}(3 − x) + 1

ОДЗ: x<3x < 3. Представим 1=log551 = \log _{5} 5 и свернём сумму:

log5(7−x)=log5(5(3−x))\log _{5}(7 − x) = \log _{5}(5(3 − x))

7−x=5(3−x)→4x=8→x=2.7 − x = 5(3 − x) \to 4x = 8 \to x = 2.

Проверка обоих аргументов: 7−2=5>07 − 2 = 5 > 0; 3−2=1>03 − 2 = 1 > 0.

06 / Алгоритм

ОДЗ → преобразование → отбор

Последовательность соответствует блок-схеме на отдельной странице PDF.

  1. Для каждого логарифма запишите условия a>0,a≠1a > 0, a \ne 1 и положительности аргумента.
  2. При необходимости представьте число как логарифм того же основания: 1=log551 = \log _{5} 5.
  3. Сверните суммы логарифмов; при одинаковых основаниях приравняйте аргументы либо перейдите от logaU=c\log _{a} U = c к U=acU = a^{c}.
  4. Решите полученное алгебраическое уравнение.
  5. Проверьте каждого кандидата по исходному ОДЗ и равенству; отбросьте недопустимые значения.
Типичная ошибка: полученный алгебраический кандидат считают корнем без проверки аргументов логарифмов.
