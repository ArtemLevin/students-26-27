01 / Определение

Угол задаёт точку

Начало отсчёта — (1; 0). Поворот против часовой стрелки положителен; по часовой — отрицателен.

На окружности радиуса 1 точке P соответствуют координаты x = cos α и y = sin α. Эти две координаты связаны уравнением x² + y² = 1.

α → P(cos α; sin α)

При α = 60° получаем P(1/2; √3/2). После полного оборота 360° = 2π снова приходим в ту же точку.

Углы −90° и 270° заканчиваются в (0; −1).

02 / Единицы

От градусов к радианам

180° соответствует π радиан. На экзамене записи через π встречаются регулярно.

αрад = αград · π / 180
Градусы0°30°45°60°90°
Радианы0π/6π/4π/3π/2

При записи одного решения используйте одну единицу измерения. Например, 270° = 3π/2.

Углы вида mπ. Для целого m: sin(mπ) = 0; cos(mπ) = 1 при чётном m и −1 при нечётном m. Например, sin(101π) = 0, cos(101π) = −1, cos(−202π) = 1.
04 / Множества решений

Найдите все подходящие углы

sin α = c означает поиск точек с y = c, cos α = c — точек с x = c. Для |c| > 1 решений нет.

УравнениеВсе решения, n ∈ ℤ
sin α = 1α = π/2 + 2πn

cos α = 1α = 2πn
cos α = −1α = π + 2πn

Две осевые точки. Для sin α = 0 допустимы 0 и π с периодом 2π. Их объединяет α = πn. Для cos α = 0 аналогично α = π/2 + πn.

05 / Свойство координат

Основное тригонометрическое тождество

Поскольку x² + y² = 1, для всех действительных α выполняется равенство.

sin² α + cos² α = 1
A

Общий множитель.
5sin² α + 5cos² α = 5

B

Разные коэффициенты.
5sin² α + 7cos² α = 5 + 2cos² α

C

Обратная замена единицы.
8 = 8sin²50° + 8cos²50°

Проверяйте квадраты, знак «+» и одинаковый угол в двух слагаемых.

06 / Формулы сложения

Сумма и разность углов

Формулы позволяют вычислять точные значения для углов, которых нет в таблице.

01

sin(α ± β) = sin α cos β ± cos α sin β

02

cos(α ± β) = cos α cos β ∓ sin α sin β

Синус 75°

sin(30° + 45°) = (√2 + √6)/4

Вторая часть суммы — sin45° · cos30°.

Косинус 135°

cos(90° + 45°) = −√2/2

В формуле косинуса знак между произведениями противоположен знаку между углами.
