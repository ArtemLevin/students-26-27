01 · Инструментарий

Степени: правила преобразований

Для ненулевого основания работаем с целыми показателями, внимательно учитываем деление и отрицательные степени.

01Произведение

am · an = am+n

02Частное

am / an = am−n

03Степень степени

(am)n = amn

04Отрицательная степень

a−n = 1 / an, a ≠ 0

Разобранный пример

1010 / (26 · 58) = 24 · 52 = 400

Используем запись 10n = 2n · 5n — большие числа считать не приходится.

02 · Прикладная модель

Давление и объём

В формуле pVa = const показатель a находится сравнением двух состояний.

p1V1a = p2V2a при положительных p и V

Объём уменьшился в 2 раза, а давление увеличилось в 4 раза. Подставляем V1 = 2V2 и p2 = 4p1.

2a = 4 = 22 → a = 2

Сокращаем только ненулевые множители. В этой модели давление и объём положительны.

03 · Прикладная модель

Температура звезды

Из мощности излучения выражаем абсолютную температуру: сначала четвёртую степень, затем положительный корень.

P = σST4 → T4 = P / (σS)

Дано: σ = 5,7 · 10−8, S = 1020/228, P = 1,5625 · 1025.

После подстановки:

T4 = 6,25 · 1014 = (5 · 103)4
Результат
T = 5000 К

Температура положительна, поэтому выбираем положительный корень четвёртой степени.

04 · Функция

График показательной функции

Исследуем две функции, разобранные в чек-листе. Переключайте случаи и сопоставляйте форму графика с основанием.

f(x) = ax + b,   a > 0,   a ≠ 1;   горизонтальная асимптота y = b
↑Если a > 1

Функция возрастает.

↓Если 0 < a < 1

Функция убывает.

↕Сдвиг b

При x = 0: f(0) = 1 + b. Следовательно, b = f(0) − 1.

Пунктир — горизонтальная асимптота. Точки A и B — узловые точки из разобранных примеров.

Текущий случай

Возрастающая функция

Основание a = 2, сдвиг b = −3. График проходит через A(0; −2), B(1; −1).

f(x) = 2x − 3

f(6) = 64 − 3 = 61.

Обе отмеченные точки можно подставить в формулу и проверить, что равенства выполняются.

05 · Метод

Восстановление функции по двум точкам

Точка с x = 0 сразу даёт сдвиг b. Вторая точка определяет основание a.

  1. Запишите f(x) = ax + b.
  2. Найдите точки A(0; y0) и B(k; y1), где k ≠ 0.
  3. По первой точке: b = y0 − 1.
  4. По второй точке: ak = y1 − b. Найдите a.
  5. Проверьте обе точки и выполните требуемое вычисление.

График возрастает

A(0; −2), B(1; −1)

b = −3, a = 2 → f(x) = 2x − 3

f(6) = 26 − 3 = 61.

График убывает

A(0; −3), B(−2; 0)

b = −4, a−2 = 4 → a = 1/2

f(x) = 2−x − 4. Если f(x) = 12, то x = −4.

10 задач из чек-листа. Отмечайте выполненные упражнения; прогресс сохраняется на этом устройстве. Ответы раскрывайте после решения.

    Проверить ответ

  3. Вычислите: (2−1 / 22)−2.

    Проверить ответ

    64.

  4. В процессе pVa = const объём уменьшился в 2 раза, а давление возросло в 8 раз. Найдите a.

  5. В процессе pVa = const объём увеличился в 4 раза, а давление уменьшилось в 16 раз. Найдите a.

    Проверить ответ

    Проверить ответ

    a = 4, b = −3, f(2) = 13.

  7. f(x) = ax + b проходит через A(0; −1), B(−2; 2). Найдите a, b и f(2).

    Проверить ответ
