01

Сначала прочитайте масштаб

По горизонтальной оси расстояние между подписями может соответствовать π/4, π/2 или π. По вертикальной оси одна клетка иногда равна половине единицы. Масштаб каждой оси определяется отдельно.

Пример. Если две клетки по вертикали означают единицу, то пять клеток вниз дают координату −2,5. Если четыре клетки по горизонтали соответствуют π, одна клетка равна π/4.

02

Метод опорных точек

  1. Прочитайте формулу функции и определите число неизвестных коэффициентов.
  2. Выберите точки с понятными координатами. При двух коэффициентах обычно нужны две точки, дающие независимые уравнения.
  3. Подставьте их координаты в формулу, найдите значения тригонометрических функций и решите систему.
  4. Если уравнения совпали, замените одну из точек; затем проверьте найденные параметры.

03

Восстановите коэффициенты

Для графика y = a cos x + b, проходящего через точки (0; u) и (π; v), из значений cos 0 = 1 и cos π = −1 получаем систему.

a + b = u,   −a + b = v   ⇒   a = (u − v)/2,   b = (u + v)/2.

В разобранном примере u = 3, v = −1, поэтому a = 2 и b = 1. Формула графика — y = 2 cos x + 1.

Синус

У функции a sin x + b значения при 0 и π совпадают и равны b. Для нахождения a возьмите точку при π/2.

b = f(0),   a = f(π/2) − f(0).

Тангенс

У функции a tg x + b удобны точки при 0 и π/4; обе должны принадлежать графику. Тангенс не определён при x = π/2 + πk.

b = f(0),   a = f(π/4) − f(0).
04

Большие углы: выделите период

При вычислении f(13π/3) сначала выделите целое число периодов: 13π/3 = 4π + π/3. Поэтому cos(13π/3) = cos(π/3) = 1/2.

Периоды. Для синуса и косинуса период равен 2π; для тангенса — π. Проверяйте область определения тангенса.

05

Прикладные задачи: три расчётные модели

Дифракционная решётка

d sin φ = kλ

Период решётки d, длина волны λ и порядок максимума k. Приводите d и λ к одним единицам и проверяйте, что 0 ≤ kλ/d ≤ 1.

Неупругое столкновение

Q = mv² sin²α

Если угол между направлениями равен 2α, сначала найдите α. При ответе обязательно учитывайте, какую величину просят: α или 2α.

Гармонические колебания

v(t) = v₀ sin(2πt/T),   E(t) = mv(t)²/2.

Сначала подставьте время t и найдите скорость. Затем по найденной скорости вычислите кинетическую энергию. Учитывайте квадрат скорости и единицы измерения.
