Где выражение меняет знак?

Два квадратных неравенства из занятия. Выберите выражение, передвигайте x и сравнивайте знак многочлена, положение на оси и график. Особенно внимательно исследуйте корни.

График и положение точки

x² − x − 6 ≥ 0

(x + 2)(x − 3) ≥ 0

Проверьте закономерность

Метка на графике и оси показывает одно и то же значение x.

Отрицательное значениеПри x = 0 неравенство не выполняется.

Три наблюдения

  1. Корни разбивают прямую на промежутки, в каждом из которых знак сохраняется.
  2. Чтобы установить знак, достаточно выбрать одну точку внутри каждого промежутка.
  3. Для ≥ и ≤ нули включаются; при строгих знаках границы исключаются.

Первый пример: x² − x − 6 ≥ 0, ответ (−∞; −2] ∪ [3; +∞). Второй пример: x² − 3x − 4 ≤ 0, ответ [−1; 4]. Для корня чётной кратности знак может не меняться.
