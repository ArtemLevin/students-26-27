Раздел 01

Линейные уравнения и пропорции

Цель любого преобразования — сохранить равенство. При делении на переменную заранее учитываем, что знаменатель не равен нулю.

2/x = 10  ⟹  2 = 10x  ⟹  x = 1/5 = 0,2

Если слагаемое переносится через знак равенства, его знак меняется: 2 − x = 10 ⟹ −x = 8 ⟹ x = −8.

Правило пропорцииИз a/b = c/d при b ≠ 0 и d ≠ 0 следует ad = bc.
x/3 = (2x + 5)/4
4x = 3(2x + 5) = 6x + 15   ⟹  x = −15/2
Типичная ошибкаПри перекрёстном умножении всю сумму 2x + 5 заключайте в скобки. Иначе множитель 3 может ошибочно примениться лишь к первому слагаемому.

Раздел 02

Линейные неравенства

При делении или умножении неравенства на отрицательное число знак меняется на противоположный.

4x + 3 ≥ 7x + 5
−3x ≥ 2   ⟹  x ≤ −2/3

Ответ: (−∞; −2/3]. Квадратная скобка и закрашенная точка означают, что граница входит в множество решений. В строгих неравенствах граница исключается. Бесконечность всегда оформляется круглой скобкой.

Раздел 03

Квадратное уравнение

Для ax² + bx + c = 0 при a ≠ 0 вычисляем дискриминант.

D = b² − 4ac;   x = (−b ± √D) / (2a)
ДискриминантЧисло действительных корней
D > 0Два различных корня
D = 0Один корень
D < 0Корней нет
x² − 3x − 4 = 0
D = 9 + 16 = 25;   x = (3 ± 5)/2   ⟹  x₁ = 4, x₂ = −1

Если свободного члена нет, удобнее вынести переменную: x² − 3x = x(x − 3) = 0, откуда x = 0 или x = 3.

Уравнение без действительных корнейx² + 4 = 0 невозможно при действительном x: квадрат любого действительного числа неотрицателен.

Раздел 04

Найдите общий числовой и буквенный множитель слагаемых. Проверяйте результат обратным раскрытием скобок.

a²b + ab² = ab(a + b)

Раздел 05

Не путайте три формулы

За буквами a и b могут стоять целые выражения. Подставляем их со скобками, а затем возводим в квадрат и перемножаем.

(3x − 5y)² = 9x² − 30xy + 25y²
(4t + 7k)² = 16t² + 56tk + 49k²
4t² − 9k² = (2t − 3k)(2t + 3k)

Положительное число c можно записать как (√c)². Поэтому x² − 3 = (x − √3)(x + √3), а уравнение x² − 3 = 0 имеет корни ±√3.

Контроль(a − b)² и a² − b² обозначают разные выражения. Нельзя терять удвоенное произведение.

Раздел 06

Алгебраические дроби и «улыбочка»

A/B − C/D = (AD − CB)/(BD)
Условие: B ≠ 0, D ≠ 0.

Для выражения ниже ОДЗ: x ≠ −3 и x ≠ 3. Сначала приводим дроби к общему знаменателю, затем используем формулы сокращённого умножения.

(x − 3)/(x + 3) − (x + 3)/(x − 3)
= [(x − 3)² − (x + 3)²]/(x² − 9) = −12x/(x² − 9)
Критические скобкиВычитается весь второй числитель, поэтому перед раскрытием скобок пишем «−(x² + 6x + 9)». Сокращать дробь можно по общим множителям, сохраняя ОДЗ.

Раздел 07

Системы неравенств: пересечение

Каждое условие определяет множество. В системе ищем общую часть множеств, то есть числа, которые удовлетворяют всем неравенствам одновременно.

x ≥ −5,   x ≤ 10  ⟹  x ∈ [−5; 10]
4x + 5 ≥ 10x − 7   ⟹  x ≤ 2
x − 1 ≥ 7x − 5   ⟹  x ≤ 2/3
Пересечение: x ∈ (−∞; 2/3]

Раздел 08

Системы уравнений: подстановка

Выразите одну переменную через другую, подставьте во второе уравнение, решите полученное уравнение и вернитесь к первой переменной.

Из x + y = 10 получаем x = 10 − y.

Подставляем в 2x − 3y = 15: 2(10 − y) − 3y = 15.

20 − 5y = 15, поэтому y = 1 и x = 9.

Проверяем оба исходных уравнения: 9 + 1 = 10; 18 − 3 = 15.

Ответ: (x; y) = (9; 1)

Раздел 09 · главный метод

Первые шаги метода интервалов

Что означает f(x) ≥ 0?Нужно найти все значения x, при которых выражение неотрицательно. Нуль входит в решение. Для f(x) ≤ 0 ищем неположительные значения.

Рассмотрим x² − x − 6 ≥ 0. Разложим трёхчлен на множители: (x + 2)(x − 3). Нули −2 и 3 делят прямую на три промежутка.

ПромежутокПроверочная точкаЗначениеЗнак
x < −2−36+
−2 < x < 30−6−
x > 346+
(+) │ −2 │ (−) │ 3 │ (+)

Нужны плюсы и нули, поэтому x ∈ (−∞; −2] ∪ [3; +∞).

Во втором примере, x² − 3x − 4 ≤ 0, корни −1 и 4. Отрицательные значения находятся между корнями, поэтому x ∈ [−1; 4].

Важное уточнениеЗнак обязательно меняется при переходе через корень нечётной кратности. Для корня чётной кратности знак может сохраниться. В обоих разобранных примерах корни различны и знак чередуется.
