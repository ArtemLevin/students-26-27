Главная идея

Вектор — это смещение с направлением

У направленного отрезка есть начало и конец. Координаты вектора показывают не положение точек, а величину смещения по двум осям.

AB→=(xB−xA;yB−yA)
Главное правило: координата конца − координата начала. Применяйте его отдельно к каждой координате.
Вправо
x > 0
Влево
x < 0
Вверх
y > 0
Вниз
y < 0

Пример: от A(2; 3) к B(8; 6)

AB→=(8−2;6−3)=(6;3)

Это означает смещение на 6 единиц вправо и на 3 единицы вверх. Если по сетке видно «4 вправо и 2 вниз», координаты такого смещения равны (4; −2).

Длина вектора

Для вектора с координатами (x; y) длина следует из теоремы Пифагора.

|a→|=x2+y2

Для (6; 3): √(36 + 9) = √45 = 3√5. Если вектор задан двумя точками, сначала найдите его координаты, и лишь затем длину.

Быстрая проверка

Длина
Не может быть отрицательной.
Косинус
Для ненулевых векторов находится от −1 до 1.
Нулевой dot product
Означает перпендикулярность.
Порядок AB
Всегда B − A, не наоборот.

Скалярное произведение через координаты

Перемножьте соответствующие координаты и сложите результаты.

a→·b→=xaxb+yayb

Для a=(1;2), b=(3;4): 1·3 + 2·4 = 11. Для k=(−1;3), p=(2;−5): (−1)·2 + 3·(−5) = −17.

Следите за знаками. Отрицательная координата должна оставаться в скобках при умножении и возведении в квадрат.

Скалярное произведение через угол

a→·b→=|a→||b→|cosφ
cosφ=xaxb+yaybxa2+ya2xb2+yb2

Формула требует двух ненулевых векторов: в знаменателе находятся их длины.

Алгоритм нахождения угла

Найдите координаты каждого вектора.
Если вектор задан точками, используйте «конец − начало».
Найдите скалярное произведение.
Найдите длины обоих векторов.
Вычислите cos φ.
Если значение табличное, определите угол.
φ0°30°45°60°90°
cos φ1√3/2√2/21/20

Что показывает знак

a·b > 0
угол острый
a·b = 0
векторы перпендикулярны
a·b < 0
угол тупой
Пример
(−1;3)·(2;−5)=−17 → угол тупой

Сложение, вычитание и умножение на число

a→+b→=(xa+xb;ya+yb)
a→−b→=(xa−xb;ya−yb)
λa→=(λx;λy)

Все действия выполняются покомпонентно. Например, −2(3;−4)=(−6;8).

Линейная комбинация: работайте по шагам

Для d=2a−3b при a=(1;2), b=(3;4):

2a=(2;4)
3b=(9;12)
d=(2;4)−(9;12)=(−7;−8)
|d|=√(49+64)=√113

Методический принцип: не выполняйте длинную цепочку мысленно. Сначала получите координаты промежуточных векторов.

Ещё один типовой пример

t=(−2;3), q=(0;5), n=−2t+3q.

−2t→=(4;−6),3q→=(0;15)

Поэтому n=(4;9), |n|=√97.

Работа с корнями в задаче на угол

Если cos φ = 5/(√5·√10), то √10=√5·√2, поэтому cos φ=1/√2=√2/2 и φ=45°.

Основной алгоритм решения

Определите участвующие векторы.
Для вектора по двум точкам найдите «конец − начало».
Для выражения вида 2a−3b сначала получите его координаты.
Примените нужную формулу: длина, dot product, косинус, сумма или разность.
Проверьте знаки.
Упростите корни и дроби.
Оцените ответ по смыслу.

10 задач из чек-листа

Открывайте решение по одному шагу. Уже открытые шаги сохраняются внутри текущего просмотра карточки.

Средний уровень · №1

A(−2;3), B(5;−1). Найдите координаты AB.

Используем правило «конец − начало».
x: 5−(−2)=7; y: −1−3=−4.
AB=(7;−4).
Ответ: (7; −4).
Средний уровень · №2

a=(−6;8). Найдите длину.

Подставляем координаты самого вектора в формулу длины.
|a|=√((−6)²+8²)=√(36+64).
|a|=√100=10.
Ответ: 10.
Средний уровень · №3

a=(2;−3), b=(−4;5). Найдите скалярное произведение.

Перемножаем соответствующие координаты.
a·b=2·(−4)+(−3)·5=−8−15.
a·b=−23.
Ответ: −23.
Выше среднего · №4

a=(3;−2), b=(−1;4). Найдите c=2a−b.

2a=(6;−4).
Вычитаем b покомпонентно: (6;−4)−(−1;4).
c=(7;−8).
Ответ: (7; −8).
Выше среднего · №5

p=(−2;1), q=(3;−4). Найдите длину r=−3p+2q.

−3p=(6;−3), 2q=(6;−8).
r=(6;−3)+(6;−8)=(12;−11).
|r|=√(12²+(−11)²)=√(144+121)=√265.
Ответ: r=(12;−11), |r|=√265.
Выше среднего · №6

a=(1;0), b=(1;√3). Найдите угол между ними.

a·b=1·1+0·√3=1.
|a|=1, |b|=√(1+3)=2.
cos φ=1/(1·2)=1/2.
Табличное значение: φ=60°.
Ответ: 60°.
Выше среднего · №7

a=(2;1), b=(1;−2). Докажите перпендикулярность.

Вычисляем скалярное произведение.
a·b=2·1+1·(−2)=2−2=0.
Для ненулевых векторов нулевое скалярное произведение означает перпендикулярность.
Следовательно, угол между ними равен 90°.
a·b=0, поэтому векторы перпендикулярны.
Выше среднего · №8

A(−1;2), B(2;3), C(4;−1), D(2;−2). Найдите AB·CD.

AB=(2−(−1);3−2)=(3;1).
CD=(2−4;−2−(−1))=(−2;−1).
AB·CD=3·(−2)+1·(−1)=−6−1=−7.
Ответ: −7.
Выше среднего · №9

A(1;1), B(3;2), C(−2;4), D(1;3). Найдите косинус угла между AB и CD.

AB=(2;1), CD=(3;−1).
AB·CD=2·3+1·(−1)=5.
|AB|=√5, |CD|=√10.
cos φ=5/(√5·√10)=1/√2=√2/2.
Ответ: √2/2.
Сложный уровень · №10

a=(1;2), b=(2;−1), c=3a−2b, d=a+b. Найдите угол между c и d.

c=3(1;2)−2(2;−1)=(3;6)−(4;−2)=(−1;8).
d=(1;2)+(2;−1)=(3;1).
c·d=(−1)·3+8·1=5.
|c|=√65, |d|=√10.
cos φ=5/(√65·√10)=1/√26=√26/26.
φ=arccos(1/√26).
Ответ: arccos(1/√26).
Мини-памятка

Типичные ошибки

Перепутать начало и конец.
Для AB всегда (xB−xA; yB−yA). Самопроверка: направление смещения должно совпадать со знаками.
Потерять минус.
Например, 3·(−5)=−15. Отрицательные координаты записывайте в скобках.
Умножить только одну координату.
3(2;−1)=(6;−3), число действует на обе координаты.
Перепутать действие в линейной комбинации.
После вычисления −2t и 3q в выражении −2t+3q результаты нужно сложить.
Забыть скобки при квадрате.
(−2)²=4, тогда как −2²=−4.
Смешать координаты точек и вектора.
Формула длины использует координаты самого вектора.
Применить формулу угла к нулевому вектору.
В знаменателе стоят длины, поэтому обе должны быть ненулевыми.

Порядок важен
Не ищите угол раньше координат и длин. Формула косинуса становится простой только после подготовки данных.
Пошаговый режим
Открывайте решение по одному действию. Кнопка «Показать всё» раскрывает весь разбор, а «К началу» очищает состояние карточки.
Свяжите формулу с рисунком
В A→B сравните знаки координат с направлением стрелки. В сценариях 60° и 90° сопоставьте рисунок со скалярным произведением.
