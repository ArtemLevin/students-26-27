01

Общие делители и кратные

Начните с разложения на простые множители.

НОД — наибольшее положительное число, на которое делятся оба исходных числа. НОК — наименьшее положительное число, кратное каждому из них.

НОД — меньшие степени

Из разложений берём каждый общий простой множитель в наименьшей из двух степеней.

НОК — большие степени

Берём все простые множители, встречающиеся хотя бы в одном числе, в наибольшей степени.

24 = 2³·3   и   32 = 2⁵
НОД(24,32) = 8   ·   НОК(24,32) = 96

Для краткости иногда используют запись (a,b) для НОД и [a,b] для НОК. В этой странице во всех вычислениях приняты русские обозначения.

02

Алгоритм Евклида

Найдите НОД, последовательно заменяя пару меньшим числом и остатком.

При делении большего числа a на меньшее b получается a = qb + r, где 0 ≤ r < b. При этом НОД(a,b) = НОД(b,r).

308 = 2·112 + 84→112 = 84 + 28→84 = 3·28

Пройти алгоритм по шагам

Шаг 1 из 4

308 и 112

Исходная пара чисел: 308 и 112.

Критерий остановки: когда остаток равен нулю, НОД — последнее ненулевое число (в примере 28). Ноль ответом не является.
03

Как узнать нужный метод

Одни задачи требуют группировки, другие — поиска первого совпадения.

НОД: одинаковые наборы

84 помидора и 112 огурцов распределены по максимально возможному числу одинаковых упаковок.

НОД(84,112) = 28

28 упаковок: по 3 помидора и 4 огурца.

НОК: первое совпадение

Если сигналы повторяются каждые 12 и 18 минут и совпали в начальный момент, то

НОК(12,18) = 36 минут

через 36 минут они совпадут снова.

Внимание. Одно слово «упаковки» или «совпадение» ещё не определяет метод. Проверьте, что условие требует максимального числа равных групп или первого совместного кратного.
04

Главная связь

Для одной и той же пары натуральных чисел.

НОД(a,b) · НОК(a,b) = a·b

Это позволяет находить неизвестную величину без повторного разложения. Например, для 84 и 180:

НОК(84,180) = (84·180) / 12 = 1260

Для каждой простой основы показатель минимальной степени плюс показатель максимальной степени равен сумме исходных показателей: min(α,β) + max(α,β) = α + β.

НЕОБХОДИМОЕ УСЛОВИЕ
НОД всегда делит НОК

Равенства НОД(a,b) = 14 и НОК(a,b) = 90 не могут выполняться одновременно, так как 90 не делится на 14.

Если d делит m, то пара (d,m) имеет НОД d и НОК m. Для доказательства существования достаточно подходящего примера; для доказательства невозможности — противоречия условию делимости.

05

Первые олимпиадные рассуждения

Учитывайте ограничения и проверяйте полученное число в исходном условии.

Неизвестное число

Для n = 2ˣ·3ʸ·5ᶻ·7ʷ и условий НОД(n,360) = 120, НОК(n,360) = 2520:

n = (120·2520) / 360 = 840

Разложение 840 = 2³·3·5·7, поэтому x = 3, y = z = w = 1. Результат проверяется по обоим данным отношениям.

Условие «простое число»

При НОК(18,p) = 90 число p — простой делитель 90 = 2·3²·5. Возможные кандидаты: 2, 3, 5; подходит только p = 5.

Частая ошибка: число 1 не является простым. Для простого числа требуется ровно два различных положительных делителя.

Метод «оценка + пример»: сначала обоснуйте ограничение, затем проверьте пример. При невозможности достаточно строгого противоречия.

09.10.26 · Пятница

3 задания · средняя сложность

  1. Найдите НОД(672, 462) алгоритмом Евклида. Запишите все деления с остатком.

    Посмотреть ответ
    42; 672 = 462 + 210, 462 = 2·210 + 42, 210 = 5·42.

  2. Найдите НОК(84, 126, 180) через разложение на простые множители.

    Посмотреть ответ
    1260 = 2²·3²·5·7.

  3. Для натурального n известно, что НОД(n, 72) = 18 и НОК(n, 72) = 360. Найдите n и проверьте оба условия.

    Посмотреть ответ
    n = 90; НОД(90,72) = 18, НОК(90,72) = 360.
ДЕНЬ 02 / 04

10.10.26 · Суббота

3 задания · средняя сложность

  1. Из 168 карандашей, 210 тетрадей и 294 закладок составляют максимально возможное число одинаковых наборов без остатка. Сколько наборов получится? Сколько предметов каждого вида будет в одном наборе?

    Посмотреть ответ
    42 набора: 4 карандаша, 5 тетрадей, 7 закладок в каждом.

  2. Три сигнала подаются каждые 18, 24 и 40 минут. В 08:00 они прозвучали одновременно. Когда они впервые прозвучат одновременно снова? Сколько раз сработает каждый сигнал за прошедшее время (не считая начального момента)?

    Посмотреть ответ
    14:00. За 360 минут: 20, 15 и 9 срабатываний.

  3. Найдите все неупорядоченные пары натуральных чисел (a,b), для которых НОД(a,b) = 18 и НОК(a,b) = 540. Обоснуйте, что других пар нет.

    Посмотреть ответ
    (18,540), (36,270), (54,180), (90,108). Для a = 18u, b = 18v имеем uv = 30 и НОД(u,v) = 1.

11.10.26 · Воскресенье

3 задания · средняя сложность

  1. Какие данные могут быть верными: (а) НОД(a,b) = 18, НОК(a,b) = 450; (б) НОД(a,b) = 18, НОК(a,b) = 455? Для возможного случая приведите пару; невозможность обоснуйте.

    Посмотреть ответ
    (а) возможно, например (18,450); (б) невозможно, поскольку 18 не делит 455.

  2. Число n = 2ˣ·3ʸ·5ᶻ·7ʷ, где x,y,z,w — целые неотрицательные числа, удовлетворяет НОД(n,420) = 84 и НОК(n,420) = 1260. Найдите n и четыре показателя, проверьте результат.

    Посмотреть ответ
    n = 252 = 2²·3²·7; x = 2, y = 2, z = 0, w = 1.

  3. Найдите все простые p, для которых выполняется хотя бы одно равенство: НОК(84,p) = 84 или НОК(84,p) = 420. Укажите, для какого равенства подходит каждое p.

    Посмотреть ответ
    НОК = 84: p = 2, 3, 7; НОК = 420: p = 5.
