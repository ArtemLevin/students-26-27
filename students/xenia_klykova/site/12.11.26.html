01 / Базовый объект

Факториал без огромных вычислений

Для целого n ≥ 1 факториал — произведение всех натуральных чисел от 1 до n. По соглашению 0! = 1. Факториал определён для неотрицательных целых чисел.

n! = 1 · 2 · 3 · … · n

Чтобы сократить выражение, отделите нужные множители:

n! = n(n − 1)!  ·  (n + 1)! = (n + 1)n!
Разобранный пример

9! / 7! = (9 · 8 · 7!) / 7! = 72.

Не требуется сначала вычислять 9! и 7!: общий множитель сокращается сразу.

02 / Каноническое разложение

Когда число делит факториал?

Запись A | n! означает, что факториал n! делится на число A без остатка. Разложите A на простые множители и проверьте, хватает ли каждого простого числа в n!.

72 = 2³ · 3²
Наименьшее n для 72 | n!

5! = 2³ · 3 · 5: троек пока недостаточно. 6! = 2⁴ · 3² · 5: и двоек, и троек уже хватает.

Ответ: n = 6. Для меньших n факториалы делят 5!, поэтому 72 не будет делить их.

Быстрый поиск по крупному простому множителю

35 = 5 · 7: семёрка впервые появится в 7!, значит минимальное n = 7. Аналогично 1170 = 2 · 3² · 5 · 13, поэтому минимальное n = 13.

Для делимости на составное число недостаточно одного множителя. Каждый требуемый простой множитель должен присутствовать в необходимом количестве.

03 / Экономим вычисления

Формула Лежандра

Обозначение vp(n!) — показатель простого числа p в каноническом разложении n!. Для его вычисления не нужно выписывать всё произведение.

vp(n!) = ⌊n/p⌋ + ⌊n/p²⌋ + ⌊n/p³⌋ + …

Каждую дробь округляйте вниз отдельно. Когда p в очередной степени становится больше n, все дальнейшие слагаемые равны нулю.

Пример: степень двойки в 6!

v2(6!) = ⌊6/2⌋ + ⌊6/4⌋ = 3 + 1 = 4.

Кратные 2 дают одну двойку; кратные 4 добавляют вторую. Так учитываются все двойки внутри 6!.

Пример: степени двойки и тройки в 10!

v2(10!) = 5 + 2 + 1 = 8.

v3(10!) = 3 + 1 = 4.

Вы можете проследить эти слагаемые по одному в цифровой лаборатории.

Важно: формула Лежандра применяется к простому p. Если делитель составной, его сначала раскладывают на простые множители.

04 / Главный результат

Как найти максимальную степень?

Пусть A = p₁α₁ · … · prαr. Нужно найти наибольшее целое k ≥ 0, для которого Ak | n!.

kmax = min {⌊vp₁(n!) / α₁⌋, …, ⌊vpᵣ(n!) / αᵣ⌋}

Одна копия числа 12 = 2² · 3 расходует две двойки и одну тройку. Если в факториале четыре двойки и две тройки, можно собрать ровно две копии 12.

Исходный примерДоступные простые степениМаксимум k
12k | 6!v₂ = 4; v₃ = 2min(⌊4/2⌋, ⌊2/1⌋) = 2
18k | 10!v₂ = 8; v₃ = 4min(⌊8/1⌋, ⌊4/2⌋) = 2
12k | 30!v₂ = 26; v₃ = 14min(⌊26/2⌋, ⌊14/1⌋) = 13
Почему 14-я степень числа 12 не делит 30!?

Для 12¹⁴ нужно 28 двоек, а внутри 30! их только 26. Поэтому k = 13 — действительно максимальное значение.

05 / Логика решения

Четыре шага вместо громоздкого разложения

  1. Разложите A на простые множители. Запишите показатели α₁, α₂, ….
  2. Для каждого простого p найдите vp(n!). Используйте формулу Лежандра.
  3. Разделите найденный показатель на α. Округлите вниз — столько полных наборов можно собрать.
  4. Возьмите минимум. Именно самый дефицитный простой множитель ограничивает степень A.

Ошибки, на которые стоит смотреть

  • Не перепутайте показатель α в делителе и показатель vp(n!) в факториале.
  • Не округляйте вниз только общий результат: в формуле Лежандра каждый член округляется отдельно.
  • Не требуйте равного числа простых множителей в факториале: лишние допустимы.
  • Не выбирайте максимум вместо минимума.
