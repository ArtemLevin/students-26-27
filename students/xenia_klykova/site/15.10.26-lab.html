Числа под наблюдением

Изменяйте n. Следите одновременно за двумя выражениями, остатками от деления и линейной комбинацией. Проверьте, почему найденный делитель подходит только для определённых n.

Эксперимент

Выберите n от 1 до 50. Изменения применяются к обеим формулам.

Делимость на 7

A(n) = 3n + 214

14 = 7 × 2 + 0

Делится на 7

B(n) = 8n + 335

35 = 7 × 5 + 0

Делится на 7

Линейная комбинация исключает n

8(3n + 2) − 3(8n + 3) = 7

8 × 14 − 3 × 35 = 7

Результат не зависит от значения n.

Оба выражения делятся на 7

Для n = 4 оба остатка равны нулю.

Сравните соседние значения n

Выделенные значения дают два числа, одновременно кратных найденному делителю. Выберите любое значение для проверки.

оба делятся не оба делятся

Объясните закономерность

Подходящие значения имеют вид n = 7t + 4, где t = 0, 1, 2, … . Каждый новый подходящий n больше предыдущего на 7.

Постоянная линейная комбинация ограничивает возможный общий делитель. Проверка остатков показывает, при каких n он действительно общий.
