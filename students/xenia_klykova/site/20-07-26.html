Графики функций: одна идея для разных форм

Полный интерактивный эквивалент пособия: метод узловых точек, восстановление прямой, параболы и гиперболы, различие между значением функции и уравнением, поиск пересечений и отбор корня по рисунку.

Идея решения

1. Сосчитайте неизвестные

Число независимых узловых точек обычно равно числу неизвестных коэффициентов.

2. Выберите удобные точки

Используйте точно читаемые целые координаты, желательно близкие к началу координат.

3. Подставьте координаты

Абсцисса идёт вместо аргумента, ордината — вместо значения функции.

4. Решите и проверьте

Найдите коэффициенты, соберите формулу, выполните вопрос и сверьтесь с рисунком.

Координатная модель

Мини-квиз

В формуле y=kx+b неизвестны оба коэффициента. Сколько независимых узловых точек обычно требуется?

Линейная функция

Общий вид

f(x)=kx+b

k — угловой коэффициент, b — ордината пересечения с осью Oy.

Узловые точки

A(−1;−3) и B(3;4).

Требование

Восстановить формулу и найти f(−5).

Пошаговый разбор

1. Что дано

Две точки прямой и два неизвестных коэффициента.

{−3=−k+b4=3k+b

2. Выразим b

b=k−3

3. Найдём k

3k+k−3=4⇒4k=7⇒k=74

4. Найдём b

b=74−3=−54

5. Соберём формулу

f(x)=74x−54

6. Вычислим значение

f(−5)=74·(−5)−54=−10

7. Проверим

Обе исходные точки удовлетворяют формуле; точка с абсциссой −5 имеет ординату −10.

Ответ: −10.

Не путайте значение функции и уравнение

Найти f(−5)

x=−5⇒ подставить аргумент

Результат — значение функции, то есть координата y.

Решить f(x)=−5

74x−54=−5⇒x=−157

Результат — аргумент, при котором ордината равна −5.

Мини-квиз

Что требуется найти в уравнении f(x)=6?

Парабола: график другой, метод тот же

Рассмотрим f(x)=2x2+bx+c. Коэффициент при квадрате известен, неизвестны b и c, поэтому нужны две точки.

1. Подставим A(−2;−2)

−2=2·(−2)2−2b+c⇒−2b+c=−10

2. Подставим B(1;1)

1=2+b+c⇒b+c=−1

3. Решим систему

{−2b+c=−10b+c=−1⇒b=3,c=−4

4. Соберём формулу

f(x)=2x2+3x−4

5. Вычислим f(−5)

f(−5)=2·25−15−4=31

6. Проверим

Обе исходные точки удовлетворяют найденной формуле.

Ответ: 31.

Форма меняется

Степень и внешний вид графика могут быть другими.

Логика сохраняется

Любая точка графика удовлетворяет его формуле.

Отрицательное число в квадрате

(−2)2=4

Мини-квиз

В функции y=2x2+bx+c неизвестны b и c. Сколько точек требуется?

Гипербола вида y=kx

Ограничение

x≠0

При нулевом знаменателе функция не определена.

Одна неизвестная

Для определения k достаточно одной точки с ненулевой абсциссой.

Быстрая формула

k=x0y0

Разобранный пример

Точка (2;1)

1=k2⇒k=2⇒f(x)=2x

Нулевая абсцисса запрещена

Точку с x=0 нельзя подставлять: она не принадлежит области определения.

Мини-квиз

Через точку (3;−4) проходит график y=kx. Чему равно k?

Пересечение гиперболы и прямой

Восстановленные функции

f(x)=2x,g(x)=5x−9

Условие пересечения

f(x)=g(x)

Отбор точки

После решения сопоставьте корни с положением точек на рисунке.

Пошаговое решение

1. Приравняем формулы

2x=5x−9,x≠0

2. Умножим на x

Умножение допустимо, потому что заранее записано x≠0.

2=5x2−9x

3. Получим квадратное уравнение

5x2−9x−2=0

4. Найдём дискриминант

D=(−9)2−4·5·(−2)=121

5. Найдём корни

x1=2,x2=−15

6. Проверим ОДЗ

Оба корня ненулевые и допустимы.

7. Выберем точку B

По рисунку −1<xB<0, следовательно:

xB=−15

Универсальный алгоритм пересечения

  1. Восстановите формулу первой функции.
  2. Восстановите формулу второй функции.
  3. Запишите ограничения и область допустимых значений.
  4. Приравняйте значения функций.
  5. Решите полученное уравнение.
  6. Исключите недопустимые значения.
  7. Сопоставьте корни с расположением точек.
  8. Запишите требуемую координату.

Мини-квиз

Почему перед умножением уравнения 2x=5x−9 на x записывают ограничение?

Типичные ошибки

Перепутан порядок координат

(x;y)≠(y;x).

Ошибка со степенью

(−2)2=4

Потерян знак при переносе

Перенос −4 в другую часть даёт +4.

Перепутаны записи

f(a) и f(x)=a — разные задачи.

Выбраны неточные точки

Приближённые координаты дают недостоверные коэффициенты.

Забыто ограничение

Для дробной функции обязательно x≠0.

Формулы приравнены без причины

Равенство функций используется только для общих точек.

Выбран любой корень

Корень нужно сопоставить с требуемой точкой и интервалом.

Ошибка в дробях

−13+1=−13+33=23

Нет проверки

Найденные коэффициенты должны удовлетворять всем исходным точкам.
