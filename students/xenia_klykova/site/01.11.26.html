Делители.
Система ограничений.

Считать подходящие делители проще через показатели простых множителей. Учимся одновременно учитывать кратность, полный квадрат и запрещённую делимость.

01 / Основа Вместо делителей — показатели

Если число N = 2ᴬ · 3ᴮ · 5ᶜ, любой его положительный делитель имеет вид d = 2ˣ · 3ʸ · 5ᶻ.

0 ≤ x ≤ A   ·   0 ≤ y ≤ B   ·   0 ≤ z ≤ C

Показатели — целые числа. Нуль разрешён: множитель с нулевым показателем равен единице. Если для x есть p вариантов, для y — q, для z — r, всего делителей p · q · r.

Из пособия · N = 2⁴ · 3² · 5³
x: 0–45 вариантов
y: 0–23 варианта
z: 0–34 варианта

Всего 5 · 3 · 4 = 60 делителей.

02 / Кратность Верхняя и нижняя границы

Из условия d | N следуют верхние границы x, y, z. Если m | d и m = 2ᵃ · 3ᵇ · 5ᶜ, добавляем нижние: x ≥ a, y ≥ b, z ≥ c.

Кратность 45

45 = 2⁰ · 3² · 5¹. Для N = 2⁶ · 3⁵ · 5³ получаем:

x: 0–67 значений
y: 2–54 значения
z: 1–33 значения

Делителей, кратных 45: 7 · 4 · 3 = 84.

Каждое требование уточняет допустимое множество показателей. Если ограничений несколько, учитывать нужно все одновременно.

03 / Полный квадрат Выбираем чётные показатели

Число является квадратом натурального числа тогда и только тогда, когда показатели всех простых множителей чётные. Нуль тоже чётный.

2²ᵘ · 3²ᵛ · 5²ʷ = (2ᵘ · 3ᵛ · 5ʷ)²
Квадраты, кратные 45, среди делителей N = 2⁶ · 3⁵ · 5³
x: 0, 2, 4, 64 варианта
y: 2, 42 варианта
z: 21 вариант

Ответ: 4 · 2 · 1 = 8 полных квадратов.

04 / Исключение Два способа учесть «не делится»

Вычитание

Для N = 2⁵ · 3⁴ · 5³ считаем делители, кратные 6, но не кратные 60.

Кратных 6 — 80; кратных 60 — 48.

80 − 48 = 32

Прямое ограничение

Для запрета кратности 64 = 2⁶ достаточно потребовать x < 6.

Этот приём особенно удобен, когда запрещённое число — степень одного простого.

x < 6

При вычитании исключаемая группа должна целиком входить в первоначально подсчитанную. При запрете числа с несколькими простыми множителями достаточно нарушить хотя бы одно условие кратности.

Квадраты среди делителей 2⁷ · 3⁶ · 5⁴, кратные 72, но не 64

72 = 2³ · 3². Значит, 3 ≤ x < 6; 2 ≤ y ≤ 6; 0 ≤ z ≤ 4.

x = 41 чётное значение
y: 2, 4, 63 значения
z: 0, 2, 43 значения

Подходящих делителей-квадратов: 1 · 3 · 3 = 9.

05 / Перевод условия Светодиодные панно

Из 38 880 000 светодиодов собирают одинаковые квадратные панно. Все элементы должны быть использованы; на каждое панно приходится целое число кассет по 90 светодиодов; разбиение на квадраты 8 × 8 запрещено.

  1. Число светодиодов в одном панно d делит общее количество: d | 38 880 000.
  2. Квадратная сетка: d = s².
  3. Кассеты: 90 | d.
  4. Запрет блоков 8 × 8: 64 ∤ d.
38 880 000 = 2⁸ · 3⁵ · 5⁴

Возможные показатели у делителя-квадрата: x ∈ {2, 4}; y ∈ {2, 4}; z ∈ {2, 4}. Количество размеров панно: 2 · 2 · 2 = 8.

Главный навык: распознать за словами «без остатка», «квадратная решётка», «кассеты» и «не допускается» математические условия на один и тот же делитель.

06 / Порядок действий Алгоритм без полного перебора

  1. Разложить исходное число и числа из дополнительных условий.
  2. Записать форму делителя и верхние границы показателей.
  3. Уточнить нижние границы для обязательной кратности.
  4. Оставить чётные показатели для полного квадрата.
  5. Исключить запрещённые случаи сужением или вычитанием.
  6. Перемножить количества допустимых вариантов и проверить ограничения.

Типичные ошибки

  • Забыть нулевое значение показателя.
  • Перепутать условия d | N и m | d.
  • Оставить нечётный показатель в делителе-квадрате.
  • Принять запрет кратности произведения за одновременный запрет каждого множителя.
  • Вычесть неподходящие случаи, не проверив вложенность множеств.
