01 · главная идея

Сначала смысл, потом вычисления

«И»События идут совместно или последовательно.

Для независимых событий — умножение.

«ИЛИ»Подходит один из несовместимых вариантов.

Вероятности вариантов складываются.

«НЕ»Переходим к противоположному событию.

P(не A)=1−P(A).

«Хотя бы один»Обычно быстрее считать через «ни одного».

1−P(ни одного).

Мини-алгоритм. Что считается успехом? → где «и»? → где «или»? → есть ли удобное противоположное событие? → задан конкретный порядок или только число успехов?

02 · базовая модель

Два биатлониста: увидеть все четыре исхода

Что дано. Первый попадает с вероятностью 0,2, второй — с вероятностью 0,3. Выстрелы независимы.

Смысл условий. «Оба попадут» = первый попадёт и второй попадёт.

P(оба)=0,2·0,3=0,06

Противоположные вероятности.

первый промах: 1−0,2=0,8
второй промах: 1−0,3=0,7

Вероятности четырёх несовместимых исходов: 0,06; 0,14; 0,24; 0,56. Их сумма равна 1.

«Хотя бы один попадёт»

Замените событие на противоположное: «ни один не попадёт».
Вероятность двух промахов: 0,8·0,7=0,56.
Вычтите из единицы: 1−0,56=0,44.
Ответ и проверка. 0,44. Полный перебор даёт тот же результат: 0,14+0,24+0,06=0,44.

Три продавца: «хотя бы один свободен»

Что дано. Каждый из трёх продавцов независимо занят с вероятностью 0,1.

Смысл вопроса. «Хотя бы один свободен» противоположно событию «заняты все».

P(все заняты)=0,1³=0,001.
P(хотя бы один свободен)=1−0,001=0,999.
Обобщение из чек-листа: при одинаковой вероятности успеха p в n независимых испытаниях вероятность хотя бы одного успеха равна 1−(1−p)n.

03 · порядок или количество

Первые три попадания и ровно три попадания — разные события

Порядок задан

Биатлонист стреляет 5 раз, p=0,8. Требуется: первые три — попадания, последние два — промахи.

0,83·0,22=0,02048

Комбинаторный коэффициент не нужен: последовательность уже указана.

Порядок не задан

Те же 5 выстрелов, но требуется ровно 3 попадания.

C53·0,83·0,22=0,2048

C₅³=10 учитывает разные позиции трёх попаданий.

Схема Бернулли. Для n независимых испытаний с одинаковой вероятностью успеха p: Pn(k)=Cnk·pk·qn−k,q=1−p

04 · дерево вероятностей

Вероятность маршрута читается прямо по ветвям

Пешеход идёт из S к F. Из S выходят три равновероятные дороги; нужная ведёт в D. Из D снова три равновероятные дороги; нужная ведёт в F.

S→D и D→F, поэтому P=1/3·1/3=1/9.

Вдоль одного пути

Последовательность соединена союзом «и» → вероятности ветвей перемножаются.

Несколько подходящих путей

Маршрут 1 «или» маршрут 2 «или» маршрут 3 → вероятности несовместимых маршрутов складываются.

Проверка узла. Сумма вероятностей всех ветвей, выходящих из одной развилки, должна быть равна 1.

05 · дерево по смыслу текста

Лампы двух заводов: разбивка «источник → качество»

Что дано. Первый завод выпускает 40% ламп, второй — 60%. Брак: 2% у первого и 3% у второго.

Смысл условий. У каждой лампы два последовательных признака: сначала завод, затем качество.

P(качественная | завод 1)=0,98
P(качественная | завод 2)=0,97

Идея решения. Качественная лампа приходит либо с первого завода, либо со второго.

Первый маршрут: 0,4·0,98=0,392.
Второй маршрут: 0,6·0,97=0,582.
Сложите маршруты: 0,392+0,582=0,974.
Ответ. Вероятность купить исправную лампу равна 0,974 = 97,4%.
Формула полной вероятности в этой модели: P(A)=P(H₁)·P(A|H₁)+P(H₂)·P(A|H₂)+…

Частые ошибки

«И» и «ИЛИ» перепутаны.
Один путь читается через «и»; альтернативные несовместимые пути — через «или».
Промах оставили равным попаданию.
Всегда используйте P(промаха)=1−P(попадания).
«Ровно 3» приняли за «первые 3».
В первом случае нужны все допустимые позиции успехов.
Для «хотя бы один» начали длинный перебор.
Сначала проверьте дополнение: 1−P(ни одного).
