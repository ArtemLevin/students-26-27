Делители натурального числа

Как посчитать делители без перебора, если они должны делиться на заданное число, быть чётными, квадратами или кубами.

Начать разбор ↓Исследовать показатели ↗
0 ≤ xᵢ ≤ αᵢ

Все условия задачи превращаются в ограничения на показатели простых множителей.

Маршрут: разложение → границы → пересечение → число вариантов.

01 / Основа От разложения к количеству

Любое натуральное число, большее единицы, раскладывается на простые множители. Каждый положительный делитель получается независимым выбором допустимых показателей.

n = p₁α₁ · p₂α₂ · … · pₖαₖ
d = p₁x₁ · p₂x₂ · … · pₖxₖ,   0 ≤ xᵢ ≤ αᵢ

Показатель ноль разрешён: p0 = 1. У показателя αᵢ есть αᵢ + 1 возможное значение, включая ноль.

τ(n) = (α₁ + 1)(α₂ + 1)…(αₖ + 1)
Пример · 360

360 = 23 · 32 · 5;   τ(360) = 4 · 3 · 2 = 24.

Выборы показателей: двойка — 0, 1, 2, 3; тройка — 0, 1, 2; пятёрка — 0, 1.

Пример · миллион

106 = 26 · 56,   τ(106) = 7 · 7 = 49.

02 / Кратность Нижняя и верхняя границы

Если делитель d должен одновременно делить n и быть кратным m, для каждого простого множителя нижнюю границу задаёт число m, а верхнюю — число n.

m | d | n   ⟹   βᵢ ≤ xᵢ ≤ αᵢ

Если m не делит n, подходящих делителей нет. Если делит — число вариантов равно произведению (αᵢ − βᵢ + 1).

Пример · делители 360, кратные 12

360 = 23 · 32 · 5;   12 = 22 · 3.

x ∈ {2, 3}показатель двойки
y ∈ {1, 2}показатель тройки
z ∈ {0, 1}показатель пятёрки

2 · 2 · 2 = 8 делителей.

Пример · делители 72, кратные 6

72 = 23 · 32;   6 = 2 · 3.

Для двойки 1, 2 или 3; для тройки 1 или 2. Получаем 3 · 2 = 6 делителей.

03 / Чётность Роль показателя двойки

Чтобы делитель оказался нечётным, показатель двойки должен быть нулём. Для чётного делителя показатель двойки должен быть хотя бы единицей.

Нечётный

x₂ = 0

Чётный

x₂ ≥ 1

Пример · нечётные делители 360

Для тройки три значения показателя, для пятёрки два. Показатель двойки фиксирован нулём. Итого 1 · 3 · 2 = 6.

Пример · чётные делители 72

Всего делителей 12, нечётных 3; чётных 12 − 3 = 9. Прямой подсчёт также даёт 3 · 3 = 9.

04 / Точные степени Квадраты, кубы, степени r

Делитель является квадратом натурального числа, если каждый показатель чётный. Для куба каждый показатель кратен трём. Число 1 удовлетворяет обоим условиям.

Квадрат

xᵢ ∈ {0, 2, 4, …}

Куб

xᵢ ∈ {0, 3, 6, …}

Qr(n) = ∏i=1…k (⌊αᵢ / r⌋ + 1)

Здесь ⌊t⌋ обозначает наибольшее целое число, не превосходящее t.

Пример · n = 2⁵ · 3⁴ · 7

Q₂(n) = (⌊5/2⌋+1)(⌊4/2⌋+1)(⌊1/2⌋+1)
= 3 · 3 · 1 = 9.

Q₃(n) = (1+1)(1+1)(0+1) = 4.

05 / Комбинированная задача Пересечение ограничений

Когда условий несколько, для каждого простого множителя оставляем только показатели, удовлетворяющие всем требованиям сразу.

Пример · делители 2⁴ · 3³ · 5², кратные 45 и являющиеся квадратами

Кратность 45 = 3² · 5 задаёт нижние границы. Условие квадрата оставляет лишь чётные показатели.

x ∈ {0, 2, 4}двойка
y = 2тройка
z = 2пятёрка

Итого 3 · 1 · 1 = 3 делителя: 225, 900, 3600.

Важно. Формулу числа делителей-квадратов применяют к границам показателей. Если уже оставлены отдельные варианты показателей после других условий, следует пересечь их с множеством чётных значений.

Пример · кратно 18, но не кратно 4

Для n = 2⁵ · 3⁴ · 5² условие кратности 18 означает x ≥ 1, y ≥ 2. Запрет кратности 4 означает x < 2. Поэтому x = 1, у остальных показателей по три варианта. Ответ 9.

Отрицательное условие

«Делится на 6, но не делится на 60» удобно считать как количество делителей, кратных 6, минус количество делителей, кратных 60.

Nитог = Nосновное − Nзапрещённое

06 / Алгоритм Маршрут от условия к ответу

Шаг 1Разложить n на простые множители
Шаг 2Записать форму делителя и границы
Шаг 3Пересечь все требования на показатели
Шаг 4Перемножить количества значений

Если хотя бы для одного показателя нет допустимых значений, ответ равен нулю.

Частые ошибки

  • Забывают нулевые показатели и делитель 1.
  • Путают верхнюю границу из n с нижней границей из требования кратности.
  • Смешивают чётность числа и условие квадрата.
  • Считают варианты по отдельным условиям без пересечения.
  • Считают «не делится» слишком сильным запретом, вместо проверки или вычитания.
