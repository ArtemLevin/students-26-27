01 / Параллелепипед

Объём: основание на высоту

Прямоугольный параллелепипед имеет шесть прямоугольных граней. Пусть три измерения равны a, b, c, причём все длины положительны.

ОБЪЁМV = Sосн · h = a · b · c

Основанием можно выбрать любую грань. Высотой тогда будет перпендикулярное этой грани ребро. Для основания со сторонами a и b площадь равна ab, высота — c.

Разбор с занятия

Объём равен 24 см³. Ребро, перпендикулярное искомой грани, равно 3 см. Найдите площадь этой грани.

S = V : h = 24 : 3 = 8 см².

Начинайте с формулы для требуемой величины. Затем отмечайте известные данные и находите недостающее.

02 / Шесть граней

Полная поверхность

ПЛОЩАДЬSполн = 2(ab + ac + bc)

Каждый из трёх типов прямоугольных граней встречается дважды. Поэтому учитываем все шесть граней.

Пример

Если a = 2, b = 3, c = 4, то площадь основания равна 2 · 3 = 6, а площадь всей поверхности:

Sполн = 2(6 + 8 + 12) = 52.

Внимание: площадь одной грани, площадь основания и площадь всей поверхности — разные величины. В задаче проверяйте формулировку вопроса.

03 / Теорема Пифагора

Две разные диагонали

Диагональ грани

Она лежит в прямоугольной грани и находится по двум её сторонам.

dab = √(a² + b²)

dac = √(a² + c²);   dbc = √(b² + c²).

Пространственная диагональ

Соединяет противоположные вершины тела. Теорему Пифагора применяем два раза: к основанию и к треугольнику с высотой.

D² = a² + b² + c²   ⇒   D = √(a² + b² + c²)
Пример с занятия

Два ребра равны 2 и 4, пространственная диагональ равна 6. Найдите объём.

c² = 6² − 2² − 4² = 16 → c = 4.

V = 2 · 4 · 4 = 32.

В формуле пространственной диагонали участвуют квадраты трёх измерений; для диагонали грани — только двух. Длины берём положительные.

04 / Частный случай

У куба все рёбра равны

В формулах параллелепипеда положите a = b = c. Тогда получим:

ВеличинаФормула
ОбъёмV = a³
Площадь всей поверхностиS = 6a²
Пространственная диагональD = a√3
Диагональ граниd = a√2

Площадь сразу через диагональ

Для вычисления площади поверхности достаточно знать квадрат диагонали:

S = 2D²    или    S = 3d²
Два коротких примера

Если пространственная диагональ равна 1, то площадь поверхности равна 2 · 1² = 2.

Если диагональ грани равна 3, то площадь поверхности равна 3 · 3² = 27.

05 / Текст → уравнение

Когда ребро изменили

Если ребро куба увеличили на 1, то новое ребро равно a + 1, новый объём — (a + 1)³. Если прирост объёма равен 19, составляем уравнение:

(a + 1)³ − a³ = 19

Раскроем куб суммы, не пропуская ни одного слагаемого:

(a + 1)³ = a³ + 3a² + 3a + 1.
Решение

3a² + 3a + 1 = 19 → a² + a − 6 = 0.

(a + 3)(a − 2) = 0. Так как длина положительна, a = 2.

Проверка: 3³ − 2³ = 27 − 8 = 19.

Если увеличили в несколько раз

При увеличении каждого ребра куба в k раз его объём увеличится в k³ раз. При k = 3 получаем 27 раз.

Различайте «увеличить на 3» и «увеличить в 3 раза»: это разные условия.

06 / Маршрут решения

Пять шагов для любой задачи

  1. Прочитайте вопрос: нужно найти объём, площадь или диагональ?
  2. Определите, куб дан или прямоугольный параллелепипед.
  3. Запишите формулу искомой величины и подставьте известные данные.
  4. Если не хватает ребра, найдите его через диагональ или условие об изменении объёма. Вернитесь к формуле.
  5. Проверьте положительность длин, расчёты и единицы измерения.

Основные ошибки: перепутать диагонали, забыть множитель 2 в площади, использовать D вместо D², потерять слагаемые при раскрытии куба суммы.
