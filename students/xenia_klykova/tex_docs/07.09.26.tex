\section*{1. Что показывает дерево вероятностей}
\sectionrule

Дерево вероятностей удобно использовать, когда случайный процесс проходит
\key{несколько последовательных этапов}.
Каждый узел показывает состояние после очередного этапа,
а каждая ветвь --- один возможный переход.

\begin{itemize}
    \item Из одного узла должны выходить все возможные продолжения процесса.
    \item Сумма вероятностей ветвей, выходящих из одного узла, равна \(1\).
    \item Полный путь от начала дерева до конечного состояния называют
    \key{траекторией}.
\end{itemize}

\section*{2. Главное правило: по пути умножаем, подходящие пути складываем}
\sectionrule

\key{Один конкретный путь.}
Если требуется, чтобы последовательно произошли события
\(A\), затем \(B\), затем \(C\), то

\[
\prob{A\cap B\cap C}
=
\prob{A}\,
\prob{B\mid A}\,
\prob{C\mid A\cap B}.
\]

На дереве это означает:

\[
\boxed{
\text{вероятности ветвей одного маршрута перемножаются}
}
\]

\key{Несколько подходящих путей.}
Если нужный результат достигается по взаимно исключающим траекториям
\(T_1,T_2,\ldots,T_k\), то

\[
\prob{T_1\cup T_2\cup\dots\cup T_k}
=
\prob{T_1}
+
\prob{T_2}
+
\dots
+
\prob{T_k}.
\]

То есть

\[
\boxed{
\text{вероятности подходящих несовместимых маршрутов складываются}
}
\]

\subsection*{Мини-пример: погода сохраняется или меняется}

Сегодня погода замечательная.
Вероятность того, что на следующий день она останется такой же,
равна \(0{,}8\).
Вероятность смены состояния равна \(0{,}2\).

Чтобы через два дня погода снова была замечательной,
подходят два пути:

\[
\text{З}\to\text{З}\to\text{З}
\]

или

\[
\text{З}\to\text{Х}\to\text{З}.
\]

Поэтому

\[
\prob{\text{З через два дня}}
=
0{,}8\cdot0{,}8
+
0{,}2\cdot0{,}2
=
0{,}68.
\]

\section*{3. Как читать длинное условие}
\sectionrule

В задачах с большим количеством текста сначала выделяйте
\key{события и этапы}.
Числа удобнее расставлять после того, как структура дерева уже понятна.

\begin{enumerate}
    \item Определите, что происходит первым:
    истинное состояние, первый опыт, первый день и т.\,п.

    \item Для каждого узла перечислите все возможные продолжения.

    \item Подпишите вероятности ветвей.

    \item Проверьте:
    сумма вероятностей ветвей из каждого узла должна быть равна \(1\).

    \item Отметьте конечные состояния, удовлетворяющие вопросу задачи.

    \item Для каждого подходящего пути перемножьте вероятности.

    \item Если подходящих несовместимых путей несколько,
    сложите полученные произведения.
\end{enumerate}

\key{Полезный приём.}
В задачах, связанных с последовательностью дней,
подписывайте даты или номера шагов рядом с уровнями дерева.
Это помогает избежать лишнего уровня разветвления.

\section*{4. Повторный анализ после отрицательного результата}
\sectionrule

Пусть для больного пациента вероятность ложноотрицательного
результата анализа равна \(0{,}3\).

Тогда вероятность положительного результата одного анализа:

\[
1-0{,}3=0{,}7.
\]

Если после отрицательного результата анализ проводят ещё раз
при тех же вероятностях,
заболевание будет выявлено

\[
\text{либо сразу,}
\]

\[
\text{либо после первого отрицательного результата на втором анализе.}
\]

Следовательно,

\[
\prob{\text{выявить заболевание за два анализа}}
=
0{,}7
+
0{,}3\cdot0{,}7
=
0{,}91.
\]

Можно рассуждать через противоположное событие:

\[
\prob{\text{не выявить за два анализа}}
=
0{,}3^2.
\]

Поэтому

\[
\prob{\text{выявить за два анализа}}
=
1-0{,}3^2
=
0{,}91.
\]

\section*{5. Диагностический тест: истинное состояние и результат анализа}
\sectionrule

В подобных задачах необходимо различать два уровня.

\begin{itemize}
    \item \key{Истинное состояние}:
    человек действительно болен или действительно здоров.

    \item \key{Результат теста}:
    анализ оказался положительным или отрицательным.
\end{itemize}

Обозначим

\[
D=\{\text{пациент действительно болен}\},
\]

\[
+=\{\text{анализ положительный}\}.
\]

Тогда дерево имеет следующий принципиальный вид.

\begin{center}
\begin{tikzpicture}[
    level distance=2.25cm,
    level 1/.style={sibling distance=7.0cm},
    level 2/.style={sibling distance=3.2cm},
    every node/.style={font=\small},
    edge from parent/.style={
        draw=accent,
        line width=0.9pt
    },
    state/.style={
        draw=darkaccent,
        rounded corners=2pt,
        inner sep=4pt,
        fill=softgray
    }
]
\node[state]{Пациент}
child {
    node[state]{Болен \(D\)}
    child {
        node[state]{Тест \(+\)}
        edge from parent
        node[left] {\(\prob{+\mid D}\)}
    }
    child {
        node[state]{Тест \(-\)}
        edge from parent
        node[right] {\(\prob{-\mid D}\)}
    }
    edge from parent
    node[left] {\(\prob{D}\)}
}
child {
    node[state]{Здоров \(\overline D\)}
    child {
        node[state]{Тест \(+\)}
        edge from parent
        node[left] {\(\prob{+\mid\overline D}\)}
    }
    child {
        node[state]{Тест \(-\)}
        edge from parent
        node[right] {\(\prob{-\mid\overline D}\)}
    }
    edge from parent
    node[right] {\(\prob{\overline D}\)}
};
\end{tikzpicture}
\end{center}

Основные величины:

\begin{itemize}
    \item
    \[
    \prob{+\mid D}
    \]
    --- \key{чувствительность теста};

    \item
    \[
    \prob{+\mid\overline D}
    \]
    --- вероятность \key{ложноположительного результата};

    \item
    \[
    \prob{-\mid D}
    \]
    --- вероятность \key{ложноотрицательного результата};

    \item
    \[
    \prob{D}
    \]
    --- доля действительно больных в рассматриваемой группе.
\end{itemize}

Слово «ложный» показывает, что результат теста
не совпал с истинным состоянием.

\[
\boxed{
\text{ложноположительный}
=
\text{здоров, но тест }+
}
\]

\[
\boxed{
\text{ложноотрицательный}
=
\text{болен, но тест }-
}
\]

\section*{6. Вероятность положительного результата}
\sectionrule

Положительный результат может появиться по двум несовместимым путям:

\[
D\to +
\]

или

\[
\overline D\to +.
\]

Следовательно,

\[
\boxed{
\prob{+}
=
\prob{D}\prob{+\mid D}
+
\prob{\overline D}\prob{+\mid\overline D}
}
\]

\subsection*{Пример}

Пусть

\[
\prob{D}=0{,}05,
\]

чувствительность теста равна

\[
\prob{+\mid D}=0{,}9,
\]

а вероятность ложноположительного результата

\[
\prob{+\mid\overline D}=0{,}01.
\]

Тогда

\[
\prob{\overline D}
=
1-0{,}05
=
0{,}95.
\]

По формуле полной вероятности:

\[
\prob{+}
=
0{,}05\cdot0{,}9
+
0{,}95\cdot0{,}01.
\]

Получаем

\[
\boxed{
\prob{+}=0{,}0545.
}
\]

\section*{7. Обратная задача: найти долю больных по доле положительных тестов}
\sectionrule

Пусть доля действительно больных неизвестна:

\[
\prob{D}=x.
\]

Тогда

\[
\prob{\overline D}=1-x.
\]

Пусть также

\[
\prob{+\mid D}=a,
\qquad
\prob{+\mid\overline D}=b,
\qquad
\prob{+}=r.
\]

По дереву вероятностей:

\[
ax+b(1-x)=r.
\]

Раскрываем скобки:

\[
ax+b-bx=r.
\]

Группируем:

\[
x(a-b)=r-b.
\]

Если \(a\ne b\), то

\[
\boxed{
x=\frac{r-b}{a-b}.
}
\]

\subsection*{Пример}

Пусть

\[
r=0{,}06,
\qquad
a=0{,}9,
\qquad
b=0{,}01.
\]

Тогда

\[
x
=
\frac{0{,}06-0{,}01}{0{,}9-0{,}01}
=
\frac{0{,}05}{0{,}89}
\approx
0{,}0562.
\]

Следовательно, доля действительно больных составляет примерно

\[
\boxed{5{,}62\%}.
\]

\section*{8. Вероятность болезни после положительного теста}
\sectionrule

Теперь вопрос имеет другой смысл:

\[
\text{тест уже положительный;}
\]

требуется узнать вероятность того, что пациент действительно болен.

Ищем условную вероятность

\[
\prob{D\mid +}.
\]

Используется формула

\[
\boxed{
\prob{D\mid +}
=
\frac{
\prob{D}\prob{+\mid D}
}{
\prob{+}
}.
}
\]

Знаменатель предварительно вычисляется по дереву:

\[
\prob{+}
=
\prob{D}\prob{+\mid D}
+
\prob{\overline D}\prob{+\mid\overline D}.
\]

Для примера

\[
\prob{D}=0{,}05,
\qquad
\prob{+\mid D}=0{,}9,
\qquad
\prob{+\mid\overline D}=0{,}01
\]

мы уже получили

\[
\prob{+}=0{,}0545.
\]

Поэтому

\[
\prob{D\mid +}
=
\frac{0{,}05\cdot0{,}9}{0{,}0545}
\approx
0{,}8257.
\]

То есть

\[
\boxed{
\prob{D\mid +}\approx82{,}57\%.
}
\]

Важно различать:

\[
\prob{D}
\]

--- долю больных во всей группе,

и

\[
\prob{D\mid +}
\]

--- вероятность болезни среди людей,
у которых тест уже оказался положительным.

Это \key{разные величины}.

\section*{9. Быстрый алгоритм решения}
\sectionrule

Перед вычислениями пройдите по следующему чек-листу.

\begin{enumerate}
    \item Что является первым этапом процесса?

    \item Какие исходы возможны на первом этапе?

    \item Какие исходы возможны после каждого из них?

    \item Сумма вероятностей из каждого узла равна \(1\)?

    \item Какие конечные ветви удовлетворяют вопросу?

    \item Для каждого подходящего пути:
    \[
    \text{умножить вероятности вдоль ветви}.
    \]

    \item Для нескольких подходящих несовместимых путей:
    \[
    \text{сложить полученные произведения}.
    \]

    \item Проверить, какую именно вероятность спрашивают:
    \[
    \prob{+},
    \qquad
    \prob{D},
    \qquad
    \prob{D\mid +}.
    \]
\end{enumerate}

\section*{10. Типичные ошибки и самопроверка}
\sectionrule

\begin{itemize}
    \item
    \key{Лишний уровень дерева.}
    Подписывайте даты или номера этапов.

    \item
    \key{Неверная операция.}
    Вдоль одного пути вероятности перемножаются;
    разные подходящие несовместимые пути складываются.

    \item
    \key{Перепутаны истинное состояние и результат теста.}
    Сначала определяется реальное состояние,
    затем результат анализа.

    \item
    \key{Неверно прочитан ложный результат.}
    Ложноположительный означает
    \[
    \overline D\to +.
    \]
    Ложноотрицательный означает
    \[
    D\to -.
    \]

    \item
    \key{Нарушена сумма ветвей.}
    Из одного узла сумма вероятностей должна равняться \(1\).

    \item
    \key{Смешаны разные вопросы.}
    «Какова доля больных?» и
    «Какова вероятность болезни при положительном тесте?»
    требуют разных вычислений.

    \item
    \key{Правильная модель испорчена арифметикой.}
    После составления выражения отдельно перепроверяйте
    десятичные дроби, раскрытие скобок и переносы.
\end{itemize}

\section*{Тренировочный блок}
\sectionrule

\textbf{Уровень: средний}

\begin{enumerate}

    \item
    Сегодня погода ясная.
    Вероятность того, что на следующий день погода сохранится,
    равна \(0{,}75\),
    а изменится --- \(0{,}25\).

    Найдите вероятность того,
    что через два дня погода снова будет ясной.

    \item
    У больного пациента анализ даёт отрицательный результат
    с вероятностью \(0{,}2\).

    После отрицательного результата анализ повторяют один раз
    при тех же вероятностях.

    Найдите вероятность того,
    что заболевание будет выявлено хотя бы одним
    из двух анализов.

    \item
    С вероятностью \(0{,}4\) деталь поступает с линии \(A\),
    с вероятностью \(0{,}6\) --- с линии \(B\).

    На линии \(A\) вероятность получить годную деталь равна \(0{,}7\),
    на линии \(B\) --- \(0{,}2\).

    Найдите вероятность получить годную деталь.

\end{enumerate}

\textbf{Уровень: выше среднего}

\begin{enumerate}[resume]

    \item
    Система имеет два состояния: \(A\) и \(B\).

    На каждом шаге она сохраняет текущее состояние
    с вероятностью \(0{,}8\)
    и меняет его с вероятностью \(0{,}2\).

    Изначально система находится в состоянии \(A\).

    Найдите вероятность того,
    что после трёх шагов она будет находиться в состоянии \(A\).

    \item
    В группе пациентов \(4\%\) действительно больны.

    Чувствительность теста равна \(0{,}92\),
    вероятность ложноположительного результата --- \(0{,}03\).

    Найдите вероятность положительного результата
    у случайно выбранного пациента.

    \item
    Общая доля положительных тестов в группе равна \(0{,}08\).

    Чувствительность теста равна \(0{,}95\),
    вероятность ложноположительного результата --- \(0{,}02\).

    Найдите долю действительно больных в группе.

    \item
    У больного пациента чувствительность каждого анализа равна \(0{,}85\).

    После отрицательного результата анализ повторяют.
    Всего проводят не более трёх анализов.

    Считайте результаты независимыми
    при фиксированном истинном состоянии пациента.

    Найдите вероятность выявить заболевание
    хотя бы одним анализом.

    \item
    Доля дефектных изделий равна \(0{,}10\).

    Контроль даёт положительный сигнал
