01Смещение

Главная идея

Конец минус начало

Пусть A(xA;yA) и B(xB;yB). Координаты направленного вектора из A в B получают вычитанием координат начала из координат конца.

AB→=(xB−xA;yB−yA)
По знаку.

x>0 — вправо, x<0 — влево; y>0 — вверх, y<0 — вниз.

Обратный вектор.
BA→=−AB→

Проверить смену направления

02Операции

Координаты как рабочий язык

Длина, сумма, разность и умножение на число

Длина

|a→|=x2+y2

Для a→=(3;4) длина равна 5.

Квадрат длины

|a→|2=x2+y2

Если в условии просят квадрат длины, извлекать корень не требуется.

Сложение: соответствующие координаты складываются.

a→+b→=(x1+x2;y1+y2)

Вычитание: соответствующие координаты вычитаются.

a→−b→=(x1−x2;y1−y2)

Умножение на число: умножаются обе координаты.

ka→=(kx;ky)

03Число из двух векторов

Два равноправных способа

Скалярное произведение

Скалярное произведение — число. Его можно вычислить через координаты либо через длины векторов и косинус угла между ними.

По координатам
a→·b→=x1x2+y1y2
Через угол
a→·b→=|a→|·|b→|·cosφ

Для p→=(1;2) и q→=(3;4) получаем p→·q→=11.

04Алгоритм

От координат к углу

Как найти cos φ

Определите координаты обоих векторов. Если один из них нулевой, формулу для угла использовать нельзя.
Найдите скалярное произведение через соответствующие координаты.
Найдите длины обоих векторов.
Разделите скалярное произведение на произведение длин:
cosφ=a→·b→|a→|·|b→|
Перпендикулярность. Для ненулевых векторов a→·b→=0 означает cosφ=0, поэтому угол равен 90°.

Увидеть случай угла 90°

05Контроль

Проверка перед ответом

Пять мест, где легко потерять балл

Порядок точек.

Для AB→ используется именно «конец − начало».

Знак при вычитании.

Отрицательную координату заключайте в скобки: 6−(−2)=8.

Квадрат отрицательного.

(−3)2=9.

Корень по сумме не разбивается.

a+b≠a+b.

Угол требует двух ненулевых векторов.

В знаменателе формулы для cosφ стоят обе длины.
