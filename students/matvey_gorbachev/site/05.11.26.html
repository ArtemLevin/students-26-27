От формулы производной к поведению функции

На занятии мы перешли от геометрического смысла производной к её вычислению. Теперь можно по формуле определить, где функция растёт, где убывает и где достигает локального экстремума.

Центральная идеяЗнак f′ → направление f

f′(x) > 0 — функция возрастает; f′(x) < 0 — убывает. Для экстремума проверяем смену знака по обе стороны критической точки.

Производная равна нулю — только кандидат в экстремум.

01 / ПРАВИЛА

Сначала узнаём форму выражения

При вычислении производной по переменной x остальные буквенные коэффициенты считаются постоянными. Производная постоянного числа равна нулю. Если постоянный множитель умножается на функцию, он сохраняется.

Константа(C)′ = 0
Степень(xⁿ)′ = nxⁿ⁻¹
Сумма и разность(u ± v)′ = u′ ± v′
Постоянный множитель(Cu)′ = Cu′
Корень, x > 0(√x)′ = 1/(2√x)
Показательная функция(aˣ)′ = aˣ ln a; a > 0, a ≠ 1
Экспонента(eˣ)′ = eˣ
Синус и косинус(sin x)′ = cos x; (cos x)′ = −sin x
Тангенс, cos x ≠ 0(tg x)′ = 1/cos²x
Котангенс, sin x ≠ 0(ctg x)′ = −1/sin²x

Как работать со степенью с дробным показателем

Перепишите x√x как x3/2. Тогда:

x32→32x, x>0

Проверка: (7x²)′ = 14x, а (7 + x²)′ = 2x. Расположение константы меняет правило.

02 / ДВА ВЫРАЖЕНИЯ

Умножение и деление требуют своих формул

Произведение
(uv)′=u′v+uv′
Частное
(uv)′=u′v−uv′v2

Оформление для обеих формул: отдельно выпишите u, v, u′, v′. Для дроби дополнительно проверяйте v(x) ≠ 0.

Общий пример с урока

Возьмём u = x² + 4 и v = x³ − 5x. Их производные: u′ = 2x, v′ = 3x² − 5.

Произведение:

2x(x³ − 5x) + (x² + 4)(3x² − 5).

Частное:

[2x(x³ − 5x) − (x² + 4)(3x² − 5)]/(x³ − 5x)².

ОДЗ дроби: x ≠ −√5, 0, √5.

Частая ошибка: в числителе частного сначала стоит u′v, затем вычитается uv′. В знаменателе остаётся квадрат исходного v.

03 / ТРИГОНОМЕТРИЯ

Знаки производных тригонометрических функций

Синус переходит в косинус, косинус — в отрицательный синус. Через правила частного и произведения получаем полезные тождества:

Частное sin x / cos x(tg x)′ = 1/cos²x
Произведение sin x · cos x(sin x cos x)′ = cos²x − sin²x = cos 2x

Формула тангенса действует при cos x ≠ 0. Для котангенса: (ctg x)′ = −1/sin²x при sin x ≠ 0.

04 / ПОКАЗАТЕЛЬНАЯ

Основание сохраняем, логарифм добавляем

Для aˣ производная повторяет исходную степень и содержит множитель ln a. Для числа e натуральный логарифм равен единице, поэтому (eˣ)′ = eˣ.

ax→axlna, a>0

Если P — константа, то (P·2ˣ)′ = P·2ˣ ln 2.

05 / СЛОЖНАЯ ФУНКЦИЯ

Сначала внешняя, затем внутренняя

Если внутри степени, косинуса или показательной функции стоит целое выражение, сначала выделите внутреннюю функцию m = g(x). Затем умножьте производную внешней функции на m′(x).

y=F(g(x))⇒y′=F′(g(x))·g′(x)

Разберите по шагам: (5x − 3)10

Шаг 1

Внутренняя функция

m(x) = 5x − 3. Её производная равна m′(x) = 5.

Шаг 2

Внешняя функция

Выражение m10 имеет производную 10m9.

Шаг 3

Возвращаем внутреннее выражение

Получаем 10(5x − 3)9 и обязательно умножаем на m′ = 5.

Шаг 4

Итог

y′ = 50(5x − 3)9.

Показательная сложная функция[2^(x² − x − 6)]′ = (2x−1)·2^(x²−x−6)·ln 2
Экспонента[e^(−3x + 5)]′ = −3e^(−3x + 5)
Ловушка: после дифференцирования степени внутри скобок остаётся всё выражение 5x − 3. Дополнительный множитель 5 — производная внутренней функции.
06 / ИССЛЕДОВАНИЕ

Таблица знаков открывает экстремумы

Метод: найти ОДЗ; вычислить f′(x); отметить точки, где f′(x) = 0 или производная не существует при существующей функции; определить знак на каждом интервале; сделать вывод.

f′ > 0Функция возрастает
f′ < 0Функция убывает
+ → −Локальный максимум
− → +Локальный минимум
f′ = 0Проверяем смену знака
Вне ОДЗТочку исключаем

Пример: f(x) = x² − x − 6

Производная f′(x) = 2x − 1 обнуляется при x = 1/2. Слева она отрицательна, справа положительна.

Знак производной и направление функции
x(−∞; 1/2)1/2(1/2; +∞)
f′(x)−0+
f(x)↘ убываетминимум↗ возрастает

Минимум в точке x = 1/2, значение f(1/2) = −25/4.

Пример с двумя критическими точками

Для f(x) = x³/3 − x²/2 − 6x + 7 имеем f′(x) = (x + 2)(x − 3). Знаки на интервалах: + / − / +. Поэтому при x = −2 локальный максимум, при x = 3 локальный минимум.

Измените x — наблюдайте знак f′

В лаборатории можно двигать точку по графику функции и сравнивать её положение со знаком производной. Выделены примеры из этого чек-листа.

Не полагайтесь на автоматическое чередование знаков: при переходе через корень чётной кратности знак не меняется. Нужна пробная точка на каждом промежутке.

07 / ДРОБИ И ОГРАНИЧЕНИЯ

Область определения определяет маршрут

В примере f(x) = 2/(x² − 4) знаменатель нельзя обращать в нуль: x ≠ −2, x ≠ 2.

f′(x)=−4x(x2−4)2

Производная положительна при отрицательных x и отрицательна при положительных, но на оси нужно отделить все четыре интервала: (−∞;−2), (−2;0), (0;2), (2;+∞).

Локальный максимум: f(0) = −1/2. Глобального максимума нет: на интервале справа от 2 значения неограниченно растут при приближении к разрыву.

При постоянном положительном числителе знак производной дроби противоположен знаку производной знаменателя на каждом промежутке ОДЗ. Если числитель зависит от x, требуется исследовать всю дробь.

08 / ПУТЬ А

Десять задач для самостоятельной работы

Задания расположены от базовых производных к исследованию монотонности. Для задач 9–10 укажите все промежутки, ОДЗ и значения локальных экстремумов. Ответы раскрываются по одному, когда Вы завершили собственное решение.

  1. Задание 01

    Найдите производную:

    y = 7x⁴ − 3x² + 9

    Посмотреть ответ

    y′ = 28x³ − 6x.

  2. Задание 02

    Найдите производную при x > 0:

    y = x√x + 4/x

    Посмотреть ответ

    y′ = (3/2)√x − 4/x²; x > 0.

  3. Задание 03

    Найдите производную произведения:

    y = (x² − 3)(x³ + 2x)

    Посмотреть ответ

    y′ = 5x⁴ − 3x² − 6.

  4. Задание 04

    Найдите производную частного:

    y = (2x + 1)/(x² + 1)

    Посмотреть ответ

    y′ = (−2x² − 2x + 2)/(x² + 1)².

  5. Задание 05

    Найдите производную:

    y = sin x · cos x

    Посмотреть ответ

    y′ = cos²x − sin²x = cos 2x.

  6. Задание 06

    Найдите производную сложной функции:

    y = (3x − 2)⁷

    Посмотреть ответ

    y′ = 21(3x − 2)⁶.

  7. Задание 07

    Найдите производную:

    y = cos(2x² − 5x)

    Посмотреть ответ

    y′ = −(4x − 5)sin(2x² − 5x).

  8. Задание 08

    Найдите производную:

    y = 5^(x² − 2x)

    Посмотреть ответ

    y′ = (2x − 2)·5^(x² − 2x)·ln 5.

  9. Задание 09

    Исследуйте возрастание, убывание и локальные экстремумы:

    f(x) = x³ − 3x

    Посмотреть ответ

    f′ = 3(x − 1)(x + 1); возрастает на (−∞;−1) и (1;+∞), убывает на (−1;1). Максимум f(−1)=2; минимум f(1)=−2.

  10. Задание 10

    Определите ОДЗ, монотонность и локальные экстремумы:

    f(x) = 2/(x² − 9)

    Посмотреть ответ

    x ≠ −3,3; f′=−4x/(x²−9)². Возрастает на (−∞;−3) и (−3;0); убывает на (0;3) и (3;+∞). Максимум f(0)=−2/9; минимума нет.
