Производная — наклон касательной

Как определить скорость изменения функции по прямой, найти знак производной и проверить касание двух графиков. Главный маршрут: чертёж → угловой коэффициент → система условий касания.

Производная в точке равна угловому коэффициенту касательной, если производная существует.

Знак, величина и точка касания — три отдельных вопроса.

01 / ГЕОМЕТРИЯ

Из двух точек — к производной

Если на касательной известны две точки A(x₁; y₁) и B(x₂; y₂), найдите изменение координат. Вертикальное изменение делят на горизонтальное. Желательно выбирать узловые точки с целочисленными координатами.

f′(x0)=k=y2−y1x2−x1,x1≠x2

Важен знак: касательная поднимается → k положителен; опускается → k отрицателен; горизонтальна → k = 0.

Передвинуть точку касания и увидеть изменение наклона ↗
02 / ПРЯМАЯ

Уравнение раскрывает угол

У невертикальной прямой y = kx + b угловой коэффициент — это число k. Свободный член b меняет положение прямой, но сохраняет её наклон.

Касательная y = −3x + 7

Производная в точке касания равна −3.

Касательная параллельна y = 5x − 2

У параллельных невертикальных прямых коэффициенты одинаковы. Производная равна 5.

Касательная, параллельная y = −20, горизонтальна: k = 0, следовательно, f′(x₀) = 0.

Тонкость. Из равенства f′(x₀) = 0 не следует автоматически, что в этой точке есть максимум или минимум. Требуется исследовать поведение функции по сторонам точки.
03 / ЧТЕНИЕ ГРАФИКОВ

Что именно изображено?

Первый вопрос при решении графической задачи: перед Вами график f(x) или график f′(x)? На графике производной знак считывают по положению относительно оси Ox.

Дан графикКак рассуждать
y = f(x)На участках возрастания f′ > 0; на участках убывания f′ < 0, где производная существует.
y = f′(x)Выше Ox: функция возрастает. Ниже Ox: убывает. В нулях производной возможны экстремумы.
Знак f′: + → −Точка максимума функции.
Знак f′: − → +Точка минимума функции.

Например, f′(x) = x² − 4 положительна при x < −2 и x > 2, отрицательна между −2 и 2. Значит, максимум при x = −2, минимум при x = 2.

Контрпример: у f(x) = x³ производная в нуле равна нулю, но экстремума нет.

04 / УСЛОВИЯ КАСАНИЯ

Одна точка. Два равенства.

Если прямая g(x) = kx + b касается графика f(x) при x = x₀, одновременно выполняются два условия: совпадает наклон и совпадает высота точек.

{f′(x0)=kf(x0)=kx0+b

Первая строка даёт кандидатов. Вторая позволяет проверить, что касательная действительно проходит через точку графика.

Пример: несколько кандидатов

Для f(x) = x³ − 2x² − 6x − 4 и прямой y = −2x − 12 рассмотрим проверку касания.

Шаг 1 / Наклон

f′(x) = 3x² − 4x − 6 = −2

Приравниваем производную угловому коэффициенту прямой.

Шаг 2 / Кандидаты

3x² − 4x − 4 = 0 → x = 2 или x = −2/3

Уравнение производных дало две возможные абсциссы касания.

Шаг 3 / Совпадение высоты

f(2) = −16;  g(2) = −16

Для x = −2/3: f(x) = −32/27, а g(x) = −32/3. Эти значения различаются.

Шаг 4 / Ответ

Абсцисса касания x₀ = 2. Проверены оба условия системы.

1 из 4

Параметр ищется той же системой

Если y = x − 3 касается f(x) = ax² + 3x − 2, то

2ax₀ + 3 = 1;  ax₀² + 3x₀ − 2 = x₀ − 3.

Из первого равенства ax₀ = −1, из второго и подстановки получаем x₀ = −1, а затем a = 1.

Типичная ошибка: после решения только f′(x₀) = k объявить все найденные корни точками касания. Проверяйте вторую строку системы.
