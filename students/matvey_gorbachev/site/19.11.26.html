01 / Пространство

Начните с системы координат

Выберите вершину A началом координат. Направьте оси вдоль трёх взаимно перпендикулярных рёбер AB, AD и AA₁.

A(0; 0; 0) · B(a; 0; 0) · D(0; a; 0) · A₁(0; 0; a)

Для середины отрезка усредните каждую координату его концов. В частности, середина BB₁ имеет координаты M(a; 0; a/2).

Выберите пример

Плоскость α: AMC₁

Единичный куб: A(0; 0; 0), M(1; 0; 1/2), C₁(1; 1; 1).

x + y − 2z = 0

Проверка по C₁: 1 + 1 − 2 = 0.

Две изображённые плоскости относятся к примерам с разным размером ребра куба. Для α ребро равно 1, для β — 2. Схема показывает расположение точек, а численные координаты приведены рядом.

02 / Принцип

Уравнение задаёт нормаль

Ax+By+Cz+D=0

Тройка коэффициентов при x, y, z образует нормальный вектор n = (A; B; C). Он перпендикулярен плоскости. Коэффициенты A, B, C не могут одновременно равняться нулю.

Через начало координат

D = 0

Подстановка точки (0; 0; 0) в уравнение.

Проверка принадлежности

Ax + By + Cz + D = 0

Подставьте координаты точки и проверьте равенство.

Проверяйте знак. Для плоскости α у коэффициента при y стоит плюс. Замена плюса на минус нарушит проверку точки C₁.

Разбор / AMC₁

Второй пример: плоскость MTQ

При ребре куба 2 заданы точки M(2; 0; 1), T(1; 0; 0), Q(0; 1; 0).

Подставьте точки в Ax + By + Cz + D = 0: получатся 2A + C + D = 0, A + D = 0, B + D = 0.

Выберите D = 1. Тогда A = −1, B = −1, C = 1.

Умножьте все коэффициенты на −1: β: x + y − z − 1 = 0; нормаль nβ = (1; 1; −1).

Проверка: M: 2 − 1 − 1 = 0; T: 1 − 1 = 0; Q: 1 − 1 = 0.

04 / Угол

Угол между плоскостями через нормали

Для меньшего угла между плоскостями используйте модуль скалярного произведения нормалей:

cos⁡φ=|n1·n2||n1|·|n2|

Из найденных уравнений: nα = (1; 1; −2) и nβ = (1; 1; −1).

Скалярное произведение: 1 · 1 + 1 · 1 + (−2) · (−1) = 4.

Длины: |nα| = √6, |nβ| = √3.

Косинус: 4/(√6 · √3) = 2√2/3.

Меньший угол: φ = arccos(2√2/3) ≈ 19,47°.

Смысл модуля: нормаль может иметь противоположное направление, но угол между самими плоскостями от этого не меняется.

06 / Практика

Десять задач на закрепление

Выполните задания по порядку. Ответы раскрываются отдельно, чтобы можно было свериться после решения. Для уравнений плоскостей используйте целые коэффициенты без общего делителя.

Базовый уровень · 1–3

01 / Координаты

В кубе ABCDA₁B₁C₁D₁ с ребром 6 оси Ax, Ay, Az направлены вдоль AB, AD, AA₁. Найдите координаты середин M ребра BB₁, T ребра AB, Q ребра AD.

Проверить ответ

M(6; 0; 3), T(3; 0; 0), Q(0; 3; 0).

02 / Вектор

Для P(1; −2; 3) и Q(4; 0; 1) найдите координаты вектора PQ и его длину.

Проверить ответ

PQ = (3; 2; −2), |PQ| = √17.

03 / Скалярное произведение

Для u = (2; −1; 2), v = (1; 2; 0) найдите u · v, |u|, |v| и угол между ними.

Проверить ответ

u · v = 0; |u| = 3; |v| = √5; угол 90°.

Средний уровень · 4–7

04 / Нормаль

Для плоскости 3x − y + 2z − 5 = 0 укажите нормальный вектор. Принадлежат ли ей X(1; 0; 1) и Y(1; 1; 1)?

Проверить ответ

n = (3; −1; 2). Точка X принадлежит; точка Y не принадлежит плоскости.

05 / Плоскость через O

Составьте уравнение плоскости через O(0; 0; 0), P(2; 0; 1), Q(0; 3; 1).

Проверить ответ

3x + 2y − 6z = 0.

06 / Три точки

Составьте уравнение плоскости через P(2; 0; 0), Q(0; 2; 0), R(0; 0; 4).

Проверить ответ

2x + 2y + z − 4 = 0.

07 / Проверка

Составьте уравнение плоскости через P(3; 0; 1), Q(1; 0; 0), R(0; 2; 0). Проверьте подстановкой.

Проверить ответ

2x + y − 4z − 2 = 0.

Повышенный уровень · 8–10

08 / Косинус угла

Найдите косинус меньшего угла между плоскостями 2x − y + 2z + 1 = 0 и x + 2y − 2z − 3 = 0.

Проверить ответ

cos φ = 4/9.

09 / Угол между плоскостями

Найдите меньший угол между плоскостями x + y − 2z = 0 и x + y + 2z − 2 = 0. Запишите через арккосинус.

Проверить ответ

φ = arccos(1/3) ≈ 70,53°.

10 / Две плоскости

Плоскость α проходит через M(2; 0; 1), T(1; 0; 0), Q(0; 1; 0). Плоскость β — через O(0; 0; 0), E(2; 0; 2), F(0; 2; 1). Составьте уравнения и найдите косинус меньшего угла.

Проверить ответ

α: x + y − z − 1 = 0; β: 2x + y − 2z = 0; cos φ = 5√3/9.
