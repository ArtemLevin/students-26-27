Неравенства · логарифмы

−1 ≤ log₂|4−x| ≤ 7/2

Точка x = 4 исключена из ОДЗ; границы ответа определяются двойным неравенством.

01 / ДопустимостьПеред каждым преобразованием

Сначала — область определения

Для логарифма logab одновременно необходимы три условия: положительное основание, основание отлично от единицы, положительный аргумент.

a > 0;  a ≠ 1;  b > 0.
Пример 1 / ОДЗ

logx+1((x−2)2)

x+1 > 0, x+1 ≠ 1, (x−2)2 > 0.

x > −1,  x ≠ 0,  x ≠ 2.

Чётная степень неотрицательна; её значение равно нулю только при нулевом основании степени. Аргумент логарифма обязан быть строго положительным.

02 / РедукцияСтепень под логарифмом

Чётная степень сохраняет модуль

После вынесения чётной степени модуль под логарифмом обязателен: основание степени может быть отрицательным.

loga(B2n) = 2n · loga|B|a > 0, a ≠ 1, B ≠ 0, n — натуральное.
Пример 2 / Единое основание

log8((4−x)4) = (4/3) log2|4−x|

log0,5((4−x)8) = −8 log2|4−x|

В первом случае 8 = 23. Во втором 0,5 = 2−1, поэтому появляется минус.

Проверьте знак. Для основания 0,5 коэффициент перед log2 отрицателен.
03 / СведениеОдин логарифм — одна переменная

Замена превращает неравенство в квадратное

9[log8((4−x)4)]2 + 5 log0,5((4−x)8) ≤ 56

  1. ОДЗ. Оба аргумента положительны при x ≠ 4.

  2. После приведения логарифмов к основанию 2 коэффициент перед квадратом равен 16:

    16(log2|4−x|)2 − 40 log2|4−x| − 56 ≤ 0.

  3. Вводим t = log2|4−x|, делим на 8:

    2t2 − 5t − 7 ≤ 0.

  4. Дискриминант равен 81, корни −1 и 7/2. Ветви параболы направлены вверх.

    −1 ≤ t ≤ 7/2.

  5. Обратная замена с основанием 2 сохраняет направления неравенств.

    1/2 ≤ |4−x| ≤ 8√2.
Исследовать ответ на числовой прямой
04 / ВозвратСистемы и совокупности

Модуль разделяет ответ на промежутки

Не меньше

|F| ≥ c ⇔ F ≥ c или F ≤ −c

Совокупность: объединяем найденные множества.

Не больше

|F| ≤ c ⇔ −c ≤ F ≤ c

Система: одновременно выполняются оба ограничения.

Здесь c ≥ 0. Для строгих знаков границы также становятся строгими.

Завершение примера 3

Из |4−x| ≥ 1/2 получаем x ≤ 7/2 или x ≥ 9/2.

Из |4−x| ≤ 8√2 получаем 4−8√2 ≤ x ≤ 4+8√2. Пересекаем результаты.

[4−8√2; 7/2] ∪ [9/2; 4+8√2].

Ключевая проверка. Точка x = 4 лежит внутри исключённого промежутка и не входит в ответ.

05 / ОснованиеПеременная меняет монотонность

Когда основание зависит от x

Если основания двух логарифмов одинаковы, сначала проверяют a(x) > 0, a(x) ≠ 1 и положительность обоих аргументов. Затем сравнение аргументов зависит от положения основания относительно единицы.

loga(x)F(x) ≥ loga(x)G(x)
⇔ (a(x)−1)(F(x)−G(x)) ≥ 0.Равносильность действует только совместно с ОДЗ.
Пример 4 / Единица справа

logx+1(x2+x−6) ≥ 1.

С учётом (x+3)(x−2) > 0 и x+1 > 0 получаем x > 2. Основание больше единицы.

1 = logx+1(x+1)

x2+x−6 ≥ x+1 ⇔ x2−7 ≥ 0.

x ∈ [√7; +∞).

Найдите корни сравнения и обязательно пересеките их множество с областью допустимых значений.
