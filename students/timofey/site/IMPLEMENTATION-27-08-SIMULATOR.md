## Learning outcomes

1. Translate a practical constraint into an equation or inequality boundary.
2. See how changing the required height moves parabola roots and can remove real solutions.
3. Convert ΔL from millimetres to metres before using the thermal-expansion model.
4. Observe the direct proportionality T ∝ ΔL for fixed L₀ and α.
5. Observe the fourth-root sensitivity T ∝ (P/(σS))^(1/4).
6. Apply exponent subtraction correctly when the denominator exponent is negative.
7. Select a mathematically valid result according to the wording and physical meaning of the task.

## Architecture

`27.08.26-simulator.js` owns state, pure calculations, scenarios, validation, rendering, animation and interaction. The HTML page contains the educational content and UI containers. Pure calculation functions are exported for regression testing.
