02 · Степени и корни

Приведите обе части к одному основанию

1/aⁿ = a⁻ⁿ    ·    ᵏ√(aᵐ) = aᵐ⁄ᵏ    ·    (aᵐ)ⁿ = aᵐⁿ
aᵘ = aᵛ,   a > 0, a ≠ 1   ⇒   u = v
Представьте обе части как степени одного основания.
Сравните показатели.
Решите полученное алгебраическое уравнение.
Проверьте дополнительные ограничения, если в исходной записи были знаменатели или корни.
Частая ошибка: потерять минус при переходе 1/aⁿ = a⁻ⁿ.

Пример: одинаковое основание

Что дано
4ˣ⁻⁷ = 1/64
Смысл условия
Число 64 — степень 4, поэтому обе части легко записать с основанием 4.
1/64 = 4⁻³.
4ˣ⁻⁷ = 4⁻³ ⇒ x − 7 = −3.
x = 4.
Ответ: 4.

Пример: корни как дробные степени

Что дано
∛2 / 8ˣ = ⁵√64.
Переходим к основанию 2: 2¹⁄³⁻³ˣ = 2⁶⁄⁵.
Сравниваем показатели: 1/3 − 3x = 6/5.
Получаем x = −13/45.
Ответ: −13/45.

03 · Иррациональные уравнения

У правой части есть обязательное знаковое условие

√f(x) = g(x)   ⇔   { g(x) ≥ 0;   f(x) = g²(x) }

Арифметический квадратный корень всегда неотрицателен. Поэтому перед возведением в квадрат фиксируйте условие g(x) ≥ 0.

Запишите условие на часть без корня.
Возведите обе части в квадрат.
Решите полученное уравнение.
Отберите корни по исходному ограничению.
Лишние корни возможны. Возведение в квадрат может дать значения, которых исходное уравнение не допускает.

Пример 1: √(x+6)=x

Что дано
√(x+6)=x
Смысл условия
Правая часть должна быть неотрицательна: x ≥ 0.
x ≥ 0.
x+6=x².
x²−x−6=0 ⇒ x=−2 или x=3.
Значение −2 не проходит ограничение, остаётся 3.
Ответ: 3.

Пример 2: √(3x+4)=−x

−x ≥ 0 ⇒ x ≤ 0.
3x+4=x².
x²−3x−4=0 ⇒ x=4 или x=−1.
Ограничение x≤0 оставляет только −1.
Ответ: −1.

04 · Логарифмы

Определение логарифма + ОДЗ

logₐ b = c   ⇔   b = aᶜ
Основание
a > 0, a ≠ 1.
Аргумент
b > 0.

Если основание в конкретном уравнении уже задано корректным числом, отдельно доказывать это не требуется. Аргументы логарифмов при этом всё равно должны оставаться положительными.

logₐu − logₐv = logₐ(u/v),   при u>0 и v>0

Пример: log₈(5x+47)=3

По определению логарифма: 5x+47=8³=512.
5x=465.
x=93.
Проверка аргумента: 5·93+47=512>0.
Ответ: 93.

Пример: log₂(x+1)=log₂x−1

ОДЗ: x+1>0 и x>0, то есть x>0.
1=log₂2, поэтому log₂(x+1)=log₂(x/2).
x+1=x/2 ⇒ x=−2.
−2 не входит в ОДЗ.
Решений нет.

05 · Тригонометрия

Узнайте структуру двойного угла

sin 2α = 2 sin α cos α
cos 2α = cos²α − sin²α = 2cos²α − 1 = 1 − 2sin²α
Сверните произведение по формуле двойного угла.
Приведите полученный угол к табличному.
Определите четверть и знак функции.
Подставьте табличное значение.
Контроль: коэффициент перед произведением, период и знак в четверти должны быть учтены.

Пример: 3 sin(13π/12) cos(13π/12)

Что дано
Произведение синуса и косинуса одного угла.
Идея решения
Добавить коэффициент 2 внутри структуры двойного угла.
3 sin α cos α = (3/2) sin 2α.
При α=13π/12 получаем (3/2)sin(13π/6).
13π/6=2π+π/6, значит синус равен 1/2.
(3/2)·(1/2)=3/4.
Ответ: 3/4 = 0,75.

Ещё один разобранный переход

5 cos(13π/8) sin(−13π/8) = −(5/2) sin(13π/4).

13π/4=3π+π/4, поэтому sin(13π/4)=−√2/2.

Итог: 5√2/4.

06 · Производная

Читайте знак графика f′(x)

f′(x)>0
Функция f возрастает.
f′(x)<0
Функция f убывает.
+ → −
Локальный максимум f.
− → +
Локальный минимум f.
Важно: равенство f′(x₀)=0 само по себе не гарантирует экстремум. Нужна смена знака производной.
Частая ошибка: забыть, чей график дан. Если изображён f′, выводы о возрастании, убывании и экстремумах делаются для f.

Производная через касательную

f′(x₀) = k = tg α = Δy / Δx
Касательная идёт вверх
k>0.
Касательная идёт вниз
k<0.
Возьмите две удобные узловые точки на касательной.
Сосчитайте вертикальное изменение Δy и горизонтальное Δx.
Найдите отношение Δy/Δx.
Проверьте знак по направлению касательной.

В разобранных примерах: 8/5=1,6 для возрастающей касательной и −2/8=−0,25 для убывающей.

Формулировки, которые важно различать

Точка максимума
Ищут значение x.
Наименьшее значение функции
Ищут число f(x).

Если функция возрастает на всём отрезке [a;b], наименьшее значение достигается при x=a, наибольшее — при x=b.
