Производная и оптимизация

Как исследовать функцию, различать переменную и константы, применять цепное правило и находить максимум в прикладной модели.

К теорииОткрыть цифровую лабораториюPDFTeX

Главное правило

(F(g(x)))′
= F′(g(x)) · g′(x)

Сначала внешняя производная, затем внутренняя. В задачах на максимум после этого обязательно исследовать знак.

01 / База

Сначала выясняем, где функция меняет направление.

Знак производной определяет движение функции

Внутри промежутка определения при f′(x) > 0 функция возрастает, при f′(x) < 0 — убывает. В точке смены знака находим экстремум.

Точка минимума
− → +
Убывает, затем возрастает
Точка максимума
+ → −
Возрастает, затем убывает
Из занятия

f(x)=x²−x−6,   f′(x)=2x−1.

Производная обращается в нуль при x=1/2. До этой точки знак отрицательный, после — положительный.

Точка минимума: x = 1/2. Значение минимума: −25/4.

Не перепутайте. «Точка минимума» — значение аргумента, «минимальное значение» — значение самой функции.

02 / ОДЗ

Для дробных функций исключённые точки отделяют промежутки исследования.

Дробь: правило частного и границы

(u/v)′ = (u′v − uv′) / v²Всегда проверяйте, что знаменатель v(x) не обращается в нуль.
Переменная в числителе и знаменателе

y = 2x/(x²−9),   x ≠ ±3.

y′ = [2(x²−9) − 2x · 2x]/(x²−9)² = −2(x²+9)/(x²−9)² < 0.

Функция убывает на каждом из промежутков (−∞,−3), (−3,3), (3,+∞).

Постоянный числитель

Если y=C/g(x), удобно воспользоваться сокращённой формой:

y′ = −C · g′(x) / g(x)²

При положительном C знак производной исходной дроби противоположен знаку g′(x). При отрицательном — совпадает. Все выводы делаем отдельно на промежутках ОДЗ.

(x−3)/(2x−5)Производная: 1/(2x−5)² > 0
3/(2x−5)Производная: −6/(2x−5)² < 0
Область определения: в обоих случаях x ≠ 5/2. Исключённая точка не может стать экстремумом.
03 / Обозначения

Одна и та же формула может иметь разные производные.

Что здесь переменная?

Аргумент в скобках определяет, по какой букве берётся производная. Остальные буквы считаем константами, если условие не говорит иного.

Производная по x

f(x)=ax³−bx

f′(x)=3ax²−b

Производная по a

g(a)=ax³−bx

g′(a)=x³

Прикладные коэффициенты также полезно собирать в одну букву: это сокращает запись без изменения математического смысла.

04 / Цепочка

Выражение внутри функции требует отдельного шага.

Производная сложной функции

В F(g(x)) сначала дифференцируйте внешнюю функцию, сохраняя g(x), затем умножьте на g′(x).

[F(g(x))]′ = F′(g(x)) · g′(x)

  1. Выделите внутреннюю функцию g(x).

  2. Найдите её производную g′(x).

  3. Найдите производную внешней функции и умножьте на результат второго шага.

Возведение в степень

y = (4x−5)¹⁰

y′ = 10(4x−5)⁹ · 4 = 40(4x−5)⁹

Составная функцияЕё производная
√g(x)g′(x)/(2√g(x)), где g(x) > 0
sin(g(x))g′(x) cos(g(x))
eᵍ⁽ˣ⁾g′(x) eᵍ⁽ˣ⁾

Для g(x)=x²−3x−4 внутренняя производная равна 2x−3. У функции √g(x) область определения: x ≤ −1 или x ≥ 4. Формула производной действует на внутренних точках этих промежутков.

05 / Приложение

Один и тот же алгоритм работает и в математической, и в физической модели.

Найти максимум: модель скоростей молекул

В модели Максвелла переменной является модуль скорости v ≥ 0. Все остальные величины — константы. Объединим коэффициенты в A > 0 и k=M/(2RT) > 0.

F(v) = A · v² · e−kv²

  1. Выбираем переменную. v ≥ 0; R, T, M — постоянные.

  2. Применяем произведение и цепочку. F′(v)=2Av · e−kv²(1−kv²).

  3. Исследуем знак. Для v > 0 первые два множителя положительны. Знак зависит от 1−kv².

  4. Обосновываем максимум. До v=1/√k производная положительна, после — отрицательна.

Наиболее вероятная скорость
R = 8,31; T = 500 К; M = 0,032 кг/моль.

v* = √(2RT/M) ≈ 510 м/с

Нуль скорости — граничная точка, отрицательные скорости исключены по смыслу. При больших скоростях распределение стремится к нулю; найденный пик является глобальным максимумом.

Проверить максимум в лаборатории
Контроль коэффициента. После вынесения 2Av · e−kv² в скобках остаётся именно 1−kv².
