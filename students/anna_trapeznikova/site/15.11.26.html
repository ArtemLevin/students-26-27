Обратимые функции

Когда у функции появляется обратная, как восстановить её формулу и почему отражение относительно прямой y = x помогает проверить ответ.

01

Критерий

Каждое значение достигается один раз

Функция f называется обратимой на своей области определения, если у каждого принимаемого ею значения y существует ровно один исходный аргумент x.

Проверка горизонтальной прямой: любая горизонтальная прямая пересекает график обратимой функции не более чем в одной точке.
ФункцияОбратима?Причина
3x + 5, x ∈ ℝДаРазным аргументам отвечают разные значения.
x³, x ∈ ℝДаФункция строго возрастает.
x², x ∈ ℝНетf(−2) = f(2) = 4.
x², x ≥ 0ДаОставлена одна ветвь параболы.

Не путайте: свойство «каждому x — одно y» относится к любой функции. Для обратимости требуется единственный x для каждого достигнутого y.

02

Алгебраический метод

Выразите аргумент через значение

Пусть f(x) = 3x + 5. Чтобы найти обратную функцию, работайте с уравнением y = 3x + 5.

  1. Выразите x через y: 3x = y − 5.
  2. Получите x = (y − 5)/3.
  3. Поменяйте обозначения входа и выхода: f⁻¹(x) = (x − 5)/3.
f⁻¹(x) = (x − 5)/3

Для общей линейной функции f(x) = ax + b, где a ≠ 0, получаем f⁻¹(x) = (x − b)/a. Знак f⁻¹ обозначает обратную функцию: это не дробь 1/f.

Контроль знака

f(x) = −2x + 1
y = −2x + 1 → x = (1 − y)/2
f⁻¹(x) = (1 − x)/2
03

Геометрический смысл

Графики зеркальны относительно y = x

Переход к обратной функции меняет координаты каждой точки местами:

(a; b) ↔ (b; a)

У функций f(x) = 2x − 1 и f⁻¹(x) = (x + 1)/2 точки (0; −1) и (−1; 0) соответствуют друг другу. Отражение происходит относительно прямой y = x, проходящей через I и III четверти.

Исследуйте закономерность. Перемещайте точку исходной функции и следите, как перемещается её пара на обратном графике. В лаборатории есть также ограниченные ветви параболы и квадратный корень.

Исследовать отражение точек

Точность формулировки: отражение относительно прямой y = x отличается от симметрии относительно начала координат.

04

Две области меняются местами

Домен и множество значений

D(f⁻¹) = E(f)
E(f⁻¹) = D(f)

На всей числовой прямой x² не обратима. После ограничения x ≥ 0 обратная функция равна √x; после ограничения x ≤ 0 — −√x.

Исходная областьИсходная функцияОбратная функция
x ≥ 0f(x)=x²f⁻¹(x)=√x, x ≥ 0
x ≤ 0f(x)=x²f⁻¹(x)=−√x, x ≥ 0

Если исходная функция содержит минус перед корнем

Для f(x)=−√x, x ≥ 0, всегда y ≤ 0. Из y=−√x при возведении в квадрат получаем x=y². При переименовании переменных:

f⁻¹(x)=x²,   x ≤ 0

После возведения в квадрат сохраните знак. Для квадратного корня √(x²)=|x|. Обратная к −√x определена только при x ≤ 0.

05

Нечётные степени

Кубические и пятые корни

Корни нечётной степени существуют для всех действительных чисел, включая отрицательные. Именно поэтому ограничивать область определения для следующих примеров не требуется:

Кубическая функция

f(x)=x³+1

f⁻¹(x)=∛(x−1)

Пятая степень

f(x)=−x⁵

f⁻¹(x)=−⁵√x

При отрицательных основаниях степень с дробным показателем и нечётным знаменателем удобно записывать через вещественный корень: (⁵√x)³ = x³⁄⁵; обратная имеет вид (∛x)⁵ = x⁵⁄³.

06

Надёжная проверка

Вычислите обе композиции

f(g(x)) = x
g(f(x)) = x

Каждое равенство проверяется на своей области: первое на D(g), второе на D(f).

Верная пара

Для f(x)=−x³, g(x)=−∛x:

f(g(x))=−(−∛x)³=x
g(f(x))=−∛(−x³)=x

Потерянный знак

Для f(x)=−x⁵ и ошибочно предложенной g(x)=⁵√x обе композиции дают −x. При x ≠ 0 это отличается от x. Правильная обратная: −⁵√x.

Проверка области для квадратного корня

Для f(x)=−√x, x≥0 и g(x)=x², x≤0:

g(f(x))=(−√x)²=x   (x≥0)
f(g(x))=−√(x²)=−|x|=x   (x≤0)
07

Маршрут решения

Алгоритм обратной функции

  1. Запишите исходную функцию и область D(f).
  2. Убедитесь, что каждое значение достигается только один раз; при необходимости ограничьте область одной ветвью.
  3. Из y=f(x) выразите x через y.
  4. Переименуйте переменные и получите g(x)=f⁻¹(x).
  5. Укажите D(g)=E(f), E(g)=D(f).
  6. Проверьте обе композиции с учётом областей.

Памятка: при чётных степенях учитывайте выбранную ветвь, при квадратном корне — знак, а при композиции подставляйте функцию целиком.

Самостоятельная тренировка

В каждом задании укажите область определения обратной функции. При проверке пары учитывайте области обеих функций. Сначала решите задачи, затем раскройте ответы.

  1. Найдите обратную к f(x)=4x−7, x∈ℝ.
  2. Найдите обратную к f(x)=−5x+4, x∈ℝ.
  3. Найдите обратную к f(x)=(3x−1)/2, x∈ℝ.
  4. Найдите обратную к f(x)=x³+8, x∈ℝ.
  5. Обратима ли f(x)=x²−4 на ℝ? Ограничьте область условием x≥0, найдите обратную, её D и E.
  6. Для f(x)=1−√(x+2) найдите D(f), E(f), обратную функцию и D(f⁻¹), E(f⁻¹).
  7. Найдите обратную к f(x)=(x+1)/(2x−3), x≠3/2, укажите её область определения и множество значений.
  8. Являются ли взаимно обратными f(x)=−x⁵ и g(x)=⁵√x на ℝ? Проверьте обе композиции и укажите верную обратную к f.
  9. Проверьте обратимость пары f(x)=−√x при x≥0 и g(x)=x² при x≤0. Вычислите обе композиции и укажите D и E.
  10. Для f(x)=(⁵√x)³, x∈ℝ, найдите обратную через корень и проверьте обе композиции.
