01

Корни и знаки

Метод интервалов

Кратность корня и строгость неравенства определяют, как читать числовую ось.

Правило: при переходе через корень нечётной кратности знак многочлена меняется; через корень чётной кратности — сохраняется.

x²(5x − 4)(x + 7) < 0

Корни: −7, 0 (двукратный), 4/5. На правом промежутке знак «+»; при проходе через 4/5 меняется на «−», через 0 остаётся «−», через −7 становится «+».

Промежуток(−∞; −7)(−7; 0)(0; 4/5)(4/5; +∞)
Знак+−−+
Подходит?нетдаданет
x ∈ (−7; 0) ∪ (0; 4/5)

Ноль выколот. Многочлен при x = 0 равен нулю; для строгого неравенства он исключается, несмотря на сохранение знака.

02

Повторяющиеся части

Замена переменной

Выбирайте t так, чтобы новое уравнение стало короче. Сначала выпишите ограничения.

Пример: весь знаменатель
12 / (x² − 2x − 3) − (x² − 2x) = −1

ОДЗ: x ≠ −1, x ≠ 3. Обозначим t = x² − 2x − 3, t ≠ 0. Тогда x² − 2x = t + 3:

12/t = t + 2 ⇔ t² + 2t − 12 = 0

t = −1 ± √13. Обратная замена приводит к (x − 1)² = t + 4. Значение t = −1 − √13 даёт отрицательную правую часть, поэтому исключается.

x = 1 ± √(3 + √13)
Пример: взаимно обратные дроби
4(x + 5)/(x² + 5x + 14) + (x² + 5x + 14)/(x + 5) = 5

ОДЗ: x ≠ −5; второй знаменатель x² + 5x + 14 действительных нулей не имеет.

Положим t = (x + 5)/(x² + 5x + 14), t ≠ 0. Обратная дробь станет 1/t.

4t + 1/t = 5 ⇔ 4t² − 5t + 1 = 0

t = 1 не даёт действительных x; при t = 1/4 получаем x² + x − 6 = 0.

x = −3 или x = 2

При возврате к x проверьте ОДЗ ещё раз. Красивое решение в t может дать недопустимый корень исходного уравнения.

03

Увидеть форму

Разность квадратов

Представьте обе части как квадраты, затем разложите их разность на множители.

A² − B² = (A − B)(A + B)

При A² = B² получаем A = B или A = −B. Всякий раз сохраняйте исходные ограничения.

((x + 1)/(x − 2))² = 4 = 2²,   x ≠ 2
((x + 1)/(x − 2) − 2)((x + 1)/(x − 2) + 2) = 0

По отдельности решаем два линейных уравнения. Ответ: x = 5 или x = 1.

Число тоже можно представить как квадрат: 2 = (√2)². Это важно, когда формула сокращённого умножения скрыта.

04

Лесенка нулей

Метод Гаусса

Преобразуйте расширенную матрицу целыми строками и выполните обратный ход.

Рассмотрим систему из пособия. В третьем уравнении нет z: его коэффициент нулевой.

x + y + z = 6
2x − y + z = 3
3x − y + 0z = 1
(1, 1, 1 | 6)
(2, −1, 1 | 3)
(3, −1, 0 | 1)
  1. R₂ ← R₂ − 2R₁ и R₃ ← R₃ − 3R₁.
  2. R₃ ← 3R₃ − 4R₂.
  3. Получаем третью строку (0, 0, −5 | −15). Отсюда z = 3, y = 2, x = 1.

Противоречие: строка (0, 0, 0 | c), где c ≠ 0, означает «0 = c», значит решений нет. Строка (0, 0, 0 | 0) — тождество; проверьте свободные переменные.
