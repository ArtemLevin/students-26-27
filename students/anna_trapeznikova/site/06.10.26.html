Неравенства с модулем

Сегодня главное — быстро распознать структуру неравенства и выбрать короткий корректный путь: замену t = |x|, разбиение оси, последовательное раскрытие вложенных модулей или сравнение квадратов модулей.

Выбор методаЗаменаИнтервалыВложениеКвадраты10 задач

Главный ориентир

структура → метод → ограничения → ответ

Решение становится короче, когда метод выбирается до вычислений.

После замены всегда проверяем t ≥ 0; внутри системы ищем пересечение, между разобранными случаями — объединение.

01 · Рабочий стол

Какой метод выбрать?

Нажмите на структуру задачи. Справа появится ровно тот маршрут, который использовался в чек-листе занятия.

Замена переменной

Сведите задачу к квадратному неравенству

x² − |x| − 6 ≥ 0 → t² − t − 6 ≥ 0, t = |x|

Так как x² = |x|², можно ввести t = |x|. После решения квадратного неравенства обязательно оставить только t ≥ 0 и сделать обратную замену.

Контроль: условие t ≥ 0 нельзя терять.

02 · Замена

t = |x|

Этот приём особенно удобен, когда рядом встречаются x² и |x|. Связь x² = |x|² превращает выражение в обычное квадратное относительно новой переменной.

Шаг 1. Замена

t = |x|,   t ≥ 0

Ограничение появляется сразу из определения модуля.

Шаг 2. Квадратное неравенство

t² − t − 6 ≥ 0

Корни: −2 и 3; по знакам получаем t ≤ −2 или t ≥ 3.

Шаг 3. Ограничение

t ≥ 0 ⇒ остаётся t ≥ 3

Ветка t ≤ −2 несовместима с t = |x|.

Шаг 4. Обратная замена

|x| ≥ 3 ⇒ x ≤ −3 или x ≥ 3

Только после этого записывается ответ относительно x.

Граница t = 0: если есть сомнение, подставьте её в неравенство по t. На занятии именно подстановка использовалась как надёжная проверка включения границы.

03 · Несколько модулей

Разбиваем ось

Нули подмодульных выражений делят ось на промежутки. На каждом промежутке знаки фиксированы, поэтому модули раскрываются однозначно.

Разобранный пример

|x − 3| + |x + 1| ≤ 10

x ≤ −1
−1 ≤ x ≤ 3
x ≥ 3
−13

Итог: после решения трёх систем и объединения подходящих частей получаем x ∈ [−4; 6].

Логика множеств

Пересечение внутри, объединение снаружи

Внутри каждого промежутка одновременно действует условие самого промежутка и раскрытое неравенство — это система, значит, берём пересечение.

После разбора всех случаев собираем все подходящие области — это объединение.

04 · Вложение

Снаружи внутрь

Вложенный модуль раскрывается послойно. Сначала убирается внешний модуль, затем решаются полученные условия для внутреннего.

Исходная запись

||x| − 3| ≥ 5

Внешний модуль сравнивается с положительным числом.

Первый переход

|x| − 3 ≥ 5   или   |x| − 3 ≤ −5

Получаем совокупность двух неравенств.

Проверка возможности

|x| ≥ 8   или   |x| ≤ −2

Вторая ветка невозможна, поскольку |x| ≥ 0.

Ответ

x ≤ −8   или   x ≥ 8

После внешнего слоя работаем с внутренним модулем обычным способом.

05 · Модуль против модуля

Сравниваем квадраты

Если обе части — модули, они неотрицательны. Поэтому допустимо возвести обе части в квадрат, сохранив знак неравенства.

Обоснование

|f(x)| ≥ 0,   |g(x)| ≥ 0

Именно неотрицательность обеих частей делает переход равносильным.

Переход

|f(x)| □ |g(x)| ⇔ f²(x) □ g²(x)

Знак □ остаётся тем же: <, ≤, > или ≥.

Пример

|x| ≥ |2x − 1| ⇒ x² ≥ (2x − 1)²

Дальше получаем квадратное неравенство 3x² − 4x + 1 ≤ 0.

Результат

x ∈ [1/3; 1]

Возведение произвольного неравенства в квадрат без проверки знаков использовать нельзя.

07 · Контроль

Частые ошибки

Проверка этих шести точек закрывает главные риски сегодняшних методов.

Забыто t ≥ 0

После замены t = |x| отрицательные значения t недопустимы.

Система перепутана с совокупностью

Система требует пересечения условий, совокупность — объединения вариантов.

Граница не проверена

Строгость знака и подстановка определяют, входит ли граничная точка.

Потеря точки при объединении

Если точка входит хотя бы в один из объединяемых случаев, она остаётся в общем ответе.

Квадрат без обоснования

Перед возведением неравенства в квадрат нужна информация о знаках обеих частей.

Нет обратной замены

Ответ по t — промежуточный; итог должен быть записан относительно x.
