01

От четвёртой степени к параболе

Решение разложено на семь последовательных действий. Переключайте их в собственном темпе или откройте все сразу.

Шаг 1 / 7

Найдите ОДЗ исходной дроби

Знаменатель обращается в нуль при двух значениях аргумента. Сразу запишите запреты.

(x−4)(x+3)≠0⇒x≠4,x≠−3

ОДЗ определяют до сокращения. Запреты сохраняются даже тогда, когда соответствующие множители сократятся.

Шаг 2 / 7

Замена переменной

В числителе только четвёртая и вторая степени. Положите t = x²: получится квадратный трёхчлен.

t=x2,t2−25t+144

Шаг 3 / 7

Найдите корни квадратного трёхчлена

Дискриминант равен 625 − 576 = 49. Корни: 16 и 9.

D=49,t1=16,t2=9

Шаг 4 / 7

Разложите на линейные множители

Вернитесь к переменной x и дважды примените разность квадратов.

x4−25x2+144=(x2−16)(x2−9)=(x−4)(x+4)(x−3)(x+3)

Шаг 5 / 7

Сократите и раскройте скобки

На ОДЗ можно сократить множители (x − 4) и (x + 3).

y=x2+x−12

Получили вспомогательную параболу. В двух запрещённых значениях исходная функция по-прежнему отсутствует: x ≠ −3, 4.

Шаг 6 / 7

Шаг 7 / 7

Удалите две точки

Используйте упрощённую формулу только для вычисления высот выколотых точек:

A(−3;−6),B(4;8)

На графике их показывают незакрашенными кружками. При x = −3 и x = 4 исходная функция не имеет значений.

Готовый график — парабола y = x² + x − 12 с двумя удалёнными точками.

03

Как читать параметры c и k

Прямая y = c

Горизонтально расположенная прямая. Меняя c, перемещайте её вверх или вниз и считайте только допустимые пересечения.

Для исследуемой дроби ровно одно пересечение возможно в трёх случаях: вершина либо уровень одной из двух выколотых точек.

c∈{−494;−6;8}

Прямая y = kx

Проходит через начало координат; k определяет наклон. Для графика y = |x| + 2 с удалёнными x = −2, 2 исследуйте ветви и исключённые пересечения.

k∈[−1;1]∪{−2;2}

При k = ±1 прямая параллельна соответствующему лучу. Все наклоны между −1 и 1 также не дают пересечений; проверяйте промежуток целиком.

04

Ещё два инструмента занятия

Схема Горнера

Для P(x) = x⁴ + x³ − 7x² − x + 6 корнем является 1. Деление на x − 1 даёт x³ + 2x² − 5x − 6. Корень −1 для оставшегося многочлена даёт множитель x + 1 и квадратный трёхчлен x² + x − 6.

P(x)=(x−1)(x+1)(x+3)(x−2)

Корню r соответствует множитель x − r. Если корень равен −1, множитель имеет вид x + 1.

Графики с модулем

При y = |f(x)| участки ниже оси Ox отражаются вверх. При y = f(|x|) правую часть графика отражают относительно Oy. Если модуль стоит внутри отдельного фрагмента, сначала раскройте его по случаям.

y=−1|x|

Для функции (3|x| − 1)/(|x| − 3x²) знаменатель запрещает x = 0 и x = ±1/3. После сокращения получается y = −1/|x|, но при x = ±1/3 остаются выколотые точки с высотой −3.

При x = 0 ветви уходят вниз без ограничений; это вертикальная асимптота, поэтому конечной выколотой точки там нет.

Функция по частям

Перед подстановкой аргумента в кусочно заданную функцию выберите интервал соответствующей формулы. Граница со знаком равенства принадлежит указанной части.

05

Самостоятельная практика

10 заданий из чек-листа. Сначала решите на бумаге, затем откройте ответ. Отмечайте только полностью завершённые решения.

Выполнено: 0 из 10.

  1. Для кусочной функции f(x) = x + 2 при x < 1 и f(x) = 5 − x при x ≥ 1 найдите f(−1), f(0), f(1), f(3).

    Проверить ответ

    1; 2; 4; 2.

  2. Разложите x⁴ − 13x² + 36 на линейные множители.

    Проверить ответ

    (x − 2)(x + 2)(x − 3)(x + 3).

  3. Разложите x⁴ + x³ − 7x² − x + 6 с помощью схемы Горнера или другим школьным способом.

    Проверить ответ

    (x − 1)(x + 1)(x − 2)(x + 3).

  4. Упростите (x⁴ − 25x² + 144)/((x − 4)(x + 3)). Укажите ОДЗ и координаты выколотых точек.

    Проверить ответ

    x² + x − 12, x ≠ −3, 4. Выколотые точки (−3; −6) и (4; 8).

  5. Для графика из задания 4 найдите все c, при которых y = c имеет ровно одно пересечение.

    Проверить ответ

    c ∈ {−49/4; −6; 8}.

  6. Постройте y = |x² − 4|. Найдите нули и значение функции при x = 0.

    Проверить ответ

    Нули −2 и 2. Значение при x = 0 равно 4.

  7. Упростите (3|x| − 1)/(|x| − 3x²). Укажите ОДЗ и выколотые точки.

    Проверить ответ

    −1/|x|; x ≠ 0, ±1/3; точки (−1/3; −3) и (1/3; −3).

  8. Раскройте модуль для y = 1/(|x| + 1). Укажите область определения и значения при x = 0, ±1.

    Проверить ответ

    При x ≥ 0: 1/(x + 1); при x < 0: 1/(1 − x). D = ℝ; y(0) = 1; y(±1) = 1/2.

  9. Для y = |x| + 2 при x ≠ −2 и x ≠ 2 найдите все k, при которых y = kx не пересекает график.

    Проверить ответ

    k ∈ [−1; 1] ∪ {−2; 2}.

  10. Исследуйте (x⁴ − 10x² + 9)/((x − 1)(x + 3)). Найдите ОДЗ, упрощённую формулу и все c, при которых y = c имеет ровно одну общую точку с графиком.

    Проверить ответ

    x ≠ 1, −3; y = x² − 2x − 3; c = 12. При c = −4 вершина выколота, пересечений нет.
