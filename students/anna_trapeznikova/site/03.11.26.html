Где функция существует. Какие значения принимает.

Два разных вопроса: какие числа можно подставить вместо x и какие значения y удаётся получить. Исследуем область допустимых значений, корни, знаменатели и множество значений функции.

01

Смысл выражения

Сначала допустимые значения x

У многочлена x² − 4 область определения — все действительные числа. В выражениях с квадратным корнем и дробью проверяем два правила.

Квадратный корень

√A(x) существует, если A(x) ≥ 0.

Ноль под корнем допустим.

Деление

B(x) / C(x) существует, если C(x) ≠ 0.

Нуль в знаменателе запрещён всегда.

Два противоположных примера

√(x² − 4): x ≤ −2 или x ≥ 2

D = (−∞; −2] ∪ [2; +∞). Граничные точки входят: √0 = 0.

√(9 − x²): −3 ≤ x ≤ 3

D = [−3; 3]. Сравните направления неравенств перед записью промежутков.

1 / (x² − 5): x ≠ −√5 и x ≠ √5

В данном случае достаточно исключить две точки из множества действительных чисел.

02

Несколько ограничений

Условия выполняются одновременно

F(x) = √(x² − 4) / (x² − 5)
  1. Из корня: x² − 4 ≥ 0, то есть x ≤ −2 или x ≥ 2.
  2. Из знаменателя: x² − 5 ≠ 0, то есть x ≠ ±√5.
  3. Найдите пересечение: оставьте разрешённые лучи, исключив две запрещённые точки.
D(F) = ((−∞; −2] ∪ [2; +∞)) \ {−√5; √5}
Не смешивайте ≥ 0 и ≠ 0. Эти условия возникают по разным причинам. Даже если знак неравенства нестрогий, нуль знаменателя исключается.
03

Равносильные преобразования

Изолировать корень. Проверить знак.

√A(x) = B(x)

Перед возведением в квадрат требуются три условия: A(x) ≥ 0, B(x) ≥ 0, A(x) = B(x)².

Разбор из занятия

√(x² − 4) = 6 − x²
  1. Замена t = x², поэтому t ≥ 0. Из радикала и правой части получаем 4 ≤ t ≤ 6.
  2. √(t − 4) = 6 − t. После возведения в квадрат: t − 4 = (6 − t)².
  3. Получается t² − 13t + 40 = 0, то есть (t − 5)(t − 8) = 0.
  4. t = 8 нарушает t ≤ 6. Значение t = 5 подходит: √1 = 1.
  5. Возвращаемся к x: x = −√5 или x = √5.
Откуда возникает лишний корень? При t = 8 слева √4 = 2, справа 6 − 8 = −2. Квадраты одинаковы, исходные стороны различаются.
04

Связь с предыдущим методом

Нули знаменателя ищем отдельным уравнением

(√(x²−4)−1)(√(x²−4)+5) / (x²−6+√(x²−4))

Из корней получаем x² − 4 ≥ 0. Для знаменателя требуется x² − 6 + √(x² − 4) ≠ 0. Его нули определяются уже разобранным уравнением.

x² − 6 + √(x² − 4) = 0 ⇔ √(x²−4) = 6−x²

Оно обращается в нуль при x = ±√5. Поэтому эти точки удаляются из области, заданной корнем.

D = ((−∞; −2] ∪ [2; +∞)) \ {−√5; √5}
05

Двойное неравенство

Модуль ограничивает величину с двух сторон

|H(x)| ≤ a ⇔ −a ≤ H(x) ≤ a, при a ≥ 0
|x² − 5| ≤ 4 ⇔ −4 ≤ x² − 5 ≤ 4
1 ≤ x² ≤ 9 ⇔ 1 ≤ |x| ≤ 3

Ответ: x ∈ [−3; −1] ∪ [1; 3]. Проверьте оба луча: отрицательные значения x тоже допустимы.

06

Дополнительная доска занятия

Какие значения y достижимы?

D(f) — допустимые аргументы x. E(f) — все значения y, принимаемые функцией. Чтобы найти E(f), важно доказать ограничения для y и достижимость каждого значения внутри них.

Первая функция с доски

f(x) = 2x / (x² + 1)

Знаменатель x²+1 ≥ 1, поэтому D(f) = ℝ. Из неотрицательности квадрата (|x| − 1)² ≥ 0 следует:

x² + 1 ≥ 2|x| ⇒ |2x/(x²+1)| ≤ 1.

Отсюда −1 ≤ f(x) ≤ 1. Крайние значения достигаются: f(−1) = −1 и f(1) = 1. Для любого y внутри отрезка уравнение yx² − 2x + y = 0 имеет действительное решение (при y = 0 берём x = 0).

E(f) = [−1; 1]

07

Второй способ с доски

Заменить f(x) на y и решить относительно x

f(x) = (4x + 8) / (x² + 5)

Поскольку x² + 5 > 0, область определения — ℝ. Пусть y = f(x). Умножение на положительный знаменатель приводит к уравнению:

yx² − 4x + 5y − 8 = 0

При y ≠ 0 это квадратное уравнение относительно x. Действительные корни существуют тогда и только тогда, когда дискриминант неотрицателен:

Dₓ = 16 − 4y(5y−8) = 16 − 20y² + 32y ≥ 0
5y² − 8y − 4 ≤ 0 ⇔ −2/5 ≤ y ≤ 2.

При y = 0 получаем линейное уравнение −4x − 8 = 0, у которого есть решение x = −2. Границы достигаются: f(−5) = −2/5, f(1) = 2.

E(f) = [−2/5; 2]
Особый случай. Если коэффициент при x² равен нулю, отдельно проверьте линейное уравнение. Не используйте условие на дискриминант механически без этой проверки.
