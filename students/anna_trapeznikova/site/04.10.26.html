Неравенства с модулем

Главная развилка занятия — определить, где нужна система, а где совокупность. После этого двойные и вложенные модули, числовая прямая и замена t = |x| складываются в один последовательный алгоритм.

ПереходыДвойное неравенствоВложенные модулиЗаменаПостер10 задач

Ключевой ориентир

система = пересечение
совокупность = объединение

Для знаков <, ≤ у модуля получается система. Для >, ≥ — совокупность.

01 · Памятка

Четыре перехода

Переключайте знак. Формула, логическая конструкция и смысл на числовой прямой меняются синхронно.

Выберите знак

У «меньше» обе границы должны выполняться одновременно. У «больше» достаточно одной из двух ветвей.

Система · пересечение
|F(x)| < G(x) ⇔ −G(x) < F(x) < G(x)
Нужно выполнить оба условияF(x) < G(x) и F(x) > −G(x).
Что брать на осиПересечение полученных промежутков.

Система

Оставляем только общую часть.

ab

Совокупность

Берём всё, где выполнено хотя бы одно условие.

ab

02 · Двойное неравенство

Сначала разорвите запись

Пример из занятия: 1 ≤ |x−2| < 4. Двойное неравенство сначала превращается в систему двух условий, а уже каждое условие раскрывается по своему правилу.

01

Разделите двойное неравенство

1 ≤ |x−2| < 4 ⇒ { |x−2| ≥ 1; |x−2| < 4 }

Внешняя логика здесь — система: оба условия должны выполняться одновременно.

02

Раскройте условие «больше или равно»

|x−2| ≥ 1 ⇒ x ≤ 1 или x ≥ 3

Знак «≥» даёт совокупность.

03

Раскройте условие «меньше»

|x−2| < 4 ⇒ −2 < x < 6

Знак «<» даёт систему, то есть один промежуток.

04

Пересеките результаты

x ∈ (−2; 1] ∪ [3; 6)

Внешняя система требует пересечения результата совокупности с промежутком (−2; 6).

03 · Вложенный модуль

Двигайтесь снаружи внутрь

В конструкции ||x+5|−3| ≥ 4 сначала раскрывается внешний модуль. Только после этого решаются условия с внутренним модулем.

Шаг 1. Внешний модуль

||x+5|−3| ≥ 4

⇒ |x+5|−3 ≥ 4 или |x+5|−3 ≤ −4

Получаем совокупность, потому что исходный знак — «≥».

Шаг 2. Внутренний модуль

|x+5| ≥ 7 или |x+5| ≤ −1

Вторая ветвь невозможна: модуль не может быть ≤ отрицательного числа.

Ответ: x ≤ −12 или x ≥ 2.

Проверка здравым смыслом

Условия вида |F(x)| < отрицательное число решений не имеют. Условия вида |F(x)| > отрицательное число выполняются при любом допустимом x.

04 · Повторяющийся |x|

Замена t = |x|

Если один и тот же фрагмент |x| повторяется несколько раз, решайте задачу сначала относительно t. Ограничение t ≥ 0 является частью замены.

Исходная задача

|1−|x|| / (1+|x|) ≥ 1/2

Вводим t = |x|, t ≥ 0. Тогда знаменатель 1+t ≥ 1, поэтому он точно положителен.

2|1−t| ≥ 1+t

Сначала дорешите относительно t

t ∈ [0; 1/3] ∪ [3; +∞)

Только теперь выполняем обратную замену.

x ∈ (−∞;−3] ∪ [−1/3;1/3] ∪ [3;+∞)

Умножение неравенства

Домножать на выражение с переменной безопасно только после установления его знака. При умножении на отрицательное выражение знак неравенства меняется.

Весь маршрут на одном листе

06 · Контроль

Пять ошибок

Именно эти места чаще всего ломают уже почти готовое решение.

Путают систему и совокупность

Система требует пересечения, совокупность — объединения.

Не замечают невозможную ветвь

Модуль не может быть меньше отрицательного числа.

Слишком рано возвращаются к x

После t = |x| сначала полностью решите задачу относительно t и учтите t ≥ 0.

Домножают без контроля знака

Знак множителя определяет, сохраняется ли направление неравенства.

Ошибаются на последнем объединении

После вычислений отдельно сформируйте итоговое множество решений.

Теряют строгую границу

Проверьте, должна точка быть закрашенной или выколотой.

  3. 1 ≤ |x−2| < 4
