01

Два уравнения · две переменные

Метод Крамера

Определитель основной матрицы показывает, можно ли найти единственное решение делением.

Для системы a₁x + b₁y = c₁ и a₂x + b₂y = c₂ сначала вычисляем главный определитель.

Δ = a₁b₂ − a₂b₁

Частный определитель Δₓ получаем, заменяя столбец коэффициентов при x свободными членами. Для Δᵧ заменяем столбец при y.

Δₓ = c₁b₂ − c₂b₁;
Δᵧ = a₁c₂ − a₂c₁
Δ ≠ 0

Одно решение: x = Δₓ/Δ; y = Δᵧ/Δ.

Δ = 0, Δₓ ≠ 0 или Δᵧ ≠ 0

Решений нет.

Δ = Δₓ = Δᵧ = 0

При ненулевой строке коэффициентов — бесконечно много решений. Если обе строки нулевые, отдельно проверьте свободные члены.

Нулевой главный определитель сам по себе не означает отсутствие решений. При Δ = 0 формулы деления применять нельзя.

02

Разбор случая с нулевым определителем

Почему решений нет?

−7x − y = 13
21x + 3y = 0

Вторые коэффициенты получаются умножением левых частей первого уравнения на −3. Свободные члены при этом не совпадают: −3 · 13 = −39, а справа стоит 0.

Δ = (−7) · 3 − 21 · (−1) = 0
Δₓ = 13 · 3 − 0 · (−1) = 39
Δᵧ = (−7) · 0 − 21 · 13 = −273

Вывод: Δ = 0 и Δₓ ≠ 0. Система несовместна. Для однородной системы (справа оба нуля) нулевое решение существует всегда.

03

Три уравнения · три переменные

Метод Гаусса: нули ступенькой

Прямой ход устраняет неизвестные из нижних строк. Обратный ход возвращает их значения снизу вверх.

Начнём с системы занятия. В матрице столбцы отвечают за x, y, z, а справа от черты стоят свободные члены.

( 2 3 −5 | 4 ) ( 3 −4 2 | 21 ) ( 7 8 −6 | 1 )
Этап 1 из 4

Записываем расширенную матрицу и выбираем первый ведущий элемент 2.

Разрешены перестановка строк, умножение строки на ненулевое число и прибавление к строке кратной другой строки. Каждое преобразование применяется ко всей строке, в том числе к свободному члену.

Ключевая проверка: −12 − (−35) = 23. Именно эта разность появляется при преобразовании третьей строки; ошибка в знаке меняет весь результат.

Если в конце получается строка 0 0 0 | c при c ≠ 0, система несовместна. Строка 0 0 0 | 0 означает зависимое уравнение; при наличии свободной переменной решений бесконечно много.
