\section*{\color{darkaccent}1. Базовые производные}
\sectionline

Производная характеризует мгновенную скорость изменения функции. Основные обозначения: $y'$ и $f'(x)$.

\keyformula{(x^n)'=nx^{n-1}}

Например,
\[
(x^{-10})'=-10x^{-11}.
\]

Для корня:
\[
(\sqrt{x})'=\frac{1}{2\sqrt{x}},\qquad x>0.
\]

Для постоянной $C$:
\keyformula{C'=0}

Если параметр $p$ не зависит от $x$, то при дифференцировании по $x$ он является константой:
\[
(p^2)'=0,\qquad (p^2x^{10})'=10p^2x^9.
\]

Сумма, разность и постоянный множитель:
\[
(u\pm v)'=u'\pm v',\qquad (C f(x))'=C f'(x).
\]

\section*{\color{darkaccent}2. Производная произведения}
\sectionline

Если перемножаются две функции, зависящие от $x$, используется правило:
\keyformula{(uv)'=u'v+uv'}

Алгоритм:
\begin{enumerate}
\item Выделите $u$ и $v$.
\item Найдите $u'$ и $v'$.
\item Подставьте в формулу $u'v+uv'$.
\item Упростите результат.
\end{enumerate}

Пример:
\[
y=x^3x^{11},\qquad u=x^3,\quad v=x^{11}.
\]
Тогда
\[
u'=3x^2,\qquad v'=11x^{10},
\]
\[
y'=3x^2x^{11}+x^3\cdot11x^{10}=14x^{13}.
\]

Ещё один пример:
\[
y=x^3(5x-2),
\]
\[
y'=3x^2(5x-2)+5x^3=20x^3-6x^2.
\]

\section*{\color{darkaccent}3. Производная частного}
\sectionline

Если
\[
y=\frac{u}{v},\qquad v\ne0,
\]
то
\keyformula{\left(\frac uv\right)'=\frac{u'v-uv'}{v^2}}

Порядок в числителе принципиален: сначала $u'v$, затем вычитается $uv'$.

Пример:
\[
y=\frac{x^4}{x^{12}},\qquad x\ne0.
\]
Тогда
\[
y'=\frac{4x^3\cdot x^{12}-x^4\cdot12x^{11}}{(x^{12})^2}
=-\frac8{x^9},\qquad x\ne0.
\]

Перед преобразованиями дробной функции всегда фиксируйте ограничение знаменателя.

\section*{\color{darkaccent}4. Тригонометрические функции}
\sectionline

\[
(\sin x)'=\cos x,
\qquad
(\cos x)'=-\sin x,
\]
\[
(\tg x)'=\frac1{\cos^2x},
\qquad
(\ctg x)'=-\frac1{\sin^2x}.
\]

Формулу для тангенса можно получить из
\[
\tg x=\frac{\sin x}{\cos x}
\]
с помощью правила частного:
\[
(\tg x)'=
\frac{\cos^2x+\sin^2x}{\cos^2x}
=\frac1{\cos^2x}.
\]

Аналогично,
\[
\ctg x=\frac{\cos x}{\sin x}
\quad\Longrightarrow\quad
(\ctg x)'=-\frac1{\sin^2x}.
\]

Пример произведения:
\[
y=x\sin x,
\qquad
y'=\sin x+x\cos x.
\]

\section*{\color{darkaccent}5. Правило цепочки}
\sectionline

Если одна функция находится внутри другой,
\[
y=F(g(x)),
\]
то
\keyformula{y'=F'(g(x))\,g'(x)}

Например,
\[
y=e^{x^2-x-6}
\quad\Longrightarrow\quad
 y'=(2x-1)e^{x^2-x-6}.
\]

\section*{\color{darkaccent}6. Показательная функция}
\sectionline

При $a>0$, $a\ne1$:
\keyformula{\bigl(a^{f(x)}\bigr)'=f'(x)a^{f(x)}\ln a}

Например,
\[
y=2^{x^2-x-6}
\quad\Longrightarrow\quad
 y'=(2x-1)2^{x^2-x-6}\ln2.
\]

Для экспоненты $\ln e=1$, поэтому
\keyformula{\bigl(e^{f(x)}\bigr)'=f'(x)e^{f(x)}}

Комбинация с правилом произведения:
\[
y=x^2e^{3x},
\]
\[
y'=2xe^{3x}+3x^2e^{3x}=xe^{3x}(2+3x).
\]

\section*{\color{darkaccent}7. Логарифмическая функция}
\sectionline

При $a>0$, $a\ne1$ и $f(x)>0$:
\keyformula{\bigl(\log_a f(x)\bigr)'=\frac{f'(x)}{f(x)\ln a}}

Например,
\[
y=\log_2(x^2-x-6).
\]
ОДЗ:
\[
x^2-x-6>0
\quad\Longrightarrow\quad
x\in(-\infty,-2)\cup(3,+\infty).
\]
Производная:
\[
y'=\frac{2x-1}{(x^2-x-6)\ln2}.
\]

Для
\[
y=\log_5(4x+3)
\]
имеем
\[
x>-\frac34,
\qquad
 y'=\frac4{(4x+3)\ln5}.
\]

Частные случаи:
\[
(\lg f(x))'=\frac{f'(x)}{f(x)\ln10},
\]
\keyformula{(\ln f(x))'=\frac{f'(x)}{f(x)}}

Например,
\[
y=\ln(5x^2),\qquad x\ne0,
\]
\[
y'=\frac{10x}{5x^2}=\frac2x.
\]

\section*{\color{darkaccent}9. Типичные ошибки}
\sectionline

\begin{enumerate}
\item Не заменяйте правило произведения ошибочной записью $(uv)'=u'v'$.
\item В правиле частного сохраняйте порядок $u'v-uv'$.
\item Помните знак минус: $(\cos x)'=-\sin x$ и $(\ctg x)'=-1/\sin^2x$.
\item Для дробей проверяйте знаменатель: он не равен нулю.
\item Для логарифмов проверяйте положительность аргумента.
\item Скобками показывайте, к чему относится степень: $(\ln x)^2$, $(\cos x)^2$.
\item После применения формулы упрощайте результат, если это возможно.
\end{enumerate}

\section*{\color{darkaccent}Тренировочный блок}
\sectionline

Найдите производную. Где требуется, укажите ОДЗ исходной функции.

\begin{enumerate}[label=\textbf{\arabic*)}]
\item $y=x^4(3x-2)$.
\item $y=\dfrac{x^3}{4x-1}$.
\item $y=x^2\sin x$.
\item $y=(2x-1)(x^5+3x^2)$.
\item $y=\dfrac{x^4+1}{x^2}$.
\item $y=x^2e^{3x}$.
\item $y=5^{2x^2-x}$.
\item $y=\log_3(x^2-4x+3)$.
\item $y=\sin x\cos x$.
\item $y=\dfrac{x^2e^{2x}}{\ln x}$.
\end{enumerate}

\clearpage
\section*{\color{darkaccent}Ответы}
\sectionline

\begin{enumerate}[label=\textbf{\arabic*)}]
\item $y'=15x^4-8x^3$.
\item $x\ne\frac14$, \quad $y'=\dfrac{x^2(8x-3)}{(4x-1)^2}$.
\item $y'=2x\sin x+x^2\cos x$.
\item $y'=2(x^5+3x^2)+(2x-1)(5x^4+6x)$.
\item $x\ne0$, \quad $y'=2x-\dfrac2{x^3}$.
\item $y'=xe^{3x}(2+3x)$.
\item $y'=(4x-1)5^{2x^2-x}\ln5$.
\item $x\in(-\infty,1)\cup(3,+\infty)$, \quad $y'=\dfrac{2x-4}{(x^2-4x+3)\ln3}$.
\item $y'=\cos^2x-\sin^2x=\cos2x$.
\item $x>0$, $x\ne1$, \quad $y'=\dfrac{xe^{2x}\bigl(2(1+x)\ln x-1\bigr)}{(\ln x)^2}$.
\end{enumerate}
