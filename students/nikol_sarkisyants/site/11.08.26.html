Что дано

2cos²x + sin²x = 2cos³x

Смысл условий

Аргумент везде одинаков: x. Косинус встречается чаще, поэтому синус удобно выразить через косинус.

sin²x + cos²x = 1 ⇒ sin²x = 1 − cos²x

Идея решения

Унификация
Оставить только cos x.
Замена
Обозначить t = cos x.
Ограничение
Для косинуса t ∈ [−1;1].
Финиш
После алгебры вернуться к x.

Пошаговое решение Пошаговый режимОткрывайте действия по одному: визуальная модель справа синхронно выделит соответствующий этап.

Шаг 1
sin²x = 1 − cos²x

Так все функции будут выражены через косинус.

Шаг 2
2cos²x + 1 − cos²x = 2cos³x
Шаг 3
2cos³x − cos²x − 1 = 0
Шаг 4
t = cos x, −1 ≤ t ≤ 1
2t³ − t² − 1 = 0
Шаг 5
(t − 1)(2t² + t + 1) = 0 ⇒ t = 1

Для 2t²+t+1 дискриминант D = −7, поэтому действительных корней нет.

Шаг 6
cos x = 1 ⇒ x = 2πn, n ∈ Z
Решение скрыто

Проверка и ответ

При x = 2πn имеем cos x = 1 и sin x = 0. Исходное равенство превращается в 2 = 2.

Ответ: x = 2πn, n ∈ Z.

Теорема Безу и целый корень

P(a)=0 ⇔ P(t) делится на (t−a)

Для многочлена с целыми коэффициентами каждый целый корень делит свободный член. Это даёт список кандидатов, который затем проверяется подстановкой.

Важно: делитель свободного члена — кандидат. Корнем он становится только после проверки P(a)=0.

Пример: полный алгоритм

P(t)=2t³−t²−1
Шаг 1 · Делители
делители −1: −1, 1
Шаг 2 · Подбор корня
P(1)=2·1³−1²−1=0

Значит, t = 1 — корень, поэтому множитель равен t − 1.

Шаг 3 · Подготовка
2t³−t²+0t−1
Шаг 4 · Деление уголком
(2t³−t²+0t−1) : (t−1) = 2t²+t+1
2t³−2t² → остаток t²+0t−1
t²−t → остаток t−1
t−1 → остаток 0
Шаг 5 · Разложение
2t³−t²−1 = (t−1)(2t²+t+1)
Решение скрыто

Ещё один пример

3t³+t²−4t−2=0

Кандидаты: ±1, ±2. Проверка даёт P(−1)=0, поэтому множитель t+1.

3t³+t²−4t−2 = (t+1)(3t²−2t−2)
t = −1; t = (1−√7)/3; t = (1+√7)/3

Если такая алгебраическая замена возникла из sin x или cos x, каждый найденный t затем проверяется по условию −1 ≤ t ≤ 1.

Отбор через двойное неравенство

Для общего решения x=2πn требуется выбрать корни на промежутке:

−7π/2 ≤ x ≤ −2π
Подставьте общий вид корня вместо x.
Разделите все части на положительное число 2π — знак не меняется.
Получите границы для целого параметра n.
Выберите только целые n и верните их в формулу x.

Расчёт

−7π/2 ≤ 2πn ≤ −2π
−7/4 ≤ n ≤ −1

Единственное целое значение на этом промежутке: n = −1.

Ответ: x = −2π.

Мини-памятка

Параметр целый
n или k принадлежит Z.
Двойное неравенство
Надёжнее отбора «на глаз».
Знак
При делении на положительное число сохраняется.
Финиш
Подставьте выбранные параметры обратно в x.

Что дано

log₁₁(2x²+1) + log₁₁(1/(32x)+1) ≥ log₁₁(x/16+1)

Основание 11 больше 1, поэтому после сведения к двум логарифмам с одинаковым основанием знак сравнения сохраняется.

ОДЗ ОДЗ только по исходникуСначала исследуйте тела исходных логарифмов. Позднейшие преобразования не должны подменять исходные ограничения.

Первое тело
2x²+1>0 при всех x.
Второе тело
1/(32x)+1>0.
Третье тело
x/16+1>0, то есть x > −16.
Пересечение
x∈(−16;−1/32)∪(0;+∞).

Пошаговое решение

Шаг 1
log₁₁((2x²+1)(1/(32x)+1)) ≥ log₁₁(x/16+1)
Шаг 2
(2x²+1)(1/(32x)+1) ≥ x/16+1
Шаг 3
[(2x²+1)(1+32x) − 2x(x+16)] / (32x) ≥ 0
Шаг 4
(64x³+1)/(32x) ≥ 0
Шаг 5
64x³+1=0 ⇒ x=−1/4; 32x=0 ⇒ x=0
Шаг 6
x∈(−∞;−1/4]∪(0;+∞)
Шаг 7
x∈(−16;−1/4]∪(0;+∞)
Решение скрыто

Типичные ошибки

Умножение на выражение с переменной.
Знак 32x заранее неизвестен, а при x=0 множитель вообще равен нулю. Надёжный путь — одна дробь и метод интервалов.
Включение нуля знаменателя.
Точка x=0 всегда исключается.
ОДЗ после преобразований.
Ограничения определяются по исходным логарифмам.
Смена направления.
При 0<a<1 логарифмическая функция убывает, поэтому знак сравнения меняется.

Показать решение

Ответ: x=π/2+πn, n∈Z.
2. Разложите на множителиСредняя

Показать решение

Проверяем целые делители свободного члена ±1, ±2. Например, P(1)=0, поэтому есть множитель t−1. После деления получаем t²−t−2.

t²−t−2=(t−2)(t+1)
Ответ: (t−1)(t−2)(t+1).
3. Решите неравенствоСредняя
log₃(x+2) ≥ log₃(5−x)
Показать решение

ОДЗ: −2<x<5. Основание 3 больше 1:

x+2 ≥ 5−x ⇒ x ≥ 3/2
Ответ: x∈[3/2;5).
4. Решите уравнениеВыше среднего
2cos³x−cos²x−1=0
Показать решение

Положим t=cos x, где t∈[−1;1].

2t³−t²−1=(t−1)(2t²+t+1)

У квадратного множителя D=−7, поэтому t=1.

Ответ: x=2πn, n∈Z.
5. Найдите все корниВыше среднего

Показать решение

P(−1)=0, поэтому делим на t+1:

(t+1)(3t²−2t−2)=0

Для квадратного множителя D=28.

Ответ: t=−1; (1−√7)/3; (1+√7)/3.
6. Решите уравнениеВыше среднего

Показать решение

Положим t=cos x и вынесем t:

t(4t²−t−1)=0

Получаем t=0 и t=(1±√17)/8. Все три значения принадлежат [−1;1].

Ответ:
x=π/2+πn;
x=±arccos((1+√17)/8)+2πn;
x=±arccos((1−√17)/8)+2πn, n∈Z.

Подходят k=−2,−1,0,1,2.

8. Решите неравенствоВыше среднего
log₅(x+4)+log₅(x−1) ≥ log₅(2x+6)
Показать решение

ОДЗ: x>1. Складываем логарифмы и сравниваем тела:

(x+4)(x−1) ≥ 2x+6 ⇒ x²+x−10 ≥ 0

Корни квадратного трёхчлена: (−1±√41)/2. С учётом x>1 остаётся правая ветвь.

Ответ: x∈[(−1+√41)/2;+∞).
9. Решите неравенствоВыше среднего

Показать решение

x+3 ≥ 7−x ⇒ x ≥ 2
Ответ: x∈[2;7).
