01 / МОДЕЛЬ

Как устроен дифференцированный кредит

Если основной долг уменьшается в одну и ту же дату на одну и ту же сумму, погашение идёт равными долями. Проценты начисляются на остаток долга перед очередным платежом.

01

Основная часть платежа

S / n

S — сумма кредита, n — число периодов.

02

Проценты за период

p · Di,   p = r / 100

Di — остаток основного долга перед начислением, r — ставка в процентах за период.

03

Полный платёж

Pi = S / n + p · Di

После i платежей остаётся S(1 − i / n). При p > 0 платежи уменьшаются.

Задача занятия · 2 года

1400 тыс. руб. → 1736 тыс. руб.

Основной долг ежегодно уменьшается на 700 тыс. руб. Найдём процентную ставку.

ГодДолгПроцентыПлатёжОстаток
114001400p700 + 1400p700
2700700p700 + 700p0

1400 + 2100p = 1736
p = 336 / 2100 = 0,16

Ответ: 16% годовых.

02 / ИНСТРУМЕНТ

Пять формул вместо длинной таблицы

Формулы применимы, когда тело кредита гасится равными долями и проценты начисляются на уменьшающийся остаток.

A = S + Sp(n + 1) / 2Общая сумма всех платежей
Δ = Sp(n + 1) / 2Переплата в денежных единицах
q = p(n + 1) / 2 · 100%Переплата в процентах от суммы кредита
P1 = S/n + SpПервый, наибольший платёж при p > 0
Pn = S/n + Sp/nПоследний, наименьший платёж при p > 0

Проверка по проценту переплаты

За 14 месяцев переплата составила 15% от суммы кредита:

p · 15 / 2 = 0,15 → p = 0,02

2% за месяц. Процент за месяц и процент переплаты за весь срок обозначают разные величины.

График и сравнение

В цифровой лаборатории можно менять сумму, срок и ставку кредита. Каждый платёж, проценты и остаток пересчитываются по одной формуле.

03 / СИСТЕМА

«Не более» и «не менее»

Ограничения для максимального и минимального платежа рассматриваем одновременно — в системе неравенств.

≤

Первый платёж — не более

S / n + Sp ≤ заданного максимума
≥

Последний платёж — не менее

S / n + Sp / n ≥ заданного минимума

Задача занятия

6 млн · 15 лет

Первый платёж ≤ 1,9 млн, последний ≥ 0,5 млн.

0,4 + 6p ≤ 1,9
0,4 + 0,4p ≥ 0,5

p ≤ 0,25 и p ≥ 0,25

Единственная ставка — 25%.

04 / ФОРМУЛЫ

Понижение степени

В квадрате косинуса или синуса полезно увидеть формулу двойного аргумента: это часто сокращает число отдельных уравнений.

sin² u = (1 − cos 2u) / 2Квадрат синуса
cos² u = (1 + cos 2u) / 2Квадрат косинуса
tg² u = (1 − cos 2u) / (1 + cos 2u)При cos u ≠ 0
ctg² u = (1 + cos 2u) / (1 − cos 2u)При sin u ≠ 0

Ключ к примеру

cos²(2x) = (1 + cos 4x) / 2

Поэтому уравнение cos²(2x) = 1/2 равносильно cos 4x = 0.

x = π/8 + πk/4,   k ∈ ℤ

Проверьте допустимость решения после обратной замены.

05 / РАЗБОР

От показательных степеней к cos 4x = 0

Главный приём: заметить повторяющийся показатель, сделать замену и вынести одинаковые степени.

42 + cos²(2x) − 4cos²(2x) = 91 + cos²(2x) + 9cos²(2x)

Замена

t = cos²(2x),   0 ≤ t ≤ 1
02

Вынесение степеней

15 · 4t = 10 · 9t
03

Одно основание

(4/9)t = 2/3 → (2/3)2t = (2/3)1 → t = 1/2

06 / ПРОВЕРКА

Ошибки, которые меняют ответ

После каждого преобразования проверяйте, на что было выполнено деление и что произошло с каждым слагаемым.

Деление на cos x

Из sin x + cos x = 1 при cos x ≠ 0 следует tg x + 1 = 1/cos x. Единицу справа тоже делим на cos x. Случай cos x = 0 проверяем отдельно.

Знак и арифметика

−3 + 1/2 = (−6 + 1)/2 = −5/2. Вынести минус можно из всего числителя. 24 + 20 = 44.
