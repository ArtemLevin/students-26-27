Главная идея

Вектор по точкам
AB→=(xB−xA;yB−yA)
Конец − начало.
Длина
|a|=x2+y2
В пространстве добавляется z².
Линейные действия

Сложение, вычитание и умножение на число выполняются покоординатно.

Контроль знаков

Отрицательные координаты при возведении в квадрат мысленно берите в скобки: (−7)² = 49.

Пример: 3a − 2b Открывайте этапы по одному и сверяйте каждый со схемой справа.

Дано: a = (−3; 2), b = (−1; 9). Найти длину c = 3a − 2b.

Идея: сначала получить координаты 3a и 2b, затем c, затем применить формулу длины.

Умножьте a на 3: 3a = (−9; 6).
Умножьте b на 2: 2b = (−2; 18).
Вычтите покоординатно: c = (−9; 6) − (−2; 18) = (−7; −12).
Найдите длину: |c|=(−7)2+(−12)2=193.
Проверка: квадрат длины равен 49 + 144 = 193, поэтому длина положительна и равна √193.

Две формулы скалярного произведения

Есть координаты
a→·b→=xaxb+yayb
Есть длины и угол
a→·b→=|a||b|cosφ
Для ненулевых векторов a ⟂ b ⇔ a·b = 0. Знак произведения сообщает тип угла: плюс — острый, ноль — прямой, минус — тупой.

Квадрат длины разности

|a−b|2=|a|2+|b|2−2a→·b→

При |a| = 6, |b| = 8, φ = 60° получаем a·b = 24, затем |a−b|² = 52 и |a−b| = 2√13.

Угол между векторами

cosφ=a→·b→|a||b|

Если |a| = 2, |b| = 5, a·b = −5, то cos φ = −1/2 и φ = 120°. Минус отбрасывать нельзя.

AB→·AD→=4·4+3·(−3)=7

|AB|=|AD|=5, поэтому cos ∠BAD = 7/25.

Типичные ошибки

Перепутано направление.
Для AB всегда B−A.
Забыли координату.
При умножении на число умножаются все координаты.
Потерян минус.
В |a−b|² перед 2a·b стоит минус.
Отброшен знак cos.
Отрицательный cos означает тупой угол.
