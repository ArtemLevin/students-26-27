Меняем вероятность. Наблюдаем разброс.

В пособии рассматривается величина X, принимающая значения 0 и 2 с вероятностями 0,7 и 0,3. Меняйте вероятность второго исхода: первый пересчитывается так, чтобы сумма всегда оставалась равной единице.

01 / управление опытом

Два возможных значения

Значения X неизменны: 0 или 2. Изменяется только вероятность появления каждого исхода.

0,30
01

Вероятность P(X = 0) = 0,70. Сумма двух вероятностей всегда равна 1.

На горизонтальной оси справа отмечается математическое ожидание. Оно перемещается вместе с вероятностью, а рассчитанные величины всегда соответствуют текущему распределению.

Что проверяется

M(X)=x1p1+x2p2
D(X)=M(X2)−(M(X))2

02 / зависимые значения

Распределение и среднее

0,60математическое ожидание M(X)
0,84дисперсия D(X)
0,92стандартное отклонение σ(X)
Показать вычисления для текущего состояния
Шаг 1. M(X) = 0 · 0,70 + 2 · 0,30 = 0,60.
Шаг 2. M(X²) = 0² · 0,70 + 2² · 0,30 = 1,20.
Шаг 3. D(X) = 1,20 − (0,60)² = 0,84.
Шаг 4. σ(X) = √0,84 ≈ 0,92.

При p = 0,30 получаем результат из пособия.
