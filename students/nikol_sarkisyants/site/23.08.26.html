Три опорных алгоритма Подсказка
Сначала определите тип уравнения. Алгоритм выбирается по внешней структуре выражения.

Показательное уравнение
Разложите числа на степени удобного основания.
Соберите степени с переменной.
Получите одинаковые основания.
Приравняйте показатели и проверьте арифметику.

Полезно: (4/3)^t = (3/4)^−t.

Уравнение с корнем

√f(x)=g(x): сначала g(x) ≥ 0, затем f(x)=g²(x).

Фильтрующее условие отсекает посторонние корни, которые могли появиться после возведения в квадрат.

Логарифмическое уравнение

logₐ f(x)=b ⇔ f(x)=aᵇ.

Условия: a>0, a≠1, f(x)>0.

Разбор примера

Корень: сначала условие, затем квадрат

Что дано: √(6x+13)=x+1.

Смысл условия: правая часть должна быть неотрицательной.

Идея решения
1) записать фильтр; 2) возвести обе части в квадрат; 3) решить квадратное уравнение; 4) отобрать допустимый корень.
Шаг 1. x+1≥0, то есть x≥−1.
Шаг 2. Возводим в квадрат: 6x+13=(x+1)².
Шаг 3. Получаем x²−4x−12=0, кандидаты x=6 и x=−2.
Шаг 4. Фильтр x≥−1 оставляет только x=6.
Проверка. √49=7 и 6+1=7. Ответ: 6.
Типичные ошибки

Что особенно контролировать

Ошибка 1. Сразу возводить уравнение с корнем в квадрат без условия неотрицательности правой части.
Ошибка 2. Терять знак показателя при переходе к обратной дроби.
Ошибка 3. Забывать ОДЗ логарифма.
Теория

Пять формул площади — один метод выбора

Смотрите на то, какие данные уже есть в условии. Формула выбирается по набору известных величин.

Основание + высота

S = ½ahₐ

Две стороны + угол между ними

S = ½ab·sinγ

Три стороны: Герон

S = √(p(p−a)(p−b)(p−c))

Вписанная окружность

S = pr

Описанная окружность

S = abc/(4R)

Метод равенства площадей
Запишите площадь одной фигуры двумя подходящими способами и приравняйте выражения.

Пример 3–4–5: два радиуса из одной площади

Что дано: прямоугольный треугольник со сторонами 3, 4 и 5.

Смысл условий: площадь легко получить как половину произведения катетов.

Идея: сначала S=6; затем приравнять эту площадь формулам через R и r.
S=½·3·4=6.
6=(3·4·5)/(4R), поэтому R=5/2.
p=(3+4+5)/2=6 и 6=6r, значит r=1.

Прямоугольный треугольник — главный объект повторения

Пифагор

c²=a²+b²

Площадь

S=½ab

Высота к гипотенузе

h=ab/c

Описанная окружность

R=c/2

Медиана к гипотенузе

AM=BM=CM=AB/2

Стратегия
В сложной планиметрии ищите готовый прямоугольный треугольник или создавайте его дополнительным построением.

Высота, биссектриса и медиана при B=32°

Второй острый угол равен 58°. Биссектриса прямого угла даёт 45°. Медиана к гипотенузе создаёт равнобедренные треугольники.

Если из-за рисунка получается отрицательная величина угла, проверьте взаимное расположение линий: чертёж должен сохранять порядок объектов, заданный условием.
Ключевые теоремы

Как выбрать формулу по набору данных

Теорема синусов

a/sin A = b/sin B = c/sin C = 2R.

Каждая сторона стоит рядом с синусом противолежащего угла.

Теорема косинусов

a²=b²+c²−2bc cos A.

Если ищете угол, записывайте формулу для стороны, которая лежит напротив этого угла.

Пример: стороны 3, 4, 5

Ищем угол между сторонами 3 и 5; напротив него лежит сторона 4.

4²=3²+5²−2·3·5 cos A, поэтому cos A=3/5=0,6.

Критическая ошибка

Корень нельзя распределять по разности

Неверно: √(a²−b²)=a−b.
Правильно: сначала вычислите всё под корнем. Если решаете z²=A, то z=±√A. Сам символ квадратного корня означает неотрицательное значение.

Для внутреннего угла треугольника синус положителен.
