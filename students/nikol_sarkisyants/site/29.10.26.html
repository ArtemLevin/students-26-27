01 / Постановка

Сначала выделите переменную

В вопросе «при какой скорости» переменной служит скорость v. Остальные величины в конкретной задаче считаются постоянными.

Например, при фиксированных M, R, T > 0:

f(v) = 4πv² (M / 2πRT)3/2 · e−Mv²/(2RT)

Соберём постоянные множители в две буквы:

A=4π(M2πRT)32>0B=−M2RT<0

Рабочая форма

f(v) = Av²eBv²,   A > 0, B < 0

Сначала решаем в буквах. Значения физических величин подставляем после упрощения.

Определите аргумент

В f(v) аргумент — v. В f(ε) аргумент — ε.

Сохраняйте знак

Если минус включён в B, повторно ставить его в показателе нельзя.

Сохраняйте единицы

Максимум плотности и значение аргумента максимума — разные ответы.

02 / Инструменты

Четыре правила производной

Самое частое затруднение — пропуск множителя исходной экспоненты после дифференцирования показателя.

СитуацияПравило
Произведение(uv)′ = u′v + uv′
Сложная экспонента(eg(x))′ = g′(x)eg(x)
Корень, x > 0(√x)′ = 1/(2√x)
Частное, v ≠ 0(u/v)′ = (u′v − uv′)/v²

Пример с квадратом в показателе

(eBv2)′=2BveBv2

В показателе Bv², производная показателя равна 2Bv.

Контроль общего множителя

2x² + 3x + 5 = x(2x + 3) + 5.

Пятёрка не содержит множителя x. Вынести x из всей суммы нельзя.

03 / Энергия

Максимум при ε = kT/2

Плотность распределения кинетической энергии: положительный коэффициент, корень из энергии и убывающая экспонента.

f(ε) = A√ε · e−Bε,   A,B > 0, ε ≥ 0
1
Производная произведения при ε > 0
f′(ε) = Ae−Bε [1/(2√ε) − B√ε]
2
Вынесите положительный множитель
f′(ε) = Ae−Bε (1 − 2Bε)/(2√ε)
3
Решите 1 − 2Bε = 0
ε* = 1/(2B) = kT/2

Экспонента строго положительна, а знаменатель положителен при ε > 0.

Функция возрастает до ε*, после убывает; f(0)=0, при больших ε значение стремится к нулю. Это глобальный максимум.

Числовой пример из занятия

k = 1,38 · 10−23 Дж/К, T = 80 К.

ε* = (1,38 · 10−23 · 80)/2 = 5,52 · 10−22 Дж

Учитывайте порядок величины: степень десяти следует сохранять на каждом шаге.

04 / Скорость

Вторая модель, тот же метод

Для скоростей молекул решаем задачу по переменной v ≥ 0. Величины M, R и T фиксированы.

f(v) = Av²eBv²,   A > 0, B < 0
1
Дифференцируйте два множителя
f′(v) = 2AveBv² + 2ABv³eBv²
2
Вынесите общий множитель
f′(v) = 2AveBv² (1 + Bv²)
3
Исследуйте v > 0
1 + Bv² = 0 → v² = −1/B → v* = √(−1/B)

Точка v = 0 — граница области. При v > 0 знак производной меняется с плюса на минус в v*.

Возвращаем физические обозначения

B = −M/(2RT) → v* = √(2RT/M)

В задаче с R = 8,31, T = 450, M = 0,004 получаем v* ≈ 1367 м/с.

05 / Сложный случай

Когда замена почти бесполезна

Функция колебательной системы содержит переменную одновременно в числителе, под корнем и во внутреннем знаменателе. Здесь пригодится прямое дифференцирование.

F(ω) = ULω / √[R² + (Lω − 1/(Cω))²],   ω > 0
1
Обозначьте h(ω)=Lω−1/(Cω).
2
Вычислите h′(ω)=L+1/(Cω²).
3
Пусть Q(ω)=R²+h(ω)². Тогда Q′=2hh′.
4
Запишите F(ω)=ULω·Q−1/2, примените произведение и цепное правило.
После упрощения
F′(ω) = UL(Q − ωhh′)/Q3/2

Числовая подстановка на раннем этапе приводит к громоздким вычислениям. Сначала приводим формулу к виду, удобному для исследования.

Три типичные ошибки

Потерять множитель экспоненты; вынести x из слагаемого без x; автоматически считать нуль производной максимумом, не проверив знаки и границы.
