Окружность, вписанная в трапецию

Решение и ответ не представлены.

К сводке ↑

Текст задания

Периметр прямоугольной трапеции, описанной около окружности, равен 3232. Найдите радиус окружности, если большая боковая сторона равна 99.

Ваше решение

Письменное решение на представленной странице отсутствует.

Ваш ответ

Не указан.

Ошибка

Задание не завершено: не использованы свойства трапеции, описанной около окружности.

Где именно возникает проблема

После условия нет первого математического шага. Последнего правильного преобразования и первого неправильного преобразования здесь нет: работа не начата.

Почему без этого нельзя получить ответ

Периметр сам по себе не задаёт высоту произвольной трапеции. Нужно воспользоваться дополнительным условием касания всех четырёх сторон окружности. У описанного четырёхугольника суммы противоположных сторон равны. Кроме того, в прямоугольной трапеции одна боковая сторона перпендикулярна основаниям и является высотой; наклонная боковая сторона не короче высоты.

Ключевая идея

Сумма оснований равна сумме боковых сторон. Из периметра можно определить их сумму, затем найти высоту и радиус.

Исправление

Обозначим основания через a,ba,b, боковые стороны через c,dc,d. Начать следует с a+b=c+da+b=c+d и a+b+c+d=32a+b+c+d=32.

Полное правильное решение

Так как трапеция описана около окружности, a+b=c+d.a+b=c+d. По условию периметр равен 3232, поэтому (a+b)+(c+d)=32,2(c+d)=32,c+d=16.(a+b)+(c+d)=32,\qquad 2(c+d)=32,\qquad c+d=16. Большая боковая сторона равна 99; другая равна 16−9=7.16-9=7. В прямоугольной трапеции перпендикулярная боковая сторона равна высоте. Наклонная боковая сторона гипотенуза прямоугольного треугольника, а потому она не меньше высоты. Значит, высота h=7h=7. Вписанная окружность касается обоих параллельных оснований. Расстояние между этими прямыми равно диаметру окружности: h=2r,r=72=3,5.h=2r,\qquad r=\frac{7}{2}=3{,}5.

Проверка

Сумма боковых сторон действительно равна 9+7=169+7=16, а сумма оснований равна 1616 по свойству описанного четырёхугольника. Тогда периметр равен 16+16=3216+16=32. Диаметр окружности 2⋅3,5=72\cdot 3{,}5=7 совпадает с высотой.

Итог

Радиус окружности равен 3,53{,}5.

Решение прерывается до вычислений. Нет корректного начального шага, от которого можно продолжить записанный ход.

Почему это важно

Полная поверхность прямой призмы состоит из двух равных оснований и боковой поверхности. Если посчитать только площадь треугольника, боковые грани останутся неучтёнными. Чтобы найти боковую поверхность, нужны периметр основания и высота призмы.

Ключевая идея

Исправление

Сначала определить гипотенузу прямоугольного треугольника. По условию именно она равна высоте призмы.

Полное правильное решение

Пусть катеты основания равны a=33a=3\sqrt3 и b=43b=4\sqrt3. Боковая поверхность прямой призмы: Sбок=Pоснh=123⋅53=180.S_{\text{бок}}=P_{\text{осн}}h=12\sqrt3\cdot5\sqrt3=180. Полная поверхность: Sполн=2⋅18+180=216.S_{\text{полн}}=2\cdot18+180=216.

Два треугольных основания дают площадь 3636. Три прямоугольные боковые грани дают площади 4545, 6060 и 7575; их сумма 180180. Получаем 36+180=21636+180=216.

Можно сделать два выстрела по первой и один по второй мишени либо один по первой и два по второй. Выберите вариант с большей вероятностью попасть в обе мишени и укажите эту вероятность.

Ваше решение

Ошибка

Не рассмотрены два допустимых варианта и не найдена вероятность попадания в обе мишени.

Где именно возникает проблема

Нет первого шага сравнения вариантов; ошибочных промежуточных вычислений в записи нет.

Почему простого сложения недостаточно

Для мишени, в которую стреляют дважды, событие «попасть хотя бы один раз» включает три возможных сочетания результатов. Удобнее рассмотреть противоположное событие: оба раза промахнуться. Затем вероятность поражения обеих мишеней при независимых выстрелах получают умножением вероятностей соответствующих попаданий.

Ключевая идея

Для двух выстрелов вероятность хотя бы одного попадания равна единице минус вероятность двух промахов. Затем сравнить произведения для обоих вариантов.

Исправление

Записать отдельно вероятность успеха для варианта с двумя выстрелами по первой мишени и варианта с двумя выстрелами по второй мишени.

Полное правильное решение

Первый вариант: два выстрела по первой мишени и один по второй. Вероятности промахов по первой мишени равны 1−0,5=0,51-0{,}5=0{,}5 и 1−0,6=0,41-0{,}6=0{,}4. При независимых выстрелах вероятность двух промахов равна 0,5⋅0,4=0,20.0{,}5\cdot0{,}4=0{,}20. Поэтому вероятность хотя бы одного попадания в первую мишень: 1−0,20=0,80.1-0{,}20=0{,}80. Вероятность попадания во вторую мишень одним выстрелом равна 0,60{,}6. Следовательно, P1=0,80⋅0,6=0,48.P_1=0{,}80\cdot0{,}6=0{,}48. Второй вариант: один выстрел по первой мишени и два по второй. Вероятности двух промахов по второй мишени равны 0,40{,}4 и 0,30{,}3; их произведение: 0,4⋅0,3=0,12.0{,}4\cdot0{,}3=0{,}12. Значит, вероятность попасть во вторую мишень хотя бы раз равна 1−0,12=0,88.1-0{,}12=0{,}88. Для первой мишени вероятность попадания одним выстрелом 0,50{,}5. Получаем P2=0,5⋅0,88=0,44.P_2=0{,}5\cdot0{,}88=0{,}44. Сравнение показывает: 0,48>0,440{,}48>0{,}44.

Проверка

Обе вероятности находятся между нулём и единицей. Разность 0,48−0,44=0,04>00{,}48-0{,}44=0{,}04>0, следовательно, первый вариант лучше.

Итог

Следует выбрать два выстрела по первой мишени и один по второй; вероятность успеха 0,480{,}48.

В первую мишень стрелок попадает первым выстрелом с вероятностью 0,40{,}4, вторым с вероятностью 0,80{,}8; во вторую с вероятностями 0,70{,}7 и 0,60{,}6. Сравните варианты «два выстрела по первой и один по второй» и «один по первой и два по второй» и найдите наибольшую вероятность поразить обе мишени.

Ошибка

По условию M=2000M=2000, поэтому C−1000=2000,C=3000.C-1000=2000,\qquad C=3000.

Производная как наклон касательной

Найден наклон не той прямой; потерян минус.

К сводке ↑

Текст задания

На рисунке изображены график функции y=f(x)y=f(x) и касательная к нему в точке с абсциссой x0x_0. Найдите значение f′(x0)f'(x_0).

Ваше решение

Записано: $\tg\alpha=\frac32=1{,}5$. На рисунке построен вспомогательный треугольник с возрастающей наклонной стороной, отличной от касательной.

Ваш ответ

1,51{,}5.

Ошибка

Найдён наклон возрастающей вспомогательной прямой вместо убывающей касательной.

Где именно возникает ошибка

Последнее верное наблюдение: производная в точке определяется угловым коэффициентом касательной. Первый неверный шаг использование отношения 3/23/2 для наклона линии, которая не совпадает с касательной на рисунке. Поэтому получен положительный знак, хотя касательная убывает.

Почему этот шаг неверен

Производная f′(x0)f'(x_0) равна наклону касательной, а не наклону произвольно проведённого отрезка и не наклону хорды графика. Когда при движении вправо вдоль касательной значение yy уменьшается, приращение ординаты отрицательно. Следовательно, отношение приращения ординаты к приращению абсциссы тоже отрицательно.

Ключевая идея

Выбирать две узловые точки именно на нарисованной касательной и вычислять отношение вертикального изменения к горизонтальному.

Исправление

По клеткам касательная проходит, например, через точки (−3;−2)(-3;-2) и (−1;−3)(-1;-3). При движении вправо на 22 клетки она опускается на 11 клетку.

Полное правильное решение

Возьмём две точки касательной: A(−3;−2),B(−1;−3).A(-3;-2),\qquad B(-1;-3). Её угловой коэффициент равен k=yB−yAxB−xA=−3−(−2)−1−(−3)=−12=−0,5.k=\frac{y_B-y_A}{x_B-x_A}= \frac{-3-(-2)}{-1-(-3)}=\frac{-1}{2}=-0{,}5. Касательная проведена в точке с абсциссой x0x_0, поэтому f′(x0)=k=−0,5.f'(x_0)=k=-0{,}5.

Проверка

Нарисованная касательная идёт сверху слева вниз направо, следовательно, её угловой коэффициент отрицателен. Значение −0,5-0{,}5 согласуется с рисунком, а 1,51{,}5 нет.

Итог

Значение производной равно −0,5-0{,}5.

Задача на закрепление

Касательная к графику функции в точке с абсциссой x0x_0 проходит через точки (−2;4)(-2;4) и (4;1)(4;1). Найдите f′(x0)f'(x_0).
