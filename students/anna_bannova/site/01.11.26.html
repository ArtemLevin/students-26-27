Два автомобиля. Одно уравнение.

Сначала определяем, сколько ехал каждый автомобиль. Затем связываем два пути через расстояние между городами. Один и тот же порядок работает и при одновременном старте, и при задержке.

В центре занятияСкорость × время = путь

Независимо от вопроса задачи таблица связывает известные величины и неизвестную.

01 / Повторение

Из текста — в формулу

Рейтинг публикации рассчитывают по формуле:

R = (3In + Op + 2Tr) / A

Все показатели принадлежат промежутку от −2 до 2. При максимальных значениях каждого из них In = Op = Tr = 2, а R = 30.

Подстановка / Пример 1
30 = (3 · 2 + 2 + 2 · 2) / A
30A = 12;   A = 0,4

Проверка: 12 / 0,4 = 30. Поскольку A находится в знаменателе, A ≠ 0.

Слова «показатели максимальны» означают выбор верхней границы заданного интервала. Коэффициенты 3 и 2 при подстановке сохраняются.

02 / Основа

Три величины движения

s = vt
v = s / t;   t = s / v

s — расстояние (км), v — скорость (км/ч), t — время (ч). При делении t > 0, v > 0.

Главное равенство встречи

s₁ + s₂ = S

Автомобили встретились, поэтому их пройденные пути составляют весь промежуток между городами.

Одновременно: t₁ = t₂. С задержкой Δt: tраньше = tпозже + Δt.

03 / Маршрут

Один порядок действий

  1. Внимательно прочитайте условие. При необходимости нарисуйте отрезок А–Б.
  2. Выберите x: искомую величину или ту, с которой уравнение окажется проще.
  3. Заполните таблицу «скорость — время — расстояние», используя s = vt или t = s / v.
  4. Найдите ещё не использованную связь: сумма пройденных путей равна S, времена равны или отличаются на задержку.
  5. Составьте и решите уравнение. Если x был вспомогательной величиной, вычислите искомую.
  6. Проверьте знак, единицы, время движения и сумму путей. Запишите ответ на вопрос задачи.

Если появляются неудобные дроби, полезно изменить смысл x. Когда ищут расстояние, можно сначала найти время и затем умножить его на скорость.

04 / Примеры

Выехали одновременно

Пример 2. Через сколько часов встретятся?

Между А и Б 560 км. Скорости автомобилей 60 и 80 км/ч.

Автомобильvts
Из А60x60x
Из Б80x80x
60x + 80x = 560
x = 4 ч

Пример 3. Где встретятся?

Между городами 480 км. Из А едет автомобиль со скоростью 55 км/ч, из Б — 65 км/ч.

Если x — расстояние от А:

x / 55 = (480 − x) / 65
x = 220 км

Если x — время:

55x + 65x = 480;   x = 4
55 · 4 = 220 км
05 / Сложнее

Один стартует раньше

Пример 4. Время после второго старта

S = 580 км. Первый едет 80 км/ч и выехал на 2 часа раньше второго, который едет 60 км/ч.

Ктоvts
Первый80x + 280(x + 2)
Второй60x60x
80(x + 2) + 60x = 580
x = 3 ч

Проверка: 400 км + 180 км = 580 км.

Пример 5. Расстояние от города Б

S = 510 км. Первый едет 60 км/ч, второй — 70 км/ч и выезжает через 2 часа.

Пусть x — время первого, тогда у второго x − 2. Требуется x > 2.

60x + 70(x − 2) = 510
x = 5 ч
70 · (5 − 2) = 210 км
Проверить задержку в лаборатории

Первый выехал раньше ⇒ он ехал дольше. При x — времени второго пишем x + 2 для первого, а при x — времени первого пишем x − 2 для второго.
