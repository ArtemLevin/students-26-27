01 / BASE

Привести к степенному виду

Вычисления со степенями: раскладывайте составные числа на множители, группируйте одинаковые основания, учитывайте скобки.

Умножение и деление
ar·as=ar+s
aras=ar−s
Степень степени
ars=ars
Отрицательная степень
a−r=1ar
Дробная степень
apq=aqp

В частном a ≠ 0. Для несократимого показателя p/q при чётном q требуется a ≥ 0; при отрицательном показателе дополнительно a ≠ 0. Свойство степени степени используйте только при сохранении области определения.

Повторение: скобки меняют результат

54−1=45

А запись 5⁻¹/4 равна 1/20. В первом случае показатель относится ко всей дроби, во втором — только к пятёрке.

02 / ROOTS

Не потерять отрицательный корень

При чётной степени выражения возможны два противоположных значения. Проверяйте ограничения и подстановку.

Случай A · знаменатель чётный
x32=64

x ≥ 0. Получаем x = 16; других действительных корней нет.

Случай B · числитель чётный
x43=81

Пусть u = ∛x. Тогда u⁴ = 81, u = ±3, x = ±27.

Случай C · степень отрицательная
x−4=81

x ≠ 0; x⁴ = 1/81; оба корня x = ±1/3 подходят.

Контроль полноты
x43=16

Подстановка подтверждает сразу два значения: x = −8 и x = 8.

Из u⁴ = 16 следует u = ±2. Из u³ = 8 следует только u = 2. Механическое возведение обеих частей в обратную степень без учёта знака может потерять решение.

03 / CUBE

Кубический зонд

Найдите наибольший размер аппарата при ограниченной силе натяжения троса.

Модель
F=ρgL3−mg

F — сила натяжения, ρ — плотность воды, g — ускорение свободного падения, L — линейный размер, m — масса.

  1. F ≤ 1000 Н, ρ = 1000 кг/м³, g = 10 м/с², m = 25 кг.
  2. 10000L³ − 250 ≤ 1000.
  3. L³ ≤ 125/1000 = (5/10)³.
  4. При L ≥ 0 имеем 0 ≤ L ≤ 0,5 м.
Максимум: L = 0,5 м.
Удобное разложение

Для второго числового примера получено L³ = 216/1000. Разложение на множители помогает увидеть точный куб.

216=23·33=63
L=610=0,6

Знак «не больше» остаётся частью условия. Граничное равенство даёт допустимый максимум.

04 / TIME

Радиоактивный распад

Как долго масса изотопа будет не меньше указанного порога?

Модель
m(t)=m0·2−tT

m₀ — начальная масса, T — период полураспада, t ≥ 0 — время; m(t) обозначает массу именно в момент t.

  1. m₀ = 40 мг, T = 10 мин, m(t) ≥ 5 мг.
  2. 2⁻ᵗ/¹⁰ ≥ 1/8 = 2⁻³.
  3. Приравниваем показатели: −t/10 ≥ −3.
  4. После умножения на −10 знак меняется: 0 ≤ t ≤ 30.
Ответ: в течение первых 30 минут.
Граница условия

В момент t = 30 мин масса равна 5 мг. Раньше — больше 5 мг, позже — меньше 5 мг. Поэтому исходное «не меньше» приводит к интервалу времени.

Функция убывает при t ≥ 0, так как основание 2 стоит в отрицательной степени.

05 / METHOD

Маршрут решения

Один и тот же подход работает в обеих прикладных задачах.

1Прочитать формулу, назвать величины.
2Выписать значения, единицы и знак.
3Подставить и выразить неизвестную.
4Проверить границу и смысл ответа.

A = B и B = A равносильны без смены знаков. При переносе слагаемого выполняйте обратную операцию. В неравенствах меняйте направление знака при умножении или делении на отрицательное число.
