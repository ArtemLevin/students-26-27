01 / METHOD

График → система → формула

Опорная (узловая) точка — точка графика с удобными, обычно целыми координатами. В записи A(x; y) сначала стоит абсцисса x, затем ордината y = f(x).

Вид 1
f(x)=ax+b

Слагаемое b прибавляется к степени. При x = 0 получаем f(0) = 1 + b.

Вид 2
f(x)=ax+b

Весь показатель равен x + b. При f(x) = 1 и a > 0, a ≠ 1 получаем x + b = 0.

Выбор точек
Для двух неизвестных коэффициентов a и b достаточно двух подходящих точек с разными абсциссами. Удобны x = 0, x = 1, x = −1 или y = 1.
Ограничения
Основание показательной функции a > 0 и a ≠ 1. Если получили a2 = 4, сохраняем положительное решение a = 2.
Свойства
a0=1, a−n=1/an, (am)n=amn.
02 / GRAPH

От двух точек к двум коэффициентам

Дана функция f(x)=ax+b. На графике отмечены A(0; −2) и B(1; −1). Требуется найти f(6).

Система
−2=a0+b
−1=a1+b
Коэффициенты
b=−3;a=2
Искомая функция
f(x)=2x−3
Ответ
f(6)=64−3=61

Решение по шагам

Нажимайте «Следующий шаг»: откроется следующее действие алгоритма. Предыдущие шаги останутся видимыми.

  1. Выбираем две точки: A(0; −2), B(1; −1).
  2. Подставляем координаты: −2 = a0 + b,  −1 = a1 + b.
  3. Упрощаем: a0 = 1, поэтому −2 = 1 + b; получаем b = −3.
  4. Находим a: −1 = a − 3, значит a = 2 (основание положительно).
  5. Собираем формулу: f(x) = 2x − 3.
  6. Отвечаем на вопрос: f(6) = 26 − 3 = 61. Проверка: f(0) = −2, f(1) = −1.

03 / QUESTION

Те же действия, другой вопрос

Рассмотрим A(0; −1) и B(2; 1) для функции f(x) = ax + b. Требуется найти x, если f(x) = 25.

Восстанавливаем формулу

−1=1+b→b=−2
1=a2−2→a2=3
a=3=312
f(x)=3x2−2

Ищем аргумент

3x2−2=25
3x2=27=33
x/2=3
x=6

Значение функции известно, неизвестен аргумент x. Коэффициенты a и b по-прежнему находим сначала.

Отрицательная абсцисса — отрицательная степень

Для A(0; −3), B(−2; 0) получаем b = −4 и a−2 = 4. Тогда a = 1/2 = 2−1, поэтому f(x) = 2−x − 4 и f(−4) = 12.

При преобразовании (2−1)x = 2−x минус в показателе сохраняется.

04 / EXPONENT

Когда b находится в показателе

Функция f(x)=ax+b, точки A(−3; 1) и B(1; 4). Нужно вычислить f(−7).

Первая точка
1=a−3+b

Поскольку 1 = a0 и a ≠ 1, получаем −3 + b = 0, то есть b = 3.

Вторая точка
4=a1+3=a4

a = 414 = 212.

Финал
f(x)=2x+32
f(−7)=2−2=0,25

06 / REVIEW

Самопроверка перед ответом

Проверьте каждый пункт, прежде чем сравнивать вычисления с ответами.

  • Координаты записаны как (x; y), где y = f(x).
  • Степень имеет вид x или x + b в точном соответствии с условием.
  • Использованы a0 = 1 и положительность основания a.
  • Знаки минус при переносах, отрицательных координатах и показателях сохранены.
  • Найденные коэффициенты воспроизводят обе опорные точки.
  • Получен именно ответ на вопрос: f(t) или аргумент x.
