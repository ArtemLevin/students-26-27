Узловые точки

Выберите один из трёх разобранных случаев, перемещайте аргумент x по графику и сравнивайте координаты точки со значением функции.

Центральный приём
f(x) = 2x − 3

Две узловые точки определяют коэффициенты a и b в выбранной формуле.

Выберите разобранную модель
Измените x и наблюдайте координату y
Текущее состояние
f(1) = −1

2¹ − 3 = −1

Узловые точки из условия
A
(0; −2)
B
(1; −1)
Найденные коэффициенты
a = 2; b = −3
Метод / Объяснение

От координат к системе

Подставьте в f(x)=aˣ+b сначала точку A(0; −2): −2 = a⁰ + b. Затем точку B(1; −1): −1 = a + b. Получится a=2, b=−3.

Условие

Первая координата

В записи (x; y) первую координату подставляем вместо x, вторую — вместо f(x).

Последний шаг

Что требуется найти?

При f(c) подставляем c вместо x; при f(x)=k подставляем k вместо всего значения функции.

Мини-эксперимент

Как поведёт себя функция?

Предскажите, что произойдёт с f(x), если увеличить x в выбранном случае.

Выберите один из ответов и сравните с графиком.
