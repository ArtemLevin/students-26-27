Равные отрезки

В геометрии сравниваем противоположные стороны прямоугольника. В алгебре различаем пересечение («и») и объединение («или»).

01

Геометрическая задача

Девять квадратов — одна переменная

Прямоугольник составлен из девяти квадратов разных размеров. Сторона наименьшего равна 1. Обозначаем сторону опорного квадрата через x и выражаем через неё остальные стороны. Используем равенство сторон каждого квадрата и сложение соседних отрезков.

Шаг 1 из 11

Начальная сторона

1

Сторона самого маленького квадрата равна единице по условию.

Можно также нажимать непосредственно на квадраты.

Выбрать xОбозначьте сторону опорного квадрата одной буквой.
Сложить и вычестьПоследовательно выразите остальные длины через x.
ПриравнятьНайдите два выражения для противоположных сторон прямоугольника.
Решающая связь. Левая сторона AD равна правой стороне BC, поскольку ABCD — прямоугольник.

AD = (2x + 1) + (x + 1) + (x + 2) = 4x + 4

BC = (x + 11) + (x + 7) = 2x + 18

4x + 4 = 2x + 18 → x = 7

Финальная проверка

AB = (2x + 1) + (x + 11) = 33; BC = 2x + 18 = 32. Площадь — 33 · 32 = 1056. Сумма площадей квадратов: 1² + 4² + 7² + 8² + 9² + 10² + 14² + 15² + 18² = 1056.

Важная ловушка: равны противоположные стороны прямоугольника. Соседние стороны в общем случае различаются. Искомый прямоугольник имеет стороны 33 и 32.

02

Алгебра · числовая прямая

Пересечение или объединение?

Система требует выполнения всех неравенств одновременно: ищем общую часть. Совокупность допускает хотя бы одно верное условие: объединяем подходящие части. Замкнутая точка принадлежит множеству решений.

Исследуйте два условия

В системе совпадающая часть двух лучей образует отрезок.

Два условия на одной прямой

Первое условиеВторое условиеРезультат

[−5;10]

x ≥ −5 и x ≤ 10

Смешанная запись

Можно объединять несколько систем и отдельных неравенств. Например, множество (−∞; −5] ∪ [0; 1] ∪ [10; +∞) означает: слева от −5, между 0 и 1 или справа от 10. Участок [0; 1] задаётся двумя условиями одновременно: x ≥ 0 и x ≤ 1.

Если промежутки в совокупности пересекаются, их следует объединить. Операция «или» допускает пересечение областей.

Самостоятельная работа · Путь А

Десять задач на закрепление

Решайте по порядку. Ответы раскрывайте после собственного решения. Первые пять задач относятся к геометрии, следующие пять — к промежуткам.

  1. Отрезок длиной x продолжили на 1 единицу. Запишите общую длину.
    Проверить ответ

    x + 1.

  2. Отрезок длиной x + 3 состоит из частей x − 1 и y (x > 1). Найдите y.
    Проверить ответ

    y = 4.

  3. У прямоугольника противоположные стороны имеют длины 4x + 4 и 2x + 18. Найдите x и длину этих сторон.
    Проверить ответ

    x = 7; стороны равны 32.

  4. Для схемы из девяти квадратов найдите длины их сторон при x = 7. Выпишите по возрастанию.
    Проверить ответ

    1; 4; 7; 8; 9; 10; 14; 15; 18.

  5. По девяти длинам из задачи 4 найдите сумму площадей квадратов и сравните с площадью прямоугольника 33 × 32.
    Проверить ответ

    1056 квадратных единиц; совпадает с 33 · 32.

  6. Представьте промежуток [−3; 8) в виде системы неравенств.
    Проверить ответ

    Оба условия: x ≥ −3 и x < 8.

  7. Решите систему: x ≥ −2 и x < 5. Запишите ответ промежутком.
    Проверить ответ

    [−2; 5).

  8. Решите совокупность x ≤ −4 или x > 3. Изобразите ответ на оси.
    Проверить ответ

    (−∞; −4] ∪ (3; +∞).

  9. Запишите одной совокупностью множество [−6; −1] ∪ (2; 4] ∪ [7; +∞).
    Проверить ответ

    Три варианта: (x ≥ −6 и x ≤ −1); (x > 2 и x ≤ 4); x ≥ 7.

  10. Решите совокупность: (x ≥ −4 и x ≤ 1) или (x ≥ 0 и x < 5) или x ≥ 9. Объедините пересекающиеся промежутки.
    Проверить ответ

    [−4; 5) ∪ [9; +∞).
