01 / Знак

Деление меняет направление только вместе со знаком числа.

  • Прибавляем или вычитаемОдно и то же число с обеих сторон — знак сохраняется.
  • Умножаем на положительноеНаправление неравенства сохраняется.
  • Умножаем на отрицательноеЗнак разворачивается: «>» превращается в «<», «≥» — в «≤».
−3x > 12 ⇔ x < −4

Сложные скобки сначала раскройте, приведите подобные, затем перенесите слагаемые. Например:

3(2x − 1) − 2(x + 4) ≥ x − 5
6x − 3 − 2x − 8 ≥ x − 5
3x ≥ 6 ⇔ x ≥ 2

При делении на выражение с параметром сначала установите знак этого выражения. Делить на ноль запрещено.

02 / Множества

Круглая или квадратная?

Круглая скобка исключает границу, квадратная включает. Бесконечность всегда записывают с круглой скобкой.

x > 2 ⇔ x ∈ (2; +∞)
x ≥ 2 ⇔ x ∈ [2; +∞)
−3 < x ≤ 4 ⇔ x ∈ (−3; 4]
  • Пересечение A ∩ BЧасть, общая для обоих множеств.
  • Объединение A ∪ BВсе точки, принадлежащие хотя бы одному из множеств.
A = (−4; 2], B = [0; 5)
A ∩ B = [0; 2]
A ∪ B = (−4; 5)
Исследовать пересечение на числовой оси

03 / Оценки

Оценка состоит из строгих границ и условий.

Двойное неравенство преобразуйте одновременно во всех трёх частях. При умножении на отрицательное число обе стрелки меняют направление; границы записывают по возрастанию.

−3 < a < 2
−4 < −2a < 6
1 < 5 − 2a < 11

Сложение интервалов: складывайте соответствующие крайние значения. Для разности используйте противоположные границы. Для произведения и частного сравните четыре граничных результата, учитывая знаки и включённость границ.

При −5 < x < −2:
4 < x² < 25
−1/2 < 1/x < −1/5
Ограничение. Для частного сначала проверьте, может ли знаменатель обращаться в ноль. Если 0 принадлежит промежутку знаменателя, деление на границы неприменимо без дополнительного исследования. При −3 < a < 1 и −2 < b < −1 выражение 2a − 3b может равняться нулю, поэтому простая оценка дроби (a+b)/(2a−3b) была бы ошибочной.
Оценка числителя→Оценка знаменателя→Проверка нуля→Оценка частного

04 / Координаты

Читаем условие по высоте, ответ — по оси x.

Для y = f(x) условие f(x) > 0 описывает часть графика выше оси Ox; f(x) ≥ c — точки на уровне y = c или выше. Для строгих знаков точки равенства исключаются.

y = 2x + 4
точки (0; 4) и (−2; 0)
2x + 4 ≥ 0 ⇔ x ≥ −2

Для двух прямых y = f(x) и y = g(x) абсциссу точки пересечения находим из равенства f(x) = g(x). Затем подставляем найденный x в любую формулу для y.

2x − 3 = −5x + 2
x = 5/7; y = −11/7

05 / Три случая

Что стоит перед x?

В неравенстве kx ≤ b значение коэффициента k определяет способ решения. Если он зависит от параметра, разберите три случая.

k > 0

x ≤ b/k

Знак сохраняется.

k < 0

x ≥ b/k

Знак меняется.

k = 0

0 ≤ b

Проверяем числовое утверждение.

(3 − a)x ≤ 2a − 1
a = 3 ⇒ 0 ≤ 5 ⇒ x ∈ ℝ

Если числовое утверждение при нулевом коэффициенте ложно, решений нет. Если верно — подходят все действительные x.

06 / Обоснование

Доказываем равносильными переходами.

При 0 < a < b знаменатели b + 1 и b + 2 положительны. Поэтому умножение на их произведение сохраняет знак:

(a + 1)/(b + 1) < (a + 2)/(b + 2)
⇔ (a + 1)(b + 2) < (a + 2)(b + 1)
⇔ a < b

Последнее неравенство дано в условии. Это завершает доказательство.
