01 · Алгебраическая основа

Корни, множители и знаки

Квадратное уравнение — один из базовых узлов занятия. Его корни сразу дают разложение квадратного трёхчлена на множители, а это понадобится и при работе с дробями, и в методе интервалов.

D = b2 − 4ac
x1,2 = (−b ± √D) / 2a
Контроль знаков. Для x2 − x − 6 = 0 коэффициенты: a = 1, b = −1, c = −6. Поэтому D = (−1)2 − 4·1·(−6) = 25.
Разбор: x2 − x − 6 = 0
Шаг 1. D = 25.
Шаг 2. x1 = (1 + 5)/2 = 3.
Шаг 3. x2 = (1 − 5)/2 = −2.
Шаг 4. x2 − x − 6 = (x − 3)(x + 2).
Произведение равно нулюx2 − x = 0 → x(x − 1) = 0 → x = 0 или x = 1.
Квадрат равен числуx2 = 6 → x = ±√6. Знак ± терять нельзя.
02 · Линейные неравенства

Один знак решает всё

Линейные неравенства решаются почти как уравнения: раскрываем скобки, переносим слагаемые, приводим подобные. Особое правило возникает при делении или умножении на отрицательное число.

−4x ≥ 1  ⇒  x ≤ −1/4При делении на −4 знак неравенства меняется.
После решения ответ удобно записывать промежутком и отмечать на числовой прямой. Для x ≥ 1/4: [1/4; +∞).

Система неравенств = пересечение

Для системы x ≥ 1/2 и x ≤ 2 подходят только значения, удовлетворяющие обоим условиям:

x ∈ [1/2; 2]
Если «заборы» не пересекаются, решений нет: ответ — ∅.
03 · Системы уравнений

Подстановка: выразить удобнее

В методе подстановки выгодно выражать переменную с коэффициентом 1 или −1: меньше действий — меньше мест для ошибки со знаком.

−k + 2b = 4  ⇒  2b − 4 = k  ⇒  k = 2b − 4
Выразите удобную переменную из одного уравнения.
Подставьте выражение во второе уравнение.
Найдите первую переменную.
Вернитесь в выражение и найдите вторую.

Для системы 2k + b = 3, −k + 2b = 4 получаем b = 11/5 и k = 2/5.

04 · Дроби и рациональные уравнения

Сначала ограничения, затем преобразования

Главный порядок работы с алгебраической дробью: определить недопустимые значения, разложить выражения на множители и только после этого сокращать.

(x2 − x − 6)/(x2 − 4) = (x − 3)/(x − 2)x ≠ −2, x ≠ 2
Сокращаем только множители. Ограничение x ≠ −2 остаётся даже после исчезновения множителя x + 2.

Общий знаменатель

Для уравнения

(x + 1)/(x − 1) − (x − 1)/(x + 1) = 2

сначала записываем x ≠ ±1, затем приводим к знаменателю (x − 1)(x + 1) = x2 − 1.

(x + 1)2 − (x − 1)2 = 4x

После преобразований получаем x2 − 2x − 1 = 0, откуда x = 1 ± √2. Оба корня допустимы.

06 · Новый метод

Метод интервалов

Квадратное неравенство нельзя решить обычным «переносом x», потому что одновременно присутствуют x и x². Мы превращаем задачу в карту знаков выражения на числовой прямой.

Нормализуйте неравенство: справа 0, слева всё выражение.
Временно замените неравенство уравнением и найдите корни.
Отметьте корни на числовой прямой: они делят её на интервалы.
Возьмите удобную точку одного интервала и определите знак выражения.
Для простых корней при переходе через каждый корень знак меняется.
Выберите интервалы того знака, который требует исходное неравенство.

Калибровка на примере x² − x − 6 > 0

+−+ −23

Выберите контрольную точку центрального интервала и проверьте только знак результата.

Все три числа лежат между −2 и 3.
x ∈ (−∞; −2) ∪ (3; +∞)Для x² − x − 6 > 0 выбираем интервалы со знаком «+».
Строгость важна. Для > или < корни не включаем. Для ≥ или ≤ нули выражения включаем, если они допустимы.
Если корень имеет нечётную кратность, знак при переходе меняется. При чётной кратности знак сохраняется.
