Уравнения: увидеть замену

Сегодняшняя ключевая идея — находить повторяющийся фрагмент и превращать сложное уравнение в знакомое квадратное. Затем аккуратно учитывать ограничения, возвращаться к x и проверять результат.

Центральное преобразование
x⁴ − x² − 6 = 0
↓ Обозначаем t = x² ≥ 0
t² − t − 6 = 0

t = 3 подходит; t = −2 исключаем. Обратная замена: x = ±√3.

01 / ПОВТОРЯЮЩИЙСЯ ФРАГМЕНТ

Замена переменной

Узнайте одинаковую конструкцию в разных степенях. Ключевой вопрос: какое выражение выбрать за t?

В уравнении x⁴ − x² − 6 = 0 степень четыре возникает из квадрата x². Поэтому при t = x² получаем обычное квадратное уравнение.

(x²)² − x² − 6 = 0 → t² − t − 6 = 0
  1. Замена. Положим t = x² ≥ 0.
  2. Решение. (t − 3)(t + 2) = 0, откуда t = 3 или t = −2.
  3. Отбор. Значение t = −2 противоречит условию t ≥ 0.
  4. Обратная замена. x² = 3, значит x = −√3 или x = √3.
Типичная ошибка: забыть знак «минус» при извлечении квадратного корня. Для A² = c > 0 существуют два случая: A = ±√c.

Повторяться может целая скобка

Для (x − 2)⁴ − (x − 2)² − 6 = 0 заменяем t = (x − 2)² ≥ 0. Получаем тот же результат t = 3.

(x − 2)² = 3 → x = 2 ± √3
02 / ДРУГАЯ ФОРМА ЗАМЕНЫ

Когда заменить дробь

Выбирайте t так, чтобы после замены исчезли именно повторяющиеся дроби.

В этом примере замена только (x − 3)² оставит дроби. Удобнее заменить весь дробный фрагмент.

1/(x − 3)⁴ − 1/(x − 3)² − 6 = 0
t = 1/(x − 3)² > 0 → t² − t − 6 = 0

Исходная ОДЗ: x ≠ 3. Так как t > 0, допустимо только t = 3. Тогда (x − 3)² = 1/3.

x = 3 ± √3/3
Сравните ограничения: t = [A(x)]² ≥ 0, а t = 1/[A(x)]² > 0 и A(x) ≠ 0.
03 / ОБЛАСТЬ ДОПУСТИМЫХ ЗНАЧЕНИЙ

Корни и ограничения

ОДЗ записываем ещё до преобразований. Случайно сократив одинаковые корни, нельзя забывать исходное условие.

Квадратный корень

√A(x) определён, когда A(x) ≥ 0.

Дробь

1/B(x) определена, когда B(x) ≠ 0.

Разберём уравнение из пособия:

x² − 3x + √(x − 3) = 4 + √(x − 3)
  1. ОДЗ: x − 3 ≥ 0, то есть x ≥ 3.
  2. Одинаковые радикалы сокращаются: x² − 3x − 4 = 0.
  3. (x − 4)(x + 1) = 0. Кандидаты: 4 и −1.
  4. По ОДЗ подходит только x = 4.

Важно: после алгебраического решения подставляйте кандидатов в исходные ограничения. Даже если одинаковые радикалы исчезли, ОДЗ сохраняется.

04 / РАЦИОНАЛЬНЫЕ УРАВНЕНИЯ

Строим общий знаменатель

Сначала раскладываем знаменатели на множители. Затем собираем их в высших степенях.

Для трёх знаменателей из занятия:

x² − 9 = (x − 3)(x + 3)
x² − 6x + 9 = (x − 3)²
2x² + 6x = 2x(x + 3)

ОДЗ: x ≠ −3, 0, 3. Наименьший общий знаменатель:

НОЗ = 2x(x − 3)²(x + 3)
ЗнаменательДополнительный множитель
(x − 3)(x + 3)2x(x − 3)
(x − 3)²2x(x + 3)
2x(x + 3)(x − 3)²

Рассмотрим 3/(x² − 9) − 1/(x² − 6x + 9) = 3/(2x² + 6x). После переноса, приведения к НОЗ и умножения на него:

6x(x − 3) − 2x(x + 3) − 3(x − 3)² = 0
x² − 6x − 27 = 0 → (x − 9)(x + 3) = 0

Кандидат x = −3 запрещён исходным знаменателем, остаётся x = 9.

05 / ФОРМУЛЫ СОКРАЩЁННОГО УМНОЖЕНИЯ

Разность кубов

Формула помогает разложить знаменатель до приведения дробей к общему знаменателю.

a³ − b³ = (a − b)(a² + ab + b²)
x³ − 27 = (x − 3)(x² + 3x + 9)

В уравнении 1/(x − 3) + 10/(x² + 3x + 9) = 27/(x³ − 27) знаменатель (x − 3)(x² + 3x + 9) общий для всех дробей. ОДЗ: x ≠ 3.

  1. После приведения числителей: (x² + 3x + 9) + 10(x − 3) − 27 = 0.
  2. Получаем x² + 13x − 48 = 0.
  3. (x + 16)(x − 3) = 0; значение 3 не входит в ОДЗ.
  4. Ответ: x = −16.

06 / САМОСТОЯТЕЛЬНОЕ ЗАКРЕПЛЕНИЕ

Путь А · 10 заданий

Сначала решите каждое уравнение самостоятельно, затем раскройте подсказку и сравните ответ.

При замене указывайте t и его ограничения. В дробных уравнениях записывайте ОДЗ до преобразований. Ответы приведены по возрастанию.

  1. 01
    x⁴ − 5x² + 4 = 0
    Показать подсказку и ответ

    t = x²; t = 1 или 4; x² = 1 или 4.

    Ответ: −2; −1; 1; 2

  2. 02
    x⁴ − 3x² − 4 = 0
    Показать подсказку и ответ

    t = x² ≥ 0; t = 4, а t = −1 отклоняется.

    Ответ: −2; 2

  3. 03
    (x − 1)⁴ − 5(x − 1)² + 4 = 0
    Показать подсказку и ответ

    t = (x − 1)²; t = 1 или 4.

    Ответ: −1; 0; 2; 3

  4. 04
    (x + 2)⁴ − 3(x + 2)² − 4 = 0
    Показать подсказку и ответ

    t = (x + 2)²; допустимо только t = 4.

    Ответ: −4; 0

  5. 05
    1/(x − 4)⁴ − 3/(x − 4)² − 4 = 0
    Показать подсказку и ответ

    x ≠ 4; t = 1/(x − 4)² > 0; t = 4.

    Ответ: 7/2; 9/2

  6. 06
    1/(x + 1)⁴ − 5/(x + 1)² + 4 = 0
    Показать подсказку и ответ

    x ≠ −1; t = 1/(x + 1)² > 0; t = 1 или 4.

    Ответ: −2; −3/2; −1/2; 0

  7. 07
    x² − 3x + √(x − 3) = 4 + √(x − 3)
    Показать подсказку и ответ

    x ≥ 3; кандидаты 4 и −1. Остаётся x = 4.

    Ответ: 4

  8. 08
    x² − 3x + √(x − 5) = 4 + √(x − 5)
    Показать подсказку и ответ

    x ≥ 5; кандидаты 4 и −1. Оба недопустимы.

    Ответ: ∅

  9. 09
    3/(x² − 9) − 1/(x² − 6x + 9) = 3/(2x² + 6x)
    Показать подсказку и ответ

    x ≠ −3, 0, 3; НОЗ = 2x(x − 3)²(x + 3); кандидаты −3 и 9.

    Ответ: 9

  10. 10
    1/(x − 3) + 10/(x² + 3x + 9) = 27/(x³ − 27)
    Показать подсказку и ответ

    x ≠ 3; x³ − 27 = (x − 3)(x² + 3x + 9); кандидаты −16 и 3.

    Ответ: −16

Перед завершением проверьте:
  • Повторяющийся элемент действительно упрощает уравнение.
  • Для t записаны ограничения t ≥ 0 или t > 0.
  • При обратной замене не потерян второй знак.
  • Знаменатели не обращаются в нуль, а подкоренные выражения неотрицательны.
  • Недопустимые кандидаты исключены.
