Алгебра · координатная лаборатория

Построение графиков линейных функций

Как получить прямую из таблицы значений, выбрать удобные координаты и правильно провести график через две точки.

y=kx+b

Вы задаёте x, вычисляете y и получаете точку графика.

Главный маршрут: формула → таблица → две точки → прямая.

01 / Формула

Как устроена линейная функция

Коэффициент при x и свободный член.

Линейная функция задаётся формулой y=kx+b, где x — аргумент, y — значение функции, k и b — числа. Её график — прямая.

y=2x+3 — пример из занятия

Число k определяет наклон: при k > 0 прямая возрастает, при k < 0 убывает. Число b задаёт точку пересечения с вертикальной осью Oy: (0; b).

Главное. Слагаемые 2x и 3 имеют разную буквенную часть, поэтому складывать их как подобные нельзя.
02 / Точка

Читаем координаты без путаницы

Сначала горизонталь, затем вертикаль.

Точка A(x; y) задаётся двумя числами. Сначала смещаемся по оси Ox вправо или влево, затем по оси Oy вверх или вниз.

Координаты и направления из чек-листа
ТочкаСмещение по OxСмещение по Oy
A(0; 3)0на 3 вверх
B(2; −1)на 2 вправона 1 вниз
C(−3; 5)на 3 влевона 5 вверх
D(0; −2)0на 2 вниз
Проверьте порядок: точки (0; 1) и (1; 0) находятся на разных осях. Если x = 0, точка лежит на Oy.
03 / Метод

Две точки — одна прямая

Алгоритм построения на примере.

Построим график y=2x+3. Выберем удобные значения x = 0 и x = 2.

  1. Подставим x = 0: y = 2 · 0 + 3 = 3.
  2. Подставим x = 2: y = 2 · 2 + 3 = 7.
  3. Запишем пары координат A(0; 3) и B(2; 7).
  4. Отметим точки и проведём через них прямую с продолжением в обе стороны.

04 / Удобство

Выбираем такие x, чтобы считать легче

Десятичные коэффициенты.

Для y=−0,8x+1 выгодно выбрать x = 0 и x = 10. Тогда получаем:

y(0) = 1 · y(10) = −8 + 1 = −7

Обе точки A(0; 1) и B(10; −7) имеют целые координаты. При x = 2 получится y = −1,6 + 1 = −0,6: отрицательный знак нужно сохранить.

В графике y=0,2x−1 подойдут x = 0 и x = 5: получим (0; −1) и (5; 0). При дробных значениях можно также менять масштаб осей, сохраняя равномерный шаг на каждой оси.

Полезный выбор: десятичный коэффициент часто подсказывает взять x = 5 или x = 10.

05 / Исключение

Если x не виден: y = b

Горизонтальная прямая.

В выражении y=−2 переменную x можно мысленно восстановить: y=0x−2. Для любого x значение y одинаковое.

Примеры горизонтальных графиков
ФормулаПервая точкаВторая точка
y = −2(0; −2)(3; −2)
y = 3(0; 3)(5; 3)

В обоих случаях график параллелен оси Ox. Для y = 0 график совпадает с осью Ox.

06 / Самопроверка

Перед проведением прямой

Короткий контрольный маршрут.

  1. Прочитайте k и b в формуле.
  2. Если k = 0, проведите горизонталь на высоте b.
  3. Иначе выберите два разных удобных x и вычислите два y.
  4. Перенесите полученные точки на координатную плоскость.
  5. Продлите прямую за точки; проверьте знаки и масштаб.
Типичные ошибки: сложение непохожих слагаемых, потеря минуса, перестановка координат, ограничение графика отрезком. При одном x у функции только одно значение y.

Проверка знака

Чему равно y при x = 2 в формуле y=−0,8x+1?

07 / Путь А

10 заданий для тренировки

От базового уровня к повышенному.

Выполняйте построения в тетради. Сначала составьте таблицу для двух точек, затем отметьте их на плоскости и проведите прямую. Ответы открывайте после самостоятельной работы.

01 · Координаты Базовый

Из точек A(−3;0), B(0;−3), C(0;3) выберите ту, у которой x = 0, а y = −3. Укажите ось.

Ответ для сверки

B(0; −3), ось Oy.

02 · Подстановка Базовый

Для функции y=3x−2 вычислите y при x = 0 и x = 2; запишите координаты.

Ответ для сверки

(0; −2), (2; 4).

03 · Две точки Базовый

Постройте y=−2x+1 при x = −1 и x = 2. Покажите обе пары в таблице.

Ответ для сверки

(−1; 3), (2; −3).

04 · Целые координаты Средний

Постройте y=0,5x+1, подобрав два x, при которых y будет целым.

Ответ для сверки

Например, (0; 1), (4; 3).

05 · Пересечение с Ox Средний

Постройте y=−0,4x+2 при x = 0 и x = 5. Укажите точку пересечения с Ox.

Ответ для сверки

(0; 2), (5; 0). Пересечение с Ox: (5; 0).

06 · Десятичные дроби Средний

Для y=−0,3x+1 найдите y при x = 0, x = 10 и x = 2. Для графика выберите две точки с целыми координатами.

Ответ для сверки

y(0) = 1, y(10) = −2, y(2) = 0,4. Точки (0; 1), (10; −2).

07 · Горизонтальные прямые Средний

Постройте y=−4 и y=2. Объясните их параллельность Ox.

Ответ для сверки

Горизонтали через (0; −4) и (0; 2), поскольку k = 0.

08 · Через начало координат Повышенный

Какие графики проходят через начало: y=−3x, y=2x+5, y=0, y=−4?

Ответ для сверки

y = −3x и y = 0: в обоих случаях b = 0.

09 · Принадлежность точки Повышенный

Для y=−0,6x+4 проверьте A(0;4), B(5;1), C(10;−1). Постройте прямую по подходящим точкам.

Ответ для сверки

A и B принадлежат. C — нет: y(10) = −2.

10 · Две прямые Повышенный

На одной плоскости постройте y=0,25x−2 и y=−3. Укажите пересечения с Oy и горизонтальную прямую.

Ответ для сверки

Первая: (0; −2), (8; 0); вторая: (0; −3), (4; −3). Горизонтальна y = −3.
