Когда прямые параллельны?

Учимся читать коэффициент k, находить прямые с одинаковым наклоном, работать с осями координат и определять коэффициент по заданной точке.

01 / ЯЗЫК ФОРМУЛЫ

Сначала различите коэффициенты k и b.

За что отвечают k и b?

График функции y = kx + b — прямая. Число k отвечает за наклон, число b показывает точку пересечения с вертикальной осью Oy.

Угловой коэффициент

k > 0 / k < 0 / k = 0

Прямая поднимается / опускается / идёт горизонтально.

Свободный член

(0; b)

Пересечение с осью ординат происходит при x = 0.

Как увидеть «скрытый» коэффициент

В записи y = −x перед x стоит число −1, поэтому k = −1. В y = x + 2 коэффициент k = 1.

02 / ГЛАВНОЕ СВОЙСТВО

Для параллельности сравнивают именно угловые коэффициенты.

Параллельность и совпадение прямых

У прямых y = k₁x + b₁ и y = k₂x + b₂ одинаковый наклон тогда и только тогда, когда k₁ = k₂.

УсловиеРасположение
k₁ = k₂, b₁ ≠ b₂Прямые различны и параллельны.
k₁ = k₂, b₁ = b₂Прямые совпадают.
k₁ ≠ k₂Прямые пересекаются ровно в одной точке.

При каком k прямая y = kx + 4 параллельна y = −x?

Во второй формуле коэффициент равен −1. Следовательно, k = −1. Прямая y = −x + 4 параллельна y = −x: наклоны равны, свободные члены различны.

Проверьте параллельность на графике →

Особый случай. При k = 0 прямая горизонтальна, её формула y = b. Если b ≠ 0, она параллельна оси Ox; если b = 0, она совпадает с осью Ox.
03 / ОСИ

У каждой оси одна координата обязательно равна нулю.

Ось Ox, ось Oy и особые точки

Где точка?Что равно нулю?Как записать?
На оси абсцисс Oxy = 0(x; 0)
На оси ординат Oyx = 0(0; y)
Пример · пересечение с Ox

Для прямой y = 0,4x − 12 возьмём y = 0:

0 = 0,4x − 12

0,4x = 12 → x = 30

Ответ: (30; 0). Точка записана двумя координатами.

Прямая y = kx + 4 не пересекает Ox только при k = 0, потому что тогда y = 4.

04 / ПОДСТАНОВКА

Заданная точка превращает формулу в уравнение относительно k.

Находим k по координатам точки

Если прямая y = kx + b проходит через T(x₀; y₀), то её координаты удовлетворяют равенству y₀ = kx₀ + b.

  1. Прочитайте координаты: первое число — x, второе — y.
  2. Подставьте оба числа в формулу.
  3. Решите полученное уравнение относительно k.
  4. Подставьте найденный k обратно и проверьте координаты.
Пример · прямая через точку T(3; 0)

Дана y = kx + 4. Подставляем x = 3, y = 0:

0 = 3k + 4 → 3k = −4 → k = −4/3

Проверка: при x = 3 получаем −4/3 · 3 + 4 = 0.

На что обратить внимание. При x₀ = 0 подстановка даёт y₀ = b. Если равенство верно, точка подходит при любом k; если нет — ни при каком.
05 / ДВА ШАГА

Сначала найдите общую точку известных графиков. Потом — искомый k.

Прямая через пересечение двух графиков

Нужно подобрать k так, чтобы y = kx + 4 проходила через точку пересечения y = 12 − x и y = x + 4.

  1. Приравняем правые части: 12 − x = x + 4.
  2. Получим 8 = 2x, откуда x = 4.
  3. Найдём ординату: y = 4 + 4 = 8. Значит, точка T(4; 8).
  4. Подставим её в искомую формулу: 8 = 4k + 4.
  5. Найдём k = 1 и проверим подстановкой.
Итог

Искомая прямая: y = x + 4. Она проходит через T(4; 8). Совпадение с одной из исходных прямых допустимо.

06 / ТОЧНОСТЬ

Ошибки часто появляются из-за знаков и неверного чтения координат.

Частые ошибки

  • В формуле y = −x коэффициент k равен −1, даже если единица не написана.
  • При проверке параллельности важно k; одинаковые b сами по себе ничего не говорят о параллельности.
  • На оси Ox всегда y = 0; на Oy всегда x = 0.
  • В записи (3; 0) первое число относится к x, второе — к y.
  • При перестановке целиком левой и правой частей равенства знаки сохраняются; при переносе отдельного слагаемого знак меняется.
  • В ответе на вопрос о точке нужны две координаты, в ответе о коэффициенте — значение k.
