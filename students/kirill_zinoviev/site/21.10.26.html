01 / Язык задачи

Чья зависимость?

Первый шаг — правильно прочитать условие.

Фраза «зависимость A от B» означает: мы выбираем B и по её значению рассчитываем A. В формуле выражаем A через B.

A(B) = правило вычисления по B
Слева — зависимая величина; в скобках — независимая.
ТребованиеФормула
Зависимость пути от времениs(t) = 80t
Зависимость времени от путиt(s) = s / 12
Зависимость массы от объёмаm(V) = 0,18V

Не путайте! Запись s(t) читается «путь как функция времени». Буква s не обязана стоять слева во всех задачах: всё зависит от требования.

02 / Движение

Путь, скорость, время

Одна формула — несколько зависимостей.

При равномерном движении s = vt. Здесь s — путь, v — постоянная скорость, t — время.

Скорость известна

При 80 км/ч:

s(t) = 80t

За 2 ч автомобиль проедет 160 км.

Время известно

При 6 ч:

s(v) = 6v

При v = 65 км/ч путь 390 км.

Если за 6 часов пройдено 363 км, составляем уравнение 6v = 363, откуда v = 60,5 км/ч.

Если требуется время как функция пути при скорости 12 км/ч, выражаем его:

t(s) = s / 12, при s ≥ 0.

Ограничение. В этих задачах время, путь и скорость выбирают неотрицательными; отрицательное время не соответствует условию движения после начала отсчёта.

03 / Физическая зависимость

Масса и объём

Тот же принцип работает с другими величинами.

Масса однородного куска материала равна плотности, умноженной на объём: m = ρV.

Плотность пробки 0,18 г/см³.
m(V) = 0,18V, где V ≥ 0.
Известен объём

V = 240 см³

m = 0,18 · 240 = 43,2 г

Известна масса

m = 64,8 г

0,18V = 64,8

V = 360 см³

Следите, какая величина дана, а какую требуется вычислить. Сначала подставляем известное, затем решаем полученное уравнение.

04 / Таблица

Выбрать и вычислить

Независимую переменную задаём сами; значения результата считаем по формуле.

Для автомобиля со скоростью 80 км/ч:

t, ч0123
s, км080160240

Другой пример: y = x(x − 3), если −2 ≤ x ≤ 2. При x = −1,5 необходимо подставить число в оба вхождения x:

y(−1,5) = (−1,5)(−1,5 − 3) = 6,75.

05 / Координаты

От таблицы к графику

Каждая пара чисел становится точкой на плоскости.

  1. Начертите и подпишите оси: по горизонтали — независимая величина x (или t), по вертикали — зависимая y (или s).
  2. Выберите удобный масштаб для каждой оси.
  3. Нанесите точки: сначала двигайтесь по x, затем по y.
  4. Соедините точки согласно формуле и указанному промежутку.

Для движения при t ≥ 0 график — луч. Для функции y = x(x − 3) на отрезке [−2; 2] — часть плавной параболы.

Пример точки: (−1; 4) — сначала на 1 единицу влево по x, затем на 4 единицы вверх по y.

06 / Закрепление

Путь А · 10 заданий

Выполняйте в тетради. Ответы скрыты до раскрытия; сначала запишите своё решение.

  1. Автомобиль едет со скоростью 20 км/ч. Запишите зависимость пути от времени и назовите независимую величину.

    Проверить ответ

    s(t) = 20t, t ≥ 0; независимая величина — t.

  2. Для движения со скоростью 80 км/ч заполните таблицу s(t) при t = 0; 0,5; 2; 3 ч.

    Проверить ответ

    s = 0; 40; 160; 240 км.

  3. Автобус движется 6 ч. Запишите s(v). Найдите путь при v = 58 км/ч и скорость при s = 420 км.

    Проверить ответ

    s(v) = 6v; 348 км; 70 км/ч.

  4. Плотность пробки 0,18 г/см³. Запишите m(V), найдите массу при V = 150 см³ и объём при m = 45 г.

    Проверить ответ

    m(V) = 0,18V; 27 г; 250 см³.

  5. Велосипедист едет 12 км/ч. Запишите t(s) и найдите время для пути 90 км.

    Проверить ответ

    t(s) = s / 12; 7,5 ч.

  6. Для s(t) = 12t, 0 ≤ t ≤ 3, составьте таблицу при t = 0; 1; 2; 3, постройте график и найдите время для 30 км.

    Проверить ответ

    s = 0; 12; 24; 36 км; график — отрезок; t = 2,5 ч.

  7. Для y = x(x − 3) при x от −2 до 2 найдите y при x = −2; −1; 0; 1; 2. Лежит ли на графике (−1;4)?

    Проверить ответ

    y = 10; 4; 0; −2; −2. Да.

  8. Для той же функции найдите y при x = −1,5; −0,5; 0,5; 1,5. Покажите полную подстановку одного значения.

    Проверить ответ

    6,75; 1,75; −1,25; −2,25.

  9. По таблицам заданий 7–8 постройте график. Какая из нанесённых точек расположена ниже остальных?

    Проверить ответ

    (1,5; −2,25). Строим только часть параболы при −2 ≤ x ≤ 2.

  10. Почему s = 12t — неверная запись ответа на требование выразить время от пути? Запишите нужную формулу и вычислите t при s = 48 км.

    Проверить ответ

    Нужна зависимость t от s: t(s) = s / 12; t = 4 ч.
