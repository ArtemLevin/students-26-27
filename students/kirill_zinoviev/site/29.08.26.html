НОД
Только общие простые множители; для каждого берётся меньшая степень.
НОК
Все простые множители из разложений; для каждого берётся большая степень.

Проверка на исходных числах

Проверка: 360 : 72 = 5, 504 : 72 = 7; 2520 : 360 = 7, 2520 : 504 = 5.

Типичная ошибка. Фраза «берём уникальные множители» недостаточно точна. Сравнивайте степени каждого простого множителя.

Знаки

Сначала уберите двойные знаки

−(−1,8)=+1,8

Если перед скобками стоит минус, знак каждого слагаемого внутри меняется на противоположный.

a−(b−c)=a−b+c

Числа разных знаков

Из большего модуля вычтите меньший и сохраните знак числа с большим модулем.

−5,2+1,8=−3,4

Модуль — расстояние до нуля

Расстояние всегда неотрицательно: |a|≥0.

xC=xA+xB2

Типичная ошибка. При подстановке отрицательной координаты сохраняйте скобки: 2,5 − (−4,5).
