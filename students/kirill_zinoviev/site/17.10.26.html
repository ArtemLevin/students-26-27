01 / понятия

Аргумент и значение

Здесь важно различать два числа: то, которое подставляют в формулу, и результат вычисления.

Функция y = 12/x. Буква x обозначает аргумент, а y — соответствующее значение функции.

y(−6) = 12−6 = −2

Запись y(−6) означает: вместо x подставляем −6. В примере −6 — аргумент, −2 — значение функции.

02 / внимательность

Скобки меняют результат

Самое важное место при подстановке отрицательных аргументов в выражения со степенью.

Для y = x² − 9 при x = −4 подставляем число целиком и вычисляем:

y(−4) = (−4)² − 9 = 16 − 9 = 7
Число в скобках

(−4)² = 16

В квадрат возводим всё отрицательное число.

Без скобок

−4² = −16

В квадрат возводим 4, а затем ставим минус.

Важное правило. Отрицательный аргумент при подстановке в степень обязательно заключайте в скобки.

03 / таблица

От шага — к значениям

Шаг задаёт, как изменяется аргумент. Значение функции каждый раз вычисляется по формуле.

Дана функция y = x(x − 3,5). Аргумент изменяется от 0 до 4 с шагом 0,5. Запишем аргументы:

0; 0,5; 1; 1,5; 2; 2,5; 3; 3,5; 4

Теперь последовательно подставляем каждое значение x. Например: y(0,5) = 0,5(0,5 − 3,5) = −1,5.

Сравните. Шаг аргумента одинаков: 0,5. Значения функции меняются по-разному.

04 / ограничение

Какие x допустимы?

Область определения — это множество значений аргумента, при которых формулу можно вычислить.

В изученных формулах важна проверка знаменателя: делить на нуль нельзя. Запись x ∈ ℝ означает, что подходит любое действительное число.

Без ограничения

y = x + 5

y = (4x − 1)/5

Для обеих функций: x ∈ ℝ.

Число нужно исключить

y = 1/(x − 7)

x − 7 = 0 → x = 7. Поэтому x ≠ 7.

Алгоритм проверки

  1. Проверьте, есть ли выражение с x в знаменателе.
  2. Если есть, приравняйте знаменатель к нулю и решите полученное уравнение.
  3. Исключите найденные числа. Если ограничений нет, запишите x ∈ ℝ.

Для y = 2/(x + 3) исключаем x = −3, потому что x + 3 = 0.

Граница правила. Эти шаги предназначены для рассмотренных на занятии видов формул.

    Посмотреть ответ

    а) x ≠ 7; б) x ≠ −3; в) x ∈ ℝ.
