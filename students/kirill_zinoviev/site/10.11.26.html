01 / Основа

Два числа описывают положение точки на плоскости.

Абсцисса и ордината

Координаты точки записываются в порядке (x; y). Горизонтальная координата x называется абсциссой, вертикальная координата y — ординатой.

A(2;5)

У точки A(2; 5) абсцисса равна 2, ордината равна 5. Сначала смотрим на x, затем на y.

Проверьте порядок: если поменять координаты местами, получится другая точка.
02 / Повторение

Два разных значения x дают две точки прямой.

Строим график по двум точкам

График линейной функции y = kx + b — прямая. Выберите два различных x, вычислите y, отметьте точки на плоскости и проведите через них прямую.

Пример: y = 2x + 5

y=2x+5

При x = 0 получаем y = 2 · 0 + 5 = 5. При x = 1 получаем y = 2 · 1 + 5 = 7.

03 / Главный метод

Приравниваем формулы, затем находим обе координаты.

Точка пересечения: точный расчёт

Точка пересечения лежит на обеих прямых. Для одной и той же абсциссы значения функций совпадают.

y1=y2

Пример: y₁ = 2x + 5 и y₂ = −x + 7

Выполните четыре перехода. Кнопки позволяют рассматривать решение по шагам.

  1. 1. Приравниваем правые части.
    2x+5=−x+7
  2. 2. Собираем неизвестные слева, числа справа.
    3x=2

    Абсцисса равна 2/3.

  3. 3. Подставляем найденный x.
    y=−23+7=193

    Получилась положительная ордината 19/3.

  4. 4. Проверяем значение по первой формуле.
    2·23+5=193

    Ответ: T(2/3; 19/3).

Шаг 1 из 4
Показать всё решение текстом

2x + 5 = −x + 7; переносим слагаемые: 3x = 2, значит x = 2/3. Подставляем: y = −2/3 + 7 = 19/3. Проверяем в первой формуле: 2 · 2/3 + 5 = 19/3. Получаем T(2/3; 19/3).

Особенно важно: требуется лишь абсцисса — найдите x. Требуются координаты точки — найдите x и затем y.

Второй пример

Прямые y₁ = x + 1 и y₂ = −x + 2 пересекаются в точке T(0,5; 1,5), поскольку x + 1 = −x + 2, затем 2x = 1.

04 / Проверка

По координатам можно установить принадлежность без построения.

Лежит ли точка на графике?

Пусть точка A(x₀; y₀) и функция y = f(x) заданы. Подставьте x₀ в формулу. Если полученное число совпало с y₀, точка принадлежит графику.

f(x0)=y0
На графике

J(100; 101)

Для y = x + 1 при x = 100 получаем 101. Значения совпадают.

Точка J принадлежит графику.

Вне графика

Q(100; 99)

Формула даёт 101, а координата точки равна 99. Значения различаются.

Точка Q не принадлежит графику.

Ещё один пример из пособия: для y = 2x − 3 точка A(0; −3) лежит на прямой, а точка B(1; 5) находится вне неё.

Самопроверка: лежит ли A(0; 4) на графике y = 3x + 4?

05 / Памятка

Что особенно важно проверить перед сдачей решения.

Частые ошибки

  • Переставили координаты. Записывайте (x; y) именно в этом порядке.
  • Начали строить вместо вычисления. Для точного пересечения проще приравнять формулы.
  • Потеряли знак. Из 2x + 5 = −x + 7 получается 3x = 2.
  • Остановились после нахождения x. Для координат точки требуется и ордината.
  • Потеряли положительный результат. 7 − 2/3 = 19/3.
  • При проверке точки сравнили не те числа. Сравнивайте именно f(x₀) и y₀.

03Базовый

Проверьте, принадлежит ли точка A(0; 4) графику y = 3x + 4.

Показать ответ и сверить

Да: 3 · 0 + 4 = 4.

Проверьте, принадлежит ли точка B(2; 1) графику y = −x + 3.

Показать ответ и сверить

Принадлежат A и B; C не принадлежит: при x = 2 значение y = 1.
