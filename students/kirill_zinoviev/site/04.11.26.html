Прямая пропорциональность

Как по одной формуле получить таблицу значений, найти точки и построить прямую, которая продолжается в обе стороны.

y = kx

Вы выбираете x. Значение y вычисляете подстановкой.

01 / Закон

Что означает запись y = kx

Две величины связаны одним множителем.

Прямая пропорциональность задаётся формулой y = kx. Число k — коэффициент пропорциональности; x — выбранное значение, y — результат вычисления.

y = k · x

Например, для y = 3x при x = 1 получаем y = 3 · 1 = 3.

Главное. Значение x разрешается выбрать самостоятельно; для выбранного x значение y уже определяется формулой.
02 / Вычисление

Таблица значений

Начинаем построение с двух удобных чисел.

Для y = 3x возьмём x = 0 и x = 1. Подставим каждое значение в формулу.

Две пары координат для y = 3x
x01
y3 · 0 = 03 · 1 = 3

Получили пары (0; 0) и (1; 3). Значение x = 0 особенно удобно: для любой формулы y = kx получим y = 0.

Важная деталь: строки таблицы обозначаются x и y. Даже если формула выглядит как y = −x, во второй строке пишем y.

03 / Геометрия

Переносим точки на плоскость

Первая координата — по горизонтали, вторая — по вертикали.

Точка B(2; −3): от начала координат вправо на 2 клетки по оси x, затем вниз на 3 клетки по оси y.

Для графика y = −1,5x удобные точки — A(0; 0) и B(2; −3).

График — вся прямая. Две точки определяют направление, однако рисовать только отрезок между ними недостаточно.
04 / Коэффициент

Куда направлена прямая

Знак коэффициента меняет наклон.

При положительном k график поднимается вправо. При отрицательном k — опускается вправо. Прямая y = kx проходит через начало координат.

y = −x. Если x = 3, то y = −3. Если x = −2, то y = −(−2) = 2.

y = 2,5x. При x = 2 получаем y = 5.

Чем больше модуль коэффициента |k|, тем круче расположена прямая относительно оси x.

05 / Маршрут

Семь шагов построения

Сначала таблица, затем прямая.

  1. Запишите формулу y = kx.
  2. Начертите таблицу с двумя строками: x и y.
  3. Выберите два разных удобных значения x; одно можно взять равным нулю.
  4. Вычислите соответствующие значения y.
  5. Отметьте две точки (x; y) на координатной плоскости.
  6. Проведите через точки прямую.
  7. Продлите её за обе точки в обе стороны.
Проверьте себя: оба значения x различны, знаки вычислены верно, прямая проходит через O(0; 0) и продолжается за отмеченные точки.

09 · Исправление Выше среднего

Для y = −3x отмечены A(0; 0) и B(2; −6). Через них провели только отрезок AB. В чём ошибка? Найдите y при x = −3.

Показать ответ

Нужно продолжить прямую за обе точки. При x = −3 получаем y = 9.

10 · Сравнение Выше среднего

На одной плоскости постройте y = 2x и y = −2x, используя x = −2, 0, 2. Запишите точки и сравните направление прямых вправо.

Показать ответ

y = 2x: (−2; −4), (0; 0), (2; 4) — вверх вправо. y = −2x: (−2; 4), (0; 0), (2; −4) — вниз вправо.
