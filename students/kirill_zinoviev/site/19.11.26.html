01 / ГЕОМЕТРИЯ

Точное обозначение определяет, какой угол мы рассматриваем.

Три буквы вместо одной

В записи ∠ADB вершина — D, стороны угла — лучи DA и DB. В записи ∠ADC вершина тоже D, но стороны — DA и DC. Это разные углы; буква вершины стоит посередине.

Смежные углы

Имеют общую сторону, а две другие стороны образуют прямую. Сумма равна 180°.

α + β = 180°
Вертикальные углы

Возникают при пересечении двух прямых. Всегда равны.

∠AOB = ∠COD

Если ∠AOC = 100°, то смежный с ним ∠AOB = 180° − 100° = 80°. Вертикальный ∠COD тоже равен 80°.

Проверка записи. Общая буква вершины ещё не означает равенство углов. Всегда проверяйте обе стороны угла.
02 / ТРЕУГОЛЬНИК

Свойство углов при основании позволяет найти два неизвестных угла одним вычислением.

Почему делим на два?

Если AB = BC, то треугольник ABC равнобедренный, его основание — AC, и ∠BAC = ∠BCA. Сумма углов любого треугольника равна 180°.

∠A = ∠C = (180° − 42°) / 2 = 69°

Сначала вычитаем угол при вершине, затем делим оставшуюся сумму на два, потому что углы при основании равны.

03 / ДОКАЗАТЕЛЬСТВО

Во втором признаке важен порядок соответствия сторон и прилежащих углов.

Сторона и два прилежащих угла

Если сторона одного треугольника и два прилежащих к ней угла равны соответственно стороне и двум прилежащим углам другого, треугольники равны.

Разбор. BO = DO, ∠ABC = 45°, ∠BCD = 55°, ∠AOC = 100°. Требуется найти ∠CDO и доказать равенство треугольников ABO и CDO. Точки B, O, C лежат на одной прямой; A, O, D — на другой.

Доказательство по шагам

0 / 4

Открывайте каждый шаг последовательно и называйте используемое свойство.

  1. ∠AOB = 180° − 100° = 80°: смежные углы.
  2. ∠COD = 80°: вертикальные углы равны.
  3. ∠CDO = 180° − 80° − 55° = 45°: сумма углов треугольника CDO.
  4. BO = DO; ∠ABO = ∠CDO = 45°; ∠AOB = ∠COD = 80°. Значит, △ABO ≅ △CDO по второму признаку.
Точность. Второй признак использует два угла, прилежащих именно к выбранной стороне. Перед доказательством проверьте соответствие вершин.

Прямоугольные треугольники

Если ∠ABD = 90°, ∠ADB = 40°, то ∠BAD = 50°. В другом прямоугольном треугольнике ACD с общей стороной AD также нужно найти два угла, прилежащих к AD, и затем сравнить их попарно.

04 / АЛГЕБРА

У любой точки на оси одна координата равна нулю.

Пересечение графика с осями

Для линейной функции y = kx + b график представляет собой прямую. Чтобы найти её пересечение с осями, строить график необязательно.

Ось Ox

При пересечении с горизонтальной осью y = 0. Найдите x; ответ имеет вид (x; 0).

Ось Oy

При пересечении с вертикальной осью x = 0. Найдите y; ответ имеет вид (0; y).

Пример из занятия: y = −2,4x + 9,6

Ox: 0 = −2,4x + 9,6 → x = 4 → (4; 0)
Oy: y = −2,4 · 0 + 9,6 = 9,6 → (0; 9,6)

05 / ПОДСТАНОВКА

Чтобы проверить точку, достаточно сравнить два значения y.

Лежит ли точка на графике?

Точка M(x₀; y₀) принадлежит прямой y = kx + b тогда и только тогда, когда выполняется равенство:

y₀ = kx₀ + b

Для функции y = 1,2x − 7 проверим точку M(100; 113):

1,2 · 100 − 7 = 120 − 7 = 113

Расчётное значение совпало с заданной второй координатой. Значит, точка M лежит на графике.

Не путайте формулировки. Для пересечения графика с Ox подставляем y = 0; для пересечения двух разных графиков приравниваем выражения для y. Это разные действия.

Проверить принадлежность точки с пояснением каждого действия.
