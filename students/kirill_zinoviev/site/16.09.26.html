Быстрое повторение: как читать x(t), определять направление движения и находить скорость.

Главная идея

Каждая точка графика отвечает на вопрос «где тело сейчас?»

Горизонтальная ось
Время t.
Вертикальная ось
Координата x.
Точка графика
Пара значений (t; x).
Пересечение с осью t
x = 0: тело проходит через начало координат.

Сначала отметьте опорные точки Ищите начало движения, пересечения с x = 0, точки излома и конец рассматриваемого участка.

Читайте историю движения слева направо. На участке AC координата уменьшается. После точки C координата увеличивается, поэтому в C тело меняет направление движения.

Ключевая формула

Скорость — изменение координаты за изменение времени

v=ΔxΔt=x2−x1t2−t1

Единицы скорости — м/с. Для скорости на конкретном прямолинейном участке берите две точки именно этого участка.

Алгоритм нахождения скорости

Выберите один прямолинейный участок.
Так скорость на нём определяется одним наклоном.
Возьмите две удобные точки.
Удобнее использовать точки с хорошо читаемыми координатами.
Найдите Δx и Δt.
По вертикали — изменение координаты; по горизонтали — изменение времени.
Разделите Δx на Δt.
Это «вертикаль на горизонталь».
Проверьте знак.
Рост x даёт положительную скорость, уменьшение x — отрицательную.
Потренировать «вертикаль на горизонталь» →

Пример из занятия

Для точек A(1; 4) и C(5; −2):

v=−2−45−1=−64=−1.5мс

Минус согласуется с графиком: координата на участке уменьшается.

Типичные ошибки

x = 0 ⇒ v = 0
Ошибка: x = 0 сообщает положение тела. Скорость может быть ненулевой.
Δt / Δx
Ошибка порядка. Скорость вычисляют как Δx / Δt.
Точки с разных участков
Для скорости одного участка выбирайте обе точки на этом участке.
Потерян знак скорости
Сначала установите, растёт координата или уменьшается.
Мини-памятка: сначала анализируйте изменение x, затем вычисляйте v.

Тренировочный блок

Три задания из пособия. Решите самостоятельно, затем раскройте ответ для проверки.

1. График: (0; 4) → (4; −2) → (6; 2)

  1. Какова координата тела при t = 0?
  2. На каком первом участке координата уменьшается?
  3. В какой момент тело изменяет направление?
  4. Какова скорость от t = 4 с до t = 6 с?
4 м; от 0 до 4 с; разворот при t = 4 с; v = 2 м/с.

2. A(1; 5), B(3; 1), C(5; −3), D(8; 3)

A, B, C лежат на одной прямой; C, D — на другой.

  1. Найдите скорость на AC.
  2. Найдите скорость на CD.
  3. Где тело изменило направление?
  4. Между какими точками тело прошло через начало координат?
vAC = −2 м/с; vCD = 2 м/с; разворот в C; начало координат проходится на BC и CD.

3. A(0; −3), B(2; 1), C(5; 1), D(7; −3)

  1. Найдите скорости на AB, BC и CD.
  2. На каком участке тело покоилось?
  3. В какие моменты тело проходило через начало координат?
  4. Сравните модули скоростей на движущихся участках.
vAB = 2 м/с; vBC = 0; vCD = −2 м/с; покой на BC; x = 0 при t = 1,5 с и t = 5,5 с; модули скоростей AB и CD равны.
