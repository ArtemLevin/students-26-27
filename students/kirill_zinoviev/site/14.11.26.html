01 / ОСНОВА

Одна формула описывает целое семейство прямых.

Линейная функция и её аргумент

Линейная функция записывается как y = kx + b. Переменная x — аргумент, y — значение функции. Число k называют угловым коэффициентом, число b — свободным коэффициентом.

y = kx + b

График всегда является прямой. При k = 0 функция постоянна и график горизонтален.

02 / ПОДСТАНОВКА

Сначала решаем прямую задачу: известно x, ищем y.

Значение функции по известному x

Подставьте число в формулу вместо x. При отрицательном аргументе ставьте скобки: они помогают сохранить знак.

Пример. y = −3x + 1,5 при x = −1,5.

y(−1,5) = −3 · (−1,5) + 1,5 = 6

Для той же функции: y(2,5) = −6, y(4) = −10,5.

Контроль знака: −7,5 + 1,5 = −6. При работе с отрицательными числами вычислите произведение и сумму отдельно.
03 / ОБРАТНАЯ ЗАДАЧА

Известно значение y; ищем аргумент x.

Как восстановить x по значению функции

Указанное значение y подставьте в левую часть формулы, затем решите уравнение относительно x.

Пример. y = −3x + 1,5; известно y = −4,5.

−4,5 = −3x + 1,5
−6 = −3x   ⇒   x = 2

Проверка: −3 · 2 + 1,5 = −4,5.

04 / ПОСТРОЕНИЕ

Для прямой достаточно двух различных точек.

График по двум точкам

  1. Выберите два различных значения x, например 0 и 1.
  2. Найдите y для каждого x и заполните таблицу.
  3. Отметьте точки на плоскости в порядке (x; y).
  4. Проведите через точки прямую и продолжите её в обе стороны.

Пример: y = −2x + 1

05 / КОЭФФИЦИЕНТ k

При чтении графика двигайтесь слева направо.

Почему прямая возрастает или убывает

k > 0

Линейная функция возрастает. Прямая идёт снизу вверх.

k < 0

Линейная функция убывает. Прямая идёт сверху вниз.

k = 0

Функция постоянна; линия горизонтальна.

Наклон

Чем больше абсолютная величина k, тем круче прямая.

У функций y = 2x + 1 и y = −2x + 1 направления противоположны, а точка пересечения с осью Oy общая.

06 / КОЭФФИЦИЕНТ b

Свободный член виден прямо на вертикальной оси.

Где прямая пересекает Oy

В формуле y = kx + b поставьте x = 0. Получится y = b. Поэтому прямая всегда пересекает ось Oy в точке (0; b).

b > 0

Пересечение с Oy выше начала координат.

b < 0

Пересечение с Oy ниже начала координат.

b = 0

Прямая проходит через начало координат.

07 / ЭСКИЗ

Можно набросать график по двум признакам.

Четыре сочетания знаков

Сначала посмотрите на знак k: он определит направление прямой. Затем на знак b: он определит, где линия пересечёт Oy.

k > 0; b > 0

Возрастает; Oy выше 0.

k > 0; b < 0

Возрастает; Oy ниже 0.

k < 0; b > 0

Убывает; Oy выше 0.

k < 0; b < 0

Убывает; Oy ниже 0.

В эскизе важны правильный знак наклона и положение пересечения с Oy. Для точного построения используйте две вычисленные точки.

08 / ДВЕ ПРЯМЫЕ

В общей точке совпадают обе координаты.

Как найти точку пересечения

  1. Приравняйте правые части двух формул.
  2. Решите уравнение и найдите x — абсциссу.
  3. Подставьте x в первую формулу, получите y.
  4. Проверьте этот же x во второй формуле: значение y должно совпасть.
  5. Запишите ответ в виде точки (x; y).

Пример. y₁ = 4x + 1, y₂ = −2x + 4.

4x + 1 = −2x + 4
6x = 3   ⇒   x = 0,5

y₁ = 4 · 0,5 + 1 = 3; y₂ = −2 · 0,5 + 4 = 3.

Ответ: (0,5; 3).

Другой пример: 3x − 4 = −2x + 5. Получается x = 1,8, y = 1,4; общая точка — (1,8; 1,4).

Если k₁ ≠ k₂, общая точка одна. При одинаковых k и разных b прямые параллельны. При равных k и b прямые совпадают.

09 / КОНТРОЛЬ

Короткий аудит решения до записи ответа.

Типичные ошибки

  • Подставляют отрицательное число без скобок.
  • Теряют минус при умножении и сложении.
  • Путают абсциссу x и ординату y.
  • Строят только отрезок между точками вместо всей прямой.
  • Путают значения k и b или знаки коэффициентов.
  • Находят x точки пересечения, но забывают вычислить y.
  • Не проверяют найденные координаты подстановкой в обе формулы.
