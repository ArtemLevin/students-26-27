01 / Сводка

Среднее арифметическое

Значение, которое учитывает каждое наблюдение.

Сложите все значения и разделите сумму на объём выборки N — количество чисел, включая повторы.

Среднее = сумма значенийчисло наблюдений

Для 6, 8, 10: (6 + 8 + 10) : 3 = 8.

Обратная задача

Среднее пяти чисел равно 9. Известны 4, 8, 10, 12. Сумма пяти чисел 45, сумма известных 34, поэтому неизвестное число равно 11.

Ключевая мысль. Среднее учитывает каждое наблюдение и чувствительно к необычно большим или маленьким значениям.
02 / Центр

Медиана

Сначала упорядочьте наблюдения.

Для нечётного количества чисел берут центральное значение. Для чётного — среднее двух центральных.

Ряд 1, 4, 7: медиана 4.
Ряд 1, 4, 6, 9: медиана (4 + 6) : 2 = 5.

Большое отдельное значение может сильно сдвинуть среднее, но почти не затронуть медиану. Медиана может отличаться от самого частого значения.

03 / Границы

Размах

Описывает расстояние между крайними значениями.

Размах = max − min

Для −4, 2, 6, x число x — наибольшее, размах 15. Поэтому x − (−4) = 15, значит x = 11. Проверка: 11 больше 6, размах действительно 15.

Среднее четырёх чисел 3, 4, 5, 6 равно 4,5, медиана тоже 4,5. После добавления 37 среднее равно 11, медиана — 5.
04 / Подсчёт

Абсолютная частота

Сколько раз встречается каждое значение.

Для ряда 2, 3, 2, 4, 3, 2, 4, 3 объём выборки N = 8. После упорядочивания получаем 2, 2, 2, 3, 3, 3, 4, 4.

Таблица распределения ряда
Значение xᵢ234
Абсолютная частота nᵢ332

Проверка: сумма частот 3 + 3 + 2 = 8 — точно объём выборки.

Величина i — номер различного значения в таблице, а N — количество всех наблюдений. Число разных значений здесь равно 3, количество наблюдений — 8.
05 / Доли

Относительная частота

Какая часть выборки приходится на значение.

ωᵢ = nᵢN   ·   pᵢ = nᵢN · 100%

Чтобы перевести долю в проценты, умножьте её на 100. Например, 3/8 = 0,375 = 37,5%.

Та же выборка, дополненная долями
Значение234
Абсолютная частота332
Относительная, дробь3/83/82/8
Относительная, %37,5%37,5%25%

Сумма абсолютных частот 8; относительных долей 1; процентов 100%.

Алгоритм таблицы частот

  1. Упорядочьте исходный ряд, посчитайте N.
  2. Выпишите каждое различное значение и его nᵢ.
  3. Для каждого значения вычислите nᵢ / N.
  4. Умножьте результат на 100% и проверьте две суммы.
Частая ошибка: 0,375 = 37,5%, а 3,75% — неверный перевод. Для знаменателя используйте все наблюдения.

06 / Путь А

10 заданий

От базовых расчётов к полной таблице распределения и нескольким характеристикам.

Сначала решите задачу самостоятельно. Ответ раскрывайте только после решения; для таблиц записывайте значения по возрастанию.

Задание 1 База

Вычислите среднее арифметическое чисел 7, 11, 12.

Показать ответ

10.

Задание 2 База

Найдите медиану и размах ряда 4, 2, 9, 2, 8, 6.

Показать ответ

Медиана 5; размах 7.

Задание 3 База

Среднее пяти чисел равно 8. Известны четыре числа: 4, 6, 8, 12. Найдите пятое число.

Показать ответ

10.

Задание 4 Практика

Числа 2, 5, 8, x, 13, 16 записаны по возрастанию. Их медиана равна 10. Найдите x.

Показать ответ

x = 12.

Задание 5 Практика

Дан ряд 3, 4, 5, 6. К нему добавили число 37. Вычислите среднее арифметическое и медиану до и после добавления. Какая характеристика изменилась сильнее?

Показать ответ

До: среднее 4,5 и медиана 4,5; после: среднее 11 и медиана 5. Сильнее изменилось среднее.

Задание 6 Практика

Составьте таблицу абсолютных частот для ряда 2, 4, 2, 3, 4, 2, 3, 3, 3, 4, 4, 4. Укажите объём выборки.

Показать ответ

N = 12; для 2 — 3, для 3 — 4, для 4 — 5.

Задание 7 Практика

Даны абсолютные частоты значений 1, 2, 3: соответственно 2, 3, 5. Найдите объём выборки и относительные частоты в процентах.

Показать ответ

N = 10; 20%, 30%, 50%.

Задание 8 Выше среднего

Для ряда 2, 3, 2, 4, 3, 2, 4, 3 составьте полную таблицу: значение, абсолютная частота, относительная частота (дробь и проценты). Проверьте обе суммы.

Показать ответ

N = 8; 2: 3, 3/8, 37,5%; 3: 3, 3/8, 37,5%; 4: 2, 2/8, 25%. Суммы 8 и 100%.

Задание 9 Выше среднего

Объём выборки 20. Значение 1 встретилось 6 раз, значение 3 — 5 раз, значение 2 составляет 20% выборки. Все остальные наблюдения равны 4. Найдите абсолютные и относительные частоты четырёх значений.

Показать ответ

Для значений 1, 2, 3, 4: частоты 6, 4, 5, 5; проценты 30%, 20%, 25%, 25%.

Задание 10 Выше среднего

Значение 2 встретилось 2 раза, значение 4 — 3 раза, значение 8 — 5 раз. Найдите объём выборки, относительные частоты, среднее арифметическое, медиану и размах.

Показать ответ

N = 10; проценты 20%, 30%, 50%; среднее 5,6; медиана 6; размах 6.
