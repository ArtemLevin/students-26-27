02 · Два уравнения

Система — это одна задача, записанная двумя связями

Одно уравнение обычно описывает целое, второе связывает неизвестные между собой. Если часть условия потеряна, модель неполна.

Контрольный вопрос

«Все ли части, о которых говорится в условии, я учёл?» Для трассы в сумму обязательно входит наземный участок 703 м.

03 · Главная идея

Подстановка убирает одну неизвестную

Если известно, чему равен y, его можно заменить этим выражением в другом уравнении.

01
Система
x + y = 392
y = x − 36
02
Заменяем y
x + (x − 36) = 392
03
Решаем одно уравнение
2x − 36 = 392 → x = 214
04
Возвращаемся за y
y = 214 − 36 = 178
05
Проверяем
214 + 178 = 392
214 − 178 = 36
Что важно заметить

Подставляется выражение, равное переменной. После нахождения одной переменной решение ещё не закончено: нужно найти вторую.

05 · Опорные примеры

Два решения целиком

Сначала система, затем подстановка, затем возврат ко второй переменной.

Дома на двух улицах

Всего 19 домов. На Парковой на 3 дома меньше, чем на Молодёжной.

x + y = 19
y = x + 3
x + (x + 3) = 19 → 2x = 16 → x = 8; y = 11. Ответ: 8 и 11 домов.

Трасса и два тоннеля

Общая длина 6940 м, наземная часть 703 м, первый тоннель длиннее второго на 17 м.

x + y + 703 = 6940
x = y + 17
(y + 17) + y + 703 = 6940 → 2y = 6220 → y = 3110; x = 3127. Проверка: 3127 + 3110 + 703 = 6940.
