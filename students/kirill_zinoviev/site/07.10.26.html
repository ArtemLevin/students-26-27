01 · Корень уравнения

Подстановка — это проверка равенства

Корень — значение переменной, при котором левая и правая части становятся равны. Отрицательное подставляемое число записывайте в скобках.

Опорный пример
x² + 4x + 3 = 0
x = −3 → (−3)² + 4·(−3) + 3
9 − 12 + 3 = 0

Вывод: x = −3 — корень этого уравнения.

Замените переменную вездеОдна пропущенная буква ломает проверку.
Минус — вместе с числомx = −3 означает, что в степень и произведение подставляется (−3).
Сравните обе частиЧисло является корнем только при равенстве левой и правой частей.

Если произведение равно нулю

A·B = 0 → A = 0 или B = 0

(2x − 3,8)(4,2 + 3x) = 0 → x = 1,9 или x = −1,4

03 · Скобки и знаки

Минус перед скобкой меняет каждый знак внутри

Скобки особенно важны при подстановке отрицательного числа и при вычитании целого выражения.

Подстановка
x = −3 → (−3)²

Отрицательное число берите в скобки.

Минус перед скобкой
−(9 − x) = −9 + x

Знак меняется у каждого слагаемого.

Вычитаемое выражение
(25p + 1) − (p − 12)

Всё вычитаемое держите в одной паре скобок.

05 · Перевод текста

Сумма → плюс, разность → минус

Особенно внимательно записывайте выражение, которое вычитается: оно должно целиком оказаться в скобках.

Сумма выражений

«Сумма выражений 2x + 7 и −x + 12 равна 24»

(2x + 7) + (−x + 12) = 24

x = 5

Разность равна сумме

Для выражений 25p + 1 и p − 12:

(25p + 1) − (p − 12) = (25p + 1) + (p − 12)
