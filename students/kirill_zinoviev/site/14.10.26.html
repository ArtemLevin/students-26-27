01 / Включение границ

Лучи на числовой оси

Область слева от границы содержит меньшие числа, справа — большие.

Закрашенная точка показывает, что само число подходит. Выколотая — что граница исключена. Эта разница одновременно меняет знак неравенства и тип скобки.

Закрашенная точка · числа слева

x ≤ 5↔x ∈ (−∞; 5]

Закрашенная точка · числа справа

x ≥ 5↔x ∈ [5; +∞)

Выколотая точка · числа слева

x < 5↔x ∈ (−∞; 5)

Выколотая точка · числа справа

x > 5↔x ∈ (5; +∞)
[   ]Квадратные скобки

Конечная граница входит в промежуток: ≤ или ≥.

(   )Круглые скобки

Конечная граница исключена: < или >.

Бесконечность всегда записывают с круглой скобкой: она указывает направление без конечного числового края.

02 / Две границы

От одного числа до другого

Слева направо: сначала меньшая граница, затем большая. Каждая точка рассматривается отдельно.

Если подходящие числа лежат между двумя границами, используйте двойное неравенство. Закрашенность левой и правой точек может различаться.

1 ≤ x ≤ 5   x ∈ [1; 5]
Четыре варианта границ
НеравенствоПромежутокКрая
−2 ≤ x ≤ 2,5[−2; 2,5]Оба входят
−2 < x < 2,5(−2; 2,5)Оба исключены
4 ≤ x < 12[4; 12)Левый входит
4 < x ≤ 12(4; 12]Правый входит

В промежутке [4; 12) число 4 подходит, число 12 — нет, а 11,9 подходит. Между границами есть также дробные числа.

03 / Проверяем себя

Алгоритм записи

Последовательность действий, которая помогает избежать перепутанных скобок и знаков.

Пройдите шаги в правильном порядке. Изображение, неравенство и промежуток должны описывать одни и те же числа.

  1. Найдите выделенную область: влево, вправо или между границами.
  2. Запишите границы от меньшей к большей. При необходимости используйте −∞ и +∞.
  3. Проверьте каждую конечную точку: закрашена или выколота?
  4. Закрашенная точка — ≤, ≥ и квадратная скобка. Выколотая — <, > и круглая.
  5. Возле −∞ и +∞ всегда ставьте круглые скобки. Сверьте три записи.

Промежуток [−1; +∞) соответствует неравенству x ≥ −1. Число −1 входит, штриховка идёт вправо.

04 / Дополнение урока

Текстовая задача

Фраза «в три раза больше» превращается в равенство с множителем 3.

У Маши и Васи сначала было поровну денег. Маша потратила 6 рублей, Вася — 14 рублей. После этого у Маши осталось втрое больше денег. Сколько рублей было у каждого?

До покупокПосле покупок
Машаxx − 6
Васяxx − 14
x − 6 = 3 · (x − 14)

Большая сумма Маши равна трём меньшим суммам Васи. Множитель 3 должен находиться рядом с выражением для Васи.

  1. x − 6 = 3x − 42
  2. x − 3x = 6 − 42
  3. −2x = −36
  4. x = 18

Проверка. У Маши осталось 12 рублей, у Васи — 4 рубля, и 12 = 3 · 4. Ошибка — записать равенство оставшихся сумм без множителя.

05 / Путь А

Самостоятельная тренировка

10 задач от простых преобразований записи до составления уравнения. После решения откройте ответ и проверьте тип границ.

  1. Запишите промежуток для x ≥ −1, затем изобразите его на оси.

    Показать ответ

    x ∈ [−1; +∞). Точка −1 закрашена; луч вправо.

  2. Запишите промежуток для x < 5, затем изобразите его на оси.

    Показать ответ

    x ∈ (−∞; 5). Точка 5 выколота; луч влево.

  3. По записи x ∈ (−3; +∞) восстановите неравенство. Подходит ли −3?

    Показать ответ

    x > −3. Число −3 исключено.

  4. По записи x ∈ (−∞; 2] восстановите неравенство. Подходит ли 2?

    Показать ответ

    x ≤ 2. Число 2 включено.

  5. Перепишите −2 ≤ x ≤ 2,5 в виде промежутка и назовите включённые границы.

    Показать ответ

    x ∈ [−2; 2,5]. Обе границы включены.

  6. Перепишите 4 ≤ x < 12 в виде промежутка. Проверьте числа 4; 11,9; 12.

    Показать ответ

    x ∈ [4; 12). Подходят 4 и 11,9. Число 12 исключено.

  7. По записи x ∈ (4; 12] восстановите двойное неравенство. Назовите целое и дробное подходящие числа.

    Показать ответ

    4 < x ≤ 12. Например, 5 и 4,5.

  8. На оси от −3 (закрашено) до 1 (выколото) выделен отрезок. Запишите обе формы.

    Показать ответ

    −3 ≤ x < 1; x ∈ [−3; 1).

  9. Из чисел −1; −0,5; 0; 3; 3,1 выберите все принадлежащие (−1; 3].

    Показать ответ

    −0,5; 0; 3. Число −1 исключено, 3 включено.

  10. У Алины и Димы поровну денег. Алина потратила 8 рублей, Дима — 20. У Алины осталось втрое больше. Сколько было у каждого?

    Показать ответ

    26 рублей. x − 8 = 3(x − 20); проверка: 18 = 3 · 6.
