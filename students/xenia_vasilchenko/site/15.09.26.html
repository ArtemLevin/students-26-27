Плакат собирает правила по компонентам действий, дробям, среднему арифметическому и средней скорости.

Главная идея

От вычисления — к модели задачи

На занятии связаны четыре опорных навыка: аккуратные вычисления, понимание компонентов действий, составление уравнения и работа с единицами измерения.

1. Вычисления
Десятичные и обыкновенные дроби.
2. Среднее
Сумма всех чисел делится на их количество.
3. Уравнение
Неизвестное обозначаем буквой и используем связи между компонентами.
4. Движение
Весь путь делим на всё время.

Десятичные дроби

При сложении и вычитании записывайте запятую под запятой. Справа можно дописывать нули: 1,2 = 1,20.

Сложение
1,57 + 1,20 = 2,77
Вычитание
1,57 − 1,20 = 0,37

Умножение

Выполните умножение как для натуральных чисел.
Посчитайте все цифры после запятых в двух множителях.
Отделите столько же цифр справа в результате.
1,2 · 1,57 = 1,884

Связи между компонентами действий Сначала определите, какую роль играет неизвестное. После этого выбирайте обратное действие.

Сложение
a + b = c
a = c − b
b = c − a
Вычитание
a − b = c
a = b + c
b = a − c
Умножение
ab = c
b = c / a
Деление
a / b = c
a = bc
b = a / c
В знаменателе делитель не может быть равен нулю.

Составное выражение как один объект

В уравнении ниже весь числитель сначала рассматривается как делимое.

x−103=50
Найдите числитель.
x − 10 = 3 · 50 = 150.
Найдите x.
x = 150 + 10 = 160.

Перевод текста на математический язык

k больше t на 50
k = t + 50
k меньше t на 50
k = t − 50
k больше t в 50 раз
k = 50t
k меньше t в 50 раз
k = t / 50
Смысл слов: «на» ведёт к сложению или вычитанию; «в раз» — к умножению или делению.

Средняя скорость

Для участков 1,2 км за 6 мин, 5,3 км за 12 мин и 2,3 км за 15 мин:

Сложите весь путь.
1,2 + 5,3 + 2,3 = 8,8 км.
Сложите всё время.
6 + 12 + 15 = 33 мин.
Переведите минуты в часы.
33/60 = 11/20 ч.
Разделите весь путь на всё время.
8,8 : 11/20 = 16 км/ч.
Типичная ошибка: среднюю скорость нельзя получать как простое среднее скоростей отдельных участков.

5 заданий для закрепления

  1. Выполните действия: 3,47 + 2,8; 5,2 − 1,76; 2/3 − 1/4; сократите 18/24.
  2. Найдите среднее арифметическое: 6,8; 7,2; 5,9; 6,1; 7.
  3. Одно из двух чисел равно 7,4, а их среднее арифметическое равно 5,2. Найдите второе число.
  4. Среднее арифметическое двух чисел равно 84. Одно число больше другого на 18. Найдите оба числа.
  5. Велосипедист проехал 2,4 км за 8 мин, 3,6 км за 12 мин и 2 км за 10 мин. Найдите среднюю скорость в км/ч.
Ответы: 1) 6,27; 3,44; 5/12; 3/4. 2) 6,6. 3) 3. 4) 75 и 93. 5) 16 км/ч.

Типичные ошибки

Запятые выровнены по правому краю.
Проверка: при сложении и вычитании десятичных дробей ставьте запятую под запятой.
Дроби складываются без общего знаменателя.
Проверка: сначала получите одинаковые знаменатели.
При делении переворачивается первая дробь.
Проверка: обратной становится только вторая дробь.
Средняя скорость ищется как среднее отдельных скоростей.
Проверка: весь путь делится на всё время.
