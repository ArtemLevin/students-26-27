01 · Разминка

Дроби: три опоры для аккуратного счёта

Вычислительная часть занятия — это база для следующих тем. Здесь важнее всего видеть структуру действия и не терять запятую, знаменатель или обратную дробь.

Десятичные дроби
При сложении и вычитании выравнивайте числа по запятой. При умножении сначала считайте как с натуральными числами, затем восстановите число знаков после запятой.
Общий знаменатель
2/3 + 1/5 = 10/15 + 3/15 = 13/15
Смешанное число
2 2/3 = (2 · 3 + 2) / 3 = 8/3
Деление дробей
2/3 : 7/5 = 2/3 · 5/7 = 10/21
Контроль: сокращаются общие множители. Слагаемые суммы сокращать нельзя.
02 · НОД

Общие множители — в наименьших степенях

Наибольший общий делитель — самое большое натуральное число, на которое оба исходных числа делятся без остатка.

Шаг 1Разложите оба числа на простые множители.
Шаг 2Выделите только общие простые множители.
Шаг 3Берите общие множители в наименьших степенях.
Шаг 4Перемножьте их и проверьте делением.

84

84 = 2² · 3 · 7

112

112 = 2⁴ · 7
НОД(84, 112) = 2² · 7 = 28
Проверка: 84 : 28 = 3, а 112 : 28 = 4. Оба частных натуральные.
03 · Смысл

Что именно означает найденный НОД?

Ключевой вопрос текстовой задачи: какая величина должна быть одинаковой и максимально возможной? Смысл НОД определяется условием задачи.

Одинаковые наборы

84 помидора и 112 огурцов распределяются по максимальному числу одинаковых наборов.

НОД(84, 112) = 28

28 — число наборов. В каждом наборе: 84 : 28 = 3 помидора и 112 : 28 = 4 огурца.

Одинаковый размер группы

108 мальчиков и 114 девочек распределяются отдельно по группам с одинаковым максимально возможным числом человек.

НОД(108, 114) = 6

6 — число человек в каждой группе. Получается 18 групп мальчиков и 19 групп девочек.

Частая ошибка: считать, что НОД всегда означает количество групп. Сначала определите, что именно по условию должно быть одинаковым.
04 · Уравнения

Разбирайте составное уравнение снаружи внутрь

Если целое выражение с x играет роль одного компонента действия, временно рассматривайте это выражение как единый объект. Выполните обратное действие, затем решайте более простое уравнение.

Связи компонентов
a + b = c → a = c − b, b = c − a
a − b = c → a = b + c, b = a − c
ab = c → a = c : b, b = c : a
a : b = c → a = bc, b = a : c (b ≠ 0; для формулы b = a : c нужно c ≠ 0)

(x + 3) / 2 = 10

ШАГ 1
Выражение x + 3 — делимое.
ШАГ 2
x + 3 = 10 · 2 = 20
ШАГ 3
x = 20 − 3 = 17
ПРОВЕРКА
(17 + 3) / 2 = 10

6 / (x − 5) = 2

ОДЗ
x − 5 ≠ 0 → x ≠ 5
ШАГ 1
Выражение x − 5 — делитель.
ШАГ 2
x − 5 = 6 : 2 = 3
ШАГ 3
x = 3 + 5 = 8
ПРОВЕРКА
6 / (8 − 5) = 2
Опора вместо зубрёжки: если правило забыто, возьмите простое верное числовое равенство, например 10 − 2 = 8 или 6 : 2 = 3, и восстановите связь компонентов по смыслу.
