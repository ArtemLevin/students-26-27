Самопроверка

Основные понятия

Разряд определяет смысл цифры

4,8
четыре целых восемь десятых
4,08
четыре целых восемь сотых
4,008
четыре целых восемь тысячных
Правило. Количество цифр после запятой определяет разряд последней цифры дробной части.

Какие нули можно убирать?

Справа в конце дробной части — можно.4,8 = 4,80 = 4,8005,3000 = 5,3
Внутри записи — нельзя.4,08 ≠ 4,84,008 ≠ 4,08

Как сравнивать десятичные дроби

целая часть→при необходимости нули справа→десятые→сотые→тысячные
4,080>4,008

Первая различающаяся цифра определяет результат: в разряде сотых 8 > 0, поэтому 4,08 > 4,008.

1,23 = 1,230 > 1,21512,345 > 1,9999

Главное правило

Запятая под запятой

выровнять по запятой→дописать нули справа→считать справа налево→снести запятую

Сложение

2,41 + 1,159 = 2,410 + 1,159 = 3,569
1,2 + 3,51 = 1,20 + 3,51 = 4,71

Вычитание

2,410 − 1,159 = 1,251

При заимствовании двигайтесь справа налево по разрядам.

10,120 − 3,453 = 6,667

Недостающий разряд справа компенсируется нулём.

10 − 1,12 = 10,00 − 1,12 = 8,88
Типичная ошибка. При вычитании нельзя менять порядок чисел. Уменьшаемое и вычитаемое определены исходным выражением.

Умножение

Запятую восстанавливаем после вычисления

Временно не учитывайте запятые.
Выполните обычное умножение натуральных чисел.
Посчитайте общее число цифр после запятой в обоих множителях.
Отделите справа столько же цифр в произведении.
1,5 · 3,2 → 15 · 32 = 480 → 4,80 = 4,8
3,12 · 1,5 → 312 · 15 = 4680 → 4,680 = 4,68
0,3 · 0,2 = 0,06

Если цифр для отделения запятой не хватает, допишите нули слева.

Деление

Запятая появляется при переходе к дробной части

Условие применимости: делитель не равен нулю.
15,6 : 3 = 5,25,2 · 3 = 15,6
17,5 : 5 = 3,53,5 · 5 = 17,5
2,4 : 4 = 0,6

Когда делим целые числа

25 : 4 = 6,25
4 · 6 = 24, остаток 1.
Целая часть закончилась: ставим запятую и дописываем нуль → 10.
10 : 4 = 2, остаток 2; дописываем нуль → 20.
20 : 4 = 5. Получаем 6,25.

Новая тема

Среднее арифметическое = сумма ÷ количество

среднее арифметическое = сумма всех чисел : количество чисел
(4 + 5 + 6 + 10 + 12) : 5 = 37 : 5 = 7,4

Удобная группировка

Если некоторые числа легко дают круглую сумму, объединяйте их первыми.

4,9 + 5,1 = 10
4,8 + 5,2 = 10
10 + 10 + 5 = 2525 : 5 = 5

Абстрактная запись

Для пяти произвольных чисел:

ā = (a₁ + a₂ + a₃ + a₄ + a₅) : 5

Такая запись помогает перейти от конкретных чисел к общей формуле.

Обратные действия

Как находить неизвестный компонент

x + a = b → x = b − ax − a = b → x = b + a
a · x = b → x = b : ax : a = b → x = a · b

Примеры

2x = 10 → x = 5
x + 2 = 10 → x = 8
x − 2 = 10 → x = 12
2(x − 8) = 10x − 8 = 5x = 13
(x − 8) : 2 = 10x − 8 = 20x = 28
Проверка. Подставьте найденное значение в исходное уравнение и убедитесь, что левая часть равна правой.
