Главная идея

От признака делимости — к НОД

Три шага связаны в одну систему: быстро определить возможный делитель, разложить числа на простые множители и выбрать из разложений общую часть.

1. Проверяем делимость
Используем признаки на 2, 3, 4, 5 и 6.
2. Раскладываем число
Последовательно делим на подходящие простые числа.
3. Находим НОД
Берём только общие простые множители в меньшем количестве.

Маршрут повторения

Вспомните вычисления.
Запятая под запятой; перевод смешанного числа в неправильную дробь; деление на дробь через обратную.
Повторите связи между компонентами действий.
Перед действием определите роль неизвестного: слагаемое, уменьшаемое, вычитаемое, множитель, делимое или делитель.
Выберите подходящий признак делимости.
Для 2 и 5 достаточно последней цифры; для 3 нужна сумма цифр; для 4 — число из двух последних цифр; для 6 нужны признаки 2 и 3 одновременно.
Разложите числа на простые множители.
Начинайте с самого маленького подходящего простого делителя и после каждого деления проверяйте полученное число снова.
Соберите НОД.
Каждый общий простой множитель берите столько раз, сколько он встречается в меньшем количестве из двух разложений.

Десятичные дроби

Сложение и вычитание
Запятые располагаем одна под другой; недостающие разряды можно дополнять нулями.
2,30 + 1,72 = 4,02
Умножение и деление
При умножении возвращаем запятую по числу десятичных знаков; при делении внимательно отмечаем появление запятой в частном.
1,72 · 2,3 = 3,956
2,42 : 4 = 0,605
Самопроверка: оцените порядок результата. Сумма чисел около 2 и 2 должна быть около 4.

Обыкновенные дроби

Смешанное число перед умножением или делением удобно переводить в неправильную дробь.

213=73

При делении на дробь умножаем на обратную дробь:

213:125=73:75=53=123

Пример

x+13=10
Сначала найдите весь числитель.
x + 1 = 10 · 3 = 30.
Теперь найдите x.
x = 30 − 1 = 29.
Проверка: (29 + 1) / 3 = 10.

Признаки, которые нужно узнавать сразу

На 2Последняя цифра чётная: 0, 2, 4, 6 или 8.
На 3Сумма всех цифр числа делится на 3.
На 4Число, составленное из двух последних цифр, делится на 4.
На 5Последняя цифра равна 0 или 5.
На 6Число одновременно делится на 2 и на 3.

Как соединять признаки

Для числа 1224 сумма цифр равна 9, поэтому число делится на 3. Последняя цифра 4 чётная, поэтому 1224 делится на 2. Значит, оно делится на 6.

1 + 2 + 2 + 4 = 9

Для делимости на 4 смотрим на две последние цифры вместе:

24 : 4 = 6
Типичная ошибка: проверять две последние цифры отдельно. Для признака на 4 нужно рассматривать число, которое они образуют.

Простое число

Простое число имеет ровно два натуральных делителя: 1 и само число.

2, 3, 5, 7, 11, 13, …

Разложить число на простые множители — представить его как произведение простых чисел.

Пример: число 54

54227393331
54 = 2 · 3 · 3 · 3 = 2 · 3³

На каждом шаге начинайте с самого маленького подходящего простого делителя. После деления снова проверяйте полученное число.

Самопроверка: перемножьте найденные множители — должно получиться исходное число.

Что такое НОД

Общий делитель двух натуральных чисел делит без остатка каждое из них. Наибольший общий делитель — самый большой из общих делителей.

НОД(a, b)

Алгоритм через простые множители

Разложите оба числа на простые множители.
Найдите общие простые множители.
Каждый общий множитель берите в меньшем количестве.
Перемножьте выбранные множители.

Пример: НОД(18, 54)

18 = 2 · 3²    54 = 2 · 3³
НОД(18, 54) = 2 · 3² = 18

Пример: НОД(12, 18)

12 = 2² · 3    18 = 2 · 3²
НОД(12, 18) = 2 · 3 = 6
Быстрая проверка: найденный НОД должен делить оба исходных числа без остатка и не может быть больше меньшего из них.

НОД и сокращение дробей

324 = 2² · 3⁴    432 = 2⁴ · 3³
НОД(324, 432) = 2² · 3³ = 108
324432=324:108432:108=34

Если общие множители уже отмечены, произведение оставшихся множителей сразу показывает результат деления каждого числа на НОД.

5 заданий для закрепления

  1. Вычислительная разминка. Найдите: а) 3,40 + 1,65; б) 1,25 · 2,4; в) 3,24 : 4; г) 2 1/4 : 1 1/2.
  2. Признаки делимости. а) Определите, на какие из чисел 2, 3, 4, 5, 6 делится 1224. б) В числе 12□4 поставьте все цифры, при которых число одновременно делится на 3 и на 4.
  3. Разложение на простые множители. Разложите 72 и 90 на простые множители.
  4. НОД. Найдите НОД(48, 72) через разложение на простые множители.
  5. НОД и сокращение дроби. Найдите НОД(414, 504), затем сократите дробь 414/504.
Ответы:
1) а) 5,05; б) 3; в) 0,81; г) 3/2 = 1 1/2.
2) а) 1224 делится на 2, 3, 4 и 6; на 5 не делится; б) 2 и 8.
3) 72 = 2³ · 3²; 90 = 2 · 3² · 5.
4) НОД(48, 72) = 24.
5) НОД(414, 504) = 18; 414/504 = 23/28.

Типичные ошибки

Для 4 проверяются цифры по отдельности.
Нужно проверять число, образованное двумя последними цифрами.
Для 6 используется только один признак.
Число должно делиться и на 2, и на 3 одновременно.
В НОД попал множитель только из одного разложения.
Берите только общие множители.
Общий множитель взят слишком много раз.
Его кратность ограничена меньшим количеством в двух разложениях.
