Равновозможные исходы и порядок

Классическая вероятность требует равновозможности исходов и точного учёта порядка.

P(A) = Nблагоприятных / Nвсех

Три музыкальные группы

Датская группа должна выступить позже шведской и норвежской. Всего 3! = 6 порядков, подходят 2! = 2.

P = 2/6 = 1/3

Сумму 8 дают упорядоченные пары (2;6), (3;5), (4;4), (5;3), (6;2). Из 36 исходов подходят пять.

P = 5/36 ≈ 0,14

Выбираются две вершины без учёта порядка. Всего сочетаний C(5,2) = 10; сторон пять.

P = 5/10 = 1/2

02 / УРОК

Выбор без возвращения

В задачах с разделением на группы события могут зависеть друг от друга.

Два близнеца в двух равных группах

После размещения Андрея во взятом на занятии примере для Сергея остаётся 25 свободных мест, из которых 12 находятся в той же группе.

P(в одной группе) = 12/25

Здесь мы считаем долю подходящих свободных мест, учитывая, что место первого человека уже занято.

При распределении без возвращения число доступных мест меняется. Формула Бернулли для такого подсчёта не требуется.

03 / УРОК

Независимость и дополнение

Прежде чем перемножать вероятности, установите независимость событий.

P(A ∩ B) = P(A) · P(B) при независимости
P(не A) = 1 − P(A)

Две авторучки

Каждая неисправна с вероятностью 0,1, неисправности независимы. Вероятность исправности одной равна 0,9.

Обе исправны

Для одновременного наступления двух независимых событий перемножаем.

0,9 · 0,9 = 0,81

Хотя бы одна исправна

Исключаем единственный вариант, когда обе неисправны.

1 − 0,1² = 0,99

События «обе исправны» и «хотя бы одна исправна» имеют разные вероятности.

Три последние цифры номера

Пять из десяти цифр нечётные. При независимом выборе трёх цифр вероятность получить все нечётные:

(5/10)³ = 1/8
04 / УРОК

Ровно k успехов: формула Бернулли

Для одинаковых независимых испытаний учитывайте все возможные расположения успехов.

P(X = k) = C(n,k) · pk · (1−p)n−k

Здесь n — число испытаний, k — требуемое число успехов, p — вероятность успеха. Коэффициент C(n,k) = n! / (k! (n−k)!) считает число расположений успехов.

Ровно два успеха из трёх

При p = 0,5 есть три способа разместить два успеха среди трёх испытаний.

C(3,2) · (0,5)² · 0,5 = 3 · 0,125 = 0,375

«Ровно два» требует учесть все расположения. Если порядок заранее закреплён, коэффициент сочетаний отсутствует.

05 / УРОК

Интервалы и вложенные события

Вычитать вероятности можно при точно установленном включении событий.

Если B ⊂ A, то P(A без B) = P(A) − P(B)

Срок службы фена

Известно P(T > 1) = 0,37 и P(T > 2) = 0,13. Второе событие содержится в первом.

P(1 < T ≤ 2) = 0,37 − 0,13 = 0,24

Т8.7

Масса буханки

P(M ≤ 810) = 0,96, P(M > 790) = 0,93. Значит P(M ≤ 790) = 0,07.

P(790 < M ≤ 810) = 0,96 − 0,07 = 0,89

Диаметр подшипника: граничный случай

Если P(|D−67| < 0,01) = 0,965, то вероятность дополнительного события равна 0,035.

P(|D−67| ≥ 0,01) = 1 − 0,965 = 0,035

Дополнение к строгому неравенству включает равенство. Для события D < 66,99 или D > 67,01 без дополнительных условий о распределении нельзя однозначно получить то же значение. При непрерывном распределении границы имеют нулевую вероятность.
