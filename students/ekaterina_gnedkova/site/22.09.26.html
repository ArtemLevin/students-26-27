ОПОРА

Что нужно видеть в векторе

Координаты вектора описывают смещение по двум осям. Действия выполняются покоординатно; длина связывает координаты с теоремой Пифагора, а скалярное произведение — с углом.

Маршрут вычисления
координаты → действия → длина или скалярное произведение → проверка смысла
01 · КООРДИНАТЫ

Координаты и длина

Пусть A(xA; yA) и B(xB; yB). Координаты показывают смещение из A в B по каждой оси.

Координаты
AB→=(xB−xA;yB−yA)

Пример из занятия

A(2; 2), B(7; 4).

AB→=(7−2;4−2)=(5;2)

Первая координата означает 5 единиц вправо, вторая — 2 единицы вверх.

Длина
|a→|=x2+y2

Для AB = (5; 2):

|AB→|=52+22=29
Знак координаты

Отрицательная координата допустима и означает смещение в отрицательном направлении оси.

Квадрат длины

Если требуется |a|², корень извлекать не нужно: |a|² = x² + y².

Нулевой вектор

Длина равна нулю тогда и только тогда, когда обе координаты равны нулю.

Исследовательская модель

02 · ДЕЙСТВИЯ

Действия и линейная комбинация

Умножение на число, сложение и вычитание выполняются по соответствующим координатам.

Три правила
λa→=(λx;λy)a→+b→=(xa+xb;ya+yb)a→−b→=(xa−xb;ya−yb)

Линейная комбинация из занятия

k = (1; 2), t = (3; 4). Найдём длину 3k − 2t.

3k→=(3;6),2t→=(6;8)3k→−2t→=(−3;−2)|3k→−2t→|=13

  1. Выпишите координаты исходных векторов.

  2. Умножьте обе координаты каждого вектора на коэффициент.

  3. Сложите или вычтите соответствующие координаты.

  4. Если требуется длина, примените формулу |c| = √(x² + y²).

03 · УГОЛ

Скалярное произведение и угол

Скалярное произведение даёт число. Для двух ненулевых векторов оно связывает координаты, длины и угол.

По координатам
a→·b→=xaxb+yayb

Пример

a = (2; −3), b = (1; −5).

a→·b→=2·1+(−3)·(−5)=17
Через угол
a→·b→=|a→||b→|cosφ

Для вычисления cos φ оба вектора должны быть ненулевыми: в знаменателе формулы стоит произведение их длин.

Перпендикулярность

Для a = (3; 4), b = (4; −3): a · b = 0, |a| = |b| = 5, поэтому cos φ = 0 и φ = 90°.

a→·b→=0⇔a→⊥b→

Эквивалентность используется для ненулевых векторов.

Порядок для угла

Скалярное произведение → длина a → длина b → cos φ.

a · b > 00° ≤ φ < 90°
a · b = 0φ = 90°
a · b < 090° < φ ≤ 180°
Самопроверка

Для любого угла между векторами должно выполняться −1 ≤ cos φ ≤ 1.

04 · ГЕОМЕТРИЯ

Правило треугольника и ромб

В ромбе используются два свойства диагоналей: они делятся пополам и взаимно перпендикулярны.

Правило треугольника
AB→+BC→=AC→

Дано: ромб ABCD; AC = 12, BD = 16; диагонали пересекаются в O.

Требуется: найти |AO + BO|.

Шаг 1. Половины диагоналей

O — середина обеих диагоналей, поэтому AO = 6, BO = OD = 8.

Шаг 2. Равные векторы

B, O, D лежат на одной прямой в порядке B—O—D и BO = OD, поэтому векторы BO и OD равны.

Шаг 3. Правило треугольника

AO + BO = AO + OD = AD.

Шаг 4. Теорема Пифагора

Треугольник AOD прямоугольный.

AD=62+82=10

Ответ: 10.

КОНТРОЛЬ

Типичные ошибки

Главные риски — порядок координатных действий, знаки и условия применимости формулы для угла.

Начало и конец перепутаны

Для AB вычисляйте B − A по каждой координате.

Коэффициент применён к одной координате

Число умножает обе координаты вектора.

Потерян минус при вычитании

Сначала выпишите обе пары координат, затем вычитайте соответствующие компоненты.

Квадрат отрицательной координаты

Записывайте отрицательное число в скобках: (−3)² = 9.

Смешаны произведение и длина

a · b — число; |a| — длина одного вектора.

Нулевой вектор в формуле угла

Формула для cos φ применяется только к двум ненулевым векторам.
