Числа из четырёх цифр

Из цифр 0, 1, 2, 3 составляем двузначные числа. Повторения разрешены. На месте десятков — три ненулевых цифры; единиц — четыре.

3×4=12

Ответ: 12 чисел.

Разложить варианты по позициям →

Маршрут из A в C

Между A и B есть три дороги, между B и C — четыре. Каждый путь состоит из двух выборов.

3×4=12

Ответ: 12 маршрутов.

Произведение подходит, когда каждый полный вариант состоит из нескольких последовательных выборов. Для непересекающихся альтернатив «или» количество вариантов складывают.

02 / ЦИФРЫ

Разрешено повторять?

Если цифру можно использовать повторно, она остаётся доступной. Если повторений быть не должно, каждый выбор сокращает число кандидатов.

С повторениями

Двузначные числа из 0, 1, 2, 3.

3×4=12

Без повторений

Трёхзначные числа из 0, 1, 2, 3. Для первой позиции ноль исключён.

3×3×2=18

В трёхзначном числе на первом месте возможны 1, 2, 3. После выбора первой цифры для второго разряда доступны три цифры, включая ноль; для третьего — две.

Первый разряд многозначного числа не бывает нулём. У кода ведущий ноль может быть допустим, если условие это разрешает.
03 / ПОРЯДОК

Разные роли или один набор?

При перестановке выбранных элементов ответ меняется только в тех задачах, где важен порядок.

Факториал и перестановки

Если все n различных объектов занимают n разных мест, количество перестановок равно n!.

n!=n·(n−1)·…·2·1

0! = 1; 5! = 120.

Пять предметов по пяти урокам: 5! = 120. Для физорга, организатора и казначея из 18 участников: 18 · 17 · 16 = 4896.

Роли различны

Из десяти человек назначают председателя и секретаря. Перестановка выбранных людей даёт другой результат.

10·9=90

Просто выбрать двоих

Каждая пара учтена дважды: A—B и B—A — один и тот же состав.

10·92!=45

Если из n разных объектов выбирают k без повторений и порядок не важен, упорядоченные способы нужно разделить на k!, поскольку один состав учитывается во всех перестановках выбранных объектов.

Сравнить два типа выбора →

Книги двухтомника рядом

Среди восьми разных книг два тома стоят рядом. Считаем их одним блоком: получаем семь объектов. При этом сами два тома внутри блока могут меняться местами.

7!·2!=10080

Ответ: 10 080 расстановок.

04 / УСЛОВИЯ

Заполняйте самые ограниченные места первыми

Фиксированная последняя цифра, запрет ведущего нуля и признаки делимости сокращают варианты до начала общего подсчёта.

Последняя цифра задана

Пятизначные числа из 1, 2, 3, 4, 5 без повторений; последняя цифра — 3.

4·3·2·1=24

Делимость на четыре

Шестизначные числа без повторений из 1, 3, 5, 6, 7, 9. Окончания: 16, 36, 56, 76, 96.

5·4!=120

Число кратно 4, если его последние две цифры образуют число, кратное 4. При делимости на 5 последняя цифра — 0 или 5.

05 / ГЕОМЕТРИЯ

Почему пары вершин делят на два

Отрезок AB совпадает с BA, поэтому подсчёт с учётом порядка дважды учитывает каждый отрезок.

  1. У n вершин есть n(n − 1) упорядоченных способов выбрать два различных конца отрезка.
  2. Разные отрезки получаем делением на 2: n(n − 1) / 2.
  3. Из всех отрезков n являются сторонами многоугольника. Вычитаем их.
D=n(n−1)2−n=n(n−3)2

Для шестиугольника: 9 диагоналей; для двадцатиугольника: 170. Формула справедлива для любого простого n-угольника при n ≥ 3.

07 ВЫШЕ СРЕДНЕГО

08 ВЫШЕ СРЕДНЕГО

Семь разных книг, из них две — тома одного произведения и должны стоять рядом. Сколько расстановок?

09 ПОВЫШЕННЫЙ

Из девяти разных книг выбирают три в поездку; порядок не важен. Сколько наборов?

Показать ответ
