01

Степени · приводим к общему основанию

Составные числа раскладываем в степени простых: 81 = 3⁴, 8 = 2³, 27 = 3³. Затем применяем правила показателей.

am · an = am+n
am / an = am−n
(am)n = amn
Типичная ошибка: при делении на a−1 вычитается отрицательный показатель. При отрицательной степени a ≠ 0.

Из разбора

8134=(34)34=27

8−23=(23)−23=14

(a−4b⁶ · a⁵)/(a−1b⁴) = a²b²

Для буквенного выражения a ≠ 0, b ≠ 0.

02

Показательное уравнение и функция

Выносим общую степень за скобку и получаем одинаковые основания.

  1. 3x+2 − 3x = 216
  2. 3x(9 − 1) = 216
  3. 3x = 27 = 3³
  4. x = 3
Различайте ax + b и ax+b. Скобки вокруг дробного основания обязательны.

Функция по двум точкам

Для f(x) = ax + b точки (0; 3) и (2; 11) дают:

3 = a⁰ + b ⇒ b = 2
11 = a² + b ⇒ a² = 9
a > 0 ⇒ a = 3

f(x) = 3x + 2, поэтому f(−1) = 7/3.

Сдвиг в показателе

Если g(x) = (1/2)x+b и g(0) = 8, то b = −3 и g(−2) = 32.

Быстрая проверка: чему равно x в исходном показательном уравнении?

03

Векторы · покоординатные действия

Вычитаем координаты начала из координат конца; длину находим по теореме Пифагора.

AB⃗ = (xB−xA; yB−yA)
|AB⃗| = √(Δx² + Δy²)

A(−4; 1), B(2; 9): AB⃗ = (6; 8), |AB⃗| = 10.

Для a⃗ = (2; −3), b⃗ = (−1; 4) получаем 3a⃗ − 2b⃗ = (8; −17).

Скалярное произведение нулевое у перпендикулярных ненулевых векторов: uxvx + uyvy = 0.

Перпендикулярность

u⃗ = (t; 5), v⃗ = (4; −8)

4t − 40 = 0 ⇒ t = 10

Движение · правильная ось времени

Два автомобиля едут навстречу из городов на расстоянии 340 км. Скорости 60 и 80 км/ч, второй выехал на час позже.

Ктоv, км/чt, чS, км
Первый60x60x
Второй80x − 180(x − 1)
60x + 80(x − 1) = 340
x = 3 часа
Сумма путей равна 340 км. x — время от старта первого автомобиля.

По кругу

Скорости 24 и 16 км/ч. Чтобы обогнать на один круг длиной L:

(24 − 16)t = L

Без указанной длины круга время не определяется числом.

По реке

Скорость катера 15 км/ч; 54 км по течению и 48 км против за 7 ч:

5415+v+4815−v=7

v = 3 км/ч; 0 ≤ v < 15.

Схема

Скорость · время · путь.

S = vt

05

Совместная работа · два этапа

Первый насос заполняет резервуар за 6 часов, второй — за 9. Два часа они работают вместе, затем остаётся первый.

2(16+19)+t6=1t=83 ч

Спрашивают общее время от начала: T = 2 + t = 4 ч 40 мин.

t — продолжительность второго этапа, после отключения второго насоса. Не забудьте добавить 2 часа первого этапа.
Проверка по частям
Вместе насосы заполнили 5/9, первый после отключения второго — ещё 4/9. Получили ровно один резервуар.
