01

Когда известна часть. Когда известно целое.

Одна и та же дробь требует разных действий. Сначала определите неизвестную величину.

Известно целое

Найти часть

A = C · a/b

3/5 от 140: 140 · 3/5 = 84.

Известна часть

Найти целое

C = A : (a/b)

54 составляют 3/10: 54 : (3/10) = 180.

Выберите, что требуется найти

Найдите 3/5 от 140.

140 · 3/5 = 84

84 меньше 140: результат правдоподобен.

Проверка: при положительной доле меньше единицы найденная часть меньше целого; найденное целое больше известной части.
02

Проценты: определите исходные 100%.

Процент — одна сотая: 1% = 1/100 = 0,01. Доля 60% соответствует числу 0,6; 95% — числу 0,95.

Первоначальная площадь

Убрали 3600 га — это 60% поля

  1. Пусть вся площадь x гектаров.
  2. 0,6x = 3600.
  3. x = 3600 : 0,6 = 6000 га.
  4. Проверка: 6000 · 0,6 = 3600.
Процентное изменениеПрибавка: C · p/100
После роста: C · (1 + p/100)
После снижения: C · (1 − p/100)

Рост на 15%

На 105 деталей больше

0,15x = 105, исходно 700, после роста 805 деталей.

Скидка 24%

На 57,6 руб. дешевле

0,24x = 57,6, исходная цена 240 руб., новая 182,4 руб.

Тонкость: 0,15x — величина прибавки; 1,15x — итог после роста на 15%.
03

Дроби и уравнения: равенство сохраняется.

При делении десятичных дробей домножайте делимое и делитель на одно и то же ненулевое число.

Два равных способа0,16 : 0,5 = 1,6 : 5 = 0,32
(16/100) : (5/10) = 8/25 = 0,32
Уравнение занятия

5¼y − 5¼ = 5¼

  1. Переносим свободное слагаемое: 5¼y = 5¼ + 5¼.
  2. Складываем одинаковые числа: 5¼y = 2 · 5¼.
  3. Делим на коэффициент: y = 2.
  4. Проверка: 5¼ · 2 − 5¼ = 5¼.
Частая ошибка: знак меняется при переносе через равенство. Если слагаемое осталось на своей стороне, менять знак нельзя.
04

Переведите условие на язык величин.

Слова «95% от второго» задают отношение первого количества ко второму. Обозначьте второе число через x.

Два отряда · 780 саженцев
  1. Второй отряд — x, первый — 0,95x.
  2. Общее количество: x + 0,95x = 780.
  3. x = 400, первый отряд посадил 380.
  4. Проверка: 380 + 400 = 780 и 380 : 400 = 0,95.
Смежные углы

Один угол в 1⅖ раза больше другого

Меньший угол x, больший — 7x/5. Их сумма равна 180°.

x + 7x/5 = 180° → x = 75°
Второй угол = 105°
Сигнал: «95% от второго» — долю считайте именно от второго, не от общей суммы.
05

Встречное движение: скорости складываются.

Если два автомобиля едут навстречу, расстояние уменьшается со скоростью, равной сумме их скоростей.

75 км/чавтомобиль 1
→
126 кмдо встречи
←
60 км/чавтомобиль 2
Общая связьvсбл = v1 + v2
S = (v1 + v2) · t

Автомобили встретятся через 14/15 часа; скорость одного составляет 80% скорости другого.

  1. Скорости x и 0,8x км/ч.
  2. (x + 0,8x) · 14/15 = 126.
  3. 1,8x = 135, значит x = 75 км/ч.
  4. Вторая скорость 0,8 · 75 = 60 км/ч.
  5. Проверка: (75 + 60) · 14/15 = 126 км.
Сравнение: при догонянии скорость сближения равна разности скоростей; при встречном движении — сумме.

  1. Найдите 3/8 числа 64.
    Показать ответ

    24

  2. Известно, что 5/6 некоторого числа равны 35. Найдите это число.
    Показать ответ

    42

  3. Решите уравнение: 4½x − 4½ = 4½.
    Показать ответ

    x = 2

  4. Вычислите: 0,24 : 0,6.
    Показать ответ

  5. Один из смежных углов в 1¼ раза больше другого. Найдите оба угла.

    Показать ответ

    Первый — 460, второй — 575 саженцев.

    Всего 600 га; осталось 180 га.

  8. После повышения производительности станок начал изготавливать на 84 детали больше, что составляет 12% прежней выработки. Сколько он изготавливал раньше?
    Показать ответ

    700 деталей.

  9. Цена товара снизилась на 18%, причём уменьшение составило 72 рубля. Найдите первоначальную и новую цены.

    400 руб. и 328 руб.

  10. Два автомобиля движутся навстречу из пунктов, удалённых на 144 км, и встречаются через 4/5 часа. Скорость одного составляет 80% другого. Найдите обе скорости.
    Показать ответ

    80 км/ч и 100 км/ч.
