Режим 3

Текст → уравнение

Используется пример: среднее двух чисел 42, второе число в 2,5 раза больше первого.

1. Текст
Среднее двух чисел равно 42; второе в 2,5 раза больше первого.
2. Обозначения
Первое число x₁; второе x₂ = 2,5x₁.
3. Формула
(x₁ + x₂)/2 = 42.
4. Уравнение
(x₁ + 2,5x₁)/2 = 42.
5. Ответ и проверка
x₁ = 24, x₂ = 60; среднее 42.
