Метод узловых точек

Как восстановить формулу функции по графику, найти неизвестные коэффициенты и правильно понять, что именно требуется подставить в финальном шаге.

01

Точка становится уравнением

Сначала считываем данные с графика без приближений.

В этом пособии узловой называем точку графика, у которой обе координаты — целые числа. Если точка A(x; y) лежит на графике, её координаты удовлетворяют равенству y = f(x).

Главный принцип: неизвестные коэффициенты определяются из независимых уравнений, полученных подстановкой координат точек.
ТочкаСтатусПочему
A(−1; −3)узловаяобе координаты целые
B(3; 4)узловаяобе координаты целые
C(2; 2,4)не узловаяордината 2,4 не является целым числом
Если узловых точек несколько, особенно удобны точки с x = 0, y = 0, x = 1 или x = −1. Это сокращает вычисления, хотя сам метод от такого выбора не зависит.
A(x0;y0) ⇒ y0=f(x0)
02

Восстанавливаем прямую

Для f(x) = kx + b нужны два коэффициента.

Пусть прямая проходит через точки A(−1; −3) и B(3; 4). Две точки с разными абсциссами дают два независимых уравнения для коэффициентов k и b.

От точек к формуле

Шаг 1 из 5

Шаг 1 · Запишите общий вид

Работаем с линейной функцией:

f(x)=kx+b

Неизвестны два коэффициента: k и b.

Шаг 2 · Подставьте первую точку

Для A(−1; −3): вместо x подставляем −1, вместо f(x) — −3.

−3=−k+b

Шаг 3 · Подставьте вторую точку

Для B(3; 4) получаем второе уравнение.

4=3k+b

Теперь перед нами система из двух уравнений.

Шаг 4 · Решите систему

Из первого уравнения: b = k − 3. Подставляем это выражение во второе и получаем 4k = 7.

k=74 , b=−54

Шаг 5 · Запишите функцию и ответьте на вопрос

f(x)= 74x −54

Для f(−5) подставляем x = −5 и получаем −10.

Самопроверка: подставьте в найденную формулу одну исходную точку. Для B(3; 4) получается f(3) = 4 — координаты подтверждаются.
03

Что именно дано?

Две похожие записи приводят к разным действиям.

Самая важная развилка финального шага — различить значение аргумента и значение функции.

Найти f(−5)

Число −5 — это значение x.

x = −5 → подставить в формулу
f(−5) =2·(−5)−1 =−11

Дано f(x) = −5

Число −5 — это значение функции.

−5 = формула → решить уравнение
−5=2x−1 ⇒ x=−2
Памятка: запись f(a) сообщает значение аргумента; запись f(x) = c сообщает значение функции и приводит к уравнению относительно x.
04

Тот же метод для параболы

Меняется формула, логика остаётся прежней.

Пусть известен общий вид f(x) = 2x² + bx + c. Коэффициент при x² уже известен, поэтому требуется определить только b и c.

C(0;−4) ⇒ c=−4

Точка с x = 0 особенно удобна: при x = 0 слагаемые с x исчезают, и значение функции сразу равно свободному коэффициенту c.

D(1;1) ⇒ 1=2+b−4 ⇒ b=3

Итоговая функция:

f(x) =2x2 +3x−4

Например, f(−5) = 31.

Само число точек не заменяет проверку логики: уравнений должно быть достаточно, чтобы неизвестные коэффициенты определялись однозначно.
05

Где чаще всего сбивается решение

Проверяем запись до вычислений.

  1. Путают порядок координат. Запись точки всегда читается как (x; y).
  2. Берут точку, которая не лежит на графике, или пытаются использовать координату, которую нельзя считать точно.
  3. Путают задачи f(a) = ? и f(x) = a.
  4. Теряют знак минус при переносе слагаемого или при подстановке отрицательного x.
  5. Находят один коэффициент и останавливаются, хотя формула содержит ещё неизвестные коэффициенты.
  6. После решения системы не записывают итоговую формулу функции.
  7. Не проверяют найденную формулу по одной из исходных точек.
−3k+b=−3 ⇒ b=3k−3

При переносе слагаемого −3k в другую часть уравнения его знак меняется.

1. Какие точки являются узловыми?

A(−2; 3), B(1,5; 4), C(0; −5), D(7; 1/2), E(3; 4).

Ответ: A, C, E.

2. Для f(x) = 4x + 1 найдите f(1) и x, если f(x) = 1.

Ответ: f(1) = 5; x = 0.

3. Прямая проходит через (−3; −4) и (1; 2). Восстановите формулу и найдите f(−5).

Ответ: f(x) = 3x/2 + 1/2; f(−5) = −7.

4. Прямая проходит через A(−3; −3) и B(1; 2). Найдите формулу и f(−9).

Ответ: f(x) = 5x/4 + 3/4; f(−9) = −21/2.

5. Прямая проходит через A(−4; −2) и B(4; 1). Найдите x, если f(x) = 5/2.

Ответ: f(x) = 3x/8 − 1/2; x = 8.

6. Для f(x) = 2x² + bx + c по точкам (0; −4) и (1; 1) найдите b, c и f(2).

Ответ: b = 3, c = −4, f(2) = 10.

7. f(x) = −2x² + bx + c проходит через D(2; 5), E(3; 3). Найдите b, c и f(−1).

Ответ: b = 8, c = −3, f(x) = −2x² + 8x − 3, f(−1) = −13.
