01 / РАЗМИНКА

Деление десятичных дробей

При делении десятичных дробей удобно одновременно умножить делимое и делитель на одну степень десяти. Так запятая исчезает в делителе; иногда целыми становятся оба числа.

1,4 : 0,25 = 140 : 25 = 5,6
Оба числа умножены на 100. Значение частного осталось прежним. Проверка: 5,6 · 0,25 = 1,4.
02 / ОБРАТНЫЕ ДЕЙСТВИЯ

Простые и линейные уравнения

Неизвестное вычитаемоеa − b = c → b = a − c

3 − x = 15 → x = −12

Неизвестный делительa : b = c → b = a : c

3 : x = 15 → x = 0,2

Формула для неизвестного делителя применима при a ≠ 0 и c ≠ 0; здесь x ≠ 0.

Если есть скобки

  1. Раскройте скобки с учётом знака перед ними.
  2. Перенесите слагаемые и приведите подобные.
  3. Разделите на коэффициент при неизвестной.
−2(x + 3) = 4(−x + 1)
−2x − 6 = −4x + 4
2x = 10
x = 5

При переносе слагаемого меняется его знак; при раскрытии скобок множитель применяется ко всем членам.

03 / КВАДРАТНОЕ УРАВНЕНИЕ

Дискриминант и корни

Для полного квадратного уравнения ax² + bx + c = 0, где a ≠ 0, используйте дискриминант.

D = b² − 4ac;   x = (−b ± √D) / (2a)

При D > 0 получаем два корня, при D = 0 один корень, при D < 0 действительных корней нет.

x² − x − 6 = 0;   a = 1, b = −1, c = −6
D = (−1)² − 4 · 1 · (−6) = 25
x₁ = (1 + 5) / 2 = 3
x₂ = (1 − 5) / 2 = −2

Отрицательные коэффициенты при подстановке записывайте в скобках.

04 / ПЕРЕД ДИСКРИМИНАНТОМ

Вынесение общего множителя

Всегда сначала спросите себя, можно ли вынести общий множитель или применить разность квадратов.

x² − x = 0 → x(x − 1) = 0 → x = 0 или x = 1
x² − 4 = 0 → (x − 2)(x + 2) = 0 → x = ±2
x² − 3 = 0 → x = ±√3

Если произведение равно нулю, хотя бы один из множителей равен нулю. Уравнение x² + 3 = 0 действительных корней не имеет, поскольку квадрат любого действительного числа неотрицателен.

Дополнительно: (x² − 10)(x² − 4x) = 0 → x ∈ {−√10; 0; √10; 4}.

05 / ЧИСЛОВАЯ ПРЯМАЯ

Линейные неравенства

Строгое неравенство изображается выколотой точкой и круглой скобкой; нестрогое — закрашенной точкой и квадратной скобкой. На бесконечности всегда ставится круглая скобка.

Посмотрите, как меняется граница

x ∈ [1,2; +∞). Граница включена.

2(x − 3) ≤ 3(x − 5) → −x ≤ −9 → x ≥ 9. При умножении на −1 знак меняется.

x ≥ 1,5 и одновременно x < 10: пересечение [1,5; 10).

06 / ОБЩАЯ ЧАСТЬ

Системы неравенств

Каждое неравенство решите отдельно. Затем на числовых прямых найдите область, где выполняются все условия системы. Границу включайте только при нестрогом знаке.

2(x − 3) + 1 ≥ −x + 5 → 3x ≥ 10 → x ≥ 10/3
3 − 3(x + 2) ≤ 4x − 7 → 7x ≥ 4 → x ≥ 4/7
Общая часть: x ∈ [10/3; +∞)
Решение двух отдельных неравенств — промежуточный этап. Ответ системы — их пересечение.
  1. Решить каждое неравенство.
  2. Правильно отметить границы и направления.
  3. Найти пересечение штриховок.
  4. Записать промежуток и проверить границы.
07 / ФОРМУЛЫ

Не путайте разность квадратов с квадратом разности

Разность квадратовa² − b² = (a − b)(a + b)

Между квадратами стоит знак минус.

16x² − 9y² = (4x − 3y)(4x + 3y)

Квадрат разности(a − b)² = a² − 2ab + b²

В середине появляется удвоенное произведение.

(5t − 3k)² = 25t² − 30tk + 9k²

Подстановка целых выражений

(2x − y)² = (2x)² − 2 · (2x) · y + y² = 4x² − 4xy + y²
(4k − 4t)² = 16k² − 32kt + 16t²
(a + b)² = a² + 2ab + b²
Частая ошибка: минус между a и b уже содержится в члене −2ab. Последнее слагаемое квадрата разности имеет знак плюс. При вычислении 2 · 4k · 4t получаем 32kt.
