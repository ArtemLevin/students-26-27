ОПОРНАЯ ФОРМУЛА

D = b² − 4ac

Знак дискриминанта определяет число действительных корней квадратного уравнения. Перед подстановкой точно запишите a, b и c.

01 / КОНТРОЛЬ

Знаки остаются при числах

При переносе слагаемого в другую часть равенства его знак меняется. Коэффициенты квадратного уравнения всегда выписывайте вместе со знаками.

2 − x = 10  ⇒  −x = 8  ⇒  x = −8

Скобки определяют порядок действий

СТЕПЕНЬ ВСЕГО ЧИСЛА
(−3)² = 9

Минус входит в основание степени.

СТЕПЕНЬ ТОЛЬКО ТРОЙКИ
−3² = −9

Знак минуса находится перед квадратом.

Чётная степень отрицательного числа положительна; нечётная — отрицательна. Например, (−2)¹⁰⁰⁰ > 0, а (−2)¹⁰⁰¹ < 0.

02 / КВАДРАТНОЕ УРАВНЕНИЕ

Дискриминант и два корня

Приведите уравнение к виду ax² + bx + c = 0, где a ≠ 0. После этого найдите D = b² − 4ac.

Знак DСколько корней
D > 0Два различных: x₁,₂ = (−b ± √D)/(2a)
D = 0Один: x = −b/(2a)
D < 0Действительных корней нет

Разбор из занятия: x² − x − 6 = 0

  1. a = 1, b = −1, c = −6
  2. D = (−1)² − 4·1·(−6) = 25
  3. √D = 5
  4. x₁ = (1 + 5)/2 = 3; x₂ = (1 − 5)/2 = −2

Проверка подстановкой: 3² − 3 − 6 = 0 и (−2)² − (−2) − 6 = 0. При отрицательном старшем коэффициенте особенно внимательно проверяйте знаки: у −x² + 3x + 4 = 0 корни −1 и 4.

03 / ПРЕОБРАЗОВАНИЕ

Вынесение общего множителя

Найдите множитель, который присутствует во всех слагаемых. Вынесите его за скобки, разделив на него каждое слагаемое.

ab + ac = a(b + c)
  1. 25x + 5y = 5(5x + y)
  2. 5x² + 3x = x(5x + 3)
  3. 5x² + 25x³ = 5x²(1 + 5x)

Единица в скобках сохраняется, если после вынесения множителя она остаётся самостоятельным слагаемым. Проверка: раскройте скобки и сравните с исходным выражением.

04 / ПРАВИЛО НУЛЕВОГО ПРОИЗВЕДЕНИЯ

Произведение равно нулю

Если произведение множителей равно нулю, хотя бы один из них равен нулю.

AB = 0  ⇔  A = 0 или B = 0
  1. x² − x = 0
  2. x(x − 1) = 0
  3. x = 0 или x − 1 = 0
  4. Ответ: 0; 1

Для (x + 3)(x + 4)(x + 10) = 0 получаем корни −3; −4; −10.

Нельзя делить x(x − 1) = 0 на x: при этом пропадает корень x = 0.

05 / КОРОТКИЙ ПУТЬ

Неполные квадратные уравнения

Если в уравнении нет свободного члена, удобно вынести x. Если нет линейного члена, удобно выделить x².

Нет свободного члена

x² − 3x = 0

x(x − 3) = 0 ⇒ x = 0; 3

Нет члена с x

x² − 4 = 0

x² = 4 ⇒ x = ±2

Если x² = mРешения
m > 0x = ±√m
m = 0x = 0
m < 0Действительных корней нет

Например, у x² − 3 = 0 корни ±√3, а у x² + 5 = 0 действительных корней нет, так как x² ≥ 0.

06 / УПРОЩЕНИЕ

Подобные слагаемые

Подобные слагаемые имеют полностью совпадающую буквенную часть: одинаковые буквы в одинаковых степенях. Складываются коэффициенты.

5x + 3x = 8x−5x² + 3x² = −2x²

5x + 3y и 5x² + 3x привести нельзя: буквенные части различны.

После приведения подобных можно решить уравнение

  1. x² − 5 + 4x² = 7
  2. 5x² = 12
  3. x² = 12/5
  4. x = ±√(12/5)
07 / МАРШРУТ РЕШЕНИЯ

Как выбрать способ решения

  1. Перенесите все слагаемые влево и приведите подобные.
  2. Если c = 0, вынесите x и приравняйте множители к нулю.
  3. Если b = 0, получите x² = −c/a и проверьте знак правой части.
  4. В остальных случаях вычислите D = b² − 4ac и найдите корни по формуле.
  5. Проверьте ответ подстановкой в исходное уравнение.

Перед окончательным ответом

  • Знаки: коэффициенты с исходными минусами, деление отрицательных чисел.
  • Скобки: отрицательное число в квадрате обязательно в скобках.
  • Все корни: у произведения могут быть несколько корней, включая ноль.
  • Проверка: подставьте каждый корень в исходное уравнение.
