ТЕОРИЯ / КЛЮЧЕВЫЕ ИДЕИ

Фундамент занятия

Сначала приводим равенство к удобному виду. Затем выражаем нужную букву. На каждом шаге проверяем знаки, единицы и скобки.

01

Как работает пропорция

Пропорция — равенство двух отношений. Для записи a/b = c/d знаменатели b и d должны быть ненулевыми.

ab = cd ⇒ad = bc
  1. Поменять части местами: c/d = a/b.
  2. Перевернуть сразу обе дроби: b/a = d/c при ненулевых a и c.
  3. Перенести множитель по диагонали: a = bc/d или c = ad/b.
ЗАПОМНИТЬ

«Фантомную» единицу в знаменателе можно опустить: A/1 = A. Но единица в числителе дроби 1/A остаётся.

02

Выражаем величины из формул

На занятии работали с законом всемирного тяготения. Неизвестная величина может находиться и в числителе, и в знаменателе.

ИСХОДНАЯ ФОРМУЛА
F = Gm₁m₂R²
НАЙТИ ПЕРВУЮ МАССУ
m₁ = FR²Gm₂
НАЙТИ ВТОРУЮ МАССУ
m₂ = FR²Gm₁
НАЙТИ КВАДРАТ РАССТОЯНИЯ
R² = Gm₁m₂F
НАЙТИ РАССТОЯНИЕ
R = √(Gm₁m₂F)

Не перепутайте: R² = A означает R = √A при R > 0. Если написано 2R = A, то R = A/2.

03

Четыре схемы для неизвестного

Узнавайте тип равенства до начала решения. Это помогает быстро выбрать операцию.

a + b = ca = c − b · b = c − a
a − b = ca = b + c · b = a − c
ab = ca = c/b · b = c/a
a/b = ca = bc · b = a/c*

* При делении знаменатель должен быть ненулевым; формула для b также требует c ≠ 0. Умножение и деление выполняются на ненулевой множитель.

ПРИМЕР ИЗ ПОСОБИЯ

Если 17 − b = 9, то b = 17 − 9 = 8. Проверка: 17 − 8 = 9.

04

Линейное уравнение

Слагаемые с неизвестным собираем в одной части, свободные числа — в другой. Коэффициент сохраняем вместе со знаком.

014x + 1 = 10x − 3
024x − 10x = −3 − 1
03−6x = −4
04x = (−4)/(−6) = 2/3

Проверка: обе части исходного уравнения равны 11/3.

05

Когда неизвестная в знаменателе

Сначала проверьте знаменатель. Затем выберите один из трёх методов — на занятии все они приводили к одному ответу.

РАЗБОР С ДОСКИ · 3 СПОСОБА
34x + 1 = 10

ОДЗ: 4x + 1 ≠ 0, то есть x ≠ −1/4.

СПОСОБ 01

(4x + 1)/3 = 1/10 → 4x + 1 = 3/10

В ЛЮБОМ СЛУЧАЕx = −7/40

Проверка: 4·(−7/40)+1 = 3/10 ≠ 0, поэтому 3/(3/10) = 10. Обратите внимание на минус: 3/10 − 1 = −7/10.

Если буква стоит в числителе, задача проще: (4x + 1)/3 = 10 ⇒ 4x + 1 = 30 ⇒ x = 29/4.

ОДЗ→Убрать знаменатель→Найти x→Проверить
06

Знак числа — часть числа

При вычислениях нельзя «отрывать» минус от коэффициента. Если −4x = 2, делим именно на −4, получая x = −1/2.

a−b = −ab = −ab

Если сверху целое выражение, скобки сохраняют смысл: (x + 1)/(−3) = −(x + 1)/3.

ПРИМЕР С ЗАНЯТИЯ

8/(−2x + 3) = 2 ⇒ x = −1/2

Проверяем знаменатель: −2·(−1/2)+3 = 4, следовательно 8/4 = 2.

07

ВУПС: скобки защищают выражение

ВУПС
Вычитаемое · Умножаемое · Подставляемое — в Скобки
01 / ВЫЧИТАЕМОЕ

Разность

Вычитаем сразу всё второе выражение:

(2x + 3) − (4x − 7)

После раскрытия: −2x + 10.

02 / УМНОЖАЕМОЕ

Произведение

Каждый многочлен — отдельный множитель:

(2x + 3)(4x − 7)

В этой записи оба множителя заключены в скобки.

03 / ПОДСТАВЛЯЕМОЕ

Подстановка

При x = 2y − 1 в выражение 2x + 3:

2(2y − 1) + 3

После раскрытия: 4y + 1.

РАСПРЕДЕЛИТЕЛЬНЫЙ ЗАКОН

k(a + b) = ka + kb · k(a − b) = ka − kb. В выражении 10(4x + 1) = 40x + 10 число 10 умножается на два слагаемых, а не на каждую букву отдельно.
