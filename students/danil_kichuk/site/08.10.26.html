Логарифмы: свойства и преобразование выражений

Логарифм отвечает на один вопрос о степени. Свойства позволяют отвечать на него и тогда, когда основания, аргументы и показатели выглядят непривычно.

Основной смысл

loga b = x ⇔ ax = b
a > 0a ≠ 1b > 0

В какую степень необходимо возвести основание a, чтобы получить число b?

01 / Определение

Логарифм — это показатель степени

Начинайте с определения. Формулы лишь помогают преобразовать выражение к более удобному виду.

Основание больше единицы

log2 8 = 3,   потому что 23 = 8.

Здесь ответ находится непосредственно по таблице степеней.

Основание меньше единицы

log1/2 8 = −3,   потому что (1/2)−3 = 8.

Отрицательный показатель — это переход к обратной величине.

Перед любым преобразованием проверьте область допустимых значений: основание положительно и отлично от единицы, аргумент положителен.

02 / Работа со степенью

Где стоит показатель?

Показатель из аргумента выходит множителем. Показатель из основания — обратным множителем. Сравните два примера из занятия.

Одна и та же степень — две роли

loga(br) = r·logab
logarb = 1r·logab

Для второй формулы дополнительно необходимо r ≠ 0. При преобразовании через logab предполагается b > 0.

Степень внутри аргумента

log3(1/∛81) = log3(3−4/3)
= −43 · log33 = −4/3

Разложите 81 как 34, затем корень превратите в дробный показатель.

Степень внутри основания

log1/∛813 = log3−4/33
= −34 · log33 = −3/4

Степень основания вынесите с обратным коэффициентом.

Когда необходим модуль
loga(b2n) = 2n·loga|b|,   b ≠ 0, n ∈ ℕ.

Например, log3((−3)2) = 2. Запись log3(−3) недопустима в действительных числах.

03 / Сложение и вычитание

Сверните выражение в один логарифм

Основания должны совпадать. Коэффициенты сначала переносятся в показатели аргументов.

Сумма

logab + logac = loga(bc)

Разность

logab − logac = loga(b/c)

Коэффициент

k·logab = loga(bk)

Сначала преобразуем, затем объединяем

Разобранный пример: сумма и разность трёх логарифмов.

log23 + 2log25 − log27
  1. log23 + log225 − log27
  2. log2(3·25/7)
  3. log2(75/7)
04 / Основное тождество

Сделайте основания одинаковыми

После согласования оснований логарифм становится показателем, который «возвращает» аргумент.

alogab = b · ar·logab = br

Основание внешней степени — 25

25log1257 = (52)(1/3)·log57
= 72/3 = ∛49

В показателе — сумма

31+log95 = 3 · 3(1/2)·log35
= 3√5

Число тоже можно представить через логарифм: 5 = log232; а 3 = 2log23.

05 / Переход к новому основанию

Основание можно изменить

Удобный выбор нового основания превращает дробь с логарифмами в простое отношение.

Любое допустимое основание c

logab = logcblogca

Для нового основания необходимо c > 0, c ≠ 1.

Основание и аргумент меняются местами

logab = 1logba

Эта запись требует дополнительно b ≠ 1.

Сокращение после перехода

Оба логарифма приводим к основанию 7.

log713log4913 = log713(1/2)·log713 = 2
