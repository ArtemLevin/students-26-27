Степени в задачах прикладного характера

Главная задача — увидеть в длинном прикладном условии знакомую алгебру: аккуратно выписать данные, привести числа к удобному степенному виду и корректно извлечь неизвестную величину.

01 / МАРШРУТ

Как читать прикладную задачу

Формула уже дана. Трудность — организовать вычисления и перевод текста.

1. Выписать только нужное

Формулу, известные величины, ограничение и то, что требуется найти.

2. Перевести текст

«Уменьшилось в два раза» превращается в связь двух состояний, например V₂ = V₁/2.

3. Подготовить числа

Десятичные коэффициенты и составные числа переписываются так, чтобы свойства степеней работали проще.

4. Подставить в скобках

Если вместо V₁ подставляется 2V₂, в степень идёт всё выражение: (2V₂)ᵃ.

5. Убрать степень у неизвестной

Если V5/3 = A, обе части возводятся в степень 3/5.

6. Проверить ответ

Ограничение, единицы и физический смысл результата проверяются в финале.

Граница «не менее / не более» требует проверки.

Равенство на границе используется только после того, как понятен характер зависимости: где достигается требуемый максимум или минимум.

02 / СТЕПЕНИ

Подготовка к вычислениям

На доске именно эта стадия позволяла упростить громоздкие выражения.

Числа, которые нужно узнавать

6,25 · 105 = 625 · 103
сдвинули запятую вправо — показатель десятки уменьшили
625 = 54

3125 = 55
получается последовательным делением на 5
128 = 27
полезно в задаче с четвёртой степенью
125 = 53
кубическая структура
(am)n = amn
основное действие при извлечении неизвестной
Если V5/3 = A, то V = A3/5.

Обратная степень применяется к обеим частям равенства. Это отдельная операция над равенством, поэтому менять показатель только слева нельзя.

03 / ПЯТЬ МОДЕЛЕЙ

Все ключевые задачи занятия

Переключайте вкладки: в каждой сохранены формула, данные и ключевой вычислительный ход с доски.

Степенная зависимость pV5/3 = 200

p ≥ 6,25 · 105,   V > 0
  1. Для максимального V проверяем: при росте p объём уменьшается, значит берём минимально допустимое давление.
  2. p = 6,25 · 105 = 625 · 103.
  3. V5/3 = 200 / (625 · 103) = 1 / 55.
  4. V = (1 / 55)3/5 = 1 / 53.
Ответ занятия: V = 0,008.

Показательный закон убывания

m(t) = m₀ · 2−t/T
  1. m₀ = 40, T = 10, m = 5.
  2. 40 · 2−t/10 = 5.
  3. 2−t/10 = 1/8 = 2−3.
  4. Основания одинаковы, поэтому −t/10 = −3.
Ответ занятия: t = 30.

Два состояния одной системы

p₁V₁a = p₂V₂a
  1. Объём уменьшился вдвое: V₂ = V₁/2, то есть V₁ = 2V₂.
  2. Давление увеличилось в четыре раза: p₂ = 4p₁.
  3. p₁(2V₂)a = (4p₁)V₂a.
  4. После сокращения: 2a = 4 = 22.
Ответ занятия: a = 2.

Четвёртая степень в формуле излучения

P = σST4
  1. σ = 5,7 · 10−8 = 57 · 10−9.
  2. S = 1020/128,   P = 1,14 · 1025 = 114 · 1023.
  3. После подстановки и сокращений: T4 = 28 · 1012.
  4. T = (28 · 1012)1/4 = 22 · 103.
Ответ занятия: T = 4000.

Кубическая зависимость в задаче о натяжении

T = ρgl3 − mg
  1. ρ = 1000, g = 10, m = 25, ограничение T ≤ 1000.
  2. Для максимальной длины используем граничное значение T = 1000.
  3. l3 = 1250/10000 = 125/1000.
  4. 125 = 53, 1000 = 103, поэтому l = 5/10.
Ответ занятия: l = 0,5 м.
04 / КОНТРОЛЬ

Ошибки, которые ломают решение

Именно здесь чаще всего теряется правильная структура вычислений.

Потеря скобок

Если V₁ = 2V₂, то V₁a = (2V₂)a.

Степень только одному множителю

(ab)n = anbn; показатель относится ко всему произведению.

Изменить показатель только слева

Если обе части возводятся в обратную степень, операция выполняется симметрично.

Рано перейти к десятичным дробям

Сначала ищите сокращения и удобные основания степеней.

Механически заменить «не менее» на «равно»

Сначала устанавливается направление зависимости и нужная граница.

Забыть итоговую единицу

Промежуточные вычисления можно вести компактно, а ответ оформляется в требуемых единицах.
