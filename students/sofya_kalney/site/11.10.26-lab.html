График с выколотыми точками

Перемещайте прямую y = kx, исследуйте точки пересечения с функцией g(x) = −1/|x| и объясните, почему некоторые значения коэффициента дают ноль общих точек.

Ваш браузер не поддерживает Canvas. Пользуйтесь расчётами справа.
График функцииПрямая y = kxВыколотые точки

Прямую можно поворачивать, перетаскивая её мышью или пальцем. Для точной настройки используйте ползунок и готовые случаи.

Изменяем один параметр

Коэффициент наклона

от −4 до 4−2,25

У прямой всегда одна закреплённая точка: начало координат.

Результат0 общих точек

При этом значении прямая проходит через выколотую точку.

Координаты пересечения

Пересечение исключено исходной ОДЗ.

Ограничения исходной функции

x ≠ 0; x ≠ −2/3; x ≠ 2/3

При x = ±2/3 выколота точка с ординатой −3/2. При x = 0 проходит вертикальная асимптота.

01 · Подставьте

Равенство функций

Условие пересечения: −1/|x| = kx. Решайте отдельно при x > 0 и x < 0.

02 · Учитывайте знак

Нужная полуось

Для k < 0 пересечение возможно только справа, а для k > 0 — только слева.

03 · Проверьте ОДЗ

Точка могла исчезнуть

Если вычисленное x = ±2/3, пересечение удалено. Сравните при k = ±9/4.

Микроэксперимент

Сначала прогноз — потом проверка

До изменения графика предположите, сколько общих точек будет при k = 9/4.

Ваш прогноз

Вывод занятия: прямая y = kx не пересекает исходный график при k ∈ {−9/4; 0; 9/4}. Два ненулевых случая возникают именно из-за выколотых точек.
