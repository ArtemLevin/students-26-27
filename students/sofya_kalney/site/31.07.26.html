Что такое парабола

Квадратичная функция задаётся формулой:

y=ax2+bx+c,a≠0
a
задаёт направление и «ширину» ветвей
b
участвует в вычислении вершины
c
ордината точки пересечения с Oy
Графический смысл. При a > 0 ветви направлены вверх; при a < 0 — вниз. Через вершину проходит ось симметрии.

Ключевые точки

Вершина
xV=−b2a,yV=f(xV)

Ось симметрии: x = xV.

Пересечения

С осью Ox: подставьте y = 0 и решите квадратное уравнение.

С осью Oy: подставьте x = 0; получим точку Q(0; c).

Для дополнительных точек выбирайте значения x симметрично относительно абсциссы вершины.

Алгебраическая дробь и выкол

  1. Сначала выпишите ограничения исходного знаменателя.
  2. Разложите выражения на множители и сократите общий множитель.
  3. Сохраните найденные ограничения.
  4. Подставьте исключённое значение в упрощённую функцию.
  5. Отметьте полученную точку пустым кружком.
Важно. Сокращение меняет запись формулы. Область допустимых значений остаётся той, которая получена из исходного выражения.

Задачи из пособия

Типичные ошибки

Потеря минуса

Ошибочное действие: записать xV = b/(2a).

Правило: перед дробью стоит минус. Проверьте коэффициент b отдельно.

Оси перепутаны

Для Ox используется y = 0. Для Oy используется x = 0.

Самопроверка: координата точки на выбранной оси должна равняться нулю.

Ограничение потеряно

После сокращения запрещённое значение x сохраняется.

Самопроверка: вернитесь к исходному знаменателю.

Минус и квадрат

Записи −x² и (−x)² дают разные результаты.

При подстановке отрицательного числа используйте скобки.

Выкол отмечен приблизительно

Ординату выкола вычисляйте подстановкой в упрощённую функцию.

Пустой кружок должен лежать на построенной параболе.
