Почему ответ состоит из трёх значений?

−x² − 1 = kx ⇔ x² + kx + 1 = 0, при x ≠ 2.

01 · Касание слева и справа

При D = k² − 4 = 0 квадратное уравнение имеет один корень. Поэтому k = −2 или k = 2. Оба корня x = 1 и x = −1 допустимы.

02 · Одна точка исключена

При x = 2 парабола имела бы значение −5, но исходная дробь не определена. Прямая через эту позицию удовлетворяет −5 = 2k, значит k = −5/2.

Уравнение получает корни x = 2 и x = 1/2. Первый выколот; единственное пересечение находится при x = 1/2.

Дискриминант равен нулю только в случаях касания. Исключённая точка создаёт дополнительный случай с ровно одним пересечением.

Ответ: k ∈ {−5/2; −2; 2}.
