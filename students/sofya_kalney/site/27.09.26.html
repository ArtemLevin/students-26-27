01 · АЛГЕБРА

Сложное неравенство: искать форму раньше вычислений

Разность квадратов убирает громоздкие четвёртые степени, а оценка знака множителя сокращает метод интервалов.

(9x − 4)² − (4x − 9)² ≥ 0
→ 65(x + 1)(x − 1) ≥ 0

Результат

x ∈ (−∞; −1] ∪ [1; +∞).

Большая степень без x⁴

(2x² − 1)² ≤ (x² − 2)²

После разности квадратов:

3(x² + 1)(x² − 1) ≤ 0

Так как x² + 1 > 0, остаётся x² − 1 ≤ 0, поэтому x ∈ [−1; 1].

Сначала определите знак

x⁴ + x¹⁰⁰ + 47 всегда строго положительно.

Такой множитель можно исключить делением без смены знака неравенства.

На выражение неизвестного знака делить нельзя.

Сумма неотрицательных выражений

|A| + |B| = 0 → A = 0 и B = 0

Та же идея работает для квадратов, чётных степеней и арифметических корней чётной степени.

02 · ТЕКСТОВАЯ ЗАДАЧА

Средняя скорость — через весь путь и всё время

Для равных половин пути среднее арифметическое скоростей использовать нельзя.

vср = Sобщ / tобщ
равные части пути:
vср = 2v₁v₂ / (v₁ + v₂)

66 км/ч и 78 км/ч

Каждая половина пути равна S, значит весь путь равен 2S.
Полное время: S/66 + S/78.
vср = 2S / (S/66 + S/78) = 71,5 км/ч.

Сокращение не возвращает запрещённую точку

ОДЗ фиксируется до сокращения. График строится по упрощённой формуле, затем исходное ограничение возвращается как выколотая точка.

Исходная функция

(x−3)(x²+6x+8)/(x+2)

ОДЗ: x ≠ −2.

После сокращения: y = x² + x − 12.
