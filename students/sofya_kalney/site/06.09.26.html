Полиномиальные и рациональные неравенства

Критическая точка сама по себе ещё не говорит, меняется ли знак

Нечётная кратность
При переходе через корень знак меняется.
Чётная кратность
При переходе через корень знак сохраняется.
(x+3)(x−2)(x−5)2≤0

Критические точки: −3, 2, 5. Точка 5 имеет кратность 2, поэтому знак около неё не переворачивается.

Ответ: x ∈ [−3; 2] ∪ {5}

Рациональное неравенство: точки знаменателя всегда выколоты

((x−4)(x+1))/((x+10)(x−3)) ≥ 0

Критические точки: −10, −1, 3, 4. При этом x ≠ −10 и x ≠ 3.

Ответ: (−∞; −10) ∪ [−1; 3) ∪ [4; +∞)
Нельзя
Включать ноль знаменателя из-за знака ≥ или ≤.
Нельзя
После сокращения общего множителя забывать ограничение исходного знаменателя.
Нельзя
Менять знак автоматически в каждой критической точке, игнорируя кратность.
Нельзя
Терять отдельный корень чётной кратности при нестрогом неравенстве.

Алгоритм

Разложите числитель и знаменатель на множители.
Выпишите все критические точки.
Отдельно пометьте нули знаменателя.
Определите кратности.
Чётная кратность сохраняет знак, нечётная меняет.
Откалибруйте знак одной удобной точкой.
Выберите нужные интервалы и корректно включите границы.

Одинаковый радикал в обеих частях

Корень может исчезнуть из записи, его ОДЗ — нет

2x² + √(2−x) = 3x + 14 + √(2−x)
ОДЗ
2−x ≥ 0 → x ≤ 2.
Упрощение
После вычитания одинакового радикала: 2x²−3x−14=0.
D = 121.
x₁ = 7/2, x₂ = −2.
Проверка ОДЗ: 7/2 > 2 — не подходит; −2 ≤ 2 — подходит.
Ответ: x = −2.

Текстовая задача на движение

Таблица сразу переводит сюжет в уравнение

Автомобиль проехал 180 км из A в B со скоростью x, обратно — со скоростью x+5 и затратил на 24 минуты меньше.

НаправлениеСкоростьВремяРасстояние
A → Bx180/x180 км
B → Ax+5180/(x+5)180 км

Ограничение: x > 0.   24 мин = 2/5 ч.

180/x − 180/(x+5) = 2/5
Общий знаменатель: 900/[x(x+5)] = 2/5.
Квадратное уравнение: x²+5x−2250=0.
D=9025=95². Корни: 45 и −50.
Физический фильтр: отрицательная скорость не подходит. Ответ: 45 км/ч.

Как извлекать большие полные квадраты без калькулятора

Удобные множители
√14400 = √(144·100) = 120
Факторизация
17424 = 2⁴·3²·11² → √17424 = 132
Близкий квадрат
998001 = (1000−1)² = 999²

Последняя цифра — только фильтр кандидатов. Если полный квадрат оканчивается на 1, корень может оканчиваться на 1 или 9. Кандидата всё равно нужно проверить возведением в квадрат.

x < −2

Вершина (−5/2; −1/4). Из корней −2 и −3 этой ветви принадлежит только −3.
