Раздел 01 / Алгебра

Квадрат разности → произведение → знаки

Когда в квадратном трёхчлене обнаруживается полный квадрат, задача на неравенство быстро сводится к методу интервалов.

x² − 18x + 81 = (x − 9)²Формула квадрата разности: a² − 2ab + b² = (a − b)².
  1. Перенесите все члены влево.
  2. Разложите выражение на множители.
  3. Найдите нули множителей и расположите их по порядку.
  4. Определите знак на каждом промежутке.
  5. Запишите только подходящие промежутки; учтите строгость знака.

Пример с занятия

81 − 18x + x² < √2(x − 9)
(x − 9)(x − 9 − √2) < 0

Ответ: x ∈ (9; 9 + √2).

Проверить второй пример

(x − 2)² + √3(x − 2) ≥ 0 ⇔ (x − 2)(x − 2 + √3) ≥ 0.

Ответ: x ∈ (−∞; 2 − √3] ∪ [2; +∞). При нестрогом знаке нули включаются.

Раздел 02 / Точные сравнения

Сначала знак, затем квадрат

Возводить части неравенства в квадрат без проверки их знаков опасно. Сначала установите, что сравниваемые величины неотрицательны; только после этого применяйте возведение в квадрат.

√2 − 1 > √3 − 2Перенесём слагаемые: √2 + 1 > √3. Обе части положительны.

(√2 + 1)² = 3 + 2√2 > 3. Значит, исходное сравнение верно.

Осторожно с минусом

Если умножаете неравенство на −1, обязательно меняйте направление знака. Например, из 3 < 2√7 следует −3 > −2√7.

Второй пример

Сравните √5 и √7 − 1. Равносильно сравнению √5 + 1 и √7: обе стороны положительны.

(√5 + 1)² = 6 + 2√5 > 7

Следовательно, √5 > √7 − 1.

Математический контроль: если числовые оценки трудно сделать устно, оформите сравнение квадратов отдельной строкой.
Раздел 03 / Текстовая задача

Время равно работе, делённой на скорость

В задачах о трубах удобно составить таблицу «производительность — объём — время». Переводите текстовые отношения в уравнение только после уточнения, кто работает быстрее.

t = A / pA — объём работы; p — производительность; t — время.
ТрубаЛитров/минОбъёмВремя
Перваяx − 3260 л260/(x − 3)
Втораяx260 л260/x

Первая медленнее на 3 л/мин

Вторая заполняет 260 литров на 6 минут быстрее. Поэтому при x > 3:

260/(x − 3) − 260/x = 6
x(x − 3) = 130
(x − 13)(x + 10) = 0

Ответ: 13 л/мин — производительность второй трубы.

Когда время одинаковое

Первая труба пропускает 770 л, вторая — 830 л; разница производительностей 6 л/мин.

770/x = 830/(x + 6) ⇒ x = 77

Первая: 77 л/мин; вторая: 83 л/мин. В обоих случаях время равно 10 минут.

Раздел 04 / Функции

Парабола с отсутствующей точкой

y = (x² + 1)(x − 2)/(2 − x)В исходной дроби знаменатель обращается в нуль при x = 2.

Поскольку 2 − x = −(x − 2), получаем y = −x² − 1 при x ≠ 2. Вершина: (0; −1). Точка (2; −5) исключена из графика.

  • Сначала записывайте область определения.
  • При сокращении сохраняйте исключённые значения аргумента.
  • Точки для построения удобно брать симметрично относительно вершины.
Открыть интерактивный график

Когда прямая y = kx имеет одну общую точку?

−x² − 1 = kx
x² + kx + 1 = 0, x ≠ 2

Первый случай: касание. Дискриминант D = k² − 4 равен нулю, поэтому k = −2 или k = 2.

Второй случай: прямая проходит через исключённую точку (2; −5). Из −5 = 2k получаем k = −5/2. Один корень x = 2 исключён, другой x = 1/2 остаётся.

k ∈ {−5/2; −2; 2}
Проверьте три особых случая в лаборатории — при k = −5/2 увидеть роль выколотой точки особенно важно.

Раздел 05 / Геометрия

Параллельность, подобие и биссектрисы

Подобные треугольники

В треугольнике ABC отрезок MN параллелен AC, точки M и N лежат на AB и BC. Дано MN = 16, AC = 20, NC = 15. Найдите BN.

BN/BC = MN/AC
x/(x + 15) = 16/20 = 4/5
5x = 4(x + 15) ⇒ x = 60

Ответ: BN = 60.

Равнобедренная трапеция

В трапеции ABCD с большим основанием AD биссектрисы углов A и C пересекаются в F; биссектриса угла A пересекает CD в K. При AB ∥ CF и FK = 4√3 найдите CF.

  1. Обозначьте угол DAB через α. Из равнобедренности угол BCD равен 180° − α.
  2. Из CF — биссектрисы и AB ∥ CF следует α = (180° − α)/2; значит α = 60°.
  3. Угол при K в △CFK прямой, а угол при F равен 30°.
  4. FK = CF · cos 30° = CF · √3/2.

Ответ: CF = 8.
