Шаг 1

Модуль превращает формулу в кусочную

Сначала выясняем знак подмодульного выражения, затем строим только допустимую часть каждой ветви.

Определение модуля

|A(x)|=A(x), если A(x)≥0−A(x), если A(x)<0

Ключевой вопрос перед раскрытием модуля: где подмодульное выражение положительно, отрицательно или равно нулю?

Базовый алгоритм

1. Нули→2. Интервалы→3. Знаки→4. Раскрыть модуль→5. Кусочная формула→6. Ветви
  1. Найдите нули каждого подмодульного выражения.
  2. Разбейте числовую прямую найденными точками.
  3. Определите знак на каждом промежутке.
  4. Раскройте модуль с нужным знаком.
  5. Получите кусочную формулу.
  6. Стройте каждую ветвь только на её промежутке.
Граница. Одну и ту же граничную точку достаточно включить только в одну соседнюю ветвь: например, одна формула действует при x ≤ a, вторая — при x > a.

Разбор: y=2−|x|

Что дано

Подмодульное выражение — x. Его нуль: x = 0.

Смысл условия

Слева от нуля x отрицателен, справа — неотрицателен.

Шаг 1. Найти границу: x = 0.
Шаг 2. При x < 0: |x| = −x, поэтому y = 2 + x.
Шаг 3. При x ≥ 0: |x| = x, поэтому y = 2 − x.
Шаг 4. Обе прямые встречаются в точке (0; 2).
Проверка. Вершина достигается, а дальше обе ветви уходят вниз.
y=2+x, x < 02−x, x ≥ 0

Шаг 2

Множество значений читаем горизонтально

Значение y входит в множество значений, если горизонтальная прямая этого уровня пересекает график хотя бы один раз.

Горизонтальный тест

Есть пересечение

Выбранное значение y достигается.

Нет пересечения

Такого значения функции нет.

Для y=2−|x| вершина имеет ординату 2, поэтому:

E(y)=(−∞;2]

Число 2 включается, потому что вершина графика существует.

Две стандартные формы

ФункцияВершинаМножество значений
y=a−|x−b|(b; a)(−∞; a]
y=a+|x−b|(b; a)[a; +∞)
Самопроверка. Смотрите не на допустимые x, а на реально достигаемые высоты графика.

Шаг 3

Несколько модулей: собираем все границы

Каждый модуль добавляет свои потенциальные точки смены формулы.

Пример: f(x)=|x−1|+|x+2|

Нули

x = −2 и x = 1.

Промежутки

(−∞; −2), [−2; 1), [1; +∞).

Шаг 1. Собрать нули обоих выражений: −2 и 1.
Шаг 2. Слева от −2 оба выражения отрицательны: f(x) = −2x − 1.
Шаг 3. Между −2 и 1 знаки разные: f(x) = 3.
Шаг 4. Справа от 1 оба выражения неотрицательны: f(x) = 2x + 1.
Вывод. На [−2; 1] график горизонтален, поэтому y = 3 имеет бесконечно много общих точек с графиком.
f(x)=−2x−1, x < −23, −2 ≤ x < 12x+1, x ≥ 1
Бесконечно много пересечений

m = 3.

Множество значений

[3; +∞).

Точки смены формулы: g(x)=|x2−4|

Нули подмодульного выражения: x = −2 и x = 2. Между ними выражение отрицательно, снаружи — положительно.

g(x)=x2−4, x ≤ −24−x2, −2 < x < 2x2−4, x ≥ 2
Не путайте. x = −2 и x = 2 — абсциссы точек смены формулы; точки графика — (−2; 0) и (2; 0).

Квадратный трёхчлен без действительных корней

Для P(x)=x2−3x+6 дискриминант равен −15. Старший коэффициент положителен, поэтому выражение положительно при всех действительных x.

|x2−3x+6|=x2−3x+6
Ловушка. Отсутствие действительных корней не означает отсутствие решений неравенства; знак определяет старший коэффициент.

Шаг 4

Алгебраическая дробь: сначала ОДЗ

Сокращение меняет формулу, но не возвращает точки, запрещённые исходным знаменателем.

Исходная функция

q(x)=2−|x−1|(x−1)2−2|x−1|
Шаг 1. ОДЗ. Знаменатель равен |x−1|(|x−1|−2), поэтому x ≠ −1, 1, 3.
Шаг 2. Сокращение. Числитель равен −(|x−1|−2), поэтому при допустимых x получаем q(x) = −1/|x−1|.
Шаг 3. Сохранить запреты. После сокращения по-прежнему x ≠ −1, 1, 3.
Шаг 4. Кусочная запись. При x < 1: q(x) = 1/(x−1); при x > 1: q(x) = −1/(x−1).
Шаг 5. Геометрия графика. x = 1 — вертикальная асимптота, y = 0 — горизонтальная; в x = −1 и x = 3 остаются выколотые точки.
Шаг 6. Множество значений. Значение −1/2 достигалось бы только в запрещённых x = −1 или x = 3, поэтому оно исключается.
q(x)=−1|x−1|,x≠−1,1,3

Асимптоты и выколотые точки

Вертикальная асимптота

x = 1.

Горизонтальная асимптота

y = 0.

Выколы

(−1; −1/2) и (3; −1/2).

В x = 1 значение функции неограниченно убывает при приближении к асимптоте. В x = −1 и x = 3 сокращённая формула дала бы конечное значение, но исходная функция там не определена.

E(q)=(−∞;−12)∪(−12;0)

Рабочий алгоритм построения гиперболы

  1. Записать ОДЗ исходной функции.
  2. Выполнить допустимые преобразования.
  3. После сокращения сохранить исходные ограничения.
  4. Раскрыть модули и получить кусочную формулу.
  5. Найти вертикальные и горизонтальные асимптоты.
  6. Найти пересечения с осями, если они существуют и допустимы.
  7. При необходимости составить небольшую таблицу значений.
  8. Строить каждую ветвь только на разрешённом промежутке.
  9. Отметить выколотые точки.

Типичные ошибки

Раскрыть модуль без знака

Сначала определите знак A(x), только потом выбирайте A(x) или −A(x).

Потерять внешний минус

Следите за двойным отрицанием при −|A(x)|.

Строить ветвь вне интервала

Формула действует только на своём промежутке.

Вернуть запрещённую точку

Сокращение не расширяет ОДЗ.

Перепутать D и E

Область определения — допустимые x; множество значений — достигаемые y.

1 · средний уровень

Кусочная запись и множество значений

Запишите функцию y = 3 − |x| в кусочном виде и найдите её множество значений.

Решение и проверка

Граница — x = 0. При x < 0 имеем |x| = −x, поэтому y = 3 + x. При x ≥ 0 имеем |x| = x, поэтому y = 3 − x.

Наибольшее значение достигается в вершине (0; 3), обе ветви идут вниз.

Ответ: y = 3 + x при x < 0; y = 3 − x при x ≥ 0; E(y) = (−∞; 3].
2 · средний уровень

Сдвинутый модуль

Запишите f(x) = |x − 2| в кусочном виде. Укажите точку смены формулы и множество значений.

Решение и проверка

Нуль x − 2 равен 2. При x < 2 выражение отрицательно, поэтому f(x) = 2 − x; при x ≥ 2 — f(x) = x − 2.

Минимум равен 0 и достигается при x = 2.

Ответ: точка смены x = 2; E(f) = [0; +∞).
3 · средний уровень

Два модуля

Для g(x) = |x − 1| + |x + 2| запишите кусочную формулу и укажите промежуток, на котором функция постоянна.

Решение и проверка

Границы: −2 и 1. Слева получаем −2x − 1, между границами — 3, справа — 2x + 1.

Ответ: функция постоянна на [−2; 1], её значение там равно 3.
4 · выше среднего

Линейное выражение под модулем

Запишите h(x) = |2x + 4| − 1 в кусочном виде. Укажите точку смены формулы и множество значений.

Решение и проверка

2x + 4 = 0 при x = −2. Слева модуль меняет знак: h(x) = −(2x + 4) − 1 = −2x − 5. Справа h(x) = 2x + 3.

В вершине x = −2 функция равна −1 — это минимум.

Ответ: x = −2; E(h) = [−1; +∞).
5 · выше среднего

Квадратное выражение под модулем

Для p(x) = |x² − 4| запишите кусочную формулу и укажите все точки смены формулы.

Решение и проверка

x² − 4 = 0 при x = −2 и x = 2. Снаружи интервала [−2; 2] выражение неотрицательно, внутри — отрицательно.

Ответ: x² − 4 при x ≤ −2 и x ≥ 2; 4 − x² при −2 < x < 2. Точки смены: x = −2 и x = 2.
6 · выше среднего

Бесконечно много общих точек

F(x) = |x − 4| + |x + 1|. Найдите m, при котором графики y = F(x) и y = m имеют бесконечно много общих точек.

Решение и проверка

Границы: x = −1 и x = 4. На промежутке [−1; 4] имеем F(x) = (4 − x) + (x + 1) = 5. Значит, график содержит горизонтальный отрезок y = 5.

Ответ: m = 5; горизонтальный участок — [−1; 4].
7 · выше среднего

Дробь с модулем

Упростите r(x) = (4 − |x|)/(x² − 4|x|) с обязательным сохранением ОДЗ. Укажите асимптоты и выколотые точки.

Решение и проверка

x² = |x|², поэтому знаменатель равен |x|(|x| − 4). Исходные запреты: |x| ≠ 0 и |x| ≠ 4, то есть x ≠ −4, 0, 4.

Числитель равен −(|x| − 4), поэтому после сокращения r(x) = −1/|x|, но исходные запреты сохраняются.

Ответ: асимптоты x = 0 и y = 0; выколы (−4; −1/4) и (4; −1/4).
8 · выше среднего

Уравнение с двумя модулями

Решите |x − 3| + |x + 1| = 6.

Решение и проверка

Границы: −1 и 3. При x < −1 получаем 2 − 2x = 6, откуда x = −2 — подходит интервалу. На [−1; 3] левая часть равна 4, решений нет. При x > 3 получаем 2x − 2 = 6, откуда x = 4 — подходит интервалу.

Ответ: x = −2 и x = 4.
9 · выше среднего

Модуль квадратичной функции

Запишите G(x) = |x² − 1| в кусочном виде. Укажите точки смены формулы и найдите G(0).

Решение и проверка

Нули x² − 1: −1 и 1. Внутри (−1; 1) выражение отрицательно, снаружи — неотрицательно. При x = 0 получаем G(0) = |−1| = 1.

Ответ: x² − 1 при x ≤ −1 и x ≥ 1; 1 − x² при −1 < x < 1; точки смены −1 и 1; G(0) = 1.
10 · сложный уровень

Полное исследование q(x)

Для q(x) = (2 − |x − 1|)/((x − 1)² − 2|x − 1|) найдите ОДЗ, упрощённую и кусочную формулы, асимптоты, выколотые точки и множество значений.

Решение и проверка

ОДЗ: x ≠ −1, 1, 3. После сокращения q(x) = −1/|x − 1| с сохранением этих запретов. При x < 1 функция равна 1/(x − 1), при x > 1 — −1/(x − 1).

Асимптоты: x = 1 и y = 0. Выколы: (−1; −1/2) и (3; −1/2). Значение −1/2 достигается только в запрещённых точках, поэтому исключается.

Ответ: E(q) = (−∞; −1/2) ∪ (−1/2; 0).
