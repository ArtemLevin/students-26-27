Рациональные графики

Сокращение не отменяет исходное ОДЗ: выколотые точки сохраняются.

Системы

Подстановка, замена t = y² и формулы (x+y)², (x−y)².

Модуль

Каждая формула работает только на своей области по x.

Рациональные неравенства

Метод интервалов: сначала критические точки

−14 / (x² + 5x − 14) ≤ 0

Знаменатель раскладывается: x² + 5x − 14 = (x−2)(x+7). Поэтому x ≠ 2 и x ≠ −7. Числитель −14 всегда отрицателен, поэтому нужны интервалы, где знаменатель положителен.

Ответ: (−∞; −7) ∪ (2; +∞)
Типичная ошибка: включить −7 или 2 из-за знака ≤. Нули знаменателя исключаются всегда.

Текстовая задача

Работа: таблица до уравнения

A = p·t, где A — работа, p — производительность, t — время.
Что дано

Два исполнителя выполняют одинаковый объём работы; различаются производительностью и временем.

Смысл условия

Уравнение появляется только после заполнения таблицы по смыслу.

  1. Введите удобную переменную.
  2. Подпишите единицы измерения.
  3. Заполните одну строку целиком, затем вторую.
  4. Свяжите величины формулой A = p·t.
  5. Составьте уравнение по условию о времени или производительности.
Если все числители имеют общий множитель, разрешено упростить уравнение до громоздких преобразований.

Системы уравнений

Одна система — два школьных метода

x² + y² = 40,
xy = −12.

Способ 1. Подстановка и замена

Из xy = −12 получаем x = −12/y. После подстановки:

144/y² + y² = 40.

Повторяется y², поэтому вводим t = y². Здесь t > 0. Получаем:

t² − 40t + 144 = 0,   D = 1024 = 32²,   t = 36 или 4.

Отсюда y = ±6 или ±2, затем x находится из xy = −12.

Решения: (−2;6), (2;−6), (−6;2), (6;−2).

Способ 2. Квадрат суммы

Умножаем xy = −12 на 2 и складываем с x²+y²=40:

x² + 2xy + y² = 16 → (x+y)² = 16 → x+y = ±4.

Далее каждый случай сводится к обычному квадратному уравнению.

Контроль: при замене t = y² всегда фиксируйте t ≥ 0; если y ≠ 0, то t > 0.

Рациональная функция

Сокращение меняет формулу, но не исходное ОДЗ

y = ((x+1)(x²−4)) / (x²−x−2)

Факторизация даёт (x+1)(x−2)(x+2) / ((x−2)(x+1)). После сокращения остаётся y = x+2, при этом исходные ограничения сохраняются:

x ≠ 2,   x ≠ −1.

Следовательно, на прямой y=x+2 выколоты точки (2;4) и (−1;1).

Параметр y = kx

Общих точек с исходным графиком нет в трёх случаях: прямая параллельна y=x+2 либо единственная точка пересечения приходится на одну из выколотых точек.

k = 1, 2, −1.

Модуль

Кусочная запись сохраняет область каждой ветви

y = x² + 4|x| − 5 = { x²+4x−5, x≥0;   x²−4x−5, x<0 }.
Правая ветвь

x²+4x−5. Полная парабола имеет корни −5 и 1, но при x≥0 остаётся только x=1.

Левая ветвь

x²−4x−5. Корни −1 и 5, но при x<0 остаётся только x=−1.

Горизонтальная прямая может иметь максимум 2 общие точки с итоговым графиком.

Проверить горизонтали →
Типичная ошибка: построить обе параболы целиком и забыть отбросить части, не удовлетворяющие условию по x.

Прямоугольный треугольник

Высота к гипотенузе через равенство площадей

Что дано

Гипотенуза 74, один катет 24.

Идея

Сначала Пифагор, затем одна площадь двумя способами.

Второй катет:

√(74²−24²) = √((74−24)(74+24)) = √(50·98) = √(100·49) = 70.

Для высоты h к гипотенузе:

½·24·70 = ½·74·h → h = 840/37.
Формула высоты здесь не заучивается отдельно: она выводится из равенства площадей.

Трапеция · доказательство

Равнобедренный треугольник подсказывает доппостроение

В трапеции ABCD дано AD ∥ BC, E — середина AB и EC = ED. Через E проводим EF ∥ AD, F∈CD.

  1. Так как прямая через середину одной боковой стороны параллельна основаниям, F — середина CD.
  2. Треугольник ECD равнобедренный, а EF — медиана к его основанию CD.
  3. В равнобедренном треугольнике такая медиана является высотой: EF ⟂ CD.
  4. EF ∥ AD, следовательно AD ⟂ CD и ∠ADC = 90°.
Главная идея: заметили специальный треугольник → вспомнили всю связанную с ним теорию → выбрали построение, которое эту теорию активирует.

Трапеция · подобие

Диагональ быстро создаёт нужные треугольники

Дано AD=45, BC=15, CN=12, ND=18 и KN ∥ основаниям. Проводим диагональ AC, Q=AC∩KN.

CN/CD = 12/30 = 2/5 → QN/AD = 2/5 → QN = 18.

Далее параллельные основания дают пропорциональное деление боковых сторон:

AK/AB = DN/DC = 18/30 = 3/5.

Из подобия ΔAKQ и ΔABC:

KQ/BC = 3/5 → KQ = 9 → KN = KQ + QN = 27.
Ориентир для трапеции: сначала подумайте о диагонали или высоте. Цель — как можно скорее получить треугольники.
