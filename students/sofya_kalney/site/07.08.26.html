1. Главная идея модуля Смотрите внутрь модуля.
Знак всего подмодульного выражения определяет, появится перед ним плюс или минус.

Модуль числа показывает расстояние от нуля. Для функции важен знак всего выражения внутри вертикальных черт.

|u(x)|={u(x), если u(x)≥0−u(x), если u(x)<0
Подмодульное ≥ 0
Модуль раскрывается со знаком «плюс».
Подмодульное < 0
Перед всем выражением появляется знак «минус».

Минус перед модулем

В выражении x² − |3x + 5| внешний минус относится ко всему модулю. Поэтому скобки обязательны.

x2−|3x+5|={x2−3x−5, x≥−53x2+3x+5, x<−53
Самопроверка: сначала решите неравенство для подмодульного выражения, затем раскрывайте модуль.

4. Сначала ОДЗ Сокращение не возвращает удалённые точки.
Все ограничения исходного знаменателя сохраняются до конца решения.

Что дано
f(x)=4−|x|x2−4|x|
Смысл условия

Нужно упростить формулу, сохранив все значения x, при которых исходная дробь не определена.

Полезное тождество

x2=|x|2
|x|² − 4|x|→|x|(|x| − 4)→−1/|x|

Пошаговый разбор

Исходный знаменатель не равен нулю.
|x|(|x| − 4) ≠ 0.
Получаем ограничения.
x ≠ 0, x ≠ −4, x ≠ 4.
Числитель переписываем как −(|x| − 4).
Сокращаем общий множитель.
Формула становится −1/|x|.
Сохраняем исходные ограничения.
На графике остаются выколотые точки (−4; −1/4) и (4; −1/4), а x = 0 задаёт вертикальную асимптоту.
Итог: f(x) = −1/|x| при x ≠ 0, ±4.

5. Как работает параметр k

Прямая y = kx всегда проходит через начало координат.

k > 0
прямая возрастает;
k < 0
прямая убывает;
k = 0
получаем ось Ox;
Точка (x₀; y₀)
k = y₀/x₀, если x₀ ≠ 0.

Когда общих точек нет

Что требуется

Найти значения k, при которых прямая y = kx не пересекает построенный график.

Идея решения
  1. использовать две выколотые точки;
  2. провести через каждую прямую из начала координат;
  3. вычислить соответствующие k;
  4. отдельно проверить k = 0;
  5. убедиться, что других пересечений нет.
k∈{−116,0,116}
Почему нужна проверка: прохождение через выколотую точку даёт кандидата. В ответ он входит после проверки отсутствия других пересечений.

6. Тренировка

Здесь сохранены все 10 упражнений из пособия. Решения раскрываются по кнопке.

1. Кусочная запись y = |x − 2|

Запишите функцию в кусочном виде и укажите координаты вершины.

Шаг 1. Граница: x − 2 = 0, значит x = 2.

Шаг 2. При x ≥ 2 получаем y = x − 2; при x < 2 получаем y = 2 − x.

Ответ: вершина (2; 0).

2. Сдвиг y = |x + 3|

Укажите вершину, направление сдвига и значение функции при x = 0.

Подмодульное выражение обращается в ноль при x = −3. Вершина (−3; 0), сдвиг влево на 3, y(0) = 3.

3. Функция y = 2 − |x|

Запишите кусочную формулу, вершину и множество значений.

При x < 0: y = x + 2. При x ≥ 0: y = 2 − x. Вершина (0; 2), поэтому y ≤ 2.

4. y = x² − |3x + 6|

Раскройте модуль и запишите кусочную формулу.

Граница: 3x + 6 = 0, x = −2.

При x < −2: y = x² + 3x + 6. При x ≥ −2: y = x² − 3x − 6.

5. y = |x² − 4|

Запишите кусочную формулу и точки смены формулы.

x² − 4 = 0 при x = −2 и x = 2.

При x ≤ −2 или x ≥ 2: y = x² − 4. При −2 < x < 2: y = 4 − x².

6. Дробь с |x| и числом 3

Для f(x) = (3 − |x|)/(x² − 3|x|) найдите область определения, упростите формулу и определите выколотые точки.

x² − 3|x| = |x|(|x| − 3), поэтому x ≠ −3, 0, 3.

После сокращения f(x) = −1/|x|. Выколотые точки: (−3; −1/3) и (3; −1/3).

7. Параметр для предыдущей функции

Найдите все k, при которых y = kx не имеет общих точек с графиком функции из задания 6.

Через выколотые точки получаем k = 1/9 и k = −1/9. При k = 0 ось Ox также не пересекает отрицательный график.

Ответ: k ∈ {−1/9, 0, 1/9}.

8. Дробь g(x)

Для g(x) = (|x| − 2)/(x² − 2|x|) найдите область определения, упростите формулу и определите все k без пересечений.

x ≠ −2, 0, 2. После сокращения g(x) = 1/|x|. Выколотые точки: (−2; 1/2), (2; 1/2).

Ответ: k ∈ {−1/4, 0, 1/4}.

9. y = −|x + 1| + 2

Запишите кусочную формулу, найдите вершину и пересечения с Ox.

При x < −1: y = x + 3. При x ≥ −1: y = 1 − x.

Вершина (−1; 2). Пересечения с Ox: (−3; 0) и (1; 0).

10. Сложная функция q(x)

q(x) = (2 − |x − 1|)/((x − 1)² − 2|x − 1|). Найдите область определения, упростите функцию, определите выколотые точки и значения k без общих точек.

Положим t = |x − 1|. Знаменатель равен t(t − 2), поэтому x ≠ −1, 1, 3.

После сокращения q(x) = −1/|x − 1|. Выколотые точки: (−1; −1/2) и (3; −1/2).

Через них получаем k = 1/2 и k = −1/6. Дополнительно k = 0.

Ответ: k ∈ {−1/6, 0, 1/2}.

7. Типичные ошибки

Смотрят только на x.
Знак определяет всё подмодульное выражение, например x − 2 или 3x + 5.
Теряют скобки.
При внешнем минусе всё выражение под модулем раскрывается в скобках.
Забывают исходное ОДЗ.
Сокращённые множители продолжают давать выколотые точки.
Продлевают ветвь за её область.
Каждая кусочная формула действует только на своём промежутке.
Пропускают k = 0.
В задачах с y = kx этот специальный случай проверяется отдельно.
