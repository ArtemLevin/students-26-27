01

Логарифм — показатель степени

Вначале вспомним определения и ограничения.

Если logau=c, то ac=u. Основание положительно и отлично от единицы; аргумент строго положителен.

Узловая идея: loga1=0. Пример: log84=23.

02

Читаем запрос задачи

Вычисление значения функции и поиск аргумента различаются.

Значение функции

f(32) означает подстановку числа 32 вместо аргумента. Для f(x)=log2x−3 ответ равен 2.

Аргумент по значению

f(x)=1 — уравнение относительно аргумента. В той же модели x=16.

03

Два сдвига графика

Положение добавочного числа меняет ОДЗ и направление смещения.

Число снаружи

f(x)=logax+b

Вертикальный сдвиг; ОДЗ: x>0.

Число внутри

g(x)=loga(x+b)

Горизонтальный сдвиг; ОДЗ: x+b>0.

Проверить оба сдвига на интерактивном графике.

04

Метод узловых точек

Выбирайте точные точки с независимыми уравнениями.

  1. Прочитайте вид функции и конечный вопрос.
  2. Выберите два узла с точными целочисленными координатами.
  3. Подставьте абсциссы и ординаты в формулу, составьте систему.
  4. Решите систему и проверьте ограничения для логарифма.
  5. Подставьте найденную функцию в обе исходные точки, затем вычислите требуемое.

Если две точки не дают независимых уравнений, ищите другой набор; если параметры неидентифицируемы, определяйте нужное значение напрямую.

05

Работа с координатами

Разберите подробный пример по шагам и сравните второй вид функции.

Пример А · сдвиг снаружи

  1. График f(x)=logax+b проходит через A(1; −3) и B(4; −1). Нужно найти значение при аргументе 32.
  2. Первая точка: loga1+b=−3. Так как loga1=0, получаем b=−3.
  3. Вторая точка даёт loga4=2, следовательно a2=4.
  4. Допустимое основание: a=2. Восстановленная функция: f(x)=log2x−3.
  5. Искомое значение: f(32)=2. Проверка по обеим точкам выполнена.

Пример Б · сдвиг внутри

График g(x)=loga(x+b) проходит через A(−4; 0) и B(−1; 2). Первая точка даёт b=5, вторая — a=2. Поэтому g(x)=log2(x+5). При аргументе 11 значение равно 4.

Минус перед логарифмом

−log2(x+2)=−4 приводит к x=14. Минус не переносится внутрь аргумента.

Невозможность определить два коэффициента

Один график могут задавать 3log2x и 6log4x. Коэффициенты по отдельности восстановить невозможно, но значение функции по точкам иногда определяется однозначно.

Сравнить эти графики в лаборатории.
