\section{Главная идея занятия}

В задачах с графиками важно разделять две части работы:

\begin{enumerate}
  \item привести функцию к виду, который удобно строить;
  \item сохранить все ограничения исходного выражения.
\end{enumerate}

Для параболы
\[
y=ax^2+bx+c,\qquad a\ne0
\]
основными ориентирами являются:

\begin{itemize}
  \item вершина;
  \item точки пересечения с осью \(Ox\);
  \item точка пересечения с осью \(Oy\);
  \item направление ветвей.
\end{itemize}

Если исходная функция содержит дробь, после сокращения обязательно сохраняется
\term{ОДЗ исходной функции}. Исключённое значение аргумента изображается на
графике \term{выколотой точкой}.

\accentline

\section{Что можно определить по виду параболы}

Для функции
\[
y=ax^2+bx+c
\]
знак коэффициента \(a\) определяет направление ветвей:

\[
\begin{array}{ccl}
a>0 &\Longrightarrow& \text{ветви направлены вверх},\\[2mm]
a<0 &\Longrightarrow& \text{ветви направлены вниз}.
\end{array}
\]

Абсцисса вершины:

\[
\boxed{x_{\mathrm{в}}=-\frac{b}{2a}}.
\]

Ординату вершины удобнее всего находить подстановкой:

\[
\boxed{y_{\mathrm{в}}=f(x_{\mathrm{в}})}.
\]

Полезное обратное соотношение:

\[
x_{\mathrm{в}}=-\frac{b}{2a}
\quad\Longrightarrow\quad
\boxed{b=-2ax_{\mathrm{в}}}.
\]

Коэффициент \(c\) сразу показывает ординату точки пересечения с осью \(Oy\):

\[
x=0
\quad\Longrightarrow\quad
y=c.
\]

Следовательно, график пересекает ось \(Oy\) в точке

\[
\boxed{(0;c)}.
\]

% ================================================================
\subsection{Пример: читаем коэффициенты по графику}

Предположим, ветви параболы направлены вверх, её вершина находится справа от
оси \(Oy\), а график пересекает ось \(Oy\) ниже начала координат.

Тогда:

\[
a>0,\qquad x_{\mathrm{в}}>0.
\]

Из формулы
\[
b=-2ax_{\mathrm{в}}
\]
следует

\[
\boxed{b<0}.
\]

Поскольку пересечение с осью \(Oy\) происходит ниже нуля,

\[
\boxed{c<0}.
\]

Таким образом,

\[
\boxed{a>0,\qquad b<0,\qquad c<0}.
\]

% ================================================================
\section{Построение параболы по трём ключевым этапам}

Рассмотрим

\[
\boxed{y=x^2-x-6}.
\]

Здесь

\[
a=1,\qquad b=-1,\qquad c=-6.
\]

\subsection{Этап 1. Вершина}

\[
x_{\mathrm{в}}
=
-\frac{-1}{2\cdot1}
=
\frac12.
\]

Подставляем \(x=\frac12\):

\[
y_{\mathrm{в}}
=
\left(\frac12\right)^2
-\frac12
-6
=
\frac14-\frac12-6
=
-\frac{25}{4}.
\]

Следовательно,

\[
\boxed{
V\left(\frac12;-\frac{25}{4}\right)
}.
\]

То есть

\[
V(0{,}5;-6{,}25).
\]

\subsection{Этап 2. Пересечения с осью \(Ox\)}

На оси \(Ox\)

\[
y=0.
\]

Поэтому решаем:

\[
x^2-x-6=0.
\]

Разложим:

\[
(x-3)(x+2)=0.
\]

Отсюда

\[
x_1=-2,\qquad x_2=3.
\]

Точки:

\[
\boxed{A(-2;0)},\qquad
\boxed{B(3;0)}.
\]

\subsection{Этап 3. Пересечение с осью \(Oy\)}

На оси \(Oy\)

\[
x=0.
\]

Следовательно,

\[
y=0^2-0-6=-6.
\]

Получаем

\[
\boxed{C(0;-6)}.
\]

\subsection{Эскиз}

Для экзаменационного эскиза достаточно корректно отметить ключевые точки.
Миллиметровая точность формы ветвей не требуется.

\section{Горизонтальная прямая \(y=m\)}

Уравнение

\[
\boxed{y=m}
\]

задаёт горизонтальную прямую.

При изменении \(m\) эта прямая перемещается вверх или вниз.

Количество решений уравнения

\[
f(x)=m
\]

совпадает с количеством общих точек графиков

\[
y=f(x)
\qquad\text{и}\qquad
y=m.
\]

Для параболы

\[
y=x^2-x-6
\]

минимальное значение достигается в вершине:

\[
y_{\min}=-\frac{25}{4}.
\]

Поэтому:

\[
\boxed{
\begin{array}{ll}
m<-\dfrac{25}{4}
&
\text{общих точек нет},
\\[3mm]
m=-\dfrac{25}{4}
&
\text{ровно одна общая точка},
\\[3mm]
m>-\dfrac{25}{4}
&
\text{две общие точки}.
\end{array}
}
\]

В интервальной записи:

\[
m\in
\left(-\infty;-\frac{25}{4}\right)
\quad\Longrightarrow\quad
0\text{ точек},
\]

\[
m=-\frac{25}{4}
\quad\Longrightarrow\quad
1\text{ точка},
\]

\[
m\in
\left(-\frac{25}{4};+\infty\right)
\quad\Longrightarrow\quad
2\text{ точки}.
\]

Круглые скобки показывают, что значение

\[
-\frac{25}{4}
\]

в соседние интервалы не входит.

\section{Сложная задача: сначала упростить}

Рассмотрим функцию

\[
\boxed{
y=
\frac{(x+4)(x^2+3x+2)}{x+1}
}.
\]

Строить исходное выражение напрямую неудобно.

Первый вопрос:

\[
\boxed{\text{Можно ли упростить выражение?}}
\]

Второй обязательный вопрос:

\[
\boxed{\text{Каково ОДЗ исходной функции?}}
\]

% ================================================================
\subsection{Шаг 1. ОДЗ}

Знаменатель не может обращаться в ноль:

\[
x+1\ne0.
\]

Следовательно,

\[
\boxed{x\ne-1}.
\]

Это ограничение сохраняется до конца решения.

% ================================================================
\subsection{Шаг 2. Разложение квадратного трёхчлена}

Для квадратного трёхчлена

\[
ax^2+bx+c
\]

при наличии двух корней \(x_1\) и \(x_2\) используем:

\[
\boxed{
ax^2+bx+c=a(x-x_1)(x-x_2)
}.
\]

Для

\[
x^2+3x+2
\]

имеем

\[
D=3^2-4\cdot1\cdot2=1.
\]

Корни:

\[
x_1=\frac{-3+1}{2}=-1,
\qquad
x_2=\frac{-3-1}{2}=-2.
\]

Поэтому

\[
x^2+3x+2=(x+1)(x+2).
\]

% ================================================================
\subsection{Шаг 3. Сокращение}

Подставляем разложение:

\[
y=
\frac{(x+4)(x+1)(x+2)}{x+1}.
\]

При \(x\ne-1\) сокращаем \(x+1\):

\[
y=(x+4)(x+2).
\]

Раскрываем скобки:

\[
\boxed{
y=x^2+6x+8,
\qquad x\ne-1.
}
\]

Очень важно: после сокращения ограничение

\[
x\ne-1
\]

никуда не исчезает.

% ================================================================
\section{Как построить полученную параболу}

Работаем с

\[
y=x^2+6x+8.
\]

\subsection{Вершина}

\[
x_{\mathrm{в}}
=
-\frac{6}{2}
=
-3.
\]

\[
y_{\mathrm{в}}
=
(-3)^2+6(-3)+8
=
9-18+8
=
-1.
\]

Следовательно,

\[
\boxed{V(-3;-1)}.
\]

% ================================================================
\subsection{Пересечения с \(Ox\)}

\[
x^2+6x+8=0.
\]

\[
(x+4)(x+2)=0.
\]

Поэтому

\[
\boxed{A(-4;0)},
\qquad
\boxed{B(-2;0)}.
\]

% ================================================================
\subsection{Пересечение с \(Oy\)}

\[
x=0
\quad\Longrightarrow\quad
y=8.
\]

Получаем

\[
\boxed{C(0;8)}.
\]

% ================================================================
\section{Выколотая точка}

После упрощения получилась парабола

\[
y=x^2+6x+8,
\]

однако исходная функция не определена при

\[
x=-1.
\]

Чтобы найти положение выколотой точки, подставим \(x=-1\) в
упрощённую формулу:

\[
y=(-1)^2+6(-1)+8.
\]

\[
y=1-6+8=3.
\]

Следовательно, из графика следует удалить точку

\[
\boxed{Q(-1;3)}.
\]

Именно эта выколотая точка сохраняет информацию об ОДЗ исходной дроби.

\textbf{Ключевая мысль.}
Упрощённая формула помогает построить форму графика, а ОДЗ показывает,
какие точки необходимо исключить.

\section{Ещё один пример}

Пусть

\[
y=
\frac{(x+1)(x^2+7x+10)}{x+2}.
\]

Сначала:

\[
x+2\ne0
\quad\Longrightarrow\quad
\boxed{x\ne-2}.
\]

Разложим квадратный трёхчлен:

\[
x^2+7x+10=(x+2)(x+5).
\]

Тогда

\[
y=
\frac{(x+1)(x+2)(x+5)}{x+2}.
\]

При \(x\ne-2\):

\[
y=(x+1)(x+5).
\]

Раскрываем скобки:

\[
\boxed{
y=x^2+6x+5,
\qquad x\ne-2.
}
\]

Координата выколотой точки:

\[
y=(-2)^2+6(-2)+5
=
4-12+5
=
-3.
\]

Поэтому

\[
\boxed{Q(-2;-3)}
\]

--- выколотая точка.

\section{Типичные ошибки}

\begin{enumerate}
  \item
  \term{Потерять ОДЗ после сокращения.}

  Если
  \[
  \frac{x+1}{x+1}=1,
  \]
  то для исходного выражения всё равно остаётся условие
  \[
  x\ne-1.
  \]

  \item
  \term{Перепутать вершину и пересечение с осью \(Oy\).}

  Точка
  \[
  (0;c)
  \]
  является пересечением с \(Oy\).
  Вершина имеет абсциссу
  \[
  -\frac{b}{2a}.
  \]

  \item
  \term{При пересечении с \(Ox\) обнулить \(x\).}

  На оси \(Ox\):
  \[
  \boxed{y=0}.
  \]

  На оси \(Oy\):
  \[
  \boxed{x=0}.
  \]

  \item
  \term{Ошибиться в арифметике при вычислении вершины.}

  После нахождения \(x_{\mathrm{в}}\) полезно отдельно записать
  подстановку в функцию и только затем считать.

  \item
  \term{Неправильно извлечь \(\sqrt D\).}

  Например,
  \[
  D=9
  \quad\Longrightarrow\quad
  \sqrt D=3.
  \]

  \item
  \term{Сокращать слагаемые.}

  Сокращение возможно только для множителей:

  \[
  \frac{(x+2)(x-3)}{x+2}=x-3,
  \qquad x\ne-2.
  \]

  Выражение вида

  \[
  \frac{x+2}{x+3}
  \]

  сократить нельзя.

  \item
  \term{Не подписать ключевые точки на эскизе.}

  Для проверяющего должны быть понятны координаты вершины,
  пересечений и выколотых точек.
\end{enumerate}

\section*{Тренировочный блок}

\textcolor{softgray}{
Пять заданий расположены по нарастающей сложности.
Решения оформляйте последовательно, ключевые точки графиков подписывайте.
}

\vspace{4mm}

\begin{enumerate}[label=\textbf{\arabic*.}]

\item
Для функции
\[
y=x^2+2x-3
\]
найдите:

\begin{itemize}
  \item координаты вершины;
  \item точки пересечения с \(Ox\);
  \item точку пересечения с \(Oy\).
\end{itemize}

Постройте эскиз графика.

\vspace{5mm}

\item
Для параболы
\[
y=x^2-4x+3
\]
определите, при каких значениях \(m\) горизонтальная прямая

\[
y=m
\]

имеет с параболой:

\begin{itemize}
  \item \(0\) общих точек;
  \item ровно \(1\) общую точку;
  \item \(2\) общие точки.
\end{itemize}

\vspace{5mm}

\item
Постройте график функции

\[
y=
\frac{(x+3)(x^2+x-2)}{x+2}.
\]

Обязательно:

\begin{itemize}
  \item укажите ОДЗ;
  \item разложите квадратный трёхчлен на множители;
  \item упростите функцию;
  \item найдите вершину;
  \item найдите пересечения с координатными осями;
  \item найдите координаты выколотой точки.
\end{itemize}

\vspace{5mm}

\item
Постройте график функции

\[
y=
\frac{(x-2)(x^2-5x+6)}{x-3}.
\]

После построения найдите все значения \(m\), при которых прямая

\[
y=m
\]

имеет с графиком ровно одну общую точку.

\vspace{5mm}

\item
Рассмотрите функцию

\[
y=
\frac{(x+1)(x^2-4x+3)}{x-1}.
\]

\begin{itemize}
  \item Найдите ОДЗ.
  \item Упростите выражение.
  \item Постройте график с учётом выколотой точки.
  \item Определите количество общих точек этого графика
  с прямой \(y=m\) в зависимости от значения \(m\).
\end{itemize}

\end{enumerate}

Выколотая точка:
\[

\]

Для обычной параболы \(y=(x-2)^2\) горизонтальная прямая имеет
одну общую точку при \(m=0\).

Кроме того, при
\[
m=1
\]
обычная парабола пересекалась бы с прямой в точках с абсциссами
\[
x=1,\qquad x=3.
\]
Точка с \(x=3\) выколота, поэтому остаётся только одна общая точка.

Итак,
\[
\boxed{m=0\quad\text{или}\quad m=1}.
\]
\\

\midrule

5 &
\[
x\ne1.
\]
Так как
\[
x^2-4x+3=(x-1)(x-3),
\]
то
\[
y=(x+1)(x-3)
=
x^2-2x-3,
\qquad x\ne1.
\]

Запишем:
\[
x^2-2x-3=(x-1)^2-4.
\]

У обычной параболы вершина
\[
V(1;-4),
\]
однако именно эта точка исключена из графика:

\[
Q(1;-4).
\]

Поэтому
\[
\boxed{
\begin{array}{ll}
m\le-4 & \text{общих точек нет},\\[1mm]
m>-4 & \text{две общие точки}.
\end{array}
}
\]

Ровно одной общей точки не бывает.
\\
