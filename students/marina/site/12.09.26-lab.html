Эксперимент 1. Коэффициенты прямой

y = 1x + 0
k > 0: функция возрастает

Управление

Наблюдение

Что меняется

k > 0Прямая возрастает.
(0; 0)Пересечение с осью Oy.

Изменяйте k: меняется наклон. Изменяйте b: прямая сдвигается, а её пересечение с осью Oy имеет ординату b.

Пограничный случай k=0: график становится горизонтальным.

Связь с занятием

По направлению прямой определяйте знак k.
По пересечению с Oy определяйте b.
Для точного пересечения двух графиков используйте f(x)=g(x).

Эксперимент 2. Коэффициенты параболы

y = x²
a > 0: ветви направлены вверх

Управление

Чтение графика

Коэффициенты и вершина

a > 0Ветви вверх.
V(0; 0)Вершина параболы.
b = 0Вершина на оси Oy.
(0; 0)Пересечение с Oy.

xV = −b/(2a)

Сначала определяйте знак a по ветвям, затем знак xV по положению вершины, после этого используйте b = −2axV. Коэффициент c читается по пересечению с Oy.

Эксперимент 3. Сколько общих точек?

Исходная парабола из тренировочного блока: y=(x−2)²−1.

y = −1
Одна общая точка

Управление

Вывод

Одна общая точка

При m = −1 горизонтальная прямая проходит через вершину параболы.

m < −1 — общих точек нет.
m = −1 — одна общая точка.
m > −1 — две общие точки.
