01

Базовая гипербола

Сначала фиксируем область определения, асимптоты и четверти. Только потом берём точки.

y = k/x,   k ≠ 0

Обратная пропорциональность задаётся формулой y = k/x. График состоит из двух ветвей, а для любой точки выполняется xy = k.

Область определенияx ∈ ℝ \ {0}
Множество значенийy ∈ ℝ \ {0}
Асимптотыx = 0 и y = 0
Знак kk > 0: I и III четверти; k < 0: II и IV

Как построить по точкам

Берём ненулевые значения x по обе стороны от нуля, вычисляем y = k/x, наносим точки и проводим две плавные ветви, приближающиеся к асимптотам.

Самопроверка. До построения определите знак k и четверти; после построения убедитесь, что ветви не пересекают оси.

02

Сдвинутая гипербола

У линейно-дробной функции центр графика задаётся пересечением двух асимптот.

(ax + b)/(cx + d),   c ≠ 0

При ad − bc ≠ 0 график является сдвинутой гиперболой. Сначала учитываем ограничение cx + d ≠ 0.

Вертикальная асимптотаx = −d/c
Горизонтальная асимптотаy = a/c
Центр(−d/c; a/c)
Удобное преобразование(ax+b)/(cx+d) = a/c + (bc−ad)/(c(cx+d))

Пример из занятия

y = (2x − 3)/(x + 5) = 2 − 13/(x + 5)
ОДЗ: x ≠ −5.
Асимптоты: x = −5 и y = 2.
Пересечение с Ox: (3/2; 0).
Пересечение с Oy: (0; −3/5).
Эскиз по структуреасимптоты + две надёжные точки
Для эскиза обычно достаточно найти асимптоты и несколько надёжных точек, особенно пересечения с осями, если они существуют.

03

Сокращение и выколотая точка

Главная ловушка: упрощённая формула не возвращает значения x, запрещённые исходным знаменателем.

f(x) = (2x + 1)/(2x² + x) = (2x + 1)/(x(2x + 1))
Сначала исходный знаменатель: x ≠ 0 и x ≠ −1/2.
После сокращения: f(x) = 1/x, но оба исходных ограничения сохраняются.
Выколотая точка: при x = −1/2 упрощённая формула дала бы y = −2, поэтому (−1/2; −2) выколота.
Правило. Сокращение упрощает формулу функции, но не меняет исходную область определения.

Параметрическая прямая y = kx

Для пересечения с y = 1/x получаем kx² = 1. При k > 0 обычная гипербола имеет две точки пересечения. Чтобы у функции с выколотой точкой осталась ровно одна общая точка, одна из двух точек должна совпасть с выколотой.

−2 = k·(−1/2)   ⇒   k = 4

Проверка: 4x² = 1, поэтому x = ±1/2. Значение x = −1/2 запрещено, x = 1/2 допустимо — остаётся ровно одна общая точка.

04

Горизонтальная прямая y = m

Отсутствие пересечений может возникнуть из-за асимптоты или из-за выколотой точки.

g(x) = 3 − (x + 2)/(x² + 2x)

Исходный знаменатель даёт x ≠ 0, −2. При допустимых x получаем g(x) = 3 − 1/x.

m = 3Это горизонтальная асимптота, общих точек нет.
m = 7/2Единственная возможная точка соответствует x = −2, но она выколота.
m = 3 − 1/x   ⇒   x = −1/(m − 3)
Ответ: m = 3 или m = 7/2.

2. Сокращение и одна общая точка

Постройте f(x) = (3x − 3)/(x² − x) с учётом ограничений. Найдите a, при котором y = ax имеет с графиком ровно одну общую точку.

Показать ответ

x ≠ 0, 1; после сокращения f(x) = 3/x; точка (1; 3) выколота; a = 3.

3. Сдвиг, выколотая точка и y = m

Постройте g(x) = 4 − (x − 3)/(x² − 3x) с учётом ограничений. Найдите все m, при которых y = m не имеет с графиком общих точек.

Показать ответ

x ≠ 0, 3; после сокращения g(x) = 4 − 1/x; точка (3; 11/3) выколота; m = 4 или m = 11/3.
