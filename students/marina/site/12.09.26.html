Линейная функция

Что видно из формулы y = kx + b

Коэффициент k
Определяет наклон прямой. При k > 0 функция возрастает, при k < 0 убывает, при k = 0 график горизонтален.
Коэффициент b
Это ордината точки пересечения с осью Oy: при x = 0 получаем y = b.
Абсцисса — координата x. Ордината — координата y.

Как сопоставить формулу и график

По направлению прямой определите знак k.
Если осталось несколько вариантов, возьмите удобную узловую точку и проверьте её подстановкой.

В занятии использовалась точка (1; −3): для y = −3x равенство −3 = −3·1 выполняется.

Визуальная интерпретация

Ключевой метод

Условие пересечения: f(x) = g(x)

В общей точке двух графиков совпадают и абсцисса, и ордината. Поэтому правые части функций можно приравнять.

Приравняйте правые части.
Решите уравнение относительно x.
Подставьте найденный x в любую исходную функцию.
Найдите y и при необходимости проверьте его по второй функции.
Точный расчёт важнее оценки по рисунку. График помогает увидеть положение точки, а уравнение даёт точные координаты.

Разобранный пример

y₁ = 2x + 5,    y₂ = −x + 7

Приравниваем:

2x + 5 = −x + 7 ⇒ 3x = 2 ⇒ x = 2/3.

Подставляем в первую функцию:

y = 2·(2/3) + 5 = 19/3.

Точка пересечения:

(2/3; 19/3).

Проверка по второй функции: −2/3 + 7 = 19/3.

Почему метод универсален

Та же логика работает при пересечении прямой и параболы: сначала решается уравнение f(x)=g(x), затем по найденным значениям x вычисляются соответствующие y.

Квадратичная функция

Парабола y = ax² + bx + c

Для квадратичной функции обязательно a ≠ 0. При a = 0 квадратный член исчезает и остаётся линейная функция y=bx+c.

a — ветви
a > 0 — ветви вверх; a < 0 — ветви вниз.
c — пересечение с Oy
При x=0 имеем y=c.

Вершина и коэффициент b

xV = −b/(2a)    ⇔    b = −2axV

По положению вершины относительно оси Oy определите знак x_V, затем учтите знак a и найдите знак b.

Алгоритм чтения коэффициентов по графику

По направлению ветвей определите знак a.
По положению вершины определите знак x_V.
Используйте b = −2ax_V и определите знак b.
По пересечению с осью Oy определите знак c.
Памятка: a — ветви; b — вершина; c — пересечение с Oy.
Пограничный случай: если вершина лежит на оси Oy, то x_V=0 и b=0.

Типичные ошибки

Забыть минус
В формуле вершины стоит x_V=−b/(2a).
Связать c с вершиной
c относится к пересечению с осью Oy.
Считать знак b напрямую
Нужно учитывать и a, и x_V.
Забыть a ≠ 0
При a=0 параболы уже нет.

Сколько общих точек у y=m и параболы

Для y=(x−h)²+q ветви направлены вверх, а вершина имеет ординату q.

m < q
Общих точек нет.
m = q
Одна общая точка.
m > q
Две общие точки.

Для параболы с ветвями вниз картина меняется зеркально.
