Кусочные функции

Одна функция может состоять из нескольких ветвей. На занятии разобрали, как ограничивать каждую ветвь её областью, работать с открытыми и закрашенными точками, подключать параболу и исследовать число пересечений с горизонталью y=m.

01

Собираем график из ветвей

Сначала строим знакомые графики, затем ограничиваем их по x.

f(x) = { x + 1, если x ≤ −1;   2x + 3, если x > −1 }
Разделите функцию на ветви и выпишите условие для каждой.
Постройте каждую формулу как обычный график.
Оставьте только те точки, у которых x входит в область этой ветви.
Отдельно проверьте граничное значение и соберите ветви на одной координатной плоскости.
Главное: формула говорит, какой график строить; условие говорит, какую часть этого графика оставить.
В одной вертикали x=−1 ветви подходят к разным значениям y, поэтому возникает разрыв.
02

Граница решает судьбу точки

Строгость неравенства определяет, принадлежит ли точка ветви.

Закрашенная

Если условие содержит ≤ или ≥, граничное значение x входит в область ветви.

Выколотая

Если условие содержит < или >, граничное значение x для этой ветви запрещено.

Полезный приём: даже запрещённое граничное x подставьте в формулу. Это показывает, куда подходит ветвь. После вычисления отметьте точку открытой или закрытой по условию.

Когда одна ветвь открыта, а другая закрыта

Если соседняя ветвь содержит ту же точку, итоговая функция в этой координате определена. Поэтому «выколотость» одной ветви не означает автоматически дырку во всём графике.

03

Горизонталь y=m считает решения

Двигаем прямую вверх-вниз и следим, где меняется число пересечений.

y = m — горизонтальная прямая

Для функции из трёх линейных ветвей на занятии критическими уровнями стали m=−2 и m=1. Именно на этих высотах число общих точек меняется.

Отметьте характерные высоты: точки стыка, вершины и экстремумы.
Проверьте сам критический уровень.
Проверьте промежутки между критическими уровнями.
Считайте только реальные точки ветвей с учётом их областей по x.
Разобранный результат: для трёхветвевой функции из пособия ровно две общие точки получаются при m=−2 или m=1.

04

Парабола остаётся параболой

Строим привычным способом, затем применяем ограничение ветви.

f(x) = { x + 9, если x < −3;   x² + 2x + 3, если x ≥ −3 }

Для параболы y=x²+2x+3 вершина находится в точке (−1;2). В точке перехода x=−3 обе формулы дают 6, поэтому ветви встречаются в координате (−3;6).

Для этой функции ровно две точки пересечения с y=m получаются при m=2 и m=6.

Если корни «некрасивые»

Во втором разобранном примере парабола имела нули x=−1±√14 ≈ −4,74 и 2,74. На эскизе их можно отметить приближённо. Важно сохранить симметрию относительно оси x=−1 и отдельно вычислить граничную точку x=−5.

Разобранный результат: для функции с ветвями −x−7 и −x²−2x+13 ровно две точки пересечения с y=m получаются при m=−2 и m=14.
05

Пять ошибок, которые ломают график

Проверка занимает меньше минуты.

01Продолжить ветвь туда, где условие для x уже не выполняется.
02Забыть вычислить значение в точке перехода.
03Перепутать открытую и закрашенную граничную точку.
04Считать выколотую точку одной ветви дыркой всего графика, не проверив соседнюю ветвь.
05При параболе потерять ось симметрии или оставить запрещённую часть ветви.
