01

Базовая модель

Удобный вид сразу показывает геометрию графика.

y = a + b/(x − c),   b ≠ 0
Вертикальная асимптотаx = c
Горизонтальная асимптотаy = a
Центр симметрииC(c; a)
Если b > 0ветви расположены относительно центра как у y = 1/x
Если b < 0ветви расположены относительно центра как у y = −1/x
В общем случае симметрия выполняется относительно точки C(c; a), поэтому ориентироваться только на начало координат нельзя.
Проверьте роль a, b и c на графике.

Лаборатория показывает асимптоты, центр и изменение положения ветвей.

02

Линейно-дробная функция

Асимптоты можно получить непосредственно из коэффициентов.

y = (Ax + B)/(Cx + D),   C ≠ 0

Если AD − BC ≠ 0, график является гиперболой.

Вертикальная асимптотаx = −D/C
Горизонтальная асимптотаy = A/C
Если AD − BC = 0, числитель и знаменатель пропорциональны. После упрощения может получиться постоянная функция с исключённой точкой, поэтому формулу гиперболы нельзя применять механически.

Пример: y = (x + 1)/(x − 1)

Асимптоты: x = 1 и y = 1.
Пересечение с Ox: x + 1 = 0, поэтому (−1; 0).
Пересечение с Oy: x = 0, поэтому (0; −1).

Полный пример: y = (2x + 1)/(−x + 2)

ОДЗ: x ≠ 2.
Асимптоты: x = 2 и y = −2.
Ox: (−1/2; 0).
Oy: (0; 1/2).

Этих данных достаточно для качественного эскиза. Если положение ветвей вызывает сомнение, допустимо взять одну-две дополнительные точки по обе стороны вертикальной асимптоты.

03

ОДЗ и сокращение

Область определения фиксируется по исходной формуле до сокращения.

y = (x + 1)/(x² + x) − 2
Разложить знаменатель: x² + x = x(x + 1).
Записать ОДЗ: x ≠ 0 и x ≠ −1.
Сократить: y = 1/x − 2, сохранив оба ограничения.
Проверить исключённое x = −1: упрощённая формула дала бы y = −3.
Отметить выколотую точку: (−1; −3).
Сокращение меняет запись функции, но не возвращает в область определения значения, запрещённые исходной формулой.
y = 1/x − 2 при x ≠ 0, −1асимптоты и выколотая точка
04

Пересечения с осями

Для каждой оси действует короткое и надёжное правило.

Пересечение с OxПоложить y = 0. Для P(x)/Q(x) = 0 нужно P(x) = 0 и одновременно Q(x) ≠ 0.
Пересечение с OyПоложить x = 0. Если 0 не входит в ОДЗ, пересечения с Oy нет.

Быстрое чтение сдвинутой гиперболы

Если функция уже дана в виде y = a + b/(x − c), предварительно собирать её в одну большую дробь не требуется.

y = 3 + 1/x: асимптоты x = 0 и y = 3.
y = 1/(2x + 3) − 1: горизонтальная асимптота y = −1.
Вертикальная асимптота: 2x + 3 = 0, поэтому x = −3/2.
Ox: (−1; 0).
Oy: (0; −2/3).
Центр: (−3/2; −1); коэффициент при дроби положителен, поэтому ветви расположены как у y = 1/x относительно этого центра.
05

Выколотая точка и y = m

Отсутствующий уровень может появиться из-за асимптоты или из-за единственной выколотой точки.

y = 1/x − 2,   x ≠ 0, −1
Асимптотыx = 0 и y = −2.
Ox(1/2; 0).
Oyпересечения нет, потому что x = 0 запрещён.
Выколотая точка(−1; −3).

Когда y = m не пересекает график

m = −2: это уровень горизонтальной асимптоты.
m = −3: уравнение 1/x − 2 = −3 даёт только x = −1, но это значение исключено из ОДЗ.
Итог: m ∈ {−3; −2}.
Перемещайте прямую y = m.

На точном примере занятия видно, почему именно два уровня не дают общих точек.

Исследовать y = m

Типичные ошибки

Короткий контроль перед построением.

ОДЗНе терять исходное ограничение после сокращения.
Порядок действийСначала ОДЗ и упрощение, затем график.
ЗнакПри −x + 2 = 0 получается x = 2.
OyНельзя подставлять x = 0, если ноль запрещён ОДЗ.
Нуль дробиНужны P(x) = 0 и Q(x) ≠ 0.
СимметрияУ y = a + b/(x − c) центр симметрии — (c; a).
Выколотая точкаЭто одно отсутствующее значение графика; асимптота описывает поведение возле прямой.
