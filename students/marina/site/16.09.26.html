Парабола, прямая y = m
и выколотая точка

Строим параболу по ключевым точкам, читаем число пересечений с горизонтальной прямой и сохраняем ОДЗ после сокращения алгебраической дроби.

Главная идея

Сначала ключевые точки, затем эскиз

Для y = ax² + bx + c сначала определите направление ветвей, вершину и пересечения с осями. Этого достаточно, чтобы получить корректный экзаменационный эскиз.

Направление ветвей
a > 0 — вверх; a < 0 — вниз.
Вершина
xв = −b/(2a), затем yв = f(xв).
Пересечение с Ox
На оси Ox имеем y = 0, поэтому решаем f(x)=0.
Пересечение с Oy
На оси Oy имеем x = 0; для квадратичной функции точка равна (0;c).
Полезная связь: из xв = −b/(2a) следует b = −2axв.

Разобранный пример

y = x² − x − 6

Вершина. xв = 1/2, yв = −25/4 = −6,25. Получаем V(0,5; −6,25).
Пересечения с Ox. x² − x − 6 = (x−3)(x+2), поэтому A(−2;0), B(3;0).
Пересечение с Oy. При x=0 получаем C(0;−6).
Эскиз. Отметьте вычисленные точки и проведите через них плавную параболу.

Графический смысл параметра

Горизонтальная прямая y = m

Меняя m, мы перемещаем горизонтальную прямую вверх или вниз. Число решений уравнения f(x)=m равно числу общих точек графиков y=f(x) и y=m.

Почему граница именно −6,25

Это ордината вершины — минимальное значение функции. Ниже минимума значений функции нет; на уровне минимума прямая касается графика в вершине; выше минимума пересекает обе ветви.

Круглые скобки в интервалах исключают значение −25/4, поскольку для него действует отдельный случай: ровно одна общая точка.

Задача повышенной сложности

Сначала упростить, затем вернуть ОДЗ

y = ((x+4)(x²+3x+2))/(x+1)
ОДЗ. x+1 ≠ 0, значит x ≠ −1.
Разложение. x²+3x+2=(x+1)(x+2).
Сокращение. При x ≠ −1: y=(x+4)(x+2)=x²+6x+8.
Построение упрощённой параболы. V(−3;−1), нули −4 и −2, пересечение с Oy: (0;8).
Возврат ОДЗ. Подставляем исключённое x=−1 в упрощённую формулу: y=3. Точка Q(−1;3) выколота.
Смысл: упрощённая формула задаёт форму параболы, а исходное ОДЗ сообщает, какую точку нужно удалить.
◇ Открыть цифровую лабораторию: выколотая точка

Второй пример из занятия

y=((x+1)(x²+7x+10))/(x+2), ОДЗ: x ≠ −2.

x²+7x+10=(x+2)(x+5), поэтому y=(x+1)(x+5)=x²+6x+5.

При x=−2 получаем y=−3, значит Q(−2;−3) — выколотая точка.

Типичные ошибки

Потерять ОДЗ
Сокращённый множитель исчезает из записи, ограничение исходной дроби сохраняется.
Сокращать слагаемые
Сокращение допустимо только для общих множителей.
Перепутать оси
На Ox обнуляется y; на Oy обнуляется x.
Забыть выколотую точку
После построения упрощённого графика исключённое значение нужно вернуть визуально пустым кружком.
