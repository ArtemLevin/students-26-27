01 / Основание

Приведение к общей степени

Составные числа и корни переводим в степени одного положительного основания, отличного от единицы.

Если основания совпадают, показатели равны. При возведении степени в степень показатели перемножаются.

43−x=8⇔26−2x=232

Получаем 6 − 2x = 3/2, следовательно x = 9/4. Различайте свойства am·an и (am)n.

Правило: au = av ⇔ u = v, если a > 0 и a ≠ 1.
02 / Преобразования

Логарифмы: от структуры к ответу

Произведение, степень аргумента и смена основания дают короткие решения.

Произведение превращается в сумму

loga(bc)=logab+logac

Показатель положительного аргумента выносим перед логарифмом: loga(br) = r·logab.

Как поменять местами основание и аргумент

logab=1logba

Если logba = −2, то logab = −1/2. Поэтому loga(b6√a) = 6·(−1/2) + 1/2 = −5/2.

ЕЩЁ ОДИН ТИП

Логарифм степени

log8(325−x) = 4. Выносим (5−x), учитываем 8 = 2³ и 32 = 2⁵: (5−x)·5/3 = 4, откуда x = 13/5.

Логарифмы с разными основаниями: log4125 / log8625 = (3/2) / (4/3) = 9/8.

Условия логарифма: основание строго положительно и отлично от единицы; аргумент строго положителен.

03 / Ограничения

Уравнение начинается с ОДЗ

Равенство логарифмов одного основания позволяет сравнить аргументы, после чего нужно проверить корни.

log3(14−x)=log3(x2−x)
  1. Ограничения: 1/4 − x > 0 и x² − x > 0.
  2. Сравниваем аргументы: 1/4 − x = x² − x.
  3. После сокращения −x получаем x² = 1/4 и кандидаты x = ±1/2.
  4. Для x = 1/2 нарушается первое ограничение. Для x = −1/2 оба аргумента положительны.
Ответ: x = −1/2. Подстановка в ОДЗ завершает решение.
04 / Функция

Узловые точки и достаточность данных

Для графика k·logax точка (1;0) верна всегда. Она не помогает определить коэффициенты.

f(x)=klogax
КЛЮЧЕВОЙ ПРИМЕР

Точки (3;2) и (9;4)

Поскольку 9 = 3², значение f(9) автоматически равно 2f(3). Вторая точка повторяет первую информацию. Однако искомое значение находится без восстановления k и a:

f(27) = f(3³) = 3f(3) = 3·2 = 6.

Ответ: x = 27. Для этой функции k ≠ 0, поэтому она строго монотонна.

05 / Угол

Привести выражение к общему углу

Используем двойной угол, периодичность, чётность и знаки по четвертям.

Двойной угол: sin(2α) = 2sinα·cosα.
Периоды: sin и cos — 2π; tg — π.
Чётность: cos(−α) = cosα; sin(−α) = −sinα.
ПРИМЕР / ГРАДУСЫ

Сумма углов 360°

10 sin85° cos85° / sin190° = 5 sin170° / sin190° = −5.

Числитель сворачиваем по формуле двойного угла. Затем 170° = 360° − 190° и sin(360° − α) = −sinα.

ПРИМЕР / РАДИАНЫ

Большие аргументы

sin(23π/6) = −1/2,   cos(−11π/4) = −√2/2,   tg(8π/3) = −√3.

Для выражения 6sin(23π/6)cos(−11π/4) / tg(8π/3) получаем −√6/2.

В записи углов: при градусах сохраняйте символ °. При радианах сначала выделяйте полный период и проверяйте знак.
06 / Прикладная модель

Какая доля времени удовлетворяет условию?

Продолжительность наблюдения задаёт отрезок. Искомое время находят через неравенство.

В течение первых 3,5 секунды скорость задана в см/с:

v(t)=22sin(πt6)

Не превышала 2 см/с означает v(t) ≤ 2. После деления на 2√2 получаем:

sin(πt6)≤22
  1. Решаем неравенство по аргументу синуса с учётом его периодичности.
  2. Подходящий периодический интервал: −5π/4 + 2πn ≤ πt/6 ≤ π/4 + 2πn.
  3. При n = 0 получаем −7,5 ≤ t ≤ 1,5. На отрезке наблюдения [0;3,5] подходит [0;1,5].
  4. Доля равна 1,5 / 3,5 = 3/7 ≈ 0,43 (до сотых).
Важно: при более длинном наблюдении могут подходить несколько периодических отрезков. Сложите длины пересечений с нужным промежутком.
