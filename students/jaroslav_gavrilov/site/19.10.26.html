01 / ПОВТОРЕНИЕ

Углы к одному значению

Ищите связь углов с 180°. Формулы приведения помогут сократить тригонометрическое выражение.

tg(180° − α) = −tg α

Тангенс во II четверти отрицателен.

tg(180° + α) = tg α

Период тангенса — 180°.

sin(180° − α) = sin α

Синус во II четверти положителен.

sin(180° + α) = −sin α

Синус в III четверти отрицателен.

Разобранный пример

5 · tg 163°tg 17° = −5 · tg 17°tg 17° = −5

163° = 180° − 17°, а tg 17° ≠ 0.

Двойной угол

10 sin 85° cos 85°sin 190° = 5 sin 170°sin 190° = −5

Использовали sin 2α = 2 sin α cos α, затем формулы приведения.

02 / ЗАКОНЫ

Увидеть структуру

Одинаковое основание, одинаковый показатель и степень степени — три разных ситуации.

am · an = am+n

Умножаем одинаковые основания.

am / an = am−n

Делим одинаковые основания.

an · bn = (ab)n

Объединяем основания при равных показателях.

an / bn = (a/b)n

Выносим общий показатель за дробь.

(am)n = amn

Показатели перемножаются.

1/an = a−n

Переходим к отрицательной степени.

(a/b)n = (b/a)−n

Обращение дроби меняет знак показателя.

⁽ᵏ⁾√(am) = am/k

Внутренняя степень идёт в числитель.

Область применения. Для произвольных действительных показателей безопасно брать a > 0, b > 0, k ≥ 2. При целых показателях ограничения могут быть шире. Сложение степеней am + an само по себе не разрешает сложить показатели.
03 / АЛГОРИТМ

Составные числа → корни → дроби

Переведите всё в общий степенной язык до сложных вычислений.

  1. Разложите составные числа.
    8 = 23 ··· 81 = 34 ··· 3125 = 55
  2. Замените корень дробным показателем.
    √8 = (23)1/2 = 23/2
  3. Переведите дроби в отрицательные степени.
    1√8 = 2−3/2 ··· 0,2 = 5−1
  4. Объедините подходящие основания и показатели. Выберите формулу, которая подходит именно к текущему действию.
  5. Проверьте знаки, скобки и допустимые значения. Помните: √(x²) = |x|.
Порядок — подсказка к действию. Не каждый шаг обязателен: применяйте его только если соответствующая структура действительно присутствует.
04 / ВЫЧИСЛЕНИЯ

Скобки сохраняют знаки

Трудности появляются прежде всего при отрицательных показателях и вычитании выражений.

Смешанные дробные показатели

21/3 · 21/4¹²√2 всё в квадрате = (21/2)2 = 2

1/3 + 1/4 − 1/12 = 1/2.

Вычитание отрицательного показателя

(0,5)√10−12−√10 = 2−(√10−1)−(−√10) = 2

Знаменатель имеет основание 2; показатель вычитаем целиком.

ВУПС. Вычитаемое, умножаемое и подставляемое берите в скобки. Иначе легко потерять минус и изменить ответ.
05 / УРАВНЕНИЯ

Сначала общий базис

При a > 0 и a ≠ 1 равенство af(x) = ag(x) позволяет приравнять показатели.

Простейшее уравнение

2x = 8 = 23  →  x = 3

Посторонний множитель приводим к степени

2 · 2x = 23  →  2x+1 = 23  →  x = 2

Сначала изолируем степень

40 · 2−x/3 = 5  →  2−x/3 = 2−3  →  x = 9

Как убрать дробный показатель

x5/3 = 32  →  x = 323/5  →  x = 8

Возводим обе части в степень, обратную 5/3.

Не теряйте отрицательный корень. Уравнение x−2 = 4 на действительных числах при x ≠ 0 имеет два решения: x = ±1/2. При дополнительном условии x > 0 остаётся один корень.
06 / ПРИКЛАДНАЯ ЗАДАЧА

Из формулы — к ответу

По условию P·v5/3 = C. Требуется найти v при P = 6,25 · 105, C = 200, v > 0.

  1. Изолируем неизвестную степень: v5/3 = C/P.
  2. Подставляем: 200 / 625000 = 1 / 3125 = 5−5.
  3. Возводим обе части в степень 3/5: v = (5−5)3/5 = 5−3.
v = 1/125 = 0,008

После получения результата проверьте его подстановкой в исходную формулу. В прикладной задаче учитывайте предусмотренные условием ограничения и единицы измерения.
