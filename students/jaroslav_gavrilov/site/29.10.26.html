Логарифмы:
от уравнения к графику

Три типа задач ЕГЭ объединяет один принцип: привести запись к знакомому виду, выполнить преобразование и проверить ограничения.

Формула-ориентир

logaU = c  ⇔  U = ac

Метод «циклопа» помогает запомнить переход от логарифма к степени.

Сохраняйте ОДЗ: a > 0, a ≠ 1, U > 0.

01 / Начало

Определение и ОДЗ

Прежде чем решать, установите, какие значения допустимы для всех логарифмов.

Логарифм числа b по основанию a — показатель степени, в которую нужно возвести a, чтобы получить b.

logab = c  ⇔  ac = b
Три условия: a > 0;   a ≠ 1;   b > 0.
Если аргумент зависит от x, его положительность проверяют для каждого найденного корня.
ПРИМЕР 01

Простейшее уравнение

log3(x + 1) = 2  →  x + 1 = 9  →  x = 8

Проверка: x + 1 = 9 > 0. Ответ: 8.

ПРИМЕР 02

Одинаковые основания

log2(x + 1) = log2(2x + 1)

ОДЗ: x + 1 > 0 и 2x + 1 > 0. Приравниваем аргументы: x + 1 = 2x + 1, откуда x = 0. Обе части ОДЗ выполнены.

Важно: приравнивать аргументы можно, когда основания одинаковы и после преобразований в каждой части осталось по одному логарифму.
02 / Метод

Как подготовить уравнение

Добавочные числа, множители и разные основания сначала приводим к общему виду.

loga(UV) = logaU + logaV
loga(U/V) = logaU − logaV
r·logaU = loga(Ur)
loga1 = 0;   logaa = 1

Условия: a > 0, a ≠ 1, U > 0, V > 0.

ПРИМЕР 03

Слагаемое вне логарифма

log2(x + 1) = log2(2x + 1) + 1
  1. ОДЗ: x + 1 > 0, 2x + 1 > 0.
  2. Заменяем 1 на log22, объединяем логарифмы справа.
  3. x + 1 = 2(2x + 1) = 4x + 2; значит, x = −1/3.
  4. Проверка: 2/3 > 0 и 1/3 > 0.

Ответ: −1/3.

ПРИМЕР 04

Коэффициент перед логарифмом

log5(5 − x) = 2log53

Справа: log5(3²) = log59. Следовательно, 5 − x = 9, x = −4. Аргумент положителен.

ПРИМЕР 05

Основание — степень

log8(28x−4) = 4

8 = 2³; поэтому (8x − 4)/3 = 4, откуда x = 2. Показательное выражение 28x−4 всегда положительно.

ПРИМЕР 06

Разные основания

log2(x/6) = log0,5(x + 1)

ОДЗ: x > 0. Поскольку 0,5 = 2−1, справа получаем −log2(x + 1). Тогда x/6 = 1/(x + 1), x² + x − 6 = 0.

Корни: −3 и 2. По ОДЗ подходит лишь x = 2.

Не применяйте формулу произведения к сумме: loga(U + V) не равен logaU + logaV.
03 / Применение

Задача с готовой формулой

Сначала выпишите исходные величины. Затем упростите коэффициент и выделите логарифм.

Q = (αcm / γ) · log2((T1−T0) / (T−T0))

По данным α = 0,7; c = 4200; m = 0,4; γ = 420; Q = 8,4; T1 = 100; T0 = 20 найдите T.

  1. Вычислите коэффициент: (0,7 · 4200 · 0,4) / 420 = 2,8.
  2. Получите 8,4 = 2,8 · log2(80/(T − 20)).
  3. Разделите на 2,8: log2(80/(T − 20)) = 3.
  4. Перейдите к степени: 80/(T − 20) = 8.
  5. T − 20 = 10; T = 30. Аргумент 80/10 = 8 > 0.

Для удобного счёта представляйте десятичные дроби через степени десяти и сокращайте одинаковые множители. Следите за смыслом и единицами величин.

04 / Интерпретация

Восстановление функции по точкам

Два неизвестных параметра — две узловые точки и система из двух уравнений.

f(x) = logax + b   (a > 0, a ≠ 1, x > 0)

Самая удобная узловая точка имеет абсциссу 1: loga1 = 0, поэтому f(1) = b. Ещё одна полезная точка — (a; b + 1).

ПРИМЕР 07

Даны A(1; −3) и B(4; −1)

По первой точке b = −3. По второй: −1 = loga4 − 3, то есть loga4 = 2. Следовательно, a² = 4, и по условию a > 0 берём a = 2.

f(x) = log2x − 3;
f(32) = 5 − 3 = 2
