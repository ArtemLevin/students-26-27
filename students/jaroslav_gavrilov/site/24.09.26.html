02

Не делить. Вынести.

Общий множитель

Сохраните нулевую ветвь

Если множитель может быть равен нулю, деление на него способно уничтожить часть решения. Вынесение сохраняет обе ветви.

Пример занятия

sin 2x + sin x = 0

Раскрываем двойной угол: 2 sin x cos x + sin x = 0.
Выносим общий множитель: sin x(2 cos x + 1) = 0.
Используем нулевое произведение: sin x = 0 или cos x = −1/2.
Получаем x = πk или x = ±2π/3 + 2πk, k ∈ Z.
Критическая ловушка. Из sin x(2 cos x + 1) = 0 нельзя сразу делить на sin x: ветвь sin x = 0 содержит реальные корни.
03

Два вынесения подряд.

Группировка

Создайте одинаковые скобки

Четыре слагаемых — полезный сигнал. Цель группировки состоит в том, чтобы после первого вынесения получить одинаковый множитель в двух группах.

AB + AC − DB − DC
= A(B + C) − D(B + C)
= (B + C)(A − D)
Знак минус перед второй группой меняет знаки внутри скобки и позволяет получить тот же множитель.
Двойное вынесение

2 sin x cos x + sin x − 2 cos x − 1 = 0

Группируем: (2 sin x cos x + sin x) + (−2 cos x − 1) = 0.
Выносим: sin x(2 cos x + 1) − (2 cos x + 1) = 0.
Повторяющаяся скобка становится общим множителем: (2 cos x + 1)(sin x − 1) = 0.
Решаем cos x = −1/2 или sin x = 1.

Откуда берётся единица? Второй множитель записан как −1 · (2 cos x + 1), поэтому после общего вынесения внутри остаётся −1.

04

Деление становится законным после обоснования.

Однородное уравнение первой степени

Оставьте одну функцию

Форма a sin x + b cos x = 0 позволяет перейти к тангенсу. Важный шаг — сначала доказать, что для корней cos x ≠ 0.

Распознавание

Только sin x, cos x и ноль; перед функциями допустимы коэффициенты.

Ограничение

Если a ≠ 0 и cos x = 0, то sin x = ±1, поэтому левая часть равна ±a ≠ 0.

Переход

Делим на cos x: a tg x + b = 0.

Ответ

tg x = −b/a, затем x = arctg(−b/a) + πk.

3 sin x − 2 cos x = 0
3 tg x − 2 = 0
tg x = 2/3
Ответ: x = arctg(2/3) + πk, k ∈ Z. Для тангенса период равен π.
05

Ищем сначала k, затем x.

Отбор корней

Переведите промежуток на язык k

Если общее решение уже получено, конкретный корень определяется целым параметром k. Значит, удобнее сначала найти допустимые k.

x = π/6 + πk, k ∈ Z

Пусть требуется выбрать корни из промежутка −π/3 ≤ x ≤ π/2.

Подставляем формулу вместо x: −π/3 ≤ π/6 + πk ≤ π/2.
Вычитаем π/6: −π/2 ≤ πk ≤ π/3.
Делим на π > 0: −1/2 ≤ k ≤ 1/3.
Из целых значений подходит только k = 0, значит x = π/6.
Зачем нужен k?

Параметр нумерует значения общего решения. При отборе корней мы выясняем, какие номера решений попадают в заданный промежуток.

06

Ошибки, которые меняют множество корней.

Контроль

Пять точек самопроверки

Деление без проверки

Нельзя делить на выражение, которое может быть равно нулю: можно потерять корни.

Знак при вынесении минуса

−(A − B) = −A + B. Группировка особенно чувствительна к знакам.

Неправильный период

Для tg x = a используется πk, а не 2πk.

Перебор x вместо k

При отборе сначала решите двойное неравенство относительно k.

Механическая эвристика

Четыре слагаемых лишь подсказывают группировку. Проверяйте, появляются ли одинаковые скобки.
