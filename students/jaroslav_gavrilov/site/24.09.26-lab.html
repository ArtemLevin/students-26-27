Отбор корней через k

Меняйте целый параметр k и наблюдайте, как меняется x в общей серии x = π/6 + πk. Цель — увидеть, почему при ограниченном промежутке сначала удобно искать допустимые k.

Исходные данные занятия x = π/6 + πk, k ∈ Z
−π/3 ≤ x ≤ π/2

Управление параметром

Выберите k

Параметр принимает только целые значения. Для каждого k лаборатория вычисляет соответствующий x и показывает его положение относительно заданного промежутка.

Почему метод работает

Промежуток превращается в фильтр

Подставьте формулу общего решения вместо x в обе границы промежутка.
Одинаковыми действиями преобразуйте левую, среднюю и правую части двойного неравенства.
Добейтесь, чтобы в центре осталось только k.
Возьмите только целые k, потому что k ∈ Z.
Подставьте каждое допустимое k обратно в формулу x.
