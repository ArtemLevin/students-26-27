01 / ОПРЕДЕЛЕНИЕ

От логарифма к степени

Логарифм — показатель степени, в которую нужно возвести основание, чтобы получить аргумент. Для определения логарифма основание должно быть положительным и отличаться от единицы, а аргумент — строго положительным.

logab=c
a>0,a≠1,b>0

Основное логарифмическое тождество:

alogab=b

При вычислении удобно представить число степенью того же основания:

log264=6

Степень степени также подчиняется правилам показателей:

(3log32)log23=3

02 / ФОРМУЛЫ

Узнавайте структуру

Все формулы применяйте с учётом области определения. Для разложения логарифма произведения и частного соответствующие множители должны быть положительными.

ФОРМУЛА 01

Свойство произведения

logauv=logau+logav
ФОРМУЛА 02

Свойство частного

logauv=logau−logav
ФОРМУЛА 03

Степень аргумента

logabk=klogab
ФОРМУЛА 04

Смена основания

logab=logcblogca
ФОРМУЛА 05

Взаимные логарифмы

logab=1logba
ФОРМУЛА 06

Частные значения

logaa=1,loga1=0

Степень разрешено выносить только из всего аргумента логарифма. При разложении частного сначала определите границы числителя и знаменателя.

03 / ОБРАЗЦЫ

Преобразования по шагам

Пример 1. Взаимные основания

Известно, что logba=17. Найдите логарифм произведения.

logaab3=logaa+logab3
1+31logba=22

Пример 2. Минус перед логарифмом

Известно, что logab=5. Вычислите:

−logab3a
−(3logab−1)=−14

При подстановке разности логарифмов внешние скобки обязательны; минус меняет знаки обоих слагаемых.

04 / ПРИЁМЫ

Два типа уравнений

Логарифм равен числу

По определению логарифма («циклопирование»):

logaF(x)=c
F(x)=ac

Логарифм равен логарифму

Только при одинаковом допустимом основании и соблюдении ОДЗ приравнивайте аргументы:

logaF(x)=logaG(x)
F(x)=G(x)

Примеры выбора корня

logx16=2

После возведения в квадрат остаётся x=4: отрицательное основание логарифма запрещено.

log−x16=2

Здесь основание −x положительно только при x<0; ответ x=−4.

Разные основания и внешнее слагаемое

log2x=log45
x=5
log2x=log25+1
x=10

Степень внутри аргумента

log828x−4=4
x=2

05 / АЛГОРИТМ

ОДЗ → корни → ответ

Рассмотрите составное уравнение:

log2x6=log12x+1

ШАГ 1 / 5

ОДЗ

x6>0,x+1>0

Общий вывод: x>0.

ШАГ 2 / 5

Смена основания

log12x+1=−log2x+1

Основание одна вторая меняем на два.

ШАГ 3 / 5

Сравнение аргументов

x6=1x+1

Используем одинаковые основания при выполненной ОДЗ.

ШАГ 4 / 5

Уравнение

x2+x−6=0

Получаем два кандидата: −3 и 2.

ШАГ 5 / 5

Отбор

x=2

Отрицательный кандидат нарушает ОДЗ; оставляем двойку.

Шаг 1 из 5

Проверка корней по ОДЗ

Выберите кандидат для проверки.

Поиск неизвестного компонента

A−B=C
B=A−C
AB=C
B=AC

При делении все указанные делители должны быть отличны от нуля. При ошибке старайтесь сохранять читаемой предыдущую строку.

06 / САМОПРОВЕРКА

Частые ошибки

  • Складывают аргументы вместо применения свойства произведения.
  • Пропускают условия существования исходных логарифмов.
  • Приравнивают аргументы при различных основаниях.
  • Путают степень аргумента и степень всего логарифма.
  • Забывают раскрыть скобки со знаком минус.
  • Путают слагаемое вне логарифма с частью его аргумента.
  • Не проверяют найденные корни по ОДЗ.

Пишите важные переходы последовательно: это помогает точно обнаруживать вычислительные ошибки.
